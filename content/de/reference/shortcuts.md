# Tastatur, Maus & Touch

EduBeam lässt sich mit Tastatur und Maus, mit einem Trackpad oder mit dem Finger bedienen. Diese Seite listet alle Tastenkürzel und Gesten auf. Auf einem Mac verwenden Sie <kbd>Cmd</kbd> überall dort, wo <kbd>Strg</kbd> steht; die Menüs der App zeigen dort ⌘ an.

## Tastatur {#keyboard}

Die Kürzel für die Zeichnung (<kbd>F</kbd>, <kbd>C</kbd>, <kbd>G</kbd>, <kbd>S</kbd>, <kbd>Entf</kbd> sowie <kbd>Strg</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>V</kbd>) sind wirkungslos, solange ein Textfeld den Fokus hat. Ein `f` oder `s`, das Sie in ein Feld tippen, löst sie also nie aus. Klicken Sie zuerst auf die Zeichnung.

### Dateien und Verlauf {#files-and-history}

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>Z</kbd> | Letzte Änderung am Modell rückgängig machen |
| <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>Z</kbd> | Wiederholen |
| <kbd>Strg</kbd>+<kbd>S</kbd> | Projekt speichern (lädt `project.json` herunter) |
| <kbd>Strg</kbd>+<kbd>O</kbd> | Projekt öffnen |
| <kbd>Strg</kbd>+<kbd>P</kbd> | Bild exportieren |

Auch das Löschen des Modells, das Öffnen einer Datei, eines Links oder eines Beispiels und das Wiederherstellen eines zuletzt verwendeten Modells lassen sich rückgängig machen. Solange Sie noch in einer Tabellenzelle tippen, nimmt <kbd>Strg</kbd>+<kbd>Z</kbd> das Getippte zurück; ist die Zelle bestätigt, macht es die Änderung am Modell rückgängig. In den Feldern eines Dialogs nimmt es immer das Getippte zurück.

### Zeichnung {#drawing}

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>A</kbd> | Alles auswählen |
| <kbd>Strg</kbd>+<kbd>C</kbd> | Ausgewählte Knoten, Elemente und Lasten kopieren |
| <kbd>Strg</kbd>+<kbd>V</kbd> | Einfügen. Ein Schattenbild der Kopie folgt dem Mauszeiger: Klicken Sie, um es zu platzieren, oder geben Sie im Banner einen Versatz Δx, Δz ein und drücken Sie **Einfügen** oder <kbd>Enter</kbd> |
| <kbd>Entf</kbd> | Auswahl löschen (auf einem Mac-Laptop <kbd>Fn</kbd>+<kbd>⌫</kbd>) |
| <kbd>Esc</kbd> | Den aktuellen Modus verlassen (Knoten, Elemente oder Bemaßungen hinzufügen, Einfügen, einen Bildausschnitt wählen) und die Auswahl aufheben; schließt auch das Menü ☰ und beendet den Rundgang |
| <kbd>F</kbd> | Inhalt an Bildschirm anpassen |
| <kbd>C</kbd> | Inhalt zentrieren |
| <kbd>G</kbd> | Raster ein/aus |
| <kbd>S</kbd> | Am Raster ausrichten ein/aus |
| <kbd>Strg</kbd>+<kbd>+</kbd> / <kbd>Strg</kbd>+<kbd>-</kbd> | Zeichnung um ihre Mitte vergrößern / verkleinern |

In EduBeam vergrößern und verkleinern <kbd>Strg</kbd>+<kbd>+</kbd> und <kbd>Strg</kbd>+<kbd>-</kbd> die Zeichnung, nie die ganze Oberfläche, wie sie es auf anderen Websites tun. Sie funktionieren mit jedem Tastaturlayout: mit den Tasten + und −, wo immer Ihr Layout sie hat (auf einer deutschen Tastatur rechts neben Ü und rechts neben dem Punkt), mit den beiden Tasten links der Rücktaste auf einer US-Tastatur und mit + und − auf dem Ziffernblock.

### Tabellen und Dialoge {#tables-and-dialogs}

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Enter</kbd> | In einer Tabellenzelle: den Wert bestätigen. In einem Textfeld eines Dialogs: den Dialog bestätigen, wie mit seiner Hauptschaltfläche |
| <kbd>Esc</kbd> | In einer Tabellenzelle: sie verlassen und den Wert behalten. In einem Dialog: ihn schließen, ohne zu speichern |
| <kbd>Tab</kbd> | Zum nächsten Feld wechseln; eine Tabellenzelle behält, was Sie eingegeben haben |

Zahlenfelder verstehen einfache Rechnungen, so wie Sie sie aufschreiben würden: `6/2`, `3*1,5`, `2^3`, `(4+2)/3` und `1e3`. Als Dezimaltrennzeichen dürfen Sie Komma oder Punkt verwenden.

## Maus {#mouse}

| Aktion | Ergebnis |
| --- | --- |
| Klick | Einen Knoten, ein Element, eine Last oder eine Bemaßungslinie auswählen und ihr Panel öffnen |
| Ziehen auf leerer Zeichenfläche | Auswahlrechteck |
| Einen Knoten ziehen | Ihn verschieben; bei eingeschaltetem Fangen rastet er am Raster ein |
| Klick beim Hinzufügen | Einen Knoten setzen oder einen Polygonzug aus Elementen beginnen oder fortsetzen |
| Doppelklick auf eine Last | Die Last bearbeiten (auch eine vorgegebene Verschiebung) |
| Rechtsklick | Menü der Zeichenfläche: Knoten hinzufügen, Element hinzufügen, Bemaßung hinzufügen, Element … bemaßen (über einem Element), Bearbeiten, Kopieren, Einfügen, Löschen |
| <kbd>Strg</kbd> + **Knoten hinzufügen** oder **Element hinzufügen** im Menü der Zeichenfläche | Mit der Maus platzieren statt einen Dialog zu öffnen |
| Ziehen mit mittlerer oder rechter Taste | Ansicht verschieben. Die Taste wählen Sie unter **Einstellungen → Steuerung & Tastenkürzel → Verschieben mit** |
| Mausrad | Zum Mauszeiger hin zoomen |
| Auf ein Objekt zeigen | Tooltip mit seinen Verschiebungen, Eigenschaften oder Lastwerten |

Auf einem Trackpad zoomen Sie, indem Sie zwei Finger auseinander- oder zusammenziehen oder mit zwei Fingern scrollen. Zum Verschieben klicken und ziehen Sie mit zwei Fingern; das entspricht einem Ziehen mit der rechten Taste.

## Touch {#touch}

| Geste | Ergebnis |
| --- | --- |
| Tippen | Ein Objekt auswählen und seine Details und Aktionen anzeigen |
| Tippen beim Hinzufügen | Einen Knoten setzen oder ein Element fortsetzen |
| Einen Knoten drücken und ziehen | Den Knoten verschieben |
| Ziehen mit einem Finger an anderer Stelle | Ansicht verschieben |
| Zwei Finger auseinander- oder zusammenziehen | Zoomen |
| Zeichenfläche gedrückt halten | Menü der Zeichenfläche |
| Schaltfläche **Rechteckauswahl** (oben rechts), dann ziehen | Auswahlrechteck; das Menü der Zeichenfläche mit Kopieren und Löschen öffnet sich dort, wo Sie den Finger abheben |

Während Sie Knoten, Elemente oder Bemaßungen hinzufügen, einfügen oder einen Bildausschnitt wählen, nennt ein Banner oben in der Zeichnung den Modus und bietet die Schaltfläche **Abbrechen**. Ohne <kbd>Esc</kbd>-Taste verlassen Sie den Modus auf einem Touchscreen auf diesem Weg.

## Objektpanels {#object-panels}

Ein Klick oder Tippen auf ein Objekt öffnet daneben ein Panel mit seinen Details und diesen Aktionen:

| Objekt | Aktionen |
| --- | --- |
| Knoten | Last hinzufügen · Knotenlagerung (Lagersymbol, Dx, Dz, Ry) · Knoten-LKS-Winkel · Verschiebung vorgeben (an einem gelagerten Knoten) · Löschen |
| Element | Element bearbeiten (Endknoten und Gelenke, Material, Querschnitt) · Last hinzufügen · Steifigkeitsmatrix · Löschen |
| Knoten- oder Elementlast | Last bearbeiten · Löschen |
| Bemaßungslinie | Bearbeiten · Bemaßung umkehren · Löschen |

Die Seite [Benutzeroberfläche](/de/essentials/user-interface) führt durch den Bildschirm, und unter [Steuerung & Tastenkürzel](/de/essentials/units-settings#controls-shortcuts) in den Einstellungen wählen Sie die Taste zum Verschieben.
