# 키보드, 마우스 및 터치

EduBeam은 키보드와 마우스, 트랙패드, 손가락으로 모두 조작할 수 있습니다. 이 페이지에는 모든 단축키와 제스처를 정리했습니다. Mac에서는 <kbd>Ctrl</kbd> 대신 <kbd>Cmd</kbd>를 쓰세요. 앱의 메뉴에도 그 자리에 ⌘가 표시됩니다.

## 키보드 {#keyboard}

그리기 단축키(<kbd>F</kbd>, <kbd>C</kbd>, <kbd>G</kbd>, <kbd>S</kbd>, <kbd>Delete</kbd>와 <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>V</kbd>)는 입력란에 포커스가 있는 동안 작동하지 않습니다. 그래서 입력란에 `f`나 `s`를 입력해도 단축키가 실행되지 않습니다. 먼저 그림을 클릭하세요.

### 파일과 실행 취소 {#files-and-history}

| 단축키 | 동작 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 모델의 마지막 변경 실행 취소 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 다시 실행 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 프로젝트 저장(`project.json` 다운로드) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 프로젝트 열기 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 이미지 내보내기 |

실행 취소로 모델 지우기, 파일·링크·예제 열기, 최근 구조물 복원도 되돌릴 수 있습니다. 표의 셀에 아직 입력하는 중이면 <kbd>Ctrl</kbd>+<kbd>Z</kbd>는 입력한 내용을 되돌리고, 셀 값을 확정한 뒤에는 모델의 변경을 되돌립니다. 대화 상자의 입력란에서는 언제나 입력한 내용을 되돌립니다.

### 그리기 {#drawing}

| 단축키 | 동작 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 모두 선택 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 선택한 절점, 요소, 하중 복사 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 붙여넣기. 사본의 윤곽이 포인터를 따라다니며, 클릭해 배치하거나 배너에 오프셋 Δx, Δz를 입력하고 **붙여넣기** 또는 <kbd>Enter</kbd>를 누름 |
| <kbd>Delete</kbd> | 선택 항목 삭제(Mac 노트북에서는 <kbd>Fn</kbd>+<kbd>Delete</kbd>) |
| <kbd>Esc</kbd> | 현재 모드(절점·요소·치수 추가, 붙여넣기, 이미지 영역 선택)에서 나가고 선택 해제. ☰ 메뉴를 닫고 둘러보기도 끝냄 |
| <kbd>F</kbd> | 화면에 맞추기 |
| <kbd>C</kbd> | 가운데 맞춤 |
| <kbd>G</kbd> | 그리드 켜기/끄기 |
| <kbd>S</kbd> | 그리드 스냅 켜기/끄기 |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 그림을 중심 기준으로 확대 / 축소 |

EduBeam에서 <kbd>Ctrl</kbd>+<kbd>+</kbd>와 <kbd>Ctrl</kbd>+<kbd>-</kbd>는 다른 사이트에서처럼 인터페이스 전체가 아니라 그림만 확대/축소합니다. 어떤 키보드 배열에서든 작동합니다. +와 −가 표시된 키라면 배열의 어디에 있든 쓸 수 있습니다. US 키보드에서는 <kbd>Backspace</kbd> 왼쪽의 두 키이며, 숫자 키패드의 +와 −도 됩니다.

### 표와 대화 상자 {#tables-and-dialogs}

| 단축키 | 동작 |
| --- | --- |
| <kbd>Enter</kbd> | 표의 셀에서: 값 확정. 대화 상자의 입력란에서: 주 버튼처럼 대화 상자 확정 |
| <kbd>Esc</kbd> | 표의 셀에서: 값을 유지한 채 셀에서 나감. 대화 상자에서: 저장하지 않고 닫기 |
| <kbd>Tab</kbd> | 다음 입력란으로 이동. 표의 셀은 입력한 값을 유지 |

숫자 입력란에는 손으로 계산하듯 산술식을 입력할 수 있습니다. `6/2`, `3*1.5`, `2^3`, `(4+2)/3`, `1e3`, 그리고 소수점 대신 쉼표도 받습니다.

## 마우스 {#mouse}

| 동작 | 결과 |
| --- | --- |
| 클릭 | 절점, 요소, 하중, 치수선을 선택하고 패널 열기 |
| 빈 캔버스에서 드래그 | 선택 사각형 |
| 절점 드래그 | 절점 이동. 스냅이 켜져 있으면 그리드에 맞춰짐 |
| 추가 모드에서 클릭 | 절점 배치, 또는 요소 폴리라인 시작이나 이어 그리기 |
| 하중 더블클릭 | 하중 편집(강제변위도 포함) |
| 마우스 오른쪽 버튼 클릭 | 캔버스 메뉴: 절점 추가, 요소 추가, 치수 추가, 요소에 치수 추가(요소 위에서), 편집, 복사, 붙여넣기, 삭제 |
| 캔버스 메뉴에서 <kbd>Ctrl</kbd> + **절점 추가** 또는 **요소 추가** | 대화 상자 대신 마우스로 배치 |
| 가운데 또는 오른쪽 버튼 드래그 | 화면 이동. 버튼은 **설정 → 조작 및 단축키 → 화면 이동 버튼**에서 선택 |
| 휠 | 포인터 쪽으로 확대/축소 |
| 객체에 포인터 올리기 | 변위, 속성, 하중 값을 보여 주는 툴팁 |

트랙패드에서는 두 손가락 벌리기/모으기와 두 손가락 스크롤 모두 확대/축소입니다. 화면을 이동하려면 두 손가락으로 클릭한 채 드래그합니다. 트랙패드에서는 이것이 오른쪽 버튼 드래그입니다.

## 터치 {#touch}

| 제스처 | 결과 |
| --- | --- |
| 탭 | 객체를 선택하고 세부 정보와 가능한 작업 표시 |
| 추가 모드에서 탭 | 절점 배치 또는 요소 이어 그리기 |
| 절점을 누른 채 드래그 | 절점 이동 |
| 다른 곳에서 한 손가락 드래그 | 화면 이동 |
| 두 손가락 벌리기/모으기 | 확대/축소 |
| 캔버스를 길게 누르기 | 캔버스 메뉴 |
| **영역 선택** 버튼(오른쪽 위)을 누른 뒤 드래그 | 선택 사각형. 손가락을 떼는 곳에 복사와 삭제가 있는 캔버스 메뉴가 열림 |

절점, 요소, 치수를 추가하거나 붙여넣거나 이미지 영역을 고르는 동안에는 그림 위쪽의 배너에 현재 모드와 **취소** 버튼이 표시됩니다. <kbd>Esc</kbd> 키가 없는 터치스크린에서는 이 버튼으로 모드에서 나갑니다.

## 객체 패널 {#object-panels}

객체를 클릭하거나 탭하면 그 옆에 세부 정보와 다음 작업이 있는 패널이 열립니다.

| 객체 | 작업 |
| --- | --- |
| 절점 | 하중 추가 · 지지조건(지점 기호, Dx, Dz, Ry) · 절점 좌표계 각도 · 강제변위 지정(지점이 있는 절점) · 삭제 |
| 요소 | 요소 편집(양 끝 절점과 힌지, 재료, 단면) · 하중 추가 · 강성 행렬 · 삭제 |
| 절점하중 또는 요소하중 | 하중 편집 · 삭제 |
| 치수선 | 편집 · 치수 뒤집기 · 삭제 |

화면 구성은 [사용자 인터페이스](/ko/essentials/user-interface)에서 둘러볼 수 있고, 화면 이동 버튼은 설정의 [조작 및 단축키](/ko/essentials/units-settings#controls-shortcuts)에서 고릅니다.
