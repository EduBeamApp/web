# 문제 해결

모델을 해석할 수 없으면 [EduBeam]{.edubeam}이 뷰어 왼쪽 위의 메시지로 이유를 알려 주며, **자세히 보기**를 누르면 모든 문제가 자세히 나열됩니다. 화면에 나온 대화 상자의 제목을 아래에서 고르세요. 각 메시지의 의미와 해결 방법을 설명합니다.

::card-grid{cols="2"}
:::card{title="아직 해석할 수 없습니다" icon="lucide:circle-dashed" to="#still-needed"}
파란색 **지점 필요** 칩. 잘못된 것은 없고, 구조물을 아직 지지하지 않았을 뿐입니다.
:::
:::card{title="모델을 해석할 수 없습니다" icon="lucide:circle-x" to="#errors"}
빨간색 메시지. 구조물을 고정하지 못하는 지점, 메커니즘을 만드는 힌지, 길이가 0인 요소.
:::
:::card{title="모델 경고" icon="lucide:triangle-alert" to="#warnings"}
노란색 메시지. 모델은 해석되었지만, 무언가가 의도와 다를 가능성이 큽니다.
:::
:::card{title="결과가 이상해 보일 때" icon="lucide:scale" to="#results-look-wrong"}
위로 작용하는 하중, 10의 거듭제곱만큼 어긋난 처짐, 뒤집힌 것 같은 부호.
:::
::

## 메시지 {#messages}

### 색의 의미 {#read-the-message}

| 보이는 것 | 의미 |
| --- | --- |
| 파란색 **지점 필요** 칩 | 모델이 아직 완성되지 않았습니다. 지점을 추가하세요. 칩에 포인터를 올리면 구조물이 아직 어떻게 움직일 수 있는지 점선 윤곽으로 보여 줍니다. |
| **빨간색** 메시지 | 무언가가 해석을 막고 있습니다. 메시지가 문제를 알려 주며, 문제가 여러 개면 *모델 오류: n*으로 표시됩니다. 관련된 절점은 그림에 원으로 표시됩니다. |
| **노란색** 메시지 | 경고입니다. 모델은 그래도 해석되었습니다. 경고가 여러 개면 *모델 경고: n*으로 표시됩니다. |
| *정의된 재료가 없습니다.* / *정의된 단면이 없습니다.* | 요소에는 둘 다 필요합니다. 메시지 옆의 **새로 추가** 버튼으로 추가하세요. |

**자세히 보기**를 누르면 *아직 해석할 수 없습니다*, *모델을 해석할 수 없습니다*, *모델 경고* 중 하나를 제목으로 하는 대화 상자가 열립니다. 대화 상자의 스위치로 구조물이 어떻게 움직일 수 있는지 보여 주거나 숨길 수 있으며, **문제 해결** 링크를 누르면 이 페이지로 옵니다.

![모델을 해석할 수 없습니다 대화 상자와 구조물의 움직임을 보여 주는 스위치](/screenshots/ko/ui-diagnostics.webp){.shot-lg}

그림 위에서는 다음과 같이 조작합니다.

- 빨간색 메시지의 **✕** 버튼을 누르면 메시지가 작은 *모델을 해석할 수 없습니다* 칩으로 접혀 작은 화면에서 공간을 확보합니다. 칩을 클릭하면 다시 펼쳐집니다.
- 빨간색 메시지의 **눈** 버튼은 움직임을 나타내는 점선 윤곽을 보여 주거나 숨깁니다. **설정 → 뷰어 설정 → 모델 검사**에서 윤곽과 그 애니메이션을 아예 끌 수 있습니다.
- 노란색 메시지의 **✕** 버튼을 누르면 경고가 숨겨집니다.

### 아직 필요한 항목 {#still-needed}

모델이 틀린 것이 아니라 아직 완성되지 않았을 뿐입니다. 칩에 포인터를 올리면 짧은 메시지가, 대화 상자에는 긴 메시지가 나옵니다.

| 메시지 | 의미와 해결 방법 |
| --- | --- |
| *구조물을 해석하려면 먼저 지점이 필요합니다.* <br> *2D 해석에서 안정하려면 모델에 구속된 자유도가 3개 이상 필요합니다.* | 구속된 방향이 모두 합쳐 3개 미만입니다. 지점을 추가하세요. |
| *구조물의 일부(절점 …)에 지점이 필요합니다.* <br> *구조물의 분리된 부분(절점 …)은 구속된 자유도가 3개 미만이어서 자유롭게 움직일 수 있습니다.* | 모델이 여러 조각으로 나뉘어 있고 그중 한 조각이 떠 있습니다. 나머지와 연결하거나 지점을 주세요. |
| *구조물 중 n개 부분에 지점이 필요합니다.* | 여러 조각이 떠 있습니다. **자세히 보기**에 모두 나열됩니다. |

### 오류 {#errors}

무언가가 해석을 막고 있습니다. 빨간색 메시지에는 짧은 메시지가, 대화 상자에는 긴 메시지가 나옵니다.

| 메시지 | 의미와 해결 방법 |
| --- | --- |
| *지점이 구조물을 고정하지 못해 구조물이 여전히 수평으로 미끄러질 / 연직으로 움직일 / 자유롭게 회전할 / 강체로 움직일 수 있습니다.* <br> *지점 수는 충분하지만 구조물을 고정하지 못해 여전히 … 수 있습니다.* | 구속의 수는 충분하지만 수평 보 아래의 롤러 지점 세 개처럼 모두 평행하거나, 작용선이 한 점에서 만나는 경우입니다. 점선 윤곽이 움직임을 보여 줍니다. 지점 하나의 방향을 바꾸거나 위치를 옮기세요. |
| *구조물의 일부(절점 …)가 고정되지 않아 여전히 … 수 있습니다.* <br> *구조물의 분리된 부분(절점 …)은 지점 수는 충분하지만 고정되지 않아 여전히 … 수 있습니다.* | 위와 같은 경우이며, 여러 조각으로 나뉜 모델의 한 조각에 해당합니다. |
| *절점 …의 힌지 때문에 구조물이 움직일 수 있습니다.* <br> *지점은 구조물을 고정하지만, 구조물은 여전히 메커니즘입니다. 절점 …의 힌지를 중심으로 부재가 회전할 수 있습니다.* | 힌지 때문에 부재끼리 서로 회전할 수 있습니다. 두 기둥 하단이 힌지 지점이고 각 기둥 상단에 힌지가 있는 라멘이나, 사재 없이 핀 접합된 사각형이 그 예입니다. 힌지를 제거하거나 부재나 지점을 추가하세요. |
| *구조물이 불안정합니다. 거의 저항 없이 움직입니다.* <br> *구조물이 불안정합니다. 다음 자유도가 거의 저항 없이 움직입니다: 절점 …의 수평 방향(Dx) …* | 거의 메커니즘이거나 강성이 0에 가깝습니다. 긴 메시지에 절점과 방향이 나옵니다. 지점, 힌지, 그리고 `E`, `A`, `Iy` 값을 확인하세요. |
| *구조물이 메커니즘입니다. 저항 없이 움직일 수 있습니다.* <br> *구조물이 메커니즘입니다. 강성 행렬이 특이 행렬입니다.* | 위의 검사에서 잡히지 않은 무언가가 자유롭게 움직일 수 있습니다. 모든 부분이 3개 이상의 구속으로 고정되어 있는지, 단부 힌지 때문에 부재가 자유롭게 회전하지 않는지 확인하세요. |
| *요소 …의 길이가 0입니다. 절점 …와(과) …이(가) 같은 위치에 있습니다.* | 한 요소의 두 절점이 겹쳐 있습니다. 절점 하나를 옮기거나 요소를 삭제하세요. |
| *요소 …의 양 끝이 같은 절점을 참조합니다.* | 요소를 삭제하고 서로 다른 두 절점 사이에 다시 그리세요. |
| *요소 …에서 참조하는 절점 / 재료 / 단면 …이(가) 없습니다.* | 요소가 쓰던 객체가 삭제되었습니다. 대개 손으로 편집한 프로젝트 파일에서 생깁니다. *요소* 표에서 다시 지정하세요. |
| *요소 …은(는) 정확히 2개의 절점을 참조해야 합니다.* | 가져온 파일의 요소가 손상되었습니다. 삭제하고 다시 그리세요. |
| *절점하중 #n에서 참조하는 절점 …이(가) 없습니다.* <br> *강제변위 #n에서 참조하는 절점 …이(가) 없습니다.* | 하중을 삭제하거나 존재하는 절점을 지정하세요. |
| *요소하중 #n에서 참조하는 요소 …이(가) 없습니다.* | 하중을 삭제하세요. |
| *모델 내부의 불일치로 해석에 실패했습니다.* | 일반적인 오류입니다. 마지막 단계를 실행 취소하거나, 프로젝트를 저장해 [신고해 주세요](#reporting-a-bug). |

### 경고 {#warnings}

모델은 그래도 해석되지만 다음을 확인하세요.

| 메시지 | 의미와 해결 방법 |
| --- | --- |
| *절점 …은(는) 어떤 요소에도 연결되어 있지 않아 해석에서 무시됩니다.* | 홀로 떨어진 절점입니다. 삭제하거나 연결하세요. |
| *절점 …에 지점이 있지만 연결된 요소가 없어 지점이 아무것도 지지하지 않습니다.* | 홀로 떨어진 절점에 지점이 있습니다. |
| *절점하중 #n에 잘못된 값이 있습니다.* <br> *강제변위 #n에 잘못된 값이 있습니다.* | 숫자가 아닌 성분이 있습니다. 하중을 편집하세요. |

### 편집 중에 나오는 메시지 {#while-editing}

작업하는 동안 브라우저 대화 상자로 나타나며, 모델은 바뀌지 않습니다.

| 메시지 | 의미와 해결 방법 |
| --- | --- |
| *먼저 재료를 추가하세요.* <br> *먼저 단면을 추가하세요.* | 요소에는 둘 다 필요합니다. *재료* 탭이나 *단면* 탭에서 추가한 뒤 요소를 다시 그리세요. |
| *재료와 단면을 선택하세요.* | **요소 추가** 대화 상자에 빈 입력란이 있습니다. 둘 다 고르세요. |
| *이름 …은(는) 이미 사용 중입니다.* | 절점, 요소, 재료, 단면은 서로 같은 이름을 쓸 수 없습니다. 다른 이름을 고르세요. |
| *이 절점에는 이미 강제변위가 있습니다. 먼저 삭제하세요.* | 절점 하나에는 강제변위를 하나만 줄 수 있습니다. 있는 강제변위를 편집하거나 먼저 삭제하세요. |

## 아무것도 그려지지 않을 때 {#no-results-are-drawn}

다이어그램이 나타나지 않으면 다음 순서로 확인하세요.

::div{.steps}

### 표시 옵션 확인 {#check-the-display-options}

메시지가 전혀 없으면 모델은 해석된 것이고, 다이어그램이 꺼져 있을 뿐일 수 있습니다. 뷰어 오른쪽 위의 표시 옵션에서 **M<sub>y</sub>(x)** 또는 다른 결과를 체크하세요. 패널이 안 보이면 그 위의 ⚙ 버튼을 누릅니다. 하중이 전혀 없는 모델은 모든 결과가 0이므로 역시 그릴 것이 없습니다.

### 지점 확인 {#check-the-supports}

솔버에는 구속된 방향이 3개 이상 필요하고, 지점 전체가 함께 구조물의 미끄러짐과 회전을 막아야 합니다. 롤러 지점 두 개 위의 보는 구속이 두 개뿐이어서 미끄러져 버립니다. 그중 하나를 **힌지** 지점으로 바꾸세요. 평행한 롤러 지점 세 개나, 작용선이 한 점에서 만나는 지점도 구조물을 고정하지 못합니다. [절점 및 지점](/ko/essentials/nodes-supports#supports)을 참고하세요.

### 요소 연결 확인 {#check-the-connections}

같은 좌표에 있는 두 절점도 여전히 별개의 절점이며, 그곳에서만 나머지와 닿아 있는 부분은 떠 있게 됩니다. 중복된 절점을 삭제하고 다시 연결하세요. 요소 위에 절점을 배치할 때 **구조물에 연결**을 고르면 요소가 그곳에서 나뉩니다.

### 힌지 개수 세기 {#count-the-hinges}

두 기둥 하단이 힌지 지점이고 각 기둥 상단에 힌지가 있는 라멘이나, 사재 없이 핀 접합된 부재로 된 사각형은 메커니즘입니다. EduBeam은 해당 힌지에 원을 표시하고 점선 윤곽으로 움직임을 보여 줍니다. [단부 힌지](/ko/essentials/elements#end-hinges)를 참고하세요.

### 강성이 0인지 확인 {#look-for-zero-stiffness}

`E`, `A`, `Iy`를 0이나 잘못된 단위로 입력하면 구조물의 일부가 거의 저항 없이 움직이게 됩니다. EduBeam은 이를 *불안정*으로 알려 줍니다.

::

## 결과가 이상해 보일 때 {#results-look-wrong}

| 증상 | 가능한 원인 |
| --- | --- |
| 하중이 위로 작용함 | 전체 **z축은 아래를 향하므로** 양의 `Fz`나 `fz`는 아래로, 음수 값은 위로 작용합니다. y 위 좌표축에서는 반대입니다. [하중](/ko/essentials/loads#sign-convention-in-one-line)을 참고하세요. |
| 처짐이 10의 거듭제곱만큼 어긋남 | 단위 혼동입니다. 입력란이 MPa를 기대하는데 `E`를 Pa로 입력했거나, m⁴를 기대하는데 `Iy`를 cm⁴로 입력한 경우입니다. 뷰어 오른쪽 아래의 단위 칩에 모든 입력란의 단위가 나옵니다. |
| 처짐이 교과서 공식보다 약간 큼 | Timoshenko 보의 전단 변형 때문입니다. [손 계산으로 결과 검증](/ko/guide/verification#shear-deformation)을 참고하세요. |
| 부호가 틀려 보임 | 부호는 다이어그램이 그려진 쪽이 아니라 값에서 읽으세요. 양의 M은 정모멘트입니다. *요소 결과*의 단부력은 N-V-M 부호 규약이 아니라 요소의 국부 좌표축을 따릅니다. [부호 읽기](/ko/essentials/results#reading-the-sign)를 참고하세요. |
| 다이어그램이 “반대쪽”에 그려짐 | 그리는 쪽은 표시 설정입니다. 휨모멘트는 인장 측 또는 압축 측에, N과 V는 점선의 어느 쪽에든 그릴 수 있습니다. **설정 → 뷰어 설정 → 단면력도**에서 바꿉니다. |
| 똑같은 두 기둥의 전단력 부호가 반대 | V의 부호는 각 요소의 방향을 따릅니다. 비교하려면 한 기둥의 절점을 교환하세요. |
| `4 · 10¹` 같은 숫자 | 과학적 표기 형식입니다. **설정 → 언어 및 지역 → 숫자 형식**에서 *자동*을 고르세요. |
| 다이어그램이 너무 크거나 작음 | 그림만의 문제입니다. **설정 → 뷰어 설정**에서 **결과 배율**을 조정하세요. |
| 국부 좌표계 하중이 엉뚱한 방향을 향함 | 요소의 국부 x축은 *시작* 절점에서 *끝* 절점으로 향합니다. 절점을 교환하거나 부호를 뒤집으세요. |
| 경사 부재의 하중이 이상함 | **LCS**가 기본으로 체크되어 있어 `fz`가 부재에 수직으로 작용합니다. 연직 하중을 주려면 체크를 해제하세요. |
| 온도하중이 아무 효과가 없음 | 정정 구조물은 온도가 변해도 부재력 없이 자유롭게 변형됩니다. 변형을 보려면 α가 0이 아닌지, 온도구배라면 단면 높이 $h$가 설정되어 있는지 확인하세요. |

## 파일과 링크 {#files-and-links}

| 증상 | 해결 방법 |
| --- | --- |
| *파일을 가져올 수 없습니다. 파일 형식을 확인하세요.* | EduBeam 프로젝트도, 데스크톱 EduBeam 세션도 아닌 파일입니다. 모델은 바뀌지 않았습니다. |
| *이 EduBeam 세션에는 하중조건이 여러 개 있지만 한 번에 하나만 열 수 있습니다.* | 하중조건이 여러 개인 데스크톱 EduBeam 세션입니다. EduBeam은 첫 번째 하중조건을 열고, 열지 않은 하중조건을 알려 줍니다. |
| 공유 링크를 열었는데 이전 모델이 그대로 열림 | 이메일 프로그램이 줄을 바꾸는 등의 이유로 링크가 잘리거나 바뀌었습니다. EduBeam은 읽을 수 없는 링크를 무시하고 모델을 그대로 둡니다. 링크 전체를 다시 복사하세요. |
| 동료가 짧은 링크를 열 수 없음 | 동료의 EduBeam이 1.3.2보다 오래된 버전입니다. 앱을 새로 고치게 하거나, **짧은 링크**를 끄고 공유하세요. [링크 공유](/ko/essentials/import-export#share-a-link)를 참고하세요. |

## 인터페이스 문제 {#interface-issues}

| 증상 | 해결 방법 |
| --- | --- |
| 단축키가 작동하지 않음 | 먼저 그림을 클릭하세요. 입력란에 포커스가 있으면 한 글자 단축키는 무시됩니다. Mac에서는 <kbd>Ctrl</kbd> 대신 <kbd>Cmd</kbd>를 쓰세요. [키보드, 마우스 및 터치](/ko/reference/shortcuts)를 참고하세요. |
| Mac에서 <kbd>Delete</kbd>가 작동하지 않음 | Mac 키보드에서 *delete*라고 적힌 키는 Backspace입니다. <kbd>Fn</kbd>+<kbd>Delete</kbd>를 누르세요. |
| 화면을 이동할 수 없음 | 화면 이동에는 마우스 가운데 또는 오른쪽 버튼을 씁니다. 어느 버튼을 쓸지는 **설정 → 조작 및 단축키**에서 고릅니다. 트랙패드에서는 두 손가락으로 클릭한 채 드래그하고, 터치스크린에서는 한 손가락으로 드래그합니다. |
| 모델이 사라짐 | 링크, 파일, 예제를 열거나 구조물을 지워도 이전 모델은 보관됩니다. **☰ → 최근 구조물**을 보거나 <kbd>Ctrl</kbd>+<kbd>Z</kbd>를 누르세요. 링크를 열면 화면 아래에 **보기** 버튼과 함께 다음 메시지가 나타납니다: *공유된 구조물을 열었습니다. 이전 구조물은 최근 구조물에 보관되어 있습니다.* |
| 언어가 다름 | **설정 → 언어 및 지역**에서 바꾸거나, 주소에 `?lang=ko`를 붙이세요. |
| 설정 변경이 유지되지 않음 | 시크릿 창이나 엄격한 개인 정보 보호 모드 등에서 로컬 스토리지가 차단되었습니다. 설정, 저장된 모델, 최근 구조물에는 모두 로컬 스토리지가 필요합니다. |

## 버그 신고 {#reporting-a-bug}

브라우저와 운영체제, 무엇을 했고 무엇을 기대했는지를 적어 [GitHub 이슈](https://github.com/janvorisek/edubeam/issues)를 등록해 주세요. 무엇보다 도움이 되는 것은 문제를 보여 주는 **공유 링크**나 **프로젝트 파일**입니다.
