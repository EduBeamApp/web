# 사용자 인터페이스

[EduBeam]{.edubeam} 화면은 세 영역으로 나뉩니다. 위쪽의 **앱 바**, 가운데에서 모델을 그리는 **뷰어**, 그리고 객체 종류마다 표가 하나씩 있는 **하단 바**입니다. 뷰어에서 할 수 있는 일은 모두 표에서도 할 수 있고, 그 반대도 마찬가지입니다.

![인터페이스의 각 부분, 번호는 아래 목록과 같습니다](/screenshots/ko/ui-overview.webp)

1. **☰ 메뉴**: 열기, 저장, 공유, 내보내기, 예제와 안내 투어.
2. **구조물 지우기**와 **모델 공유**.
3. **실행 취소**와 **다시 실행**.
4. **뷰어 버튼**: 가운데 맞춤, 화면에 맞추기, 표시 옵션.
5. **표시 옵션**: 어떤 결과와 모델의 어느 부분을 그릴지 선택.
6. **그리드, 스냅, 십자선, 단위.**
7. **하단 바 탭**: 절점, 요소, 하중, 재료, 단면, 결과.
8. 열린 탭의 **표**: 모든 값을 여기서 편집할 수 있습니다.

::callout{type="tip" title="둘러보기"}
**☰ → 둘러보기**를 선택하면 앱 안에서 이 부분을 하나씩 짚어 줍니다.
::

## 앱 바 {#app-bar}

- **☰** 버튼은 아래에서 설명하는 메인 메뉴를 엽니다.
- **구조물 지우기**는 확인을 거친 뒤 모든 절점, 요소, 하중을 삭제합니다. **재료 삭제**나 **단면 삭제**를 체크하면 재료와 단면도 함께 지웁니다. <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 모델을 되돌릴 수 있고, 지운 모델은 *최근 구조물*에도 보관됩니다.
- **모델 공유**는 모델 전체가 담긴 링크를 보여 주는 [공유 대화 상자](/ko/essentials/import-export#share-a-link)를 엽니다.
- **새로운 기능**은 릴리스 노트를 보여 줍니다. 업데이트 후에는 한 번 저절로 열리기도 합니다.
- **사용 설명서**는 이 사용 설명서를, GitHub 아이콘은 소스 코드를 엽니다.

휴대폰에서는 ☰와 **사용 설명서**만 앱 바에 들어가므로 **구조물 지우기**와 **모델 공유**는 메뉴 안에 있습니다.

### ☰ 메뉴 {#the-☰-menu}

![☰ 메뉴](/screenshots/ko/ui-app-menu.webp){.shot-xs}

- **프로젝트 열기**와 **프로젝트 저장**은 `project.json` 파일을 열거나 내려받습니다(<kbd>Ctrl</kbd>+<kbd>O</kbd>, <kbd>Ctrl</kbd>+<kbd>S</kbd>).
- **최근 구조물**에는 지우거나 다른 모델로 바꾼 최근 모델 10개가 남아 있어 바로 복원할 수 있습니다.
- **이미지 내보내기**는 그림을 PNG나 SVG로 저장하거나 복사합니다(<kbd>Ctrl</kbd>+<kbd>P</kbd>).
- **예제**는 미리 만들어 둔 모델 모음이고, **첫 번째 보 그리기**는 7단계로 안내하는 과제, **둘러보기**는 인터페이스 투어입니다.
- **모델 공유**와 **구조물 지우기**는 앱 바의 버튼과 같습니다.

메뉴 맨 아래에는 앱 버전과 출시일이 표시됩니다. 열기, 저장, 공유, 내보내기는 [파일, 링크 및 내보내기](/ko/essentials/import-export)에서 설명합니다.

## 뷰어 {#viewer}

뷰어의 캔버스에서 모델을 그리고 살펴봅니다. 모델을 바꿀 때마다 EduBeam이 결과를 다시 계산하므로 *해석* 버튼은 따로 없습니다.

### 캔버스의 버튼 {#buttons-on-the-canvas}

**왼쪽 위: 실행 취소와 다시 실행.** 추가, 편집, 드래그, 삭제, 지우기 등 모델의 모든 변경을 한 단계씩 되돌리거나 다시 적용합니다(<kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>).

**오른쪽 위:**

- **영역 선택**은 터치스크린 기기에서 나타납니다. 이 버튼을 누른 뒤 손가락으로 드래그하면 사각형 영역을 선택합니다.
- **가운데 맞춤**은 확대 배율을 바꾸지 않고 모델을 가운데로 옮기고(<kbd>C</kbd>), **화면에 맞추기**는 모델 전체가 화면에 들어오도록 확대하거나 축소합니다(<kbd>F</kbd>).
- **⚙** 버튼은 [표시 옵션](#display-options)을 보이거나 숨깁니다.

**오른쪽 아래:**

![그리드, 스냅, 십자선, 단위 버튼](/screenshots/ko/ui-grid-units.webp){.shot-sm}

- **G**는 그리드와 눈금자를 보이거나 숨기고(<kbd>G</kbd>), **S**는 그리드 스냅을 켜고 끕니다(<kbd>S</kbd>).
- **십자선** 버튼은 포인터 위치를 눈금자에 표시합니다. 마우스를 쓸 때만 동작합니다.
- **단위 칩**은 설정의 [언어 및 지역](/ko/essentials/units-settings#language-locale)을 엽니다.

### 표시 옵션 {#display-options}

⚙ 버튼을 누르면 체크박스가 두 줄로 나타납니다. 첫째 줄에서는 모델 위에 그릴 결과로 *변형 형상*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *반력*을 고르며, 처음에는 변형 형상, 휨모멘트, 반력이 켜져 있습니다. 둘째 줄에서는 *지점*, *하중*, *절점 이름*, *요소 이름*을 보이거나 숨기며, 처음에는 모두 켜져 있습니다.

![뷰어 버튼과 표시 옵션](/screenshots/ko/ui-display-settings.webp){.shot-lg}

**설정 더 보기**는 [뷰어 설정](/ko/essentials/units-settings#viewer-settings)을 엽니다. 크기, 색상, 다이어그램을 그리는 방식을 여기서 바꿉니다. 각 결과가 무엇을 보여 주는지는 [결과 및 다이어그램](/ko/essentials/results#overlays-in-the-viewer)에서 설명합니다.

### 화면 이동 {#navigating}

| 동작 | 마우스와 키보드 | 터치 |
| --- | --- | --- |
| 확대/축소 | 마우스 휠(포인터 쪽으로). 트랙패드에서는 두 손가락 벌리기/모으기 또는 두 손가락 스크롤 | 두 손가락 벌리기/모으기 |
| 화면 이동 | 오른쪽 버튼이나 휠을 누른 채 드래그. 어느 쪽을 쓸지는 [조작 및 단축키](/ko/essentials/units-settings#controls-shortcuts)에서 고릅니다 | 한 손가락으로 드래그 |
| 화면에 맞추기, 가운데 맞춤 | <kbd>F</kbd>, <kbd>C</kbd> 또는 오른쪽 위 버튼 | 오른쪽 위 버튼 |

<kbd>Ctrl</kbd>+<kbd>+</kbd>와 <kbd>Ctrl</kbd>+<kbd>-</kbd>는 키보드 배열과 관계없이 그림을 중심 기준으로 확대하고 축소합니다. 브라우저 자체의 확대/축소와 달리 인터페이스 전체의 크기는 바꾸지 않습니다.

### 선택과 편집 {#selecting-and-editing}

| 하려는 일 | 방법 |
| --- | --- |
| 객체 하나 선택 | 절점, 요소, 하중, 치수선을 클릭합니다. 그 옆에 패널이 열리고 하중 추가, 지점 설정, 편집, 강성 행렬 보기, 삭제 같은 작업이 나타납니다. 하단 바도 해당 탭으로 바뀝니다. |
| 여러 개 선택 | 빈 캔버스에서 사각형을 드래그합니다(터치스크린에서는 먼저 **영역 선택**을 누릅니다). 사각형 안의 절점과 사각형에 걸친 요소가 모두 선택되고, 그 하중과 치수선도 함께 선택됩니다. <kbd>Ctrl</kbd>+<kbd>A</kbd>는 전체를 선택합니다. |
| 삭제, 복사, 붙여넣기 | <kbd>Delete</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd>. 붙여 넣은 객체는 클릭할 때까지 포인터를 따라다니며, 배너에 이동량 Δx, Δz를 입력해 놓을 수도 있습니다. |
| 절점 이동 | 절점을 드래그합니다. 스냅이 켜져 있으면 그리드에 맞춰지고, 연결된 요소와 하중도 함께 움직입니다. |
| 하중 편집 | 하중을 더블클릭합니다. |
| 세부 정보 보기 | 어떤 객체든 포인터를 올리면 툴팁이 나타납니다. 절점은 변위와 회전각, 요소는 재료와 단면, 하중은 그 값을 보여 줍니다. 터치스크린에서는 탭하면 패널에 같은 정보가 나타납니다. |
| 캔버스 메뉴 열기 | 캔버스를 마우스 오른쪽 버튼으로 클릭합니다. 터치스크린에서는 길게 누릅니다. |

::div{.shots}

![절점 패널: 하중 추가, 지점 설정, 강제변위 지정](/screenshots/ko/ui-node-menu.webp)

![절점에 포인터를 올리면 변위와 회전각이 표시됩니다](/screenshots/ko/ui-hover.webp)

**캔버스 메뉴**에는 *절점 추가*, *요소 추가*, *치수 추가*가 있고(요소 위에서 열면 *요소 1에 치수 추가*처럼 그 요소에 치수를 다는 항목도 있습니다), 그 아래에 현재 선택에 대한 *편집*, *복사*, *붙여넣기*, *삭제*가 있습니다. *절점 추가*나 *요소 추가*를 고를 때 <kbd>Ctrl</kbd>을 누르고 있으면 대화 상자 대신 마우스로 배치합니다.

![캔버스 메뉴](/screenshots/ko/ui-canvas-menu.webp){.shot-sm}

모든 단축키와 터치 동작은 [키보드, 마우스 및 터치](/ko/reference/shortcuts) 페이지에 정리되어 있습니다.

### 모델을 해석할 수 없을 때 {#when-the-model-cannot-be-solved}

뷰어 왼쪽 위에 메시지가 나타납니다.

| 메시지 | 의미 |
| --- | --- |
| *정의된 재료가 없습니다.*, *정의된 단면이 없습니다.* | 옆에 있는 **새로 추가** 버튼으로 추가합니다. |
| 파란색 **지점 필요** 칩 | 모델이 아직 완성되지 않았을 뿐입니다. 지점이 더 필요합니다. |
| **자세히 보기**가 있는 빨간색 메시지 | 모델에 잘못된 곳이 있습니다. **자세히 보기**를 누르면 모든 문제가 해결 방법과 함께 나열됩니다. |
| 노란색 메시지 | 모델은 해석했지만, 어떤 요소에도 연결되지 않은 절점처럼 이상해 보이는 점이 있습니다. |

구조물이 아직 움직일 수 있으면 EduBeam이 그 움직임을 점선 윤곽의 애니메이션으로 보여 주고, 원인이 되는 절점이나 힌지에 원을 그립니다. 메시지에 포인터를 올리면 움직임을 다시 볼 수 있고, 눈 모양 버튼으로 숨길 수 있습니다.

![B와 C에 힌지가 있는 라멘은 메커니즘입니다. EduBeam이 어떻게 움직이는지 보여 줍니다](/screenshots/ko/ui-mechanism.webp)

[문제 해결](/ko/reference/troubleshooting#messages)에서 각 메시지의 의미와 해결 방법을 설명합니다.

## 하단 바 {#bottom-bar}

탭 6개가 있고, 탭마다 도구 모음과 편집할 수 있는 표가 있습니다. 탭 이름에는 그 탭에 있는 객체 수가 표시됩니다. 탭 줄을 위아래로 드래그하면 하단 바의 높이가 바뀌고, 오른쪽 끝의 버튼으로 접을 수도 있습니다. 그 옆의 **?** 버튼은 열린 탭을 설명하고, 일부 열 제목 옆의 **?** 버튼도 그 열을 설명합니다.

| 탭 | 도구 모음 | 표의 열 |
| --- | --- | --- |
| **절점** | 절점 추가(대화 상자), 절점 추가(마우스) | 절점, 좌표, **구속 자유도**(지점 기호, `Dx`, `Dz`, `Ry`, 각도 α), 하중, 작업 |
| **요소** | 요소 추가(대화 상자), 요소 추가(마우스) | 요소, 유형, 절점(**절점 교환** 포함), 재료, 단면, **단부 힌지**, 하중, 작업 |
| **하중** | 절점하중 추가, 요소하중 추가 | 유형, 대상, 성분, 작업 |
| **재료** | 재료 추가, 재료 라이브러리 | 재료, E, G, α<sub>T</sub>, 작업 |
| **단면** | 단면 추가, 단면 라이브러리, 다각형 단면 | 형상, 단면, 단면적, I<sub>y</sub>, 높이, 전단 보정계수, 작업 |
| **결과** | 절점 결과, 요소 결과, CSV 내보내기, 복사 | 절점별 변위 또는 요소별 단부력. [결과 및 다이어그램](/ko/essentials/results#results-tab) 참고 |

각 탭은 [절점 및 지점](/ko/essentials/nodes-supports), [요소, 재료 및 단면](/ko/essentials/elements), [하중](/ko/essentials/loads), [결과 및 다이어그램](/ko/essentials/results#results-tab)에서 자세히 설명합니다.

### 값 입력 {#typing-values}

표와 대화 상자의 숫자 입력란은 모두 같은 방식으로 동작합니다.

- 값은 [현재 단위](/ko/essentials/units-settings#units)로 입력합니다. 단위는 열 제목이나 입력란 뒤에 표시됩니다.
- 소수점은 마침표와 쉼표 모두 됩니다. `2.5`와 `2,5`는 같은 값입니다.
- 계산식도 입력할 수 있습니다. `+ - * / ^`와 괄호를 쓸 수 있으므로 `6/2`, `3*1.5`, `2^3`, `(4+2)/3`은 EduBeam이 계산해 주고, `1e-5`는 $10^{-5}$가 됩니다.
- 표에서는 <kbd>Enter</kbd>, <kbd>Esc</kbd>, <kbd>Tab</kbd>을 누르거나 다른 곳을 클릭하면 값이 적용됩니다. 그 뒤에 <kbd>Ctrl</kbd>+<kbd>Z</kbd>를 누르면 값이 되돌아가고, 아직 입력하는 중이라면 입력한 글자를 되돌립니다.

## 뷰어 위의 탭 {#tabs-above-the-viewer}

**뷰어**는 캔버스를 보여 줍니다. **설정**은 그 자리에 [설정](/ko/essentials/units-settings)을 크게 보여 주므로 색상이나 단위를 바꾼 뒤 뷰어로 돌아가 효과를 확인할 수 있습니다. 단위 칩과 *설정 더 보기*는 같은 설정을 모델 위의 대화 상자로 엽니다.

## 플로팅 창 {#floating-windows}

**강성 행렬**(요소 패널이나 *요소* 표에서 엽니다)은 요소의 6 × 6 강성 행렬을 전체 좌표계로 나타내 창에 보여 줍니다. 캔버스 메뉴의 **편집**은 현재 선택한 객체의 표를 엽니다. 창은 제목 표시줄을 드래그해 옮기고 ×로 닫습니다.
