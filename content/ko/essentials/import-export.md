# 파일, 링크 및 내보내기

모델을 파일로 저장하거나, 링크로 보내거나, 웹 페이지에 삽입하거나, 그림이나 표로 내보낼 수 있습니다. [EduBeam]{.edubeam}의 모든 작업은 브라우저 안에서 이루어지며 서버에 업로드되는 것은 없습니다. 공유 링크에는 말 그대로 모델이 담겨 있습니다.

## 프로젝트 저장 {#save-a-project}

**☰ → 프로젝트 저장** 또는 <kbd>Ctrl</kbd>+<kbd>S</kbd>(Mac에서는 <kbd>⌘</kbd>+<kbd>S</kbd>, 이 페이지의 다른 단축키도 마찬가지)를 누르면 `project.json`을 내려받습니다. 이 파일에는 절점, 요소, 재료, 단면(그린 형상 포함), 하중, 치수선과 파일을 작성한 앱 버전이 들어 있습니다. 파일 이름은 자유롭게 바꿔도 됩니다.

## 프로젝트 열기 {#open-a-project}

**☰ → 프로젝트 열기** 또는 <kbd>Ctrl</kbd>+<kbd>O</kbd>를 누른 뒤 파일을 고르거나, **파일을 앱 창의 아무 곳에나 끌어다 놓습니다**. EduBeam은 다음 파일을 엽니다.

- 모든 버전의 EduBeam이 저장한 `project.json` 파일.
- 2.x–3.5 버전의 **데스크톱 EduBeam**이 저장한 `.xml` 세션. 이 파일의 값에는 단위가 없으므로, 당시 매뉴얼이 쓰던 단위인 kN, kPa, m로 읽습니다. EduBeam은 한 번에 하중조건 하나만 엽니다. 하중조건이 여러 개인 세션은 첫 번째 하중조건을 열고, 빠진 하중조건의 이름을 알려 줍니다.

파일을 열면 재료와 단면을 포함한 현재 모델이 대체됩니다. 이전 모델은 사라지지 않습니다. <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 되돌릴 수 있고, [최근 구조물](#recent-structures)에도 보관됩니다. EduBeam이 읽을 수 없는 파일은 메시지와 함께 거부되며, 모델은 그대로 유지됩니다.

## 링크 공유 {#share-a-link}

앱 바나 ☰ 메뉴의 **모델 공유**는 *URL로 모델 공유* 대화 상자를 엽니다.

![URL로 모델 공유 대화 상자](/screenshots/ko/c1-share.webp){.shot-lg}

- **복사**를 누르거나 입력란 안 아무 곳이나 클릭하면 링크가 복사됩니다.
- **링크 열기**는 링크를 새 탭에서 열어, 받는 사람이 보게 될 화면을 확인할 수 있게 합니다.
- **시스템 공유 창으로 공유**는 브라우저가 지원하는 경우 기기의 공유 시트로 링크를 넘깁니다.
- **짧은 링크**(기본으로 켜짐)는 같은 모델을 약 절반의 글자 수로 씁니다. 버전 1.3.2(2026년 11월)보다 오래된 EduBeam은 업데이트하기 전까지 이 링크를 읽지 못하므로, 링크가 어디서나 바로 열려야 한다면 끄세요.
- **내 화면 그대로 보기**(기본으로 꺼짐)를 켜면 받는 사람의 표시 옵션 대신 지금 켜 둔 다이어그램, 하중, 레이블이 그대로 보이도록 링크가 열립니다.

링크의 형식은 `https://run.edubeam.app/?model=…`이며 모델 전체가 인코딩되어 있습니다. 링크를 연 사람은 각자 편집할 수 있는 사본을 받고, 편집 내용은 원본으로 동기화되지 **않습니다**. 모델이 바뀌면 새 링크를 보내세요. 모델이 아주 크면 링크도 아주 길어지므로 그럴 때는 프로젝트 파일을 공유하세요.

누군가 링크를 열면 그 사람이 작업하던 이전 모델은 최근 구조물로 옮겨지고, 어디서 찾을 수 있는지 메시지로 알려 줍니다. 링크는 만료되지 않습니다. 작년 강의 노트의 링크는 오늘도 같은 모델을 엽니다.

## 뷰어 삽입 {#embed-a-read-only-viewer}

공유 링크에 `&viewer=1`을 붙이면 모델이 **뷰어 모드**로 열립니다. 앱 바, 하단 바, 실행 취소와 다시 실행, 그리드 칩과 단위 칩, 십자선이 숨겨지고 그림, 화면에 맞추기와 가운데 맞춤 버튼, 표시 옵션만 남습니다. 환영 대화 상자와 릴리스 노트도 열리지 않습니다. 이 URL을 `<iframe>`에 넣으면 확대/축소할 수 있는 실시간 모델을 강의 노트, 과목 홈페이지, 슬라이드에 삽입할 수 있습니다.

```html
<iframe
  src="https://run.edubeam.app/?viewer=1&show=MRLS&model=…"
  width="100%"
  height="400"
></iframe>
```

![뷰어 모드의 3힌지 라멘](/screenshots/ko/viewer-mode.webp){.shot-lg}

뷰어 모드는 보기용이지만 잠겨 있지는 않습니다. 방문자는 여전히 절점을 드래그하고 다이어그램을 바꿀 수 있습니다. 뷰어 링크를 삽입하지 않고 직접 열면 다른 링크와 마찬가지로 방문자의 모델이 대체되고, 그 모델은 최근 구조물에 보관됩니다. 다른 사이트의 페이지에 삽입하면 요즘 브라우저는 대부분 프레임에 별도의 저장 공간을 주므로 방문자의 모델은 건드리지 않지만, 모든 브라우저가 그런 것은 아닙니다.

앱이 전혀 필요 없는 그림, 예를 들어 웹 페이지, 슬라이드, 연습 문제지에 넣을 정적인 다이어그램에는 [@edubeam/plot](/ko/plot) 라이브러리가 코드로 구조물과 다이어그램을 그려 줍니다. 이 사이트의 실시간 그림도 이 라이브러리로 그렸습니다.

## URL 매개변수 {#url-parameters}

| 매개변수 | 효과 |
| --- | --- |
| `model=<data>` | 인코딩된 모델을 불러와 화면에 맞춥니다. **모델 공유**가 작성합니다. |
| `viewer=1` | [뷰어 모드](#embed-a-read-only-viewer). |
| `show=<letters>` | 지정한 레이어만 켠 채 엽니다. 글자 하나가 레이어 하나를 뜻합니다. `N` 축력, `V` 전단력, `M` 휨모멘트, `U` 변형 형상, `R` 반력, `L` 하중, `S` 지점, `n` 절점 이름, `e` 요소 이름. `show=MRLS`는 휨모멘트, 반력, 하중, 지점을 보여 줍니다. **내 화면 그대로 보기**가 작성합니다. |
| `lang=<code>` | 인터페이스 언어를 바꿉니다: `en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn`(중국어), `th`, `uk`, `ru`, `tr`, `hi`, `vi`, `it`, `id`, `ja`, `ko`. |
| `panel=examples` | 예제 갤러리를 바로 엽니다. |

매개변수는 `?lang=de&viewer=1&model=…`처럼 `&`로 이어 붙입니다. EduBeam은 매개변수를 읽은 뒤 주소 표시줄에서 지웁니다. `lang`과 `show`는 방문자가 앱에서 직접 고른 것처럼 방문자의 설정으로 남습니다.

## 이미지 내보내기 {#export-an-image}

**☰ → 이미지 내보내기** 또는 <kbd>Ctrl</kbd>+<kbd>P</kbd>로 이미지 내보내기를 엽니다. 그림은 고른 크기에 맞춰 새로 배치되므로 선과 레이블이 실제 굵기를 유지합니다.

![이미지 내보내기: 레이어, 영역, 크기를 고른 다음 내려받거나 복사합니다](/screenshots/ko/export-image.webp)

::div{.steps}

### 레이어 고르기 {#choose-the-layers}

위쪽의 칩으로 변형 형상, N, V, M, 반력과 지점, 하중, 절점 이름, 요소 이름 가운데 그릴 항목을 고릅니다. 처음에는 뷰어의 표시 옵션과 같고, 여기서 바꿔도 뷰어는 그대로입니다.

### 영역 정하기 {#frame-the-drawing}

화면 비율(16:9, 4:3, 3:2, 1:1), **전체 맞춤**, 또는 그림 위에 사각형을 드래그하는 **영역…** 중에서 고릅니다. 미리보기의 가장자리를 드래그할 수도 있습니다.

### 크기 정하기 {#set-the-size}

픽셀 단위의 너비와 높이, 또는 종이에 축척대로 그릴 때 쓰는 1 : 50 같은 **축척**(96 DPI 기준)을 정합니다. **다이어그램 높이**는 결과 다이어그램의 크기를 정하고, **투명 배경**은 흰색 배경을 뺍니다. 다이어그램이나 레이블이 다 들어가지 않으면 대화 상자가 이를 알리고, 다이어그램을 줄이거나 캔버스를 키울 수 있는 버튼을 보여 줍니다.

### 저장 {#save-it}

**PNG 다운로드**나 **SVG 다운로드**를 누르거나, 브라우저가 허용하면 **클립보드에 복사**를 누릅니다. 파일 이름에는 `edubeam-512x512.svg`처럼 크기가 들어갑니다. 고해상도 화면에서는 앱과 똑같이 선명하도록 PNG의 픽셀 수가 화면의 픽셀 밀도에 비례해 지정한 너비와 높이보다 많아집니다. 실제 픽셀 크기는 버튼 옆에 표시됩니다.

::

SVG는 어떤 크기에서도 선명하고 Word, Inkscape, Overleaf의 LaTeX에서 쓸 수 있으므로 보고서와 학위 논문에 가장 알맞습니다. 크기가 같으면 구조물이 언제나 같은 위치에 배치되므로, N, V, M을 차례로 내보내면 나란히 정렬됩니다.

연습 문제지의 문제마다 그림을 하나씩 넣을 때처럼 이런 그림을 코드로 만들려면, 시각화 라이브러리 @edubeam/plot으로 같은 프로그램에서 열리는 [독립 SVG 파일](/ko/plot/functions#a-standalone-svg-file)을 만들 수 있습니다.

## 자동 저장 {#automatic-persistence}

모델과 설정은 변경할 때마다 브라우저의 로컬 스토리지에 저장되고, 브라우저를 닫았다가 다시 열어도 복원됩니다. 이는 편의 기능일 뿐 백업이 아닙니다. 한 기기의 한 브라우저 프로필에만 속하고, 시크릿 창에서는 남지 않으며, 사이트 데이터를 지우면 사라집니다. 중요한 작업은 프로젝트 파일로 저장하세요. 저장되는 내용은 [브라우저에 저장되는 내용](/ko/essentials/units-settings#what-is-stored-in-your-browser)에 모두 나와 있습니다.

## 프로젝트 파일 형식 {#project-file-format}

`project.json`은 사람이 읽을 수 있는 일반 JSON입니다. 다음은 라이브러리의 강재와 IPE 200을 쓴 [빠른 시작](/ko/guide/quick-start)의 보입니다.

```json [project.json]
{
  "edubeam": true,
  "version": "1.3.4",
  "domain": {
    "materials": [
      {
        "label": "Steel (S235)",
        "d": 7850,
        "e": 210000000000,
        "g": 81000000000,
        "alpha": 0.000012
      }
    ],
    "crossSections": [
      {
        "label": "IPE 200 (approx)",
        "a": 0.002848,
        "iy": 0.00001943,
        "h": 0.2,
        "k": 0.3932584269662922
      }
    ],
    "nodes": [
      { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] },
      { "label": "2", "coords": [6, 0, 0], "bcs": [2] }
    ],
    "elements": [
      {
        "label": "1",
        "nodes": ["1", "2"],
        "mat": "Steel (S235)",
        "cs": "IPE 200 (approx)",
        "hinges": [false, false]
      }
    ],
    "loadCases": [
      {
        "label": "DefaultLC",
        "nodalLoads": [],
        "elementLoads": [
          { "type": "udl", "target": "1", "lcs": true, "values": [0, 12000] }
        ],
        "prescribedBC": []
      }
    ]
  },
  "dimensions": []
}
```

앱의 표시 단위와 관계없이 모든 값은 **SI 단위**(m, N, Pa, rad)입니다. 좌표는 `[x, y, z]`이며 $y = 0$이고 $z$는 아래를 향합니다. 지점과 하중 성분은 자유도 번호 `0 = Dx`, `2 = Dz`, `4 = Ry`를 씁니다.

| 요소하중 `type` | 값 |
| --- | --- |
| `udl` | `values: [fx, fz]`, N/m |
| `trapezoidal` | `startValues: [f1x, f1z]`, `endValues: [f2x, f2z]`, N/m |
| `concentrated` | `values: [Fx, Fz, My, a]`, N, N·m, 시작 절점으로부터의 거리 m |
| `temperature` | `values: [ΔTc, ΔTb, ΔTt]`, K. 온도구배는 ΔTb − ΔTt |

`lcs: true`이거나 `lcs`가 아예 없으면 요소하중은 요소의 국부 좌표축 기준이고, `false`이면 전체 좌표축 기준입니다. 나머지 항목은 다음과 같습니다.

- **절점하중**: `{ "target": "2", "values": { "0": Fx, "2": Fz, "4": My } }`. 회전된 지점의 축으로 준 하중에는 `"lcs": true`가 더해집니다.
- **강제변위**: `{ "target": "2", "prescribedValues": { "0": Dx, "2": Dz, "4": Ry } }`. 빠진 성분은 0입니다.
- 앱이 작성한 파일에는 `date`, `commit`, 회전된 지점의 축(절점의 `lcs`), 그린 단면의 `shape`도 들어 있습니다.
