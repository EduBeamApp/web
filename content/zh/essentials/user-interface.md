# 用户界面

[EduBeam]{.edubeam} 的界面分为三个区域：顶部是**应用栏**，中间是用来绘图的**视图**，底部是**底部栏**，每类对象在底部栏中各有一个表格。在视图中能做的事，在表格中都能做，反过来也一样。

![界面各部分，编号与下面的列表一致](/screenshots/zh/ui-overview.webp)

1. **☰ 菜单**：打开、保存、分享和导出；示例和新手引导。
2. **清空结构**和**分享模型**。
3. **撤销**和**重做**。
4. **视图按钮**：居中、适配屏幕，以及显示选项。
5. **显示选项**：绘制哪些结果和模型的哪些部分。
6. **网格、吸附、十字准线和单位。**
7. **底部栏选项卡**：节点、单元、荷载、材料、截面、结果。
8. 当前选项卡的**表格**，其中每个数值都可以编辑。

::callout{type="tip" title="跟着导览走一遍"}
**☰ → 带我看看**会在应用中逐一指出这些部分。
::

## 应用栏 {#app-bar}

- **☰** 打开主菜单，见下文。
- **清空结构**在确认后删除所有节点、单元和荷载；勾选**删除材料**或**删除截面**，材料或截面也一并删除。按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可以恢复模型，它也会保留在*最近的结构*中。
- **分享模型**打开[分享对话框](/zh/essentials/import-export#share-a-link)，其中的链接包含整个模型。
- **更新内容**显示版本更新说明。应用更新后，它也会自动打开一次。
- **文档**打开本指南，GitHub 图标打开源代码。

在手机上，应用栏只放得下 ☰ 和**文档**；**清空结构**和**分享模型**在菜单中。

### ☰ 菜单 {#the-☰-menu}

![☰ 菜单](/screenshots/zh/ui-app-menu.webp){.shot-xs}

- **打开项目**和**保存项目**打开或下载 `project.json` 文件（<kbd>Ctrl</kbd>+<kbd>O</kbd>、<kbd>Ctrl</kbd>+<kbd>S</kbd>）。
- **最近的结构**保留你最近清空或替换掉的 10 个模型，可随时恢复。
- **导出图像**将图形保存为 PNG 或 SVG，或复制到剪贴板（<kbd>Ctrl</kbd>+<kbd>P</kbd>）。
- **示例**是现成模型的示例库；**绘制第一根梁**是七步引导任务；**带我看看**是界面导览。
- **分享模型**和**清空结构**与应用栏上的按钮相同。

菜单底部显示应用的版本号及其发布日期。打开、保存、分享和导出详见[文件、链接与导出](/zh/essentials/import-export)。

## 视图 {#viewer}

视图就是画布，在这里绘制和查看模型。每次修改后，EduBeam 都会立即重新计算结果，所以没有*求解*按钮。

### 画布上的按钮 {#buttons-on-the-canvas}

**左上角：撤销和重做**，对模型的每一次修改都可以逐步后退和前进，包括添加、编辑、拖动、删除和清空（<kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>）。

**右上角：**

- **框选**，仅在带触摸屏的设备上出现：接下来手指拖出的矩形会选中其中的对象。
- **内容居中**把模型移到中间，不改变缩放（<kbd>C</kbd>）；**适配屏幕**缩放到能看到整个模型（<kbd>F</kbd>）。
- **⚙** 显示或隐藏[显示选项](#display-options)。

**右下角：**

![网格、吸附、十字准线和单位按钮](/screenshots/zh/ui-grid-units.webp){.shot-sm}

- **G** 显示或隐藏网格和标尺（<kbd>G</kbd>）；**S** 开启或关闭网格吸附（<kbd>S</kbd>）。
- **十字准线**按钮在标尺上标出指针的位置，仅在使用鼠标时有效。
- **单位标记**打开设置中的[语言与区域](/zh/essentials/units-settings#language-locale)。

### 显示选项 {#display-options}

⚙ 按钮打开两行复选框。第一行选择叠加在模型上的结果：*变形图*、*N (x)*、*V<sub>z</sub> (x)*、*M<sub>y</sub> (x)* 和*支反力*；默认勾选变形图、弯矩和支反力。第二行显示或隐藏模型的各部分：*支座*、*荷载*、*节点标签*和*单元标签*，默认全部勾选。

![视图按钮和显示选项](/screenshots/zh/ui-display-settings.webp){.shot-lg}

**更多设置**打开[视图设置](/zh/essentials/units-settings#viewer-settings)：大小、颜色以及内力图的绘制方式。各项结果的含义见[结果与内力图](/zh/essentials/results#overlays-in-the-viewer)。

### 视图导航 {#navigating}

| 操作 | 鼠标与键盘 | 触控 |
| --- | --- | --- |
| 缩放 | 滚轮，朝指针所在位置缩放；触控板上双指捏合或双指滚动 | 双指捏合 |
| 平移 | 按住右键或按下滚轮拖动；用哪一种，在[控制与快捷键](/zh/essentials/units-settings#controls-shortcuts)中选择 | 单指拖动 |
| 适配、居中 | <kbd>F</kbd>、<kbd>C</kbd> 或右上角的按钮 | 右上角的按钮 |

<kbd>Ctrl</kbd>+<kbd>+</kbd> 和 <kbd>Ctrl</kbd>+<kbd>-</kbd> 以图形中心为基准缩放，任何键盘布局都适用。它们只缩放图形，不会像浏览器自带的缩放那样放大整个界面。

### 选择与编辑 {#selecting-and-editing}

| 目的 | 操作 |
| --- | --- |
| 选中一个对象 | 点击节点、单元、荷载或尺寸标注。旁边会打开一个面板，列出相应的操作：添加荷载、设置支座、编辑、显示刚度矩阵、删除。底部栏同时切换到对应的选项卡。 |
| 选中多个对象 | 在空白画布上拖出一个矩形（触摸屏上先点**框选**）。矩形内的所有节点和与矩形相交的所有单元都会被选中，连同它们的荷载和尺寸标注。<kbd>Ctrl</kbd>+<kbd>A</kbd> 全选。 |
| 删除、复制、粘贴 | <kbd>Delete</kbd>、<kbd>Ctrl</kbd>+<kbd>C</kbd>、<kbd>Ctrl</kbd>+<kbd>V</kbd>。粘贴的对象跟随指针移动，点击后放下；也可以在横幅中输入偏移量 Δx、Δz。 |
| 移动节点 | 拖动节点。开启吸附时，节点落在网格上；相连的单元和荷载随之移动。 |
| 编辑荷载 | 双击荷载。 |
| 查看详细信息 | 指向任何对象都会显示提示信息：节点的位移和转角、单元的材料和截面、荷载的数值。触摸屏上轻点对象，面板中显示同样的信息。 |
| 打开画布菜单 | 在画布上右键单击，触摸屏上长按。 |

::div{.shots}

![节点面板：添加荷载、设置支座、施加位移约束](/screenshots/zh/ui-node-menu.webp)

![指向节点会显示它的位移和转角](/screenshots/zh/ui-hover.webp)

::

**画布菜单**中有*添加节点*、*添加单元*、*添加标注*（在单元上打开时还有*标注单元*），然后是作用于当前所选对象的*编辑*、*复制*、*粘贴*和*删除*。选择*添加节点*或*添加单元*时按住 <kbd>Ctrl</kbd>，就改用鼠标放置，不再打开对话框。

![画布菜单](/screenshots/zh/ui-canvas-menu.webp){.shot-sm}

所有快捷键和手势都列在[键盘、鼠标与触控](/zh/reference/shortcuts)页面中。

### 模型无法求解时 {#when-the-model-cannot-be-solved}

消息显示在视图的左上角：

| 消息 | 含义 |
| --- | --- |
| *尚未定义材料*、*尚未定义截面* | 用旁边的**新增**按钮添加一个。 |
| 蓝色的**需要支座**标记 | 模型只是还没建完：还需要更多支座。 |
| 红色消息，带**显示详情** | 模型有错误。详情中列出每一个问题，并各附一条提示。 |
| 黄色消息 | 模型已经求解，但有些地方可能有问题，例如某个节点没有与任何单元相连。 |

如果结构仍然可以运动，EduBeam 会用虚线轮廓画出它的摆动，并圈出导致问题的节点或铰。指向消息可以再看一遍运动，点消息上的眼睛按钮可以把它隐藏。

![在 B、C 处设铰的刚架是机构：EduBeam 演示它如何运动](/screenshots/zh/ui-mechanism.webp)

每条消息的含义和处理方法见[疑难解答](/zh/reference/troubleshooting#messages)。

## 底部栏 {#bottom-bar}

底部栏有六个选项卡，每个都有一个工具栏和一个可编辑的表格。选项卡名称上显示其中对象的数量。上下拖动选项卡栏可以调整底部栏的高度，用右侧的按钮可以把它收起。旁边的 **?** 解释当前打开的选项卡，部分列标题旁的 **?** 也有同样的作用。

| 选项卡 | 工具栏 | 表格列 |
| --- | --- | --- |
| **节点** | 添加节点（对话框）、添加节点（鼠标） | 节点、坐标、**受约束自由度**（支座符号、`Dx`、`Dz`、`Ry`、角度 α）、荷载、操作 |
| **单元** | 添加单元（对话框）、添加单元（鼠标） | 单元、类型、节点（带**交换节点顺序**）、材料、截面、**端部铰接**、荷载、操作 |
| **荷载** | 添加节点荷载、添加单元荷载 | 类型、作用位置、分量、操作 |
| **材料** | 添加材料、材料库 | 材料、E、G、α<sub>T</sub>、操作 |
| **截面** | 添加截面、截面库、多边形截面 | 形状、截面、面积、I<sub>y</sub>、高度、剪切系数、操作 |
| **结果** | 节点结果、单元结果、导出 CSV、复制 | 每个节点的位移，或每个单元的端力；见[结果与内力图](/zh/essentials/results#results-tab) |

各选项卡的详细说明见[节点与支座](/zh/essentials/nodes-supports)、[单元、材料与截面](/zh/essentials/elements)、[荷载](/zh/essentials/loads)和[结果与内力图](/zh/essentials/results#results-tab)。

### 输入数值 {#typing-values}

表格和对话框中的所有数字输入框用法都相同：

- 数值采用[当前单位](/zh/essentials/units-settings#units)，单位显示在列标题中或输入框后面。
- 小数点和逗号都可以用：`2.5` 和 `2,5` 是同一个数。
- 可以输入算式：支持 `+ - * / ^` 和括号，`6/2`、`3*1.5`、`2^3` 或 `(4+2)/3` 都会自动算出结果，`1e-5` 表示 $10^{-5}$。
- 在表格中，按 <kbd>Enter</kbd>、<kbd>Esc</kbd>、<kbd>Tab</kbd> 或点击别处即确认数值。之后按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可以撤销这次修改；还在输入时，它撤销的是刚输入的文字。

## 视图上方的选项卡 {#tabs-above-the-viewer}

**视图**显示画布。**设置**在同一位置以全尺寸显示[设置](/zh/essentials/units-settings)，你可以修改颜色或单位，再切换回来查看效果。单位标记和*更多设置*以对话框的形式在模型上方打开同样的设置。

## 浮动窗口 {#floating-windows}

在单元面板或*单元*表格中点击**刚度矩阵**，会打开一个窗口，显示该单元在整体坐标系中的 6 × 6 刚度矩阵。画布菜单中的**编辑**打开当前所选对象的表格。拖动标题栏可以移动窗口，点击 × 关闭。
