# 单元、材料与截面

[EduBeam]{.edubeam} 中的每个单元都是连接两个节点的梁，带有一种材料和一个截面。在节点之间绘制单元，在结构有铰的地方用端部铰接释放杆端，再从库中选取材料和截面，或自己定义。

## 梁单元 {#the-beam-element}

EduBeam 只有一种单元：位于 x–z 平面内的**二维 Timoshenko 梁单元**，每端有三个自由度（`Dx`、`Dz`、`Ry`）。它承受轴力、剪力和弯矩，并考虑[剪切变形](#shear-deformation)。桁架杆就是[两端铰接](#end-hinges)的同一种单元。单元列式见理论手册中的[梁单元](/zh/elements/beam)。

对线性模型而言，沿单元的结果是精确的，所以**每根杆件用一个单元就够了**。只有在需要设置支座、铰、变截面，或需要读取某点位移的地方，才在杆件中间添加节点。集中荷载处不必加节点：[集中荷载](/zh/essentials/loads#concentrated-load)可以作用在单元上的任意位置。

## 添加单元 {#adding-elements}

单元需要材料和截面，所以要先添加它们（见[材料](#materials)和[截面](#cross-sections)）。还没有材料或截面时，视图中会显示*尚未定义材料*或*尚未定义截面*，并带有**新增**按钮。

- **选择节点**：*单元*选项卡 → **添加单元**（带 **+** 图标的按钮），或在画布上右键 → *添加单元*。选择**起始节点**和**终止节点**，需要时勾选其下方的**铰接**，再选择**材料**和**截面**。模型中至少要有两个节点。
- **鼠标点击**：*单元*选项卡 → **添加单元**（带光标图标的按钮），或在画布菜单中选择*添加单元*时按住 <kbd>Ctrl</kbd>。先点击一个节点（点击空白画布会在该处创建节点），再点击下一个；连续点击可以画出一串单元，按 <kbd>Esc</kbd> 或点**取消**结束。顶部横幅中的**起点铰接**和**终点铰接**作用于画出的每个单元。这些单元使用模型中的第一种材料和第一个截面。

![添加单元对话框](/screenshots/zh/qs-element.webp){.shot-md}

## 单元方向 {#element-direction}

每个单元都有自己的**局部坐标系**。局部 x 轴从**起始节点**指向**终止节点**；局部 z 轴由局部 x 轴在屏幕上顺时针转 90° 得到。从左向右画的单元，局部坐标轴与整体坐标轴一致。沿每个单元画出的**虚线**标出其局部 +z 一侧，即“下缘纤维”。

![按 A → B → C → D 顺序绘制的门式刚架：三个单元的虚线都在刚架内侧](/screenshots/zh/p2b-element-direction.webp){.shot-md}

在这个刚架中，单元 1 从 A 向上到 B，所以它的局部 z 轴和虚线都朝右；单元 3 从 C 向下到 D，所以虚线在左侧。按这种顺序绘制，门式刚架的虚线全部落在内侧。

单元方向影响：

- 按局部坐标系输入的荷载（勾选 **LCS**，即局部坐标系），见[单元荷载](/zh/essentials/loads#element-loads)；
- 集中荷载的**距起始节点的荷载位置**；
- 结果中[单元端力](/zh/elements/conventions#end-forces-element-results-table)的顺序：起始节点为 `X12, Z12, M12`，终止节点为 `X21, Z21, M21`；
- [内力图设置](/zh/essentials/units-settings#viewer-settings)中的*虚线侧*是哪一侧。

要把单元反向，点**交换节点顺序**（*单元*表格中两个节点之间的箭头）。

## 端部铰接 {#end-hinges}

端部铰接释放单元一端的弯矩：该处弯矩为零，杆端可以独立于节点转动。

- **一端铰接**，相当于在梁或刚架中设置一个铰。
- **两端铰接**，就得到只承受轴力的**桁架杆**。

可以在以下任一处勾选：

- *单元*表格的**端部铰接**列，每端一个复选框；
- **添加单元**对话框中的**铰接**复选框，或单元面板 → **编辑单元**中的同名复选框；
- 用鼠标绘制时横幅中的**起点铰接**和**终点铰接**。

![三铰刚架的单元表格：单元 2 的终点（节点 C 处）有一个铰](/screenshots/zh/elements-table.webp)

手算：连续梁 $M_B = -qL^2/8 = -31.25\ \text{kNm}$，每跨正弯矩最大为 $9qL^2/128 = 17.58\ \text{kNm}$；设铰后 $M_B = 0$，每跨跨中 $M_{max} = qL^2/8 = 31.25\ \text{kNm}$。铰卸去了支座处的弯矩，但跨中弯矩几乎翻了一倍。想手算一道带中间铰的梁，并在输入时即时核对答案，试试[练习题 G2048](/zh/practice?p=G2048)。

### 两端铰接：桁架杆 {#both-hinges-a-truss-bar}

由两根杆组成的墙面托架，两根杆都两端铰接，B 点作用 20 kN 竖向荷载。杆件只承受轴力，弯矩图为空。

手算：压杆长 5 m，竖向高差 3 m，所以 $N_{CB} = -20 \cdot 5/3 = -33.33\ \text{kN}$；拉杆平衡其水平分量，$N_{AB} = 33.33 \cdot 4/5 = 26.67\ \text{kN}$。[教程：平面桁架](/zh/tutorials/truss)用这种方法建立整个桁架，[结构力学练习题](/zh/practice?p=T2048)中也有可以手算的桁架题。

### 铰设在单元上，而不是节点上 {#hinge-the-element-not-the-node}

铰属于某个单元的某一端：它让这一端可以单独转动，而节点上的其他单元仍与节点刚性连接。所以两根杆件相交处，设一个铰就构成铰接点；多根杆件相交处，除一根以外全部设铰。桁架节点上每根杆都是桁架杆，因此全部铰接。

如果某个节点上的所有单元都是铰接的，该节点就没有转动刚度。EduBeam 接受这种节点，并把它的转角报告为 0。如果铰使结构成为机构，EduBeam 会圈出这些铰并显示结构如何运动；见[疑难解答](/zh/reference/troubleshooting#messages)。

## 材料 {#materials}

*材料*选项卡 → **添加材料**，或从**材料库**中选取现成的材料。多个单元可以共用一种材料；修改材料会更新所有使用它的单元。

| 输入框 | 单位 | 作用 |
| --- | --- | --- |
| 弹性模量 $E$ | MPa | 轴向刚度 $EA$ 和抗弯刚度 $EI_y$。钢材 210 000 MPa，混凝土约 30 000 MPa，木材约 11 000 MPa。 |
| 剪切模量 $G$ | MPa | 剪切刚度 $kGA$。只要截面的 $k$ 不是极大值，它就会引入[剪切变形](#shear-deformation)：挠度增大，超静定结构的内力也随之改变。$G = E/(2(1+\nu))$：钢材约 81 000 MPa。 |
| 密度 $\rho$ | kg/m³ | 随材料保存，但不参与计算：没有自重荷载。 |
| 线膨胀系数 $\alpha$ | 1/K | 用于[温度荷载](/zh/essentials/loads#temperature-load)。钢材 $12 \times 10^{-6}$ 1/K。 |

表中为国际单位制的默认单位；单位随[设置](/zh/essentials/units-settings#units)变化，美制单位下 E 和 G 以 ksi 计，密度以 lb/ft³ 计，α 以 1/°F 计。

新材料的初始值为 $E$ = 210 000 MPa、$G$ = 87 500 MPa（$E/2.4$，即 $\nu = 0.2$）、$\rho$ = 1000 kg/m³、$\alpha = 12 \times 10^{-6}$ 1/K；美制单位下初始为 ASTM A992 钢材。如果是钢材，把 $G$ 改为 81 000 MPa，或直接从库中选一种钢材。

![添加材料对话框](/screenshots/zh/qs-material.webp){.shot-md}

**材料库**（添加材料对话框中的*或从库中选择*也能打开它）把公制（EN）材料排在前面；当长度单位为英尺或英寸时，美国材料（ASTM 钢材、ACI 混凝土）排在前面。点某一行中的 **+** 即添加该材料，并以它的名称命名：

| 类别 | 材料 |
| --- | --- |
| 金属 | 钢材 S235、S275、S355；不锈钢 304、316；铸铁；铝合金 6061-T6、7075-T6、5083；铜、黄铜、青铜；钛 Grade 2 和 Ti-6Al-4V；美国钢材 ASTM A992、A36、A572 Gr. 50，以及 HSS A500 Gr. C |
| 混凝土 | C25/30、C30/37、C40/50、轻质混凝土；美国 $f'_c$ = 4 ksi 和 5 ksi |
| 木材 | C24、GL24h、GL32h |
| 其他 | 玻璃、GFRP、CFRP、HDPE、PVC、PMMA、聚碳酸酯 |

仍被单元使用的材料不能删除：请先给这些单元指定别的材料。

## 截面 {#cross-sections}

*截面*选项卡 → **添加截面**、**截面库**，或用**多边形截面**绘制自己的截面形状。和材料一样，一个截面可以由多个单元共用。

| 输入框 | 单位 | 作用 |
| --- | --- | --- |
| 面积 $A$ | m² | 轴向刚度 $EA$，以及剪切面积 $kA$。 |
| 惯性矩 $I_y$ | m⁴ | 绕垂直于图形平面的轴的抗弯刚度 $EI_y$。 |
| 高度 $h$ | m | 只用于温度荷载：曲率为 $\alpha\,(\Delta T_b - \Delta T_t)/h$。 |
| 剪切系数 $k$ | – | 有效剪切面积为 $kA$，所以剪切刚度为 $kGA$。矩形约为 0.83，工字形截面为 $A_{web}/A$。 |

新截面的初始值为 $A$ = 1 m²、$I_y = 10^{-4}$ m⁴、$h$ = 1 m、$k$ = 1（美制单位下为 W12×26，$k$ = 1）。请换成你的截面数值，或从库中选取。

::callout{type="tip" title="与不考虑剪切变形的教材对照"}
大多数手算采用 Euler–Bernoulli 梁，不考虑剪切变形。要与之一致，把 $k$ 设为很大的值，例如 `1e10`；应用中的示例和本网站的图都使用 `1e32`。新截面（$k = 1$）、截面库和多边形编辑器都考虑剪切变形；它的影响有多大，见[下文](#shear-deformation)。
::

**截面库**给出以下截面的近似值：

| 类别 | 截面 | $k$ |
| --- | --- | --- |
| 实心截面 | 矩形、正方形、圆形 | 0.833（矩形），0.9（圆形） |
| 工字形 | IPE 100、IPE 200、HEA 100、HEA 200；AISC W 型钢 W8×31 至 W36×150 | $h\,t_w/A$，即腹板 |
| 矩形管 | RHS 100×50×3、150×100×5；AISC HSS | $2ht/A$，即两侧腹板 |
| 圆管 | CHS Ø60×3、Ø114×5；AISC 圆形 HSS | 0.5 |

正式使用库中的数值前，请对照型钢表核对。

![截面库](/screenshots/zh/sections-library.webp){.shot-lg}

手算快速核对：矩形 $b \times h$ 有 $A = bh$、$I_y = bh^3/12$；直径为 $d$ 的实心圆有 $A = \pi d^2/4$、$I_y = \pi d^4/64$。

### 剪切变形：G 和 k 何时起作用 {#shear-deformation}

剪切刚度 $kGA$ 通过[剪切参数](/zh/elements/beam#timoshenko-or-euler-bernoulli) $\Phi = 12EI_y/(kGAL^2)$ 进入单元。$k$ 极大时 $\Phi = 0$，单元就是 Euler–Bernoulli 梁，$G$ 不起作用。$k$ 取实际值时，剪切变形总会使挠度增大。静定结构的内力不变；超静定结构的内力也会改变，因为多余未知力取决于刚度。

影响有多大，取决于杆件的粗短程度。下面是库中的 IPE 200（$k = h\,t_w/A = 0.393$），S235 钢材（$G$ = 81 000 MPa），承受 10 kN/m 均布荷载，与 $k$ = `1e32` 的同一根梁比较：

| 梁 | 考虑剪切变形 | Euler–Bernoulli |
| --- | --- | --- |
| 简支梁，$L$ = 2 m（$L/h$ = 10）：跨中挠度 | 0.566 mm | 0.511 mm |
| 一端固定一端简支梁，$L$ = 2 m：固定端弯矩 | −4.84 kNm | −5.00 kNm |
| 简支梁，$L$ = 6 m（$L/h$ = 30）：跨中挠度 | 41.85 mm | 41.36 mm |

手算：跨中挠度中的剪切部分为 $qL^2/(8kGA)$，短梁为 0.055 mm，在弯曲部分 $5qL^4/(384EI_y)$ 之上多出 11 %。一端固定一端简支梁的固端弯矩从 $qL^2/8$ 降为 $(qL^2/8)/(1 + \Phi/4)$。$L/h$ = 30 时，两种影响都只有约 1 % 或更小，所以细长刚架无论 $k$ 取多少，都与教材答案一致。

### 多边形截面 {#polygonal-sections}

*截面*选项卡 → **多边形截面**，或添加截面对话框中的*或定义多边形形状*，会打开形状编辑器，替你计算截面特性。

![多边形截面编辑器：工字形预设，以及它的主轴和惯性椭圆](/screenshots/zh/sections-polygon.webp)

::div{.steps}

### 从预设开始 {#start-from-a-preset}

选择一个**预设**（矩形、工字形、T 形、L 形（角钢）、槽形 (U)、矩形空心、圆形、圆形空心），输入尺寸，然后点**应用**。

### 调整形状 {#adjust-the-shape}

拖动顶点（会吸附到**吸附步长**的整数倍上），点击边的中点插入顶点，双击顶点将其删除。也可以在**顶点**表格中输入坐标。**添加孔洞**添加一个内轮廓，**以形心居中**移动形状，使形心位于原点。

### 读取截面特性 {#read-the-properties}

**截面特性**选项卡显示 $A$、形心、对形心轴的 $I_y$、$I_z$、$I_{yz}$，主惯性矩 $I_1$、$I_2$ 及**主轴角** $\alpha$（从 $y$ 轴量到轴 1），以及回转半径。图中画出主轴和惯性椭圆。

### 添加截面 {#add-it}

检查**标签**和**剪切系数** $k$：初始值 0.833 适用于矩形；工字形截面约需 $A_{web}/A$。然后点**添加截面**（编辑已有形状时点**保存**）。$A$、$I_y$ 和 $h$ 由形状算出，在表格中只读；要修改它们，用*操作*列中的多边形按钮重新编辑形状。

::

截面坐标为局部右手坐标系：$x$ 指向屏幕外，$y$ 向左，$z$ 向下。

如果截面形状关于刚架平面不对称（例如角钢），编辑器会给出提示：只有当杆件沿全长受到侧向变形和扭转约束时（例如由楼板约束），二维分析才是精确的。当 $I_{yz}$ 较大时，由你选择抗弯刚度：**沿全长侧向及扭转约束**（$I_y$），或数值较小的**侧向自由变形**。两种情况都不计入扭转。
