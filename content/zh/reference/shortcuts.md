# 键盘、鼠标与触控

EduBeam 可以用键盘和鼠标、触控板或手指操作。本页列出所有快捷键和手势。在 Mac 上，凡是显示 <kbd>Ctrl</kbd> 的地方请使用 <kbd>Cmd</kbd>；应用的菜单里也会相应显示 ⌘。

## 键盘 {#keyboard}

文本框获得焦点时，绘图快捷键（<kbd>F</kbd>、<kbd>C</kbd>、<kbd>G</kbd>、<kbd>S</kbd>、<kbd>Delete</kbd> 以及 <kbd>Ctrl</kbd>+<kbd>A</kbd>、<kbd>C</kbd>、<kbd>V</kbd>）不起作用，所以在输入框里输入 `f` 或 `s` 不会误触发。要使用这些快捷键，先点击一下图形。

### 文件与历史记录 {#files-and-history}

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销对模型的上一次修改 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 重做 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存项目（下载 `project.json`） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 打开项目 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 导出图像 |

清空模型，打开文件、链接或示例，恢复最近的结构，这些操作也都可以撤销。在表格单元格中还在输入时，<kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤回的是输入的内容；单元格一经确认，它撤销的就是对模型的修改。在对话框的输入框中，它始终撤回输入的内容。

### 绘图 {#drawing}

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 复制所选的节点、单元和荷载 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 粘贴。副本的虚影跟随指针移动：点击即可放置，或在横幅中输入偏移量 Δx、Δz，再点击**粘贴**或按 <kbd>Enter</kbd> |
| <kbd>Delete</kbd> | 删除所选对象（在 Mac 笔记本上按 <kbd>Fn</kbd>+<kbd>Delete</kbd>） |
| <kbd>Esc</kbd> | 退出当前模式（添加节点、单元或标注，粘贴，为图像框选窗口）并清除选择；还会关闭 ☰ 菜单、结束导览 |
| <kbd>F</kbd> | 适配屏幕 |
| <kbd>C</kbd> | 内容居中 |
| <kbd>G</kbd> | 切换网格 |
| <kbd>S</kbd> | 切换网格吸附 |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 以图形中心为基准放大 / 缩小图形 |

在 EduBeam 中，<kbd>Ctrl</kbd>+<kbd>+</kbd> 和 <kbd>Ctrl</kbd>+<kbd>-</kbd> 缩放的是图形，而不会像在其他网站上那样缩放整个界面。它们适用于任何键盘布局：无论标有 + 和 − 的键在你的键盘上位于何处都可以用（美式键盘上是 <kbd>Backspace</kbd> 左边的两个键），数字小键盘上的 + 和 − 也可以。

### 表格与对话框 {#tables-and-dialogs}

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Enter</kbd> | 在表格单元格中：确认数值。在对话框的文本框中：确认对话框，与主按钮作用相同 |
| <kbd>Esc</kbd> | 在表格单元格中：离开单元格，保留数值。在对话框中：关闭对话框，不保存 |
| <kbd>Tab</kbd> | 移到下一个输入框；表格单元格会保留已输入的内容 |

数字输入框接受算式，按手算时的写法输入即可：`6/2`、`3*1.5`、`2^3`、`(4+2)/3`；也可以写 `1e3`，或用逗号作小数点。

## 鼠标 {#mouse}

| 操作 | 结果 |
| --- | --- |
| 点击 | 选中节点、单元、荷载或尺寸标注，并打开其面板 |
| 在空白画布上拖动 | 拉出选择框 |
| 拖动节点 | 移动节点；开启吸附时会吸附到网格 |
| 添加模式下点击 | 放置节点，或开始、继续绘制单元折线 |
| 双击荷载 | 编辑荷载（位移约束也可以） |
| 右键单击 | 画布菜单：添加节点、添加单元、添加标注、标注单元（在单元上时）、编辑、复制、粘贴、删除 |
| 在画布菜单中按住 <kbd>Ctrl</kbd> 点击**添加节点**或**添加单元** | 用鼠标放置，而不是打开对话框 |
| 按住中键或右键拖动 | 平移。在**设置 → 控制与快捷键 → 平移方式**中选择用哪个键 |
| 滚轮 | 以指针位置为中心缩放 |
| 鼠标悬停在对象上 | 显示其位移、属性或荷载数值的提示信息 |

在触控板上，双指捏合和双指滚动都用于缩放。要平移，请用双指按下并拖动，这相当于右键拖动。

## 触控 {#touch}

| 手势 | 结果 |
| --- | --- |
| 轻点 | 选中对象，并显示其详细信息和操作 |
| 添加模式下轻点 | 放置节点或继续绘制单元 |
| 按住节点并拖动 | 移动节点 |
| 在其他位置单指拖动 | 平移 |
| 双指捏合 | 缩放 |
| 长按画布 | 画布菜单 |
| 轻点**框选**按钮（右上角），然后拖动 | 选择框；手指抬起处会打开画布菜单，其中有复制和删除 |

在添加节点、单元或标注，粘贴，或为图像框选窗口时，图形顶部的横幅会显示当前模式，并有一个**取消**按钮。触摸屏上没有 <kbd>Esc</kbd> 键，就用这个按钮退出当前模式。

## 对象面板 {#object-panels}

点击或轻点对象，会在它旁边打开一个面板，显示其详细信息和以下操作：

| 对象 | 操作 |
| --- | --- |
| 节点 | 添加荷载 · 节点支座（支座符号、Dx、Dz、Ry） · 节点局部坐标系角度 · 施加位移约束（在有支座的节点上） · 删除 |
| 单元 | 编辑单元（端节点和铰接、材料、截面） · 添加荷载 · 刚度矩阵 · 删除 |
| 节点荷载或单元荷载 | 编辑荷载 · 删除 |
| 尺寸标注 | 编辑 · 翻转标注 · 删除 |

[用户界面](/zh/essentials/user-interface)带你认识整个界面；设置中的[控制与快捷键](/zh/essentials/units-settings#controls-shortcuts)用来选择平移所用的鼠标键。
