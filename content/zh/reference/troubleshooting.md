# 疑难解答

模型无法求解时，[EduBeam]{.edubeam} 会在视图左上角的消息中说明原因，**显示详情**会完整列出每个问题。请按你看到的对话框标题查找：下面每条消息都说明了它的含义和解决方法。

::card-grid{cols="2"}
:::card{title="尚不能求解" icon="lucide:circle-dashed" to="#still-needed"}
蓝色的**需要支座**标记。没有出错，只是结构还没有被固定住。
:::
:::card{title="无法求解模型" icon="lucide:circle-x" to="#errors"}
红色消息。支座固定不住结构，铰使结构成为机构，单元长度为零。
:::
:::card{title="模型警告" icon="lucide:triangle-alert" to="#warnings"}
黄色消息。模型已求解，但某些地方可能不是你的本意。
:::
:::card{title="结果看起来不对" icon="lucide:scale" to="#results-look-wrong"}
荷载向上作用，挠度差了几个数量级，符号看似反了。
:::
::

## 消息 {#messages}

### 颜色的含义 {#read-the-message}

| 你看到的 | 含义 |
| --- | --- |
| 蓝色的**需要支座**标记 | 模型尚未完成，请添加支座。鼠标指向该标记，会用虚线轮廓显示结构还能怎样运动。 |
| **红色**消息 | 有问题阻止了求解。消息会指出问题；如果有多个问题，则显示*模型有 n 个错误*。图上会圈出相关节点。 |
| **黄色**消息 | 警告。模型照常求解。如果有多个警告，则显示*模型有 n 个警告*。 |
| *尚未定义材料。* / *尚未定义截面。* | 单元既需要材料，也需要截面。用消息旁的**新增**按钮添加。 |

**显示详情**会打开一个对话框，标题为*尚不能求解*、*无法求解模型*或*模型警告*。对话框中的开关用来显示或隐藏结构的运动，其中的**疑难解答**链接指向本页。

![无法求解模型对话框，带有显示结构运动的开关](/screenshots/zh/ui-diagnostics.webp){.shot-lg}

在图形上：

- 红色消息上的 **✕** 会把它折叠成一个小的*无法求解模型*标记，在小屏幕上腾出空间。点击该标记即可重新展开。
- 红色消息上的**眼睛**按钮用来显示或隐藏运动的虚线轮廓。**设置 → 视图设置 → 模型检查**可以彻底关闭虚线轮廓及其动画。
- 黄色消息上的 **✕** 会隐藏警告。

### 尚需完成 {#still-needed}

模型没有错，只是尚未完成。鼠标指向标记可以看到简短的说明，对话框中显示完整的说明。

| 消息 | 含义和解决方法 |
| --- | --- |
| *结构需要支座才能求解。* <br> *在二维分析中，模型至少需要 3 个受约束自由度才能保持稳定。* | 受约束的方向总共不到三个。请添加支座。 |
| *包含节点 … 的部分需要支座。* <br> *结构中一个独立部分（节点 …）的受约束自由度少于 3 个，可以自由运动。* | 模型分成了几块，其中一块处于悬空状态。把它与其余部分连接起来，或为它设置支座。 |
| *结构中有 n 个部分需要支座。* | 有几块处于悬空状态。**显示详情**会把它们逐一列出。 |

### 错误 {#errors}

有问题阻止了求解。红色消息显示简短的说明，对话框中显示完整的说明。

| 消息 | 含义和解决方法 |
| --- | --- |
| *支座无法固定结构：结构仍可水平滑动 / 竖向移动 / 自由转动 / 作刚体运动。* <br> *结构的支座数量足够，但无法将其固定：结构仍可……* | 约束数量够，但它们全部平行，或作用线交于一点，例如水平梁上的三个滑动铰支座。虚线轮廓显示了运动方式；请改变其中一个支座的方向或位置。 |
| *包含节点 … 的部分未被固定：仍可……* <br> *结构中一个独立部分（节点 …）的支座数量足够，但无法将其固定：该部分仍可……* | 与上一条相同，只是发生在分成几块的模型中的某一块上。 |
| *节点 … 处的铰使结构可以运动。* <br> *支座能够固定结构，但它仍是机构：杆件可绕节点 … 处的铰转动。* | 铰使杆件之间可以相对转动，例如两个柱脚为固定铰支座、两根柱顶都设铰的刚架，或没有斜杆的铰接方框。请去掉一个铰，或添加杆件或支座。 |
| *结构不稳定：几乎可以无阻力地运动。* <br> *结构不稳定：以下自由度几乎没有抵抗即可运动：节点 … 水平方向 (Dx) ……* | 接近机构，或刚度接近于零。完整的消息会指出相关的节点和方向。请检查支座、铰，以及 `E`、`A` 和 `Iy` 的数值。 |
| *结构是机构：可以无阻力地运动。* <br> *结构为机构：刚度矩阵奇异。* | 有某个部分可以自由运动，而上述检查没有发现。请检查每个部分是否至少有三个约束，以及端部铰接是否使某根杆件可以自由转动。 |
| *单元 … 长度为零：节点 … 和 … 位于同一位置。* | 一个单元的两个节点重合。移动其中一个，或删除该单元。 |
| *单元 … 的两端引用了同一个节点。* | 删除该单元，在两个不同的节点之间重新绘制。 |
| *单元 … 引用了不存在的节点 / 材料 / 截面 …* | 它引用的对象已被删除，通常发生在手动编辑过的项目文件中。请在*单元*表格中重新指定。 |
| *单元 … 必须恰好引用 2 个节点。* | 导入的文件中有损坏的单元。删除后重新绘制。 |
| *节点荷载 #n 引用了不存在的节点 …。* <br> *位移约束 #n 引用了不存在的节点 …。* | 删除该荷载，或为它指定一个存在的节点。 |
| *单元荷载 #n 引用了不存在的单元 …。* | 删除该荷载。 |
| *由于模型内部不一致，求解失败。* | 一般性错误。撤销上一步，或保存项目并[报告问题](#reporting-a-bug)。 |

### 警告 {#warnings}

模型照常求解，但请检查以下内容：

| 消息 | 含义和解决方法 |
| --- | --- |
| *节点 … 未与任何单元相连，求解器将忽略该节点。* | 多余的节点。删除它，或把它连接到结构上。 |
| *节点 … 设有支座，但没有单元与之相连，因此该支座不承受任何力。* | 支座设在了多余的节点上。 |
| *节点荷载 #n 包含无效数值。* <br> *位移约束 #n 包含无效数值。* | 某个分量不是数字。编辑该荷载。 |

### 编辑时 {#while-editing}

下列消息在操作过程中以浏览器对话框的形式弹出，模型保持原样：

| 消息 | 含义和解决方法 |
| --- | --- |
| *请先添加材料。* <br> *请先添加截面。* | 单元既需要材料，也需要截面。在*材料*或*截面*选项卡中添加，然后重新绘制单元。 |
| *请选择材料和截面。* | **添加单元**对话框中有空着的输入框。两项都要选择。 |
| *标签 … 已被使用。* | 节点、单元、材料或截面不能共用一个标签。请换一个。 |
| *该节点已存在位移约束。请先将其删除。* | 一个节点只能有一个位移约束。编辑已有的那个，或先将其删除。 |

## 什么都没画出来 {#no-results-are-drawn}

没有显示内力图时，请按以下顺序检查：

::div{.steps}

### 检查显示选项 {#check-the-display-options}

如果没有任何消息，模型就已经求解了：内力图可能只是被关闭了。在视图右上角的显示选项中勾选 **M<sub>y</sub>(x)** 或其他结果；其上方的 ⚙ 按钮用于显示该面板。没有任何荷载的模型，结果处处为零，同样没有东西可画。

### 检查支座 {#check-the-supports}

求解器至少需要三个受约束的方向，而且所有支座合起来必须阻止结构滑移或转动。放在两个滑动铰支座上的梁只有两个约束，会滑走：把其中一个改为**固定铰支座**。三个相互平行的滑动铰支座，或作用线交于一点的支座，同样固定不住结构。见[节点与支座](/zh/essentials/nodes-supports#supports)。

### 检查单元是否相连 {#check-the-connections}

坐标相同的两个节点仍然是两个独立的节点；如果某部分只在这样的位置与其余部分相接，它实际上是悬空的。删除多余的节点，重新连接。把节点放在单元上时，选择**连接到结构**，单元就会在该处拆分。

### 数一数铰 {#count-the-hinges}

两个柱脚为固定铰支座、两根柱顶都设铰的刚架，或没有斜杆的铰接方框，都是机构。EduBeam 会圈出这些铰，并用摆动的虚线轮廓显示运动。见[端部铰接](/zh/essentials/elements#end-hinges)。

### 检查是否有刚度为零 {#look-for-zero-stiffness}

`E`、`A` 或 `Iy` 输入为 0 或单位错误，会使结构的一部分几乎无阻力地运动。EduBeam 会报告为*不稳定*。

::

## 结果看起来不对 {#results-look-wrong}

| 现象 | 可能的原因 |
| --- | --- |
| 荷载向上作用 | 整体坐标 **z 轴向下**，因此正的 `Fz` 或 `fz` 向下作用，负值指向上方。采用 y 向上的坐标轴时正好相反。见[荷载](/zh/essentials/loads#sign-convention-in-one-line)。 |
| 挠度差了几个数量级 | 单位混淆：输入框要求 MPa 时以 Pa 输入了 `E`，或要求 m⁴ 时以 cm⁴ 输入了 `Iy`。视图右下角的单位标记列出了每个输入框使用的单位。 |
| 挠度略大于教材公式 | Timoshenko 梁的剪切变形。见[手算校核结果](/zh/guide/verification#shear-deformation)。 |
| 符号看起来不对 | 根据数值而不是内力图画在哪一侧来判断符号：M 为正即正弯矩（下缘受拉）。*单元结果*中的端力遵循单元的局部坐标轴，而不是 N-V-M 符号约定。见[判读符号](/zh/essentials/results#reading-the-sign)。 |
| 内力图画在了“错误”的一侧 | 画在哪一侧是显示设置：弯矩画在受拉侧或受压侧，N 和 V 画在虚线的哪一侧。见**设置 → 视图设置 → 内力图**。 |
| 两根相同的柱剪力符号相反 | V 的符号随各单元的方向而定。交换其中一根的节点顺序再比较。 |
| 出现 `4 · 10¹` 这样的数字 | 这是科学计数格式。在**设置 → 语言与区域 → 数字格式**中选择*自动*。 |
| 内力图过大或过小 | 这只影响图形显示。在**设置 → 视图设置**中调整**结果缩放**。 |
| 局部坐标系中的荷载方向反了 | 单元的局部 x 轴从*起始*节点指向*终止*节点。交换节点顺序，或改变符号。 |
| 斜杆上的荷载不对 | **LCS** 默认勾选，因此 `fz` 垂直于杆件作用。要施加竖向荷载，请取消勾选。 |
| 温度荷载不起作用 | 静定结构在温度作用下自由变形，不产生内力。要看到变形，请检查 α 不为 0；对于上下缘温差，还要检查是否设置了截面高度 $h$。 |

## 文件与链接 {#files-and-links}

| 现象 | 解决方法 |
| --- | --- |
| *无法导入该文件。请检查文件格式。* | 该文件既不是 EduBeam 项目，也不是桌面版 EduBeam 的会话。你的模型没有改变。 |
| *此 EduBeam 会话包含多个荷载工况，但一次只能打开一个。* | 桌面版 EduBeam 的会话含多个荷载工况：EduBeam 打开第一个，并列出未打开的工况。 |
| 分享链接打开的却是你原来的模型 | 链接被截断或改动了，例如被邮件客户端折行。EduBeam 会忽略无法读取的链接，保留你的模型。请重新复制完整的链接。 |
| 同事打不开更短的链接 | 同事的 EduBeam 版本早于 1.3.2。请对方刷新应用，或者你关闭**更短的链接**后再分享。见[分享链接](/zh/essentials/import-export#share-a-link)。 |

## 界面问题 {#interface-issues}

| 现象 | 解决方法 |
| --- | --- |
| 快捷键没有反应 | 先点击图形：文本框获得焦点时，单键快捷键会被忽略。在 Mac 上，用 <kbd>Cmd</kbd> 代替 <kbd>Ctrl</kbd>。见[键盘、鼠标与触控](/zh/reference/shortcuts)。 |
| 在 Mac 上按 <kbd>Delete</kbd> 没有反应 | Mac 键盘上标着 *delete* 的键其实是退格键（Backspace）。请按 <kbd>Fn</kbd>+<kbd>Delete</kbd>。 |
| 无法平移 | 平移用鼠标中键或右键，可在**设置 → 控制与快捷键**中选择用哪个键。在触控板上，用双指按下并拖动。在触摸屏上，用单指拖动。 |
| 我的模型不见了 | 打开链接、文件或示例，以及清空结构时，旧模型都会保留下来：**☰ → 最近的结构**，或 <kbd>Ctrl</kbd>+<kbd>Z</kbd>。打开链接时，屏幕底部会显示一条带**查看**按钮的提示：*已打开共享的结构。之前的结构保存在“最近的结构”中。* |
| 语言不对 | **设置 → 语言与区域**，或在地址后加上 `?lang=cn`。 |
| 设置修改无法保存 | 本地存储被阻止了，例如在无痕窗口或严格的隐私模式下。设置、保存的模型和最近的结构都需要本地存储。 |

## 报告 bug {#reporting-a-bug}

提交一个 [GitHub issue](https://github.com/janvorisek/edubeam/issues)，写明你的浏览器和操作系统、你做了什么、预期是什么。最有用的是能够复现问题的**分享链接**或**项目文件**。
