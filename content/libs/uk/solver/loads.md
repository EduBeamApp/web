# Вузлові навантаження та навантаження на стрижні {#nodal-and-member-loads}

Навантаження належать до випадку навантаження. Новий розв’язувач має один випадок, `solver.loadCases[0]`, і кожен метод `create…` цього випадку додає навантаження та повертає його. Про кілька випадків навантаження та їхні комбінації див. [Випадки навантаження](/uk/solver/load-cases).

Значення задають у N, N/m і N·m, а напрями відповідають [осям](/uk/solver/conventions#axes): вісь +z напрямлена вниз, додатний момент діє проти годинникової стрілки.

## Балка з усіма видами навантажень {#a-beam-with-every-kind}

Балка прольотом 8 m на шарнірно-нерухомій і шарнірно-рухомій опорах, з розподіленим навантаженням, що зростає від 4 до 10 kN/m, зосередженою силою 20 kN, зосередженим моментом 10 kNm і горизонтальною силою на шарнірно-рухомій опорі:

```ts [loads.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
domain.createMaterial(1, { e: 210e9, g: 81e9 })
domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, k: 1e32 })
domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz]) // шарнірно-нерухома опора
domain.createNode('B', [8, 0, 0], [DofID.Dz]) // шарнірно-рухома опора
domain.createBeam2D(1, ['A', 'B'], 1, 1)

const lc = solver.loadCases[0]
// 4 kN/m в A, зростає до 10 kN/m в B, донизу
lc.createBeamElementTrapezoidalEdgeLoad(1, [0, 4e3], [0, 10e3], false)
// [fx, fz, my, a]: 20 kN донизу, 2 m від A
lc.createBeamConcentratedLoad(1, [0, 20e3, 0, 2], false)
// зосереджений момент 10 kNm проти годинникової стрілки, 6 m від A
lc.createBeamConcentratedLoad(1, [0, 0, 10e3, 6], false)
// 5 kN праворуч у B
lc.createNodalLoad('B', { [DofID.Dx]: 5e3 })
solver.solve()

// getReactions повертає матрицю mathjs або масив: перетворимо на масив
const list = (v: unknown): number[] =>
  Array.isArray(v) ? v : (v as { toArray(): number[] }).toArray()

console.log(list(domain.getNode('A').getReactions(lc).values))
console.log(list(domain.getNode('B').getReactions(lc).values))
```

```text [Вивід]
[ -5000, -40250 ]
[ -35750 ]
```

Вручну: рівнодійна розподіленого навантаження — 56 kN на відстані 4,571 m від A, тож рівняння моментів відносно A дає $8R_B = 56 \cdot 4{,}571 + 20 \cdot 2 - 10 = 286$, $R_B = 35{,}75$ kN угору і $R_A = 76 - 35{,}75 = 40{,}25$ kN угору. Шарнірно-нерухома опора також утримує силу 5 kN, через що вся балка розтягнута силою 5 kN.

## Вузлові навантаження {#nodal-loads}

```ts
lc.createNodalLoad(node, { [DofID.Dx]: fx, [DofID.Dz]: fz, [DofID.Ry]: my }, lcs)
```

Задавайте лише ті складові, які потрібні. Значення подаються в глобальних осях або, якщо `lcs` дорівнює `true`, у власних осях вузла, повернутого за допомогою [`updateLcs`](/uk/solver/nodes-supports#inclined-supports). Сила, прикладена за напрямом ступеня вільності, який закріплює опора, передається безпосередньо в реакцію і нічого не згинає.

## Навантаження на стрижні {#member-loads}

| Метод | Значення | Навантаження |
| --- | --- | --- |
| `createBeamElementUniformEdgeLoad(el, [fx, fz], lcs)` | N/m | рівномірне по всьому стрижню |
| `createBeamElementTrapezoidalEdgeLoad(el, [fx1, fz1], [fx2, fz2], lcs)` | N/m | лінійне, від першого вузла до другого |
| `createBeamConcentratedLoad(el, [fx, fz, my, a], lcs)` | N, N·m, m | сила і зосереджений момент на відстані `a` метрів від першого вузла |

Розподілені навантаження завжди діють по всій довжині стрижня. Щоб навантажити лише частину прольоту, поділіть стрижень вузлом там, де навантаження починається: додатковий вузол не змінює жодного результату. Зосереджену силу або момент можна прикласти будь-де на стрижні.

### Глобальні чи локальні осі {#global-or-local-axes}

Останній аргумент, `lcs`, визначає, у яких осях задано складові:

- `false`: глобальні x і z. `fz` діє вертикально незалежно від нахилу стрижня.
- `true`: локальні осі стрижня x (уздовж нього) і z (поперек нього). `fz` діє перпендикулярно до стрижня.

На горизонтальному стрижні, заданому зліва направо, обидва варіанти однакові; на заданому справа наліво локальне `fz` напрямлене вгору.

::callout{type="info" title="Розподілені навантаження задаються на метр довжини стрижня"}
В обох випадках навантаження задається на метр власної довжини стрижня. На крокві завдовжки 5 m, що перекриває 4 m по горизонталі, `[0, 10e3]` у глобальних осях дає разом 50 kN. Снігове навантаження 10 kN/m, віднесене до горизонтальної проєкції, дорівнює $10 \cdot 4/5 = 8$ kN/m уздовж крокви: задайте `[0, 8e3]`.
::

## Зміна або вилучення навантаження {#change-or-remove-a-load}

Кожен метод `create…` повертає навантаження. Змініть його значення та розрахуйте знову:

```ts
const q = lc.createBeamElementUniformEdgeLoad(1, [0, 10e3], true)
solver.solve()
q.values = [0, 20e3] // удвічі більше навантаження
solver.solve()
```

Навантаження зберігаються у звичайних масивах `lc.nodalLoadList` і `lc.elementLoadList` (навантаження на стрижні й температурні навантаження), тож `lc.elementLoadList.splice(index, 1)` вилучає одне з них. Назви властивостей кожного навантаження наведено в [довіднику API](/uk/solver/reference#loads).

Зміни температури та осідання опор — теж навантаження: див. [Температура та осідання опор](/uk/solver/temperature-settlements).
