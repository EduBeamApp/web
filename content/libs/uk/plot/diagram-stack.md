# DiagramStack

`DiagramStack` малює рисунок, знайомий з кожного підручника будівельної механіки: пряму балку з опорами, навантаженням і реакціями, а під нею на тій самій осі x епюри поперечних сил V(x), згинальних моментів M(x) і прогинів w(x). Курсор зчитує всі рядки одночасно, а за бажанням зосереджену силу можна перетягувати вздовж балки.

```vue
<DiagramStack :solver="solver" />
```

![DiagramStack: шарнірно оперта балка прольотом 6 m із силою 20 kN, яку читач може перетягувати, тут на відстані 4,3 m від лівої опори; реакції 5,7 kN і 14,3 kN, поперечна сила під силою стрибком змінюється з 5,7 kN на −14,3 kN, згинальний момент там досягає максимуму 24,4 kNm, а найбільший прогин становить 17 mm](/screenshots/uk/p2p-plot-diagram-stack.webp){.shot-lg}

Стрижні мають утворювати одну горизонтальну лінію, накреслену зліва направо. Усе інше — похилу чи ламану лінію або стрижень, накреслений справа наліво, — компонент відхиляє з помилкою, а не малює неправильно, бо вісь x рисунка — це вісь балки. Усі пропси наведено в [API компонентів](/uk/plot/components#diagramstack).

## Рядки {#rows}

| Проп | Типово | Що задає |
| --- | --- | --- |
| `rows` | `['V', 'M', 'w']` | епюри згори вниз; доступна також `'N'` |
| `loadRow` | `true` | балку з опорами, навантаженням і реакціями над рядками |
| `members` | усі стрижні | стрижні, що утворюють балку, якщо в моделі є й інші |
| `rowHeights` | N 100, V 116, M 128, w 76 px | висоти рядків; за ширини менше ніж 560 px трохи менші |
| `maxHeight` | немає | рядки зменшуються, щонайбільше до 60 %, щоб рисунок умістився; текст зберігає розмір |
| `ranges` | власний для кожного рядка | фіксовані діапазони значень для рядків, в одиницях СІ |

V і N відкладено додатними вгору, M і w — додатними вниз, як у більшості підручників: додатний момент і прогин униз розташовані під віссю. Кожен рядок підписує свої екстремальні значення.

## Курсор для зчитування {#the-reading-cursor}

`hover` типово ввімкнено. Коли вказівник рухається над рисунком, через усі рядки проходить вертикальний курсор, а значення кожного рядка показано в плашці. У межах 8 px від стрибка, тобто біля зосередженої сили чи опори, курсор прив’язується до нього, а V показує обидва боки, як `5.7 → −14.3 kN` під силою на рисунку вище. Значення також надсилаються як подія:

```vue
<DiagramStack :solver="solver" @readout="(r) => (reading = r)" />
```

Зчитані значення мають вигляд `{ x, values }`: `x` у метрах уздовж балки та `{ left, right }` для кожного рядка в одиницях СІ; коли вказівник залишає рисунок, подія передає `null`.

## Сила, яку перетягує читач {#a-load-the-reader-can-drag}

Передайте у `v-model:load-at` положення зосередженої сили, і вона отримає маркер: читач перетягує його вказівником або переводить на нього фокус і рухає клавішами зі стрілками. Компонент лише повідомляє нове положення. Розрахуйте балку знову із силою в цьому місці й передайте новий розв’язувач назад, як це робить `MovingLoad.vue`:

```vue [MovingLoad.vue]
<script setup lang="ts">
import { computed, ref } from 'vue'
import { DofID, LinearStaticSolver } from '@edubeam/fem'
import { beamLine, DiagramStack, lineDiagram, modelFromSolver, rowRange, type StackRow } from '@edubeam/plot'

const L = 6 // m
const P = 20e3 // N

/** Розрахована балка із зосередженою силою на відстані `at` метрів від A. */
const solveWithLoadAt = (at: number): LinearStaticSolver => {
  const solver = new LinearStaticSolver()
  const { domain } = solver
  domain.createMaterial(1, { e: 210e9, g: 81e9 })
  domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, h: 0.2, k: 1e32 })
  domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz])
  domain.createNode('B', [L, 0, 0], [DofID.Dz])
  domain.createBeam2D(1, ['A', 'B'], 1, 1)
  solver.loadCases[0].createBeamConcentratedLoad(1, [0, P, 0, at], true)
  solver.solve()
  return solver
}

/** Діапазон кожного рядка для всіх положень сили, щоб епюри росли й зменшувалися, а не змінювали масштаб. */
const rows: StackRow[] = ['V', 'M', 'w']
const envelope = (() => {
  const ranges: Partial<Record<StackRow, [number, number]>> = {}
  for (let at = 0.25; at < L; at += 0.25) {
    const model = modelFromSolver(solveWithLoadAt(at))
    const line = beamLine(model)
    for (const row of rows) {
      const [lo, hi] = rowRange(lineDiagram(model, line, row))
      const [min, max] = ranges[row] ?? [0, 0]
      ranges[row] = [Math.min(min, lo), Math.max(max, hi)]
    }
  }
  return ranges
})()

const at = ref(2)
const solver = computed(() => solveWithLoadAt(at.value))
</script>

<template>
  <DiagramStack v-model:load-at="at" :solver="solver" :rows="rows" :ranges="envelope" load-label="P = 20 kN" />
  <p>The load is {{ at.toFixed(2) }} m from A.</p>
</template>
```

Коли сила стоїть на відстані 4,3 m, рисунок показує реакції 5,7 kN і 14,3 kN, стрибок поперечної сили під силою з 5,7 на −14,3 kN і момент у цьому місці $M = 5{,}67 \cdot 4{,}3 = 24{,}4$ kNm. Без `ranges` кожен рядок під час руху сили змінював би масштаб за власними екстремумами, і здавалося б, що епюри взагалі не змінюються.

| Проп | Типово | Що задає |
| --- | --- | --- |
| `loadAt` | немає | положення сили, m від початку лінії; з `v-model:load-at` |
| `loadLabel` | `P = …` | текст біля маркера |
| `loadStep` | 0.05 | крок, до якого округлюється перетягування, m; на цей крок маркер зсувають клавіші зі стрілками |

Маркер — це `role="slider"`, який отримує фокус і повідомляє екранним читачам свій діапазон і положення. Клавіші зі стрілками зсувають його на `loadStep`, Page Up і Page Down — на 1 m, а Home і End — на кінці балки. На сенсорному екрані його можна перетягувати пальцем, і вертикальне прокручування над рисунком при цьому працює.

Маркер замінює собою зосереджену силу, яку розрахована модель має в точці `loadAt`: цю силу намальовано як маркер, підписаний її величиною, якщо ви не задали `loadLabel`. Прикладіть силу в моделі в тому самому місці, як це робить `solveWithLoadAt`.

## Розміри й рендеринг на сервері {#size-and-server-rendering}

Рисунок вимірює свій контейнер і будує компонування на цю ширину, але не менше ніж 320 px. Поки виміряти контейнер неможливо, він використовує `width`, типово 720 px. Текст має розмір 12,5 px (`fontSize`) і разом із рисунком ніколи не зменшується.
