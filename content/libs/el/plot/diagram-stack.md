# DiagramStack

Το `DiagramStack` σχεδιάζει το σχήμα που υπάρχει σε κάθε βιβλίο Στατικής: μια ευθύγραμμη δοκό με τις στηρίξεις, τα φορτία και τις αντιδράσεις της, και από κάτω, στον ίδιο άξονα x, την τέμνουσα δύναμη V(x), την καμπτική ροπή M(x) και το βέλος κάμψης w(x). Ένας δρομέας διαβάζει όλες τις γραμμές μαζί, και ένα προαιρετικό συγκεντρωμένο φορτίο μπορεί να μετακινηθεί κατά μήκος της δοκού.

```vue
<DiagramStack :solver="solver" />
```

![DiagramStack: αμφιέρειστη δοκός 6 m με φορτίο 20 kN που ο αναγνώστης μπορεί να μετακινήσει, εδώ 4,3 m από την αριστερή στήριξη· αντιδράσεις 5,7 kN και 14,3 kN, η τέμνουσα δύναμη αλλάζει απότομα κάτω από το φορτίο από 5,7 kN σε −14,3 kN, η καμπτική ροπή φτάνει εκεί το μέγιστο 24,4 kNm, και η ελαστική γραμμή με μέγιστη τιμή 17 mm](/screenshots/el/p2p-plot-diagram-stack.webp){.shot-lg}

Τα μέλη πρέπει να σχηματίζουν μία οριζόντια γραμμή, ορισμένη από αριστερά προς τα δεξιά. Οτιδήποτε άλλο, δηλαδή κεκλιμένη ή τεθλασμένη γραμμή ή μέλος ορισμένο από δεξιά προς τα αριστερά, απορρίπτεται με σφάλμα αντί να σχεδιαστεί λάθος, επειδή ο άξονας x του σχήματος είναι ο άξονας της δοκού. Όλα τα props περιγράφονται στο [API των components](/el/plot/components#diagramstack).

## Γραμμές {#rows}

| Prop | Προεπιλογή | Ορίζει |
| --- | --- | --- |
| `rows` | `['V', 'M', 'w']` | τα διαγράμματα, από πάνω προς τα κάτω· διαθέσιμο είναι και το `'N'` |
| `loadRow` | `true` | τη δοκό με τις στηρίξεις, τα φορτία και τις αντιδράσεις πάνω από τις γραμμές |
| `members` | όλα τα μέλη | τα μέλη που σχηματίζουν τη δοκό, όταν το μοντέλο έχει και άλλα |
| `rowHeights` | N 100, V 116, M 128, w 76 px | τα ύψη των γραμμών· λίγο μικρότερα όταν το πλάτος είναι κάτω από 560 px |
| `maxHeight` | κανένα | οι γραμμές μικραίνουν, έως το 60 % το πολύ, ώστε να χωρέσει το σχήμα· το κείμενο κρατά το μέγεθός του |
| `ranges` | το εύρος κάθε γραμμής | σταθερά εύρη τιμών ανά γραμμή, σε μονάδες SI |

Τα V και N σχεδιάζονται θετικά προς τα πάνω, τα M και w θετικά προς τα κάτω, όπως στα περισσότερα βιβλία: μια θετική ροπή (εφελκυσμός στις κάτω ίνες) και ένα βέλος κάμψης προς τα κάτω βρίσκονται κάτω από τον άξονα. Κάθε γραμμή γράφει τις ακραίες τιμές της.

## Ο δρομέας ανάγνωσης {#the-reading-cursor}

Το `hover` είναι ενεργό από προεπιλογή. Όταν μετακινείτε τον δείκτη πάνω από το σχήμα, μια κατακόρυφη γραμμή διασχίζει όλες τις γραμμές και η τιμή κάθε γραμμής εμφανίζεται σε μια ετικέτα. Σε απόσταση έως 8 px από ένα άλμα, σε συγκεντρωμένο φορτίο ή σε στήριξη, ο δρομέας προσκολλάται σε αυτό και το V δείχνει και τις δύο πλευρές, όπως `5.7 → −14.3 kN` κάτω από το φορτίο στο παραπάνω σχήμα. Οι τιμές εκπέμπονται επίσης ως συμβάν:

```vue
<DiagramStack :solver="solver" @readout="(r) => (reading = r)" />
```

Μια ανάγνωση έχει τη μορφή `{ x, values }`: το `x` σε μέτρα κατά μήκος της δοκού και `{ left, right }` για κάθε γραμμή σε μονάδες SI· όταν ο δείκτης φύγει από το σχήμα, είναι `null`.

## Φορτίο που μετακινεί ο αναγνώστης {#a-load-the-reader-can-drag}

Δώστε στο `v-model:load-at` τη θέση ενός συγκεντρωμένου φορτίου και αυτό αποκτά λαβή: ο αναγνώστης τη σύρει με τον δείκτη ή μεταφέρει την εστίαση σε αυτήν και χρησιμοποιεί τα πλήκτρα βέλους. Το component αναφέρει μόνο τη νέα θέση. Επιλύστε ξανά τη δοκό με το φορτίο σε εκείνη τη θέση και δώστε πίσω τον νέο επιλυτή, όπως κάνει το `MovingLoad.vue`:

```vue [MovingLoad.vue]
<script setup lang="ts">
import { computed, ref } from 'vue'
import { DofID, LinearStaticSolver } from '@edubeam/fem'
import { beamLine, DiagramStack, lineDiagram, modelFromSolver, rowRange, type StackRow } from '@edubeam/plot'

const L = 6 // m
const P = 20e3 // N

/** Η επιλυμένη δοκός με το συγκεντρωμένο φορτίο σε απόσταση `at` μέτρων από το A. */
const solveWithLoadAt = (at: number): LinearStaticSolver => {
  const solver = new LinearStaticSolver()
  const { domain } = solver
  domain.createMaterial(1, { e: 210e9, g: 81e9 })
  domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, h: 0.2, k: 1e32 })
  domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz])
  domain.createNode('B', [L, 0, 0], [DofID.Dz])
  domain.createBeam2D(1, ['A', 'B'], 1, 1)
  solver.loadCases[0].createBeamConcentratedLoad(1, [0, P, 0, at], true)
  solver.solve()
  return solver
}

/** Το εύρος κάθε γραμμής για όλες τις θέσεις του φορτίου, ώστε τα διαγράμματα να μεγαλώνουν και να μικραίνουν αντί να αλλάζουν κλίμακα. */
const rows: StackRow[] = ['V', 'M', 'w']
const envelope = (() => {
  const ranges: Partial<Record<StackRow, [number, number]>> = {}
  for (let at = 0.25; at < L; at += 0.25) {
    const model = modelFromSolver(solveWithLoadAt(at))
    const line = beamLine(model)
    for (const row of rows) {
      const [lo, hi] = rowRange(lineDiagram(model, line, row))
      const [min, max] = ranges[row] ?? [0, 0]
      ranges[row] = [Math.min(min, lo), Math.max(max, hi)]
    }
  }
  return ranges
})()

const at = ref(2)
const solver = computed(() => solveWithLoadAt(at.value))
</script>

<template>
  <DiagramStack v-model:load-at="at" :solver="solver" :rows="rows" :ranges="envelope" load-label="P = 20 kN" />
  <p>The load is {{ at.toFixed(2) }} m from A.</p>
</template>
```

Με το φορτίο στα 4,3 m, το σχήμα δείχνει τις αντιδράσεις 5,7 kN και 14,3 kN, το άλμα της τέμνουσας κάτω από το φορτίο από 5,7 σε −14,3 kN και τη ροπή $M = 5{,}67 \cdot 4{,}3 = 24{,}4$ kNm στο ίδιο σημείο. Χωρίς `ranges`, κάθε γραμμή θα προσαρμοζόταν στα δικά της ακρότατα καθώς μετακινείται το φορτίο, και τα διαγράμματα θα έμοιαζαν να μην αλλάζουν καθόλου.

| Prop | Προεπιλογή | Ορίζει |
| --- | --- | --- |
| `loadAt` | κανένα | τη θέση του φορτίου, σε m από την αρχή της γραμμής· με `v-model:load-at` |
| `loadLabel` | `P = …` | το κείμενο δίπλα στη λαβή |
| `loadStep` | 0.05 | το βήμα σε m στο οποίο στρογγυλεύεται η μετακίνηση· κατά τόσο μετακινούν το φορτίο τα πλήκτρα βέλους |

Η λαβή είναι ένα στοιχείο `role="slider"` που δέχεται εστίαση και ανακοινώνει στους αναγνώστες οθόνης το εύρος και τη θέση της. Τα πλήκτρα βέλους τη μετακινούν κατά `loadStep`, τα Page Up και Page Down κατά 1 m, και τα Home και End στα άκρα της δοκού. Σε οθόνη αφής μπορεί να συρθεί με το δάχτυλο, ενώ η κατακόρυφη κύλιση πάνω από το σχήμα εξακολουθεί να λειτουργεί.

Η λαβή αντικαθιστά τη συγκεντρωμένη δύναμη που έχει το επιλυμένο μοντέλο στη θέση `loadAt`: αυτή η δύναμη σχεδιάζεται ως λαβή, με το μέγεθός της ως ετικέτα, εκτός αν δώσετε `loadLabel`. Βάλτε το φορτίο στο μοντέλο στην ίδια θέση, όπως κάνει η `solveWithLoadAt`.

## Μέγεθος και απόδοση στον διακομιστή {#size-and-server-rendering}

Το σχήμα μετρά το πλάτος του περιέκτη του και προσαρμόζει τη διάταξή του σε αυτό, τουλάχιστον 320 px. Πριν μπορέσει να μετρήσει, χρησιμοποιεί το `width`, από προεπιλογή 720 px. Το κείμενο έχει μέγεθος 12,5 px (`fontSize`) και δεν μικραίνει ποτέ μαζί με το σχήμα.
