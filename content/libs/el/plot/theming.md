# Θέματα και χρώματα

Ένα σχήμα παίρνει τα χρώματά του από τις μεταβλητές CSS (custom properties) της σελίδας, οπότε το φωτεινό και το σκοτεινό θέμα του ιστότοπου εφαρμόζονται χωρίς επιπλέον εργασία. Όπου η σελίδα δεν ορίζει καμία, τη θέση τους παίρνουν τα χρώματα συστήματος του CSS, τα οποία ακολουθούν το `color-scheme` της σελίδας. Χωρίς καμία ρύθμιση, το σχήμα είναι μαύρο σε λευκό σε φωτεινή σελίδα και ανοιχτόχρωμο σε σκούρο φόντο σε σκοτεινή.

## Μεταβλητές CSS {#custom-properties}

| Χρήση | Μεταβλητή CSS | Εναλλακτική τιμή |
| --- | --- | --- |
| Μέλη, στηρίξεις, κείμενο | `--figure-ink`, μετά `--ink` | `CanvasText` |
| Φόντο, περιγράμματα ετικετών | `--paper` | `Canvas` |
| Γραμμές διάστασης, άξονες | `--muted` | `GrayText` |
| Κόμβοι, το μετακινούμενο φορτίο | `--brand` | `#4f46e5` |
| Αξονική δύναμη | `--color-normal` | `#2222ff` |
| Τέμνουσα δύναμη | `--color-shear` | `#00af00` |
| Καμπτική ροπή | `--color-moment` | `#ff2222` |
| Παραμορφωμένος φορέας | `--figure-ink`, μετά `--ink` | `CanvasText` |
| Φορτία | `--color-load` | `#ff8700` |
| Αντιδράσεις | `--color-reaction` | `#a020f0` |
| Εφελκυόμενες ράβδοι δικτυώματος | `--color-tension`, μετά `--color-moment` | `#ff2222` |
| Θλιβόμενες ράβδοι δικτυώματος | `--color-compression`, μετά `--color-normal` | `#2222ff` |
| Γραμματοσειρά | `--ebp-font`, μετά `--font-sans` | `inherit` |

Ορίστε τις μεταβλητές σε οποιοδήποτε στοιχείο πάνω από το σχήμα, για ολόκληρο τον ιστότοπο στο `:root`:

```css
:root {
  --ink: #1b1b3a;
  --paper: #ffffff;
  --color-moment: #d7263d;
}

.dark {
  --ink: #eeeeff;
  --paper: #0b0d1f;
}
```

Οι ετικέτες έχουν περίγραμμα στο χρώμα του `--paper`, ώστε να διαβάζονται πάνω από τη διαγράμμιση: ταιριάξτε το με το φόντο πάνω στο οποίο βρίσκεται το σχήμα.

## Το prop `colors` {#the-colors-prop}

Για να χρωματίσετε ένα μόνο σχήμα, δώστε όποιους τόνους θέλετε με το όνομά τους:

```vue
<StructurePlot :solver="solver" :colors="{ moment: '#c00', paper: 'transparent' }" />
```

Οι τόνοι είναι `ink`, `paper`, `muted`, `brand`, `normal`, `shear`, `moment`, `deformed`, `load`, `reaction`, `tension` και `compression`. Λειτουργεί οποιοδήποτε χρώμα CSS, ακόμη και ένα `var(…)`. Η προεπιλεγμένη τιμή κάθε τόνου βρίσκεται στο `DEFAULT_COLORS`.

## Ασπρόμαυρα {#black-and-white}

Για ένα διαγώνισμα που θα φωτοτυπηθεί ή για ασπρόμαυρη εκτύπωση, ορίστε κάθε χρωματιστό τόνο ίσο με το χρώμα του κειμένου:

```vue
<script setup lang="ts">
import type { PlotColors } from '@edubeam/plot'

const print: Partial<PlotColors> = {
  ink: '#000', paper: '#fff', muted: '#555', brand: '#000',
  normal: '#000', shear: '#000', moment: '#000', deformed: '#000',
  load: '#000', reaction: '#000', tension: '#000', compression: '#000',
}
</script>

<template>
  <StructurePlot :solver="solver" :colors="print" :animate="false" />
</template>
```

Τα διαγράμματα διαβάζονται και χωρίς χρώμα: είναι διαγραμμισμένα και η ροπή σχεδιάζεται στην εφελκυόμενη πλευρά.

## Χρώματα σε αρχείο SVG {#colours-in-an-svg-file}

Ένα αρχείο που γράφεται από τη [`structureSvg`](/el/plot/functions#a-standalone-svg-file) δεν έχει σελίδα γύρω του, οπότε χρησιμοποιεί απλά χρώματα: τα `PRINT_COLORS`, δηλαδή τα χρώματα της εφαρμογής EduBeam σε λευκό φόντο. Η επιλογή `colors` δέχεται τους ίδιους τόνους με το prop, οπότε το παραπάνω ασπρόμαυρο σύνολο λειτουργεί κι εδώ:

```ts
structureSvg(model, { colors: print }) // μαύρο σε λευκό
structureSvg(model, { background: false }) // χωρίς φόντο, για χρωματιστή διαφάνεια
```

Μόνο απλά χρώματα: ένα `var(…)` δεν σημαίνει τίποτα για το Word ή το Inkscape.

## Γραμματοσειρές {#fonts}

Το κείμενο χρησιμοποιεί τη γραμματοσειρά της σελίδας, μέσω `--ebp-font` ή `--font-sans`, με αριθμούς σταθερού πλάτους. Τα ονόματα των γραμμών, όπως V(x) στο `DiagramStack`, στοιχειοθετούνται με τις γραμματοσειρές του KaTeX όταν η σελίδα τις φορτώνει, διαφορετικά με μια γραμματοσειρά serif. Ένα αρχείο SVG χρησιμοποιεί την επιλογή `fontFamily`, από προεπιλογή Helvetica ή Arial, αφού δεν μπορεί να γνωρίζει τη γραμματοσειρά της σελίδας.

## Δικό σας στυλ για τα κινούμενα εφέ {#restyling-the-animation}

Οι λίγοι κανόνες CSS που χρειάζεται ένα σχήμα ενσωματώνονται σε κάθε SVG, οπότε δεν χρειάζεται φύλλο στυλ. Κάθε κλάση έχει το πρόθεμα `ebp-` και η σελίδα μπορεί να τις αντικαταστήσει. Κάθε επίπεδο είναι ένα `<g class="ebp-layer ebp-layer-{name}">`, το οποίο παίρνει την κλάση `ebp-on` όταν εμφανίζεται:

```css
/* Πιο αργή εμφάνιση, για μεγάλο αμφιθέατρο */
.slides .ebp-animate .ebp-layer {
  transition-duration: 1s;
}
```

Το `PLOT_CSS` εξάγει τους ενσωματωμένους κανόνες και το `toneVars(colors)` τις μεταβλητές CSS που ορίζει ένα σχήμα στο ριζικό του στοιχείο, για να φτιάξετε δικά σας σχήματα με τις [συναρτήσεις σχεδίασης](/el/plot/functions#drawing).
