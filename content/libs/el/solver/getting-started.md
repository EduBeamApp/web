# Πρώτα βήματα {#getting-started}

Το @edubeam/fem είναι ο επιλυτής πεπερασμένων στοιχείων πίσω από το [EduBeam]{.edubeam}: κάθε διάγραμμα, αντίδραση και βέλος κάμψης που δείχνει η εφαρμογή προέρχεται από αυτόν. Μπορείτε να τον χρησιμοποιήσετε από τον δικό σας κώδικα, στο πρόγραμμα περιήγησης ή στο Node, για να επιλύετε επίπεδες δοκούς, πλαίσια και δικτυώματα: να δημιουργείτε ασκήσεις μαζί με τις λύσεις τους, να ελέγχετε εργασίες, να εκτελείτε παραμετρικές μελέτες ή να τοποθετείτε έναν επιλυτή πίσω από μια ιστοσελίδα.

::div{.actions}
[Επιλύστε την πρώτη σας δοκό](#a-simply-supported-beam) [Δείτε τα παραδείγματα](/el/solver/beams)
::

Είναι γραμμένος σε TypeScript, περιλαμβάνει τους δικούς του τύπους και είναι ελεύθερο λογισμικό με άδεια GPL-3.0. Τον δημιούργησε ο Bořek Patzák και τον αναπτύσσει μαζί με τον Jan Voříšek και άλλους συνεισφέροντες.

## Εγκατάσταση {#install}

```bash
npm install @edubeam/fem
```

Λειτουργεί με `import` και `require`, στο πρόγραμμα περιήγησης και στο Node 18 ή νεότερο, και έχει μία μόνο εξάρτηση, το [mathjs](https://mathjs.org). Έως την έκδοση 0.3.0 εγκαθιστόταν από το GitHub ως `ts-fem`: αν τον είχατε εγκαταστήσει έτσι, αλλάξτε τα imports σε `@edubeam/fem`. Τίποτε άλλο δεν άλλαξε.

Για να δοκιμάσετε το παρακάτω παράδειγμα σε έναν κενό φάκελο, μετατρέψτε τον σε έργο που χρησιμοποιεί `import` και μετά εγκαταστήστε τη βιβλιοθήκη:

```bash
npm init -y
npm pkg set type=module
npm install @edubeam/fem
```

Χωρίς `"type": "module"` στο `package.json` το παράδειγμα εκτελείται κανονικά, αλλά το Node εμφανίζει πρώτα μια προειδοποίηση.

## Η πρώτη σας δοκός {#a-simply-supported-beam}

Χαλύβδινη δοκός IPE 200 μήκους 6 m, σε άρθρωση και κύλιση, με ομοιόμορφα κατανεμημένο φορτίο 12 kN/m:

```ts [beam.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver

// Παντού μονάδες SI: m, N, Pa. Χάλυβας και IPE 200.
domain.createMaterial('steel', { e: 210e9, g: 81e9 })
domain.createCrossSection('IPE200', { a: 28.5e-4, iy: 1943e-8, k: 5 / 6 })

// Κόμβοι στα [x, y, z] σε μέτρα, με τους βαθμούς ελευθερίας που δεσμεύει η στήριξή τους
domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz]) // άρθρωση
domain.createNode('B', [6, 0, 0], [DofID.Dz]) // κύλιση
const beam = domain.createBeam2D(1, ['A', 'B'], 'steel', 'IPE200')

// 12 kN/m κατά τον τοπικό άξονα z του μέλους: προς τα κάτω σε δοκό σχεδιασμένη από αριστερά προς τα δεξιά
const lc = solver.loadCases[0]
lc.createBeamElementUniformEdgeLoad(1, [0, 12e3], true)

solver.solve()

console.log(beam.computeBendingMomentAt(lc, 3)) // N·m στο μέσο του ανοίγματος
console.log(beam.computeShearForceAt(lc, 0)) // N στο A
console.log(beam.computeLocalDefl(lc, 2).w[1]) // m στο μέσο του ανοίγματος
```

Αποθηκεύστε τον ως `beam.ts` και εκτελέστε `node beam.ts`: το Node 22.18 και νεότερο εκτελεί TypeScript όπως είναι. Το αρχείο δεν έχει σημειώσεις τύπων, οπότε σε παλαιότερο Node αποθηκεύστε το ως `beam.mjs`. Εμφανίζει:

```text [Έξοδος]
54000
36000
0.04990940552616746
```

Αυτές είναι οι τιμές του βιβλίου, $M = qL^2/8 = 54$ kNm και $V = qL/2 = 36$ kN. Ακολουθεί η ίδια δοκός, επιλυμένη στο πρόγραμμα περιήγησής σας από τον ίδιο επιλυτή:

::model-figure{caption="Η παραπάνω δοκός: 6 m, IPE 200, 12 kN/m"}
---

  - { member: 1, qz: 12 }

show: [nodeLabels]

Το βέλος κάμψης, 49,91 mm, είναι κατά 0,28 mm μεγαλύτερο από την τιμή Euler–Bernoulli $5qL^4/384EI = 49{,}63$ mm. Δεν πρόκειται για σφάλμα: το μέλος είναι δοκός Timoshenko και τα 0,28 mm είναι το $qL^2/8kGA$, η διατμητική παραμόρφωση αυτής της δοκού. Δώστε στο `k` τεράστια τιμή, π.χ. `1e32`, και η διαφορά εξαφανίζεται: δείτε [Διατμητική παραμόρφωση](/el/solver/materials-sections#shear-deformation).

## Τι κάνει ο κώδικας {#what-the-code-does}

::div{.steps}
### Δημιουργήστε έναν επιλυτή {#make-a-solver}

Το `new LinearStaticSolver()` έρχεται με ένα κενό `domain`, που περιέχει το μοντέλο, και μία περίπτωση φόρτισης, την `solver.loadCases[0]`.

### Περιγράψτε το μοντέλο {#describe-the-model}

Υλικά και διατομές, κόμβοι με τις στηρίξεις τους, και μετά μέλη μεταξύ των κόμβων. Κάθε αντικείμενο έχει μια ετικέτα, κείμενο ή αριθμό, με την οποία το αναφέρει το υπόλοιπο μοντέλο. Δείτε [Κόμβοι και στηρίξεις](/el/solver/nodes-supports), [Υλικά και διατομές](/el/solver/materials-sections) και [Μέλη και αρθρώσεις](/el/solver/members-hinges).

### Φορτίστε το {#load-it}

Τα φορτία ανήκουν σε μια περίπτωση φόρτισης: δυνάμεις στους κόμβους, φορτία κατά μήκος των μελών, θερμοκρασία και υποχωρήσεις στηρίξεων. Δείτε [Φορτία](/el/solver/loads).

### Επιλύστε {#solve}

Το `solver.solve()` συναρμολογεί και επιλύει κάθε περίπτωση φόρτισης. Δείτε [Επίλυση](/el/solver/solving).

### Διαβάστε τα αποτελέσματα {#read-the-results}

Εντατικά μεγέθη σε οποιοδήποτε σημείο ενός μέλους, βέλη κάμψης, δυνάμεις άκρων, μετακινήσεις κόμβων και αντιδράσεις. Δείτε [Ανάγνωση αποτελεσμάτων](/el/solver/results) και, για διαγράμματα, [Σχεδίαση αποτελεσμάτων](/el/solver/drawing).
::

## Μονάδες και πρόσημα με λίγα λόγια {#axes-and-signs}

Μονάδες SI στην είσοδο, μονάδες SI στην έξοδο. Το μοντέλο βρίσκεται στο επίπεδο x–z με τον **άξονα z προς τα κάτω**, οπότε θετικό `fz` ωθεί προς τα κάτω και η κορυφή ενός υποστυλώματος ύψους 4 m βρίσκεται στο $z = -4$. Οι θέσεις κατά μήκος ενός μέλους δίνονται σε μέτρα από τον πρώτο του κόμβο. Θετική είναι η ροπή που εφελκύει τις κάτω ίνες. Η σελίδα [Μονάδες και πρόσημα](/el/solver/conventions) έχει τον πλήρη κατάλογο.

## Έξι συνηθισμένες παγίδες {#pitfalls}

1. **Ο άξονας z δείχνει προς τα κάτω.** Τα φορτία βαρύτητας είναι θετικά και ό,τι βρίσκεται πάνω από τις στηρίξεις έχει αρνητικό z. Δείτε [Άξονες](/el/solver/conventions#axes).
2. **Η φορά του μέλους καθορίζει το πρόσημο των M και w.** Ορίστε τις δοκούς από αριστερά προς τα δεξιά και τα υποστυλώματα από κάτω προς τα πάνω, και τα πρόσημα θα είναι όπως στο βιβλίο. Δείτε [Φορά του μέλους](/el/solver/conventions#member-direction).
3. **Μια παράμετρος που λείπει δίνει `NaN` ή αριθμούς χωρίς νόημα, όχι σφάλμα.** Μια διατομή χρειάζεται `a`, `iy` και `k`· ένα υλικό χρειάζεται `e`, και `g` εκτός αν το `k` είναι τεράστιο. Δείτε [Υλικά και διατομές](/el/solver/materials-sections).
4. **Αφού προσθέσετε κόμβους ή μέλη ή αλλάξετε στηρίξεις,** θέστε `solver.codeNumberGenerated = false` πριν επιλύσετε ξανά. Δείτε [Νέα επίλυση μετά από αλλαγή](/el/solver/solving#solving-again-after-a-change).
5. **Οι αντιδράσεις επιστρέφονται ως μητρώο mathjs ή ως πίνακας (array),** με τη σειρά με την οποία δόθηκαν οι βαθμοί ελευθερίας της στήριξης. Δείτε [Αντιδράσεις](/el/solver/results#reactions).
6. **Ένας μηχανισμός δεν προκαλεί πάντα εξαίρεση.** Μετακίνηση της τάξης των $10^{12}$ m σημαίνει ότι ο φορέας μπορεί να κινηθεί ελεύθερα. Δείτε [Όταν η επίλυση αποτυγχάνει](/el/solver/solving#when-solving-fails).
