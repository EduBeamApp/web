# Κομβικά φορτία και φορτία μελών {#nodal-and-member-loads}

Τα φορτία ανήκουν σε μια περίπτωση φόρτισης. Ο επιλυτής ξεκινά με μία, την `solver.loadCases[0]`, και κάθε μέθοδος `create…` της προσθέτει ένα φορτίο και το επιστρέφει. Για περισσότερες περιπτώσεις και τους συνδυασμούς τους, δείτε [Περιπτώσεις φόρτισης](/el/solver/load-cases).

Οι τιμές δίνονται σε N, N/m και N·m και ακολουθούν τους [άξονες](/el/solver/conventions#axes): ο +z δείχνει προς τα κάτω και μια θετική ροπή είναι αριστερόστροφη.

## Δοκός με όλα τα είδη φορτίων {#a-beam-with-every-kind}

Δοκός μήκους 8 m με άρθρωση και κύλιση, με τραπεζοειδές φορτίο που αυξάνεται από 4 σε 10 kN/m, συγκεντρωμένο φορτίο 20 kN, συγκεντρωμένη ροπή 10 kNm και οριζόντια δύναμη στην κύλιση:

```ts [loads.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
domain.createMaterial(1, { e: 210e9, g: 81e9 })
domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, k: 1e32 })
domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz]) // άρθρωση
domain.createNode('B', [8, 0, 0], [DofID.Dz]) // κύλιση
domain.createBeam2D(1, ['A', 'B'], 1, 1)

const lc = solver.loadCases[0]
// 4 kN/m στο A, αυξάνεται σε 10 kN/m στο B, προς τα κάτω
lc.createBeamElementTrapezoidalEdgeLoad(1, [0, 4e3], [0, 10e3], false)
// [fx, fz, my, a]: 20 kN προς τα κάτω, 2 m από το A
lc.createBeamConcentratedLoad(1, [0, 20e3, 0, 2], false)
// αριστερόστροφη συγκεντρωμένη ροπή 10 kNm, 6 m από το A
lc.createBeamConcentratedLoad(1, [0, 0, 10e3, 6], false)
// 5 kN προς τα δεξιά στο B
lc.createNodalLoad('B', { [DofID.Dx]: 5e3 })
solver.solve()

// η getReactions δίνει Matrix του mathjs ή πίνακα: μετατρέψτε το σε πίνακα
const list = (v: unknown): number[] =>
  Array.isArray(v) ? v : (v as { toArray(): number[] }).toArray()

console.log(list(domain.getNode('A').getReactions(lc).values))
console.log(list(domain.getNode('B').getReactions(lc).values))
```

```text [Έξοδος]
[ -5000, -40250 ]
[ -35750 ]
```

Με το χέρι: η συνισταμένη του τραπεζοειδούς φορτίου είναι 56 kN και ασκείται 4,571 m από το A, οπότε η ισορροπία ροπών ως προς το A δίνει $8R_B = 56 \cdot 4{,}571 + 20 \cdot 2 - 10 = 286$, $R_B = 35{,}75$ kN προς τα πάνω και $R_A = 76 - 35{,}75 = 40{,}25$ kN προς τα πάνω. Η άρθρωση συγκρατεί επίσης τα 5 kN, οπότε ολόκληρη η δοκός εφελκύεται με 5 kN.

## Κομβικά φορτία {#nodal-loads}

```ts
lc.createNodalLoad(node, { [DofID.Dx]: fx, [DofID.Dz]: fz, [DofID.Ry]: my }, lcs)
```

Δώστε μόνο τις συνιστώσες που χρειάζεστε. Οι τιμές είναι στο καθολικό σύστημα ή, με `lcs` ίσο με `true`, στους δικούς άξονες του κόμβου, για κόμβο στραμμένο με την [`updateLcs`](/el/solver/nodes-supports#inclined-supports). Μια δύναμη σε βαθμό ελευθερίας που δεσμεύει η στήριξη περνά κατευθείαν στην αντίδραση και δεν κάμπτει τίποτε.

## Φορτία μελών {#member-loads}

| Μέθοδος | Τιμές | Φορτίο |
| --- | --- | --- |
| `createBeamElementUniformEdgeLoad(el, [fx, fz], lcs)` | N/m | ομοιόμορφο σε όλο το μέλος |
| `createBeamElementTrapezoidalEdgeLoad(el, [fx1, fz1], [fx2, fz2], lcs)` | N/m | γραμμικά μεταβαλλόμενο, από τον πρώτο κόμβο στον δεύτερο |
| `createBeamConcentratedLoad(el, [fx, fz, my, a], lcs)` | N, N·m, m | δύναμη και συγκεντρωμένη ροπή, `a` μέτρα από τον πρώτο κόμβο |

Τα κατανεμημένα φορτία καλύπτουν πάντα ολόκληρο το μέλος. Για φορτίο σε τμήμα ενός ανοίγματος, χωρίστε το μέλος με έναν κόμβο εκεί όπου αρχίζει το φορτίο: ένας επιπλέον κόμβος δεν αλλάζει κανένα αποτέλεσμα. Μια συγκεντρωμένη δύναμη ή ροπή μπορεί να βρίσκεται σε οποιοδήποτε σημείο του μέλους.

### Καθολικό ή τοπικό σύστημα {#global-or-local-axes}

Το τελευταίο όρισμα, `lcs`, ορίζει σε ποιους άξονες δίνονται οι συνιστώσες:

- `false`: καθολικοί x και z. Το `fz` ασκείται κατακόρυφα, όποια κι αν είναι η κλίση του μέλους.
- `true`: ο τοπικός x του μέλους (κατά μήκος του) και ο z (εγκάρσια). Το `fz` ασκείται κάθετα στο μέλος.

Σε οριζόντιο μέλος σχεδιασμένο από αριστερά προς τα δεξιά τα δύο ταυτίζονται· σε μέλος σχεδιασμένο από δεξιά προς τα αριστερά, το τοπικό `fz` δείχνει προς τα πάνω.

::callout{type="info" title="Τα κατανεμημένα φορτία δίνονται ανά μέτρο μήκους μέλους"}
Και τα δύο είδη ασκούνται ανά μέτρο του μήκους του ίδιου του μέλους. Σε αμείβοντα μήκους 5 m με οριζόντια προβολή 4 m, το `[0, 10e3]` στο καθολικό σύστημα δίνει συνολικά 50 kN. Ένα φορτίο χιονιού 10 kN/m μετρημένο στην οριζόντια προβολή είναι $10 \cdot 4/5 = 8$ kN/m κατά μήκος του αμείβοντα: δώστε `[0, 8e3]`.
::

## Αλλαγή ή αφαίρεση φορτίου {#change-or-remove-a-load}

Κάθε μέθοδος `create…` επιστρέφει το φορτίο. Αλλάξτε τις τιμές του και επιλύστε ξανά:

```ts
const q = lc.createBeamElementUniformEdgeLoad(1, [0, 10e3], true)
solver.solve()
q.values = [0, 20e3] // διπλάσιο φορτίο
solver.solve()
```

Τα φορτία βρίσκονται σε απλούς πίνακες, `lc.nodalLoadList` και `lc.elementLoadList` (φορτία μελών και θερμοκρασιακά φορτία), οπότε η `lc.elementLoadList.splice(index, 1)` αφαιρεί ένα. Τα ονόματα των ιδιοτήτων κάθε φορτίου αναφέρονται στην [τεκμηρίωση API](/el/solver/reference#loads).

Οι μεταβολές θερμοκρασίας και οι υποχωρήσεις στηρίξεων είναι επίσης φορτία: δείτε [Θερμοκρασία και υποχωρήσεις](/el/solver/temperature-settlements).
