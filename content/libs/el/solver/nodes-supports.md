# Κόμβοι και στηρίξεις {#nodes-and-supports}

Οι κόμβοι είναι τα σημεία όπου συνδέονται τα μέλη. Μια στήριξη δεν είναι ξεχωριστό αντικείμενο: είναι ο κατάλογος των βαθμών ελευθερίας που ο κόμβος κρατά δεσμευμένους. Τα αποσπάσματα κώδικα αυτής της σελίδας είναι τμήματα ενός προγράμματος όπως αυτό των [Πρώτων βημάτων](/el/solver/getting-started) και χρησιμοποιούν τα `solver`, `domain` και `lc` του.

## Δημιουργία κόμβου {#create-a-node}

```ts
domain.createNode(label, [x, y, z], bcs)
```

| Όρισμα | Τύπος | Σημασία |
| --- | --- | --- |
| `label` | `string \| number` | Το όνομά του, αποθηκευμένο ως κείμενο: το `1` και το `'1'` είναι ο ίδιος κόμβος |
| `coords` | `number[]` | `[x, y, z]` σε μέτρα, με `y = 0`. Ο z δείχνει προς τα κάτω. |
| `bcs` | `DofID[]` | Οι βαθμοί ελευθερίας που δεσμεύει η στήριξη. Παραλείψτε το για ελεύθερο κόμβο. |

Επιστρέφει το αντικείμενο `Node`· η `domain.getNode(label)` το βρίσκει ξανά. Μια ετικέτα που χρησιμοποιείται ήδη αντικαθιστά τον παλιό κόμβο.

```ts
import { DofID } from '@edubeam/fem'

const fixed = [DofID.Dx, DofID.Dz, DofID.Ry]
domain.createNode('A', [0, 0, 0], fixed)
domain.createNode('B', [0, 0, -4]) // ελεύθερος: η κορυφή υποστυλώματος ύψους 4 m
```

## Στηρίξεις {#supports}

Κάθε στήριξη της εφαρμογής EduBeam είναι ένα σύνολο δεσμευμένων βαθμών ελευθερίας:

| Στήριξη | `bcs` | Δεσμεύει |
| --- | --- | --- |
| Πάκτωση | `[DofID.Dx, DofID.Dz, DofID.Ry]` | τα πάντα |
| Άρθρωση | `[DofID.Dx, DofID.Dz]` | και τις δύο μετακινήσεις, στρέφεται ελεύθερα |
| Κύλιση | `[DofID.Dz]` | την κατακόρυφη μετακίνηση, κυλίεται κατά x |
| Κατακόρυφη κύλιση | `[DofID.Dx]` | την οριζόντια μετακίνηση, κυλίεται κατά z |
| Ολισθαίνουσα πάκτωση | `[DofID.Dz, DofID.Ry]` | την κατακόρυφη μετακίνηση και τη στροφή, ολισθαίνει κατά x |
| Κατακόρυφη ολισθαίνουσα πάκτωση | `[DofID.Dx, DofID.Ry]` | την οριζόντια μετακίνηση και τη στροφή, ολισθαίνει κατά z |
| Στροφική δέσμευση | `[DofID.Ry]` | τη στροφή |

Με τη σειρά με την οποία τους γράφετε επιστρέφονται και οι [αντιδράσεις](/el/solver/results#reactions). Ένας φορέας χρειάζεται τουλάχιστον τρεις δεσμευμένους βαθμούς ελευθερίας, διατεταγμένους έτσι ώστε να μην μπορεί να κινηθεί ως μηχανισμός: δείτε [Όταν η επίλυση αποτυγχάνει](/el/solver/solving#when-solving-fails).

Ένας δεσμευμένος βαθμός ελευθερίας μπορεί επίσης να μετακινηθεί κατά δεδομένη τιμή, δηλαδή υποχώρηση στήριξης: δείτε [Επιβαλλόμενες μετακινήσεις](/el/solver/temperature-settlements#prescribed-displacements).

## Κεκλιμένες στηρίξεις {#inclined-supports}

Μια κύλιση σε κεκλιμένο επίπεδο δεσμεύει τον κόμβο κάθετα στην κλίση, όχι κατακόρυφα. Στρέψτε τους άξονες του κόμβου με την `updateLcs`· τα `bcs` του αναφέρονται τότε στους στραμμένους άξονες. Στο πρόγραμμα των Πρώτων βημάτων δημιουργήστε τον B ως εξής:

```ts
const b = domain.createNode('B', [6, 0, 0], [DofID.Dz]) // δεσμεύει τον δικό του z
const a = (30 * Math.PI) / 180 // 30°, από τον x προς τον z: δεξιόστροφα στην οθόνη
b.updateLcs({ locx: [Math.cos(a), 0, Math.sin(a)], locy: [0, 1, 0] })
```

Το `locx` είναι ο δικός άξονας x του κόμβου ως διάνυσμα στο καθολικό σύστημα και το `locy` ο άξονας y του, που μένει `[0, 1, 0]`. Στην εφαρμογή EduBeam η ίδια γωνία είναι η *Γωνία τοπικού συστήματος κόμβου* του κόμβου, 30°.

Μετά την `solve()`, η κύλιση στο B ωθεί κάθετα στην κλίση και η άρθρωση στο A παραλαμβάνει την οριζόντια συνιστώσα:

```ts
b.getReactions(lc).values // [-41569]: N κατά τον δικό z του B, 36 kN / cos 30°
b.getReactions(lc, true).values // [20785, -36000, 0]: κατά x, κατά z, ροπή
```

::model-figure{caption="Κύλιση στραμμένη κατά 30°: η αντίδρασή της είναι κάθετη στην κλίση και η δοκός εφελκύεται"}
---

supports: { A: pin, B: roller }
angles: { B: 30 }
members: [[A, B]]
loads:
  - { member: 1, qz: 12 }
results: [M, N]
show: [nodeLabels]
---
::

Η κατακόρυφη συνιστώσα είναι πάλι $qL/2 = 36$ kN· η οριζόντια, $36 \tan 30° = 20{,}8$ kN, τραβά τη δοκό και από τα δύο άκρα. Η ροπή δεν αλλάζει.

Σε στραμμένο κόμβο οι μετακινήσεις και οι αντιδράσεις δίνονται στους δικούς του άξονες, εκτός αν δώσετε `true` για το καθολικό σύστημα. Τα κομβικά φορτία σε αυτόν είναι στο καθολικό σύστημα, εκτός αν ορίσετε διαφορετικά: δείτε [Κομβικά φορτία](/el/solver/loads#nodal-loads). Η `node.updateLcs()` χωρίς όρισμα επαναφέρει τους άξονες.

## Αλλαγή κόμβου {#change-a-node}

Ένας κόμβος είναι απλό αντικείμενο: αλλάξτε το `node.coords` για να τον μετακινήσετε ή αντικαταστήστε το `node.bcs`, ένα `Set<DofID>`, για να αλλάξετε τη στήριξή του.

```ts
domain.getNode('B').coords = [8, 0, 0] // μεγαλύτερο άνοιγμα: αρκεί η solve()
domain.getNode('A').bcs = new Set(fixed) // νέα στήριξη: πρώτα νέα αρίθμηση
solver.codeNumberGenerated = false
solver.solve()
```

Η αλλαγή στηρίξεων ή η προσθήκη και αφαίρεση κόμβων αλλάζει τις εξισώσεις: χωρίς `codeNumberGenerated = false` ο επιλυτής **κρατά σιωπηλά τις παλιές στηρίξεις**. Η ενότητα [Νέα επίλυση μετά από αλλαγή](/el/solver/solving#solving-again-after-a-change) αναφέρει ποιες αλλαγές το απαιτούν.
