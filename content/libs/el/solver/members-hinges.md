# Μέλη και αρθρώσεις {#members-and-hinges}

Κάθε μέλος είναι ένα `Beam2D`: ευθύγραμμη δοκός Timoshenko δύο κόμβων στο επίπεδο x–z, που φέρει αξονική δύναμη, τέμνουσα δύναμη και καμπτική ροπή. Αρθρώσεις στα άκρα του απελευθερώνουν εκεί τη ροπή. Τα αποσπάσματα κώδικα χρησιμοποιούν τα `solver`, `domain` και `lc` ενός προγράμματος όπως αυτό των [Πρώτων βημάτων](/el/solver/getting-started), με το υλικό του `'steel'` και τη διατομή του `'IPE200'`.

## Δημιουργία μέλους {#create-a-member}

```ts
domain.createBeam2D(label, [startNode, endNode], material, crossSection, hinges)
```

| Όρισμα | Τύπος | Σημασία |
| --- | --- | --- |
| `label` | `string \| number` | Το όνομά του, αποθηκευμένο ως κείμενο |
| `nodes` | `[label, label]` | Πρώτος και δεύτερος κόμβος. Ο τοπικός x πηγαίνει από τον πρώτο στον δεύτερο: δείτε [Φορά του μέλους](/el/solver/conventions#member-direction). |
| `mat`, `cs` | `string \| number` | Ετικέτες υλικού και διατομής |
| `hinges` | `[boolean, boolean]` | Άρθρωση στον πρώτο και στον δεύτερο κόμβο. Προαιρετικό· προεπιλογή `[false, false]`, άκαμπτα άκρα. |

Επιστρέφει το `Beam2D`: κρατήστε το για να διαβάζετε αποτελέσματα. Η `domain.getElement(label)` το βρίσκει ξανά, αλλά με τον γενικό τύπο `Element`, οπότε η TypeScript απαιτεί `as Beam2D` πριν διαβάσετε αποτελέσματα από αυτό.

Μέλη που συναντώνται σε κόμβο χωρίς αρθρώσεις συνδέονται άκαμπτα: στρέφονται μαζί. Οι κόμβοι, το υλικό και η διατομή μπορούν να δημιουργηθούν με οποιαδήποτε σειρά, αρκεί να υπάρχουν όλα κατά την επίλυση· αν λείπει κάποιο, η `solve()` προκαλεί `RangeError` με το όνομά του.

## Ακραίες αρθρώσεις {#end-hinges}

Μια άρθρωση ανήκει σε άκρο μέλους, όχι σε κόμβο. Εδώ το μέλος 2 αρχίζει με άρθρωση στο C, οπότε το C μεταφέρει από το άνοιγμα C–D στον πρόβολο A–C τέμνουσα δύναμη αλλά όχι ροπή:

```ts [hinge.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
const lc = solver.loadCases[0]
domain.createMaterial('steel', { e: 210e9, g: 81e9 })
domain.createCrossSection('IPE200', { a: 28.5e-4, iy: 1943e-8, k: 5 / 6 })

domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz, DofID.Ry])
domain.createNode('C', [2, 0, 0])
domain.createNode('D', [6, 0, 0], [DofID.Dz])
const ac = domain.createBeam2D(1, ['A', 'C'], 'steel', 'IPE200')
const cd = domain.createBeam2D(2, ['C', 'D'], 'steel', 'IPE200', [true, false])

lc.createBeamElementUniformEdgeLoad(2, [0, 10e3], true)
solver.solve()

cd.computeBendingMomentAt(lc, 0) // 0 στην άρθρωση
cd.computeBendingMomentAt(lc, 2) // 20000 N·m: qL²/8 του ανοίγματος 4 m
ac.computeBendingMomentAt(lc, 0) // -40000 N·m: τα 20 kN από το C–D, σε απόσταση 2 m
```

Όπου πολλά μέλη συναντώνται σε αρθρωτό κόμβο, αρκεί άρθρωση στα άκρα όλων των μελών εκτός από ένα. Λειτουργεί και η άρθρωση σε όλα τα άκρα: τότε τίποτε δεν στρέφει τον κόμβο και ο επιλυτής δίνει τη στροφή του ως 0. Μια ροπή όμως που ασκείται σε τέτοιον κόμβο δεν έχει τίποτε να την παραλάβει και [η επίλυση αποτυγχάνει](/el/solver/solving#when-solving-fails).

## Ράβδοι δικτυώματος {#truss-bars}

Βάλτε αρθρώσεις και στα δύο άκρα και το μέλος φέρει μόνο αξονική δύναμη, εφόσον φορτίζεται στους κόμβους του: είναι ράβδος δικτυώματος.

```ts
domain.createBeam2D('AE', ['A', 'E'], 'steel', 'bar', [true, true])
```

Το [παράδειγμα δικτυώματος](/el/solver/trusses) επιλύει με αυτόν τον τρόπο ολόκληρο δικτύωμα. Το παράδειγμα δικτυώματος της εφαρμογής EduBeam χρησιμοποιεί αντίθετα άκαμπτους κόμβους, με τόσο μεγάλο εμβαδόν ώστε οι καμπτικές ροπές να είναι αμελητέες δίπλα στις αξονικές δυνάμεις. Και τα δύο είναι έγκυρα μοντέλα· διαφέρουν μόνο σε αυτές τις μικρές ροπές. Το μητρώο στιβαρότητας της ίδιας της ράβδου εξάγεται στη σελίδα [Στοιχείο δικτυώματος](/el/elements/truss) του θεωρητικού εγχειριδίου.

## Τα μητρώα του στοιχείου {#the-element-s-matrices}

Για τη διδασκαλία της ίδιας της μεθόδου, ένα `Beam2D` δίνει τα μητρώα του ως μητρώα [mathjs](https://mathjs.org)· η `.toArray()` τα μετατρέπει σε `number[][]`:

| Μέθοδος | Επιστρέφει |
| --- | --- |
| `computeGeo()` | `{ l, dx, dz }`: μήκος και προβολές, m |
| `computeLocalStiffnessMtrx().answer` | μητρώο στιβαρότητας 6 × 6 στο τοπικό σύστημα, με τις αρθρώσεις απαλειμμένες (στατική συμπύκνωση) |
| `computeT()` | μητρώο μετασχηματισμού 6 × 6 από το καθολικό στο τοπικό σύστημα |
| `computeStiffness()` | μητρώο στιβαρότητας 6 × 6 στο καθολικό σύστημα, $T^T K_l T$ |
| `computeShearFactor()` | $\Phi = 12EI_y/kGAL^2$ |

```ts
ac.computeStiffness().toArray() // number[][], N/m, N και N·m
```

Οι βαθμοί ελευθερίας έχουν τη σειρά $u_1, w_1, \varphi_1, u_2, w_2, \varphi_2$. Η σελίδα [Στοιχείο δοκού](/el/elements/beam) του θεωρητικού εγχειριδίου εξάγει αυτά τα μητρώα και η σελίδα [Πώς επιλύει το EduBeam](/el/elements/analysis) δείχνει πώς συναρμολογούνται.
