# Начало работы {#getting-started}

@edubeam/fem — это решатель метода конечных элементов, на котором работает [EduBeam]{.edubeam}: все эпюры, реакции и прогибы, которые показывает приложение, вычислены им. С его помощью можно рассчитывать плоские балки, рамы и фермы из собственного кода, в браузере или в Node: генерировать задачи вместе с ответами, проверять домашние задания, проводить параметрические исследования или сделать решатель расчётным ядром веб-страницы.

::div{.actions}
[Рассчитать первую балку](#a-simply-supported-beam) [Примеры программ](/ru/solver/beams)
::

Библиотека написана на TypeScript, поставляется со своими типами и распространяется как свободное ПО по лицензии GPL-3.0. Её создал Борек Пацак, а развивает он вместе с Яном Воржишеком и другими участниками.

## Установка {#install}

```bash
npm install @edubeam/fem
```

Библиотека работает и с `import`, и с `require`, в браузере и в Node 18 и новее, и имеет одну зависимость — [mathjs](https://mathjs.org). До версии 0.3.0 её устанавливали с GitHub под именем `ts-fem`: если вы ставили её оттуда, замените импорты на `@edubeam/fem`. Больше ничего не изменилось.

Чтобы опробовать пример ниже в пустой папке, сделайте из неё проект, который использует `import`, и установите пакет:

```bash
npm init -y
npm pkg set type=module
npm install @edubeam/fem
```

Без `"type": "module"` в `package.json` пример тоже запустится, но Node сначала выведет предупреждение.

## Первая балка {#a-simply-supported-beam}

Стальная балка IPE 200 пролётом 6 м на шарнирно-неподвижной и шарнирно-подвижной опорах под нагрузкой 12 кН/м:

```ts [beam.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver

// Везде единицы СИ: m, N, Pa. Сталь и IPE 200.
domain.createMaterial('steel', { e: 210e9, g: 81e9 })
domain.createCrossSection('IPE200', { a: 28.5e-4, iy: 1943e-8, k: 5 / 6 })

// Узлы в точках [x, y, z] в метрах и степени свободы, которые закрепляет их опора
domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz]) // шарнирно-неподвижная
domain.createNode('B', [6, 0, 0], [DofID.Dz]) // шарнирно-подвижная
const beam = domain.createBeam2D(1, ['A', 'B'], 'steel', 'IPE200')

// 12 kN/m вдоль локальной оси z стержня: у балки, заданной слева направо, вниз
const lc = solver.loadCases[0]
lc.createBeamElementUniformEdgeLoad(1, [0, 12e3], true)

solver.solve()

console.log(beam.computeBendingMomentAt(lc, 3)) // N·m в середине пролёта
console.log(beam.computeShearForceAt(lc, 0)) // N в A
console.log(beam.computeLocalDefl(lc, 2).w[1]) // m в середине пролёта
```

Сохраните код в файл `beam.ts` и запустите `node beam.ts`: Node 22.18 и более новые версии выполняют TypeScript напрямую. Аннотаций типов в файле нет, поэтому для более старого Node достаточно сохранить его как `beam.mjs`. Программа выведет:

```text [Вывод]
54000
36000
0.04990940552616746
```

Это значения из учебника: $M = qL^2/8 = 54$ кН·м и $V = qL/2 = 36$ кН. Вот та же балка, рассчитанная тем же решателем прямо в вашем браузере:

Прогиб 49,91 мм на 0,28 мм больше, чем по формуле Эйлера — Бернулли $5qL^4/384EI = 49{,}63$ мм. Это не ошибка: стержень здесь — балка Тимошенко, а 0,28 мм — это $qL^2/8kGA$, вклад деформации сдвига этой балки. Задайте очень большое `k`, например `1e32`, и разница исчезнет: см. [Деформация сдвига](/ru/solver/materials-sections#shear-deformation).

## Что делает этот код {#what-the-code-does}

::div{.steps}
### Создайте решатель {#make-a-solver}

`new LinearStaticSolver()` создаётся с пустым `domain`, в котором хранится модель, и с одним случаем нагружения, `solver.loadCases[0]`.

### Опишите модель {#describe-the-model}

Материалы и сечения, узлы с опорами, затем стержни между узлами. У каждого объекта есть метка — строка или число, — по которой на него ссылается остальная модель. См. [Узлы и опоры](/ru/solver/nodes-supports), [Материалы и сечения](/ru/solver/materials-sections) и [Стержни и шарниры](/ru/solver/members-hinges).

### Приложите нагрузки {#load-it}

Нагрузки принадлежат случаю нагружения: силы в узлах, нагрузки вдоль стержней, температура и осадки опор. См. [Узловые нагрузки и нагрузки на стержни](/ru/solver/loads).

### Выполните расчёт {#solve}

`solver.solve()` собирает и решает все случаи нагружения. См. [Расчёт](/ru/solver/solving).

### Прочитайте результаты {#read-the-results}

Внутренние усилия в любой точке стержня, прогибы, концевые усилия, перемещения узлов и реакции. См. [Чтение результатов](/ru/solver/results), а для эпюр — [Отрисовка результатов](/ru/solver/drawing).
::

## Единицы и знаки вкратце {#axes-and-signs}

На входе единицы СИ, на выходе тоже СИ. Модель лежит в плоскости x–z, и **ось z направлена вниз**, поэтому положительная нагрузка `fz` действует вниз, а верх стойки высотой 4 м находится в точке $z = -4$. Положение на стержне задаётся в метрах от его первого узла. Положителен момент, растягивающий нижние волокна. Полный список — на странице [Единицы и знаки](/ru/solver/conventions).

## Шесть частых ошибок {#pitfalls}

1. **Ось z направлена вниз.** Нагрузки от силы тяжести положительны, а у всего, что выше опор, координата z отрицательна. См. [Оси](/ru/solver/conventions#axes).
2. **Направление стержня определяет знак M и w.** Задавайте балки слева направо, а стойки снизу вверх, и знаки будут как в учебнике. См. [Направление стержня](/ru/solver/conventions#member-direction).
3. **Пропущенный параметр даёт `NaN` или бессмыслицу, а не ошибку.** Сечению нужны `a`, `iy` и `k`; материалу — `e`, а также `g`, если только `k` не задан очень большим. См. [Материалы и сечения](/ru/solver/materials-sections).
4. **После добавления узлов или стержней или изменения опор** перед новым расчётом присвойте `solver.codeNumberGenerated = false`. См. [Повторный расчёт после изменений](/ru/solver/solving#solving-again-after-a-change).
5. **Реакции возвращаются как матрица mathjs или как массив**, в том порядке, в котором были перечислены степени свободы опоры. См. [Реакции](/ru/solver/results#reactions).
6. **Механизм не всегда вызывает исключение.** Перемещение порядка $10^{12}$ м означает, что конструкция может свободно двигаться. См. [Если расчёт не удался](/ru/solver/solving#when-solving-fails).
