# Узловые нагрузки и нагрузки на стержни {#nodal-and-member-loads}

Нагрузки принадлежат случаю нагружения. Решатель создаётся с одним случаем, `solver.loadCases[0]`, и каждый его метод `create…` добавляет нагрузку и возвращает её. О нескольких случаях и их сочетаниях рассказано на странице [Случаи нагружения](/ru/solver/load-cases).

Значения задаются в Н, Н/м и Н·м, а направления — по [осям](/ru/solver/conventions#axes): ось z направлена вниз, положительный момент действует против часовой стрелки.

## Балка со всеми видами нагрузок {#a-beam-with-every-kind}

Балка пролётом 8 м на шарнирно-неподвижной и шарнирно-подвижной опорах: погонная нагрузка, растущая от 4 до 10 кН/м, сосредоточенная сила 20 кН, сосредоточенный момент 10 кН·м и горизонтальная сила на подвижной опоре:

```ts [loads.ts]
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
domain.createMaterial(1, { e: 210e9, g: 81e9 })
domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, k: 1e32 })
domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz]) // шарнирно-неподвижная
domain.createNode('B', [8, 0, 0], [DofID.Dz]) // шарнирно-подвижная
domain.createBeam2D(1, ['A', 'B'], 1, 1)

const lc = solver.loadCases[0]
// 4 kN/m в A, растёт до 10 kN/m в B, вниз
lc.createBeamElementTrapezoidalEdgeLoad(1, [0, 4e3], [0, 10e3], false)
// [fx, fz, my, a]: 20 kN вниз, в 2 m от A
lc.createBeamConcentratedLoad(1, [0, 20e3, 0, 2], false)
// сосредоточенный момент 10 kNm против часовой стрелки, в 6 m от A
lc.createBeamConcentratedLoad(1, [0, 0, 10e3, 6], false)
// 5 kN вправо в B
lc.createNodalLoad('B', { [DofID.Dx]: 5e3 })
solver.solve()

// getReactions выдаёт матрицу mathjs или массив: приводим к массиву
const list = (v: unknown): number[] =>
  Array.isArray(v) ? v : (v as { toArray(): number[] }).toArray()

console.log(list(domain.getNode('A').getReactions(lc).values))
console.log(list(domain.getNode('B').getReactions(lc).values))
```

```text [Вывод]
[ -5000, -40250 ]
[ -35750 ]
```

Проверим вручную: равнодействующая погонной нагрузки равна 56 кН и приложена в 4,571 м от A, поэтому из уравнения моментов относительно A $8R_B = 56 \cdot 4{,}571 + 20 \cdot 2 - 10 = 286$, $R_B = 35{,}75$ кН вверх, а $R_A = 76 - 35{,}75 = 40{,}25$ кН вверх. Шарнирно-неподвижная опора к тому же удерживает силу 5 кН, поэтому вся балка растянута усилием 5 кН.

## Узловые нагрузки {#nodal-loads}

```ts
lc.createNodalLoad(node, { [DofID.Dx]: fx, [DofID.Dz]: fz, [DofID.Ry]: my }, lcs)
```

Задавайте только нужные составляющие. Значения задаются в глобальных осях или, если `lcs` равен `true`, в собственных осях узла — для узла, повёрнутого методом [`updateLcs`](/ru/solver/nodes-supports#inclined-supports). Сила, приложенная по закреплённой степени свободы, целиком уходит в реакцию и ничего не изгибает.

## Нагрузки на стержни {#member-loads}

| Метод | Значения | Нагрузка |
| --- | --- | --- |
| `createBeamElementUniformEdgeLoad(el, [fx, fz], lcs)` | Н/м | равномерная по всей длине стержня |
| `createBeamElementTrapezoidalEdgeLoad(el, [fx1, fz1], [fx2, fz2], lcs)` | Н/м | линейная, от первого узла ко второму |
| `createBeamConcentratedLoad(el, [fx, fz, my, a], lcs)` | Н, Н·м, м | сила и момент на расстоянии `a` метров от первого узла |

Погонные нагрузки всегда действуют по всей длине стержня. Для нагрузки на части пролёта разбейте стержень узлом там, где нагрузка начинается: лишний узел не меняет ни одного результата. Сосредоточенная сила или момент может находиться в любой точке стержня.

### Глобальные или локальные оси {#global-or-local-axes}

Последний аргумент, `lcs`, указывает, в каких осях заданы составляющие:

- `false`: глобальные оси x и z. `fz` действует вертикально при любом наклоне стержня.
- `true`: локальные оси стержня, x (вдоль него) и z (поперёк). `fz` действует перпендикулярно стержню.

У горизонтального стержня, нарисованного слева направо, оба варианта совпадают; у нарисованного справа налево локальная `fz` направлена вверх.

::callout{type="info" title="Погонные нагрузки — на метр длины стержня"}
Оба варианта действуют на метр собственной длины стержня. На стропильной ноге длиной 5 м с горизонтальной проекцией 4 м нагрузка `[0, 10e3]` в глобальных осях даёт в сумме 50 кН. Снеговая нагрузка 10 кН/м на метр горизонтальной проекции — это $10 \cdot 4/5 = 8$ кН/м вдоль стропильной ноги: задайте `[0, 8e3]`.
::

## Изменение и удаление нагрузки {#change-or-remove-a-load}

Каждый метод `create…` возвращает нагрузку. Измените её значения и выполните расчёт снова:

```ts
const q = lc.createBeamElementUniformEdgeLoad(1, [0, 10e3], true)
solver.solve()
q.values = [0, 20e3] // нагрузка вдвое больше
solver.solve()
```

Нагрузки хранятся в обычных массивах `lc.nodalLoadList` и `lc.elementLoadList` (нагрузки на стержни и температурные), поэтому `lc.elementLoadList.splice(index, 1)` удаляет одну из них. Имена свойств каждой нагрузки приведены в [справочнике API](/ru/solver/reference#loads).

Изменение температуры и осадки опор — тоже нагрузки: см. [Температура и осадки опор](/ru/solver/temperature-settlements).
