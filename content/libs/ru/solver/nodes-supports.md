# Узлы и опоры {#nodes-and-supports}

Узлы — это точки, в которых соединяются стержни. Опора — не отдельный объект: это список степеней свободы, которые закреплены в узле. Фрагменты кода на этой странице — части программы вроде той, что на странице [Начало работы](/ru/solver/getting-started), и используют её `solver`, `domain` и `lc`.

## Создание узла {#create-a-node}

```ts
domain.createNode(label, [x, y, z], bcs)
```

| Аргумент | Тип | Смысл |
| --- | --- | --- |
| `label` | `string \| number` | Имя узла, хранится как строка: `1` и `'1'` — один и тот же узел |
| `coords` | `number[]` | `[x, y, z]` в метрах, `y = 0`. Ось z направлена вниз. |
| `bcs` | `DofID[]` | Степени свободы, которые закрепляет опора. Для свободного узла не указывайте. |

Метод возвращает `Node`; `domain.getNode(label)` находит его снова. Если метка уже занята, новый узел заменяет старый.

```ts
import { DofID } from '@edubeam/fem'

const fixed = [DofID.Dx, DofID.Dz, DofID.Ry]
domain.createNode('A', [0, 0, 0], fixed)
domain.createNode('B', [0, 0, -4]) // свободный: верх стойки высотой 4 m
```

## Опоры {#supports}

Каждая опора приложения EduBeam — это набор закреплённых степеней свободы:

| Опора | `bcs` | Что закреплено |
| --- | --- | --- |
| Заделка | `[DofID.Dx, DofID.Dz, DofID.Ry]` | всё |
| Шарнир | `[DofID.Dx, DofID.Dz]` | оба перемещения, поворот свободен |
| Подвижный шарнир | `[DofID.Dz]` | вертикальное перемещение, узел перемещается вдоль x |
| Вертикальный подвижный шарнир | `[DofID.Dx]` | горизонтальное перемещение, узел перемещается вдоль z |
| Скользящая заделка | `[DofID.Dz, DofID.Ry]` | вертикальное перемещение и поворот, узел скользит вдоль x |
| Вертикальная скользящая заделка | `[DofID.Dx, DofID.Ry]` | горизонтальное перемещение и поворот, узел скользит вдоль z |
| Только поворот | `[DofID.Ry]` | только поворот |

В каком порядке вы их перечислите, в таком же вернутся [реакции](/ru/solver/results#reactions). Конструкции нужны как минимум три закреплённые степени свободы, расположенные так, чтобы она не могла двигаться как механизм: см. [Если расчёт не удался](/ru/solver/solving#when-solving-fails).

Закреплённую степень свободы можно также сместить на заданную величину, т. е. задать осадку опоры: см. [Заданные перемещения](/ru/solver/temperature-settlements#prescribed-displacements).

## Наклонные опоры {#inclined-supports}

Подвижная опора на наклонной плоскости удерживает узел поперёк уклона, а не по вертикали. Поверните оси узла методом `updateLcs`, и его `bcs` будут относиться к повёрнутым осям. В программе со страницы «Начало работы» создайте B так:

```ts
const b = domain.createNode('B', [6, 0, 0], [DofID.Dz]) // закрепляет свою ось z
const a = (30 * Math.PI) / 180 // 30°, от x к z: по часовой стрелке на экране
b.updateLcs({ locx: [Math.cos(a), 0, Math.sin(a)], locy: [0, 1, 0] })
```

`locx` — собственная ось x узла, заданная вектором в глобальных осях, а `locy` — его ось y, которая остаётся `[0, 1, 0]`. В приложении EduBeam тот же угол задаётся в поле *Угол локальной системы координат* узла: 30°.

После `solve()` опора B давит поперёк уклона, а горизонтальную составляющую воспринимает шарнирно-неподвижная опора A:

```ts
b.getReactions(lc).values // [-41569]: N вдоль собственной оси z узла B, 36 kN / cos 30°
b.getReactions(lc, true).values // [20785, -36000, 0]: вдоль x, вдоль z, момент
```

Вертикальная составляющая по-прежнему равна $qL/2 = 36$ кН; горизонтальная, $36 \tan 30° = 20{,}8$ кН, растягивает балку с обоих концов. Момент не меняется.

В повёрнутом узле перемещения и реакции выдаются в собственных осях узла; чтобы получить их в глобальных осях, передайте `true`. Узловые нагрузки на такой узел задаются в глобальных осях, если не указано иное: см. [Узловые нагрузки](/ru/solver/loads#nodal-loads). `node.updateLcs()` без аргумента возвращает оси в исходное положение.

## Изменение узла {#change-a-node}

Узел — обычный объект: чтобы переместить его, измените `node.coords`, а чтобы изменить опору, замените `node.bcs`, множество `Set<DofID>`.

```ts
domain.getNode('B').coords = [8, 0, 0] // пролёт длиннее: достаточно solve()
domain.getNode('A').bcs = new Set(fixed) // новая опора: сначала перенумеровать
solver.codeNumberGenerated = false
solver.solve()
```

Изменение опор, добавление и удаление узлов меняют систему уравнений: без `codeNumberGenerated = false` решатель **молча оставит старые опоры**. На странице [Повторный расчёт после изменений](/ru/solver/solving#solving-again-after-a-change) перечислено, каким изменениям это нужно.
