# Темы и цвета

Цвета рисунок берёт из пользовательских CSS-свойств (CSS-переменных) страницы, поэтому светлая и тёмная темы сайта применяются к нему без доработки. Если страница их не задаёт, используются системные цвета CSS, которые следуют `color-scheme` страницы. Без всякой настройки рисунок на светлой странице чёрный на белом, а на тёмной — светлый на тёмном.

## CSS-переменные {#custom-properties}

| Для чего | CSS-переменная | Запасное значение |
| --- | --- | --- |
| Стержни, опоры, текст | `--figure-ink`, затем `--ink` | `CanvasText` |
| Фон, ореолы подписей | `--paper` | `Canvas` |
| Размерные линии, оси | `--muted` | `GrayText` |
| Узлы, перетаскиваемая сила | `--brand` | `#4f46e5` |
| Продольная сила | `--color-normal` | `#2222ff` |
| Поперечная сила | `--color-shear` | `#00af00` |
| Изгибающий момент | `--color-moment` | `#ff2222` |
| Деформированная схема | `--figure-ink`, затем `--ink` | `CanvasText` |
| Нагрузки | `--color-load` | `#ff8700` |
| Реакции | `--color-reaction` | `#a020f0` |
| Растянутые стержни фермы | `--color-tension`, затем `--color-moment` | `#ff2222` |
| Сжатые стержни фермы | `--color-compression`, затем `--color-normal` | `#2222ff` |
| Шрифт | `--ebp-font`, затем `--font-sans` | `inherit` |

Задайте переменные на любом элементе выше рисунка, а для всего сайта — на `:root`:

```css
:root {
  --ink: #1b1b3a;
  --paper: #ffffff;
  --color-moment: #d7263d;
}

.dark {
  --ink: #eeeeff;
  --paper: #0b0d1f;
}
```

Подписи обводятся ореолом цвета `--paper`, чтобы оставаться читаемыми поверх штриховки, поэтому задайте этот цвет под фон, на котором стоит рисунок.

## Свойство `colors` {#the-colors-prop}

Чтобы задать цвета одного рисунка, передайте нужные тона по имени:

```vue
<StructurePlot :solver="solver" :colors="{ moment: '#c00', paper: 'transparent' }" />
```

Тона называются `ink`, `paper`, `muted`, `brand`, `normal`, `shear`, `moment`, `deformed`, `load`, `reaction`, `tension` и `compression`. Подойдёт любой цвет CSS, в том числе `var(…)`. Значения по умолчанию для каждого тона хранятся в `DEFAULT_COLORS`.

## Чёрно-белая печать {#black-and-white}

Для контрольной, которую будут размножать на копире, или для чёрно-белой печати сделайте все цветные тона того же цвета, что и линии (`ink`):

```vue
<script setup lang="ts">
import type { PlotColors } from '@edubeam/plot'

const print: Partial<PlotColors> = {
  ink: '#000', paper: '#fff', muted: '#555', brand: '#000',
  normal: '#000', shear: '#000', moment: '#000', deformed: '#000',
  load: '#000', reaction: '#000', tension: '#000', compression: '#000',
}
</script>

<template>
  <StructurePlot :solver="solver" :colors="print" :animate="false" />
</template>
```

Эпюры остаются читаемыми и без цвета: они заштрихованы, а эпюра моментов отложена со стороны растянутых волокон.

## Цвета в SVG-файле {#colours-in-an-svg-file}

У файла, записанного функцией [`structureSvg`](/ru/plot/functions#a-standalone-svg-file), нет окружающей страницы, поэтому в нём используются фиксированные цвета: `PRINT_COLORS`, цвета приложения EduBeam на белом фоне. Его параметр `colors` принимает те же тона, что и свойство компонента, так что чёрно-белый набор выше подходит и здесь:

```ts
structureSvg(model, { colors: print }) // чёрное на белом
structureSvg(model, { background: false }) // без фона, для цветного слайда
```

Только фиксированные цвета: для Word и Inkscape `var(…)` ничего не значит.

## Шрифты {#fonts}

Текст набирается шрифтом страницы через `--ebp-font` или `--font-sans`, с цифрами одинаковой ширины (табличными). Названия рядов, например V(x) в `DiagramStack`, набираются шрифтами KaTeX, если страница их загружает, а иначе — шрифтом с засечками. SVG-файл использует свой параметр `fontFamily`, по умолчанию Helvetica или Arial, потому что шрифт страницы ему неизвестен.

## Настройка анимации {#restyling-the-animation}

Те немногие CSS-правила, которые нужны рисунку, встроены в каждый SVG, поэтому отдельная таблица стилей не требуется. Все классы начинаются с `ebp-`, и страница может их переопределить. Каждый слой — это `<g class="ebp-layer ebp-layer-{name}">`, который получает класс `ebp-on`, когда слой показан:

```css
/* Более медленное появление — для большой аудитории */
.slides .ebp-animate .ebp-layer {
  transition-duration: 1s;
}
```

`PLOT_CSS` экспортирует встроенные правила, а `toneVars(colors)` — CSS-переменные, которые рисунок задаёт на своём корневом элементе; они пригодятся, если вы строите собственные рисунки из [функций рисования](/ru/plot/functions#drawing).
