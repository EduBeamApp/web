# DiagramStack

`DiagramStack` рисует картинку из любого учебника строительной механики: прямую балку с опорами, нагрузками и реакциями, а под ней на той же оси x — эпюры поперечных сил V(x), изгибающих моментов M(x) и прогибов w(x). Курсор считывает значения сразу во всех рядах, а сосредоточенную силу, если она задана, можно перетаскивать вдоль балки.

```vue
<DiagramStack :solver="solver" />
```

![DiagramStack: шарнирно опёртая балка пролётом 6 м с силой 20 кН, которую читатель может перетаскивать, здесь в 4,3 м от левой опоры; реакции 5,7 кН и 14,3 кН, поперечная сила под силой скачком меняется с 5,7 кН на −14,3 кН, изгибающий момент там достигает максимума 24,4 кН·м, наибольший прогиб равен 17 мм](/screenshots/ru/p2p-plot-diagram-stack.webp){.shot-lg}

Стержни должны образовывать одну горизонтальную линию и идти слева направо. Всё остальное — наклонная или ломаная линия, стержень, заданный справа налево, — отклоняется с ошибкой, а не рисуется неправильно, потому что ось x рисунка — это ось балки. Все свойства перечислены в [API компонентов](/ru/plot/components#diagramstack).

## Ряды {#rows}

| Свойство | По умолчанию | Задаёт |
| --- | --- | --- |
| `rows` | `['V', 'M', 'w']` | эпюры сверху вниз; доступна и `'N'` |
| `loadRow` | `true` | балку с опорами, нагрузками и реакциями над эпюрами |
| `members` | все стержни | стержни балочной линии, если в модели есть и другие |
| `rowHeights` | N 100, V 116, M 128, w 76 px | высоты рядов; при ширине меньше 560 px — немного меньше |
| `maxHeight` | нет | чтобы рисунок поместился, ряды сжимаются, но не ниже 60 % своей высоты; размер текста не меняется |
| `ranges` | у каждого ряда свой | фиксированные диапазоны значений для рядов, в единицах СИ |

Положительные V и N откладываются вверх, а M и w — вниз, как в большинстве учебников: положительный момент и прогиб вниз оказываются под осью. В каждом ряду подписаны экстремальные значения.

## Курсор для считывания {#the-reading-cursor}

Свойство `hover` включено по умолчанию. Когда указатель движется над рисунком, через все ряды проходит вертикальный курсор, а значение каждого ряда выводится в плашке. На расстоянии до 8 px от скачка — у сосредоточенной силы или опоры — курсор притягивается к нему, и для V показываются обе стороны, как `5.7 → −14.3 kN` под силой на рисунке выше. Значения передаются и в событии:

```vue
<DiagramStack :solver="solver" @readout="(r) => (reading = r)" />
```

Показания имеют вид `{ x, values }`: `x` — положение вдоль балки в метрах, `{ left, right }` — значения для каждого ряда в единицах СИ; когда указатель уходит, передаётся `null`.

## Сила, которую перетаскивает читатель {#a-load-the-reader-can-drag}

Передайте в `v-model:load-at` положение сосредоточенной силы, и у неё появится маркер: читатель перетаскивает его указателем или переводит на него фокус и пользуется клавишами со стрелками. Компонент лишь сообщает новое положение. Рассчитайте балку заново с силой в этом месте и передайте новый решатель обратно, как это делает `MovingLoad.vue`:

```vue [MovingLoad.vue]
<script setup lang="ts">
import { computed, ref } from 'vue'
import { DofID, LinearStaticSolver } from '@edubeam/fem'
import { beamLine, DiagramStack, lineDiagram, modelFromSolver, rowRange, type StackRow } from '@edubeam/plot'

const L = 6 // м
const P = 20e3 // Н

/** Балка с сосредоточенной силой на расстоянии `at` м от A, уже рассчитанная. */
const solveWithLoadAt = (at: number): LinearStaticSolver => {
  const solver = new LinearStaticSolver()
  const { domain } = solver
  domain.createMaterial(1, { e: 210e9, g: 81e9 })
  domain.createCrossSection(1, { a: 28.5e-4, iy: 1943e-8, h: 0.2, k: 1e32 })
  domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz])
  domain.createNode('B', [L, 0, 0], [DofID.Dz])
  domain.createBeam2D(1, ['A', 'B'], 1, 1)
  solver.loadCases[0].createBeamConcentratedLoad(1, [0, P, 0, at], true)
  solver.solve()
  return solver
}

/** Диапазон каждого ряда по всем положениям силы, чтобы эпюры росли и уменьшались, а не перемасштабировались. */
const rows: StackRow[] = ['V', 'M', 'w']
const envelope = (() => {
  const ranges: Partial<Record<StackRow, [number, number]>> = {}
  for (let at = 0.25; at < L; at += 0.25) {
    const model = modelFromSolver(solveWithLoadAt(at))
    const line = beamLine(model)
    for (const row of rows) {
      const [lo, hi] = rowRange(lineDiagram(model, line, row))
      const [min, max] = ranges[row] ?? [0, 0]
      ranges[row] = [Math.min(min, lo), Math.max(max, hi)]
    }
  }
  return ranges
})()

const at = ref(2)
const solver = computed(() => solveWithLoadAt(at.value))
</script>

<template>
  <DiagramStack v-model:load-at="at" :solver="solver" :rows="rows" :ranges="envelope" load-label="P = 20 kN" />
  <p>The load is {{ at.toFixed(2) }} m from A.</p>
</template>
```

Когда сила стоит в 4,3 м от A, на рисунке видны реакции 5,7 кН и 14,3 кН, скачок поперечной силы под силой с 5,7 до −14,3 кН и момент в этой точке $M = 5{,}67 \cdot 4{,}3 = 24{,}4$ кН·м. Без `ranges` каждый ряд при движении силы перемасштабировался бы по своим экстремумам, и казалось бы, что эпюры вообще не меняются.

| Свойство | По умолчанию | Задаёт |
| --- | --- | --- |
| `loadAt` | нет | положение силы, м от начала линии; используется с `v-model:load-at` |
| `loadLabel` | `P = …` | текст рядом с маркером |
| `loadStep` | 0.05 | шаг округления при перетаскивании, м; на этот шаг сдвигают клавиши со стрелками |

Маркер — это фокусируемый элемент `role="slider"`, который сообщает программам экранного доступа свой диапазон и положение. Клавиши со стрелками сдвигают его на `loadStep`, Page Up и Page Down — на 1 м, а Home и End переносят к концам балки. На сенсорном экране маркер можно перетаскивать пальцем, а вертикальная прокрутка над рисунком по-прежнему работает.

Маркер заменяет собой сосредоточенную силу, которая в рассчитанной модели приложена в точке `loadAt`: эта сила рисуется как маркер и подписывается своей величиной, если не задан `loadLabel`. Поэтому силу в модели нужно поставить в ту же точку, как это делает `solveWithLoadAt`.

## Размер и отрисовка на сервере {#size-and-server-rendering}

Рисунок измеряет свой контейнер и компонуется под его ширину, но не уже 320 px. Пока измерить контейнер нельзя, используется `width`, по умолчанию 720 px. Размер текста — 12,5 px (`fontSize`), и вместе с рисунком он не уменьшается.
