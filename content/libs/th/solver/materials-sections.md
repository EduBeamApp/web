# วัสดุและหน้าตัด {#materials-and-sections}

ชิ้นส่วนได้ความแข็งเกร็งจากวัสดุและหน้าตัด ซึ่งแต่ละอย่างสร้างเพียงครั้งเดียวแล้วอ้างถึงด้วยชื่อ

```ts
domain.createMaterial('steel', { e: 210e9, g: 81e9, alpha: 12e-6 })
domain.createCrossSection('IPE200', {
  a: 28.5e-4, // m²
  iy: 1943e-8, // m⁴
  h: 0.2, // m
  k: 5 / 6,
})
```

## วัสดุ {#material}

| พารามิเตอร์ | ความหมาย | หน่วย | ใช้สำหรับ |
| --- | --- | --- | --- |
| `e` | มอดุลัสของยัง $E$ | Pa | ทุกกรณี |
| `g` | มอดุลัสเฉือน $G$ | Pa | ทุกกรณี เว้นแต่ `k` มีค่ามหาศาล (ไม่มีการเสียรูปเนื่องจากแรงเฉือน) |
| `alpha` | สัมประสิทธิ์การขยายตัวเนื่องจากความร้อน $\alpha$ | 1/K | แรงกระทำเนื่องจากอุณหภูมิ |
| `d` | ความหนาแน่น $\rho$ | kg/m³ | ไม่ใช้ในการวิเคราะห์สถิต |

พารามิเตอร์ที่ไม่ได้ใส่จะมีค่าเป็น **1** ไม่ใช่ค่าทั่วไปของวัสดุ และไม่มีคำเตือนใด ๆ ถ้าลืม `g` ในคานของหน้าเริ่มต้นใช้งาน การโก่งตัวจะออกมาเป็น 22,700 km

## หน้าตัด {#cross-section}

| พารามิเตอร์ | ความหมาย | หน่วย | ใช้สำหรับ |
| --- | --- | --- | --- |
| `a` | พื้นที่ $A$ | m² | ทุกกรณี: ความแข็งเกร็งตามแนวแกนและต่อแรงเฉือน |
| `iy` | โมเมนต์ความเฉื่อยของหน้าตัด $I_y$ | m⁴ | ทุกกรณี: ความแข็งเกร็งต่อการดัด |
| `k` | สัมประสิทธิ์เฉือน $k$ | – | ทุกกรณี: ความแข็งเกร็งต่อแรงเฉือน $kGA$ |
| `h` | ความลึกของหน้าตัด $h$ | m | ผลต่างอุณหภูมิ |
| `iz`, `dyz`, `j` | $I_z$, $I_{yz}$, ค่าคงที่การบิด | m⁴ | ไม่ใช้ในโมเดลระนาบ |

หน้าตัดไม่มีค่าเริ่มต้น ถ้าขาด `a`, `iy` หรือ `k` ผลลัพธ์ทุกค่าจะเป็น `NaN` และถ้าขาด `h` ผลต่างอุณหภูมิจะให้ `NaN` ทั้งสองกรณีไม่มี error ดังนั้นผลลัพธ์ที่เป็น `NaN` แทบทุกครั้งหมายถึงพารามิเตอร์ที่ขาดไป

## การเสียรูปเนื่องจากแรงเฉือน {#shear-deformation}

ชิ้นส่วนเป็นคาน Timoshenko คือเสียรูปทั้งจากแรงเฉือนและจากการดัด จะมากน้อยเท่าใดขึ้นกับ

$$
\Phi = \frac{12\,EI_y}{k\,G\,A\,L^2},
$$

ซึ่ง `beam.computeShearFactor()` คืนค่าให้ ชิ้นส่วนที่เพรียวมีค่า $\Phi$ น้อยมาก การโก่งตัวเพิ่มขึ้นไม่ถึงหนึ่งเปอร์เซ็นต์ แต่สำหรับชิ้นส่วนที่สั้นและลึก ผลนี้มีนัยสำคัญ

ถ้าต้องการคาน Euler–Bernoulli แบบในตารางของตำรา ให้ความแข็งเกร็งต่อแรงเฉือนแทบเป็นอนันต์ด้วยสัมประสิทธิ์เฉือนที่มีค่ามหาศาล อย่างที่ตัวอย่างในแอป EduBeam ทำ:

```ts
domain.createCrossSection('IPE200-EB', { a: 28.5e-4, iy: 1943e-8, k: 1e32 })
```

ตัวอย่างโปรแกรมในหน้าเหล่านี้ทำแบบนี้ ตัวเลขจึงตรงกับสูตรพอดี ถ้าใช้สัมประสิทธิ์เฉือนจริง หน้าตัดสี่เหลี่ยมผืนผ้าใช้ $k = 5/6$ หน้า [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification#shear-deformation) แสดงว่าผลนี้มีขนาดเท่าใด

## ชิ้นส่วนที่ไม่ยืดหดตามแนวแกน {#rigid-in-axial-direction}

พื้นที่หน้าตัดที่มีค่ามากทำให้ชิ้นส่วนแทบไม่ยืดหด ตามที่การคำนวณมือมักสมมติ แรงภายในของโครงข้อแข็งขึ้นกับพื้นที่เพียงเล็กน้อย แต่การกระจัดของโครงถักขึ้นกับพื้นที่โดยตรง ส่วนแรงภายในของโครงสร้างดีเทอร์มิเนทไม่ขึ้นกับความแข็งเกร็งเลย

## เปลี่ยนค่าภายหลัง {#change-them-later}

```ts
domain.getMaterial('steel').change({ e: 200e9 })
domain.getCS('IPE200').change({ iy: 2000e-8 })
solver.solve()
```

ชิ้นส่วนแต่ละชิ้นอ่านวัสดุและหน้าตัดตอนที่ตัวคำนวณประกอบเมทริกซ์ ดังนั้นแค่เรียก `solve()` ใหม่ก็พอ ชิ้นส่วนต่าง ๆ ใช้หน้าตัดต่างกันได้ โดยตั้งชื่อแยกให้แต่ละหน้าตัด
