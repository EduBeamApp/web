# 材料と断面 {#materials-and-sections}

部材の剛性は、材料と断面から決まります。どちらも 1 回だけ作成し、ラベルで参照します。

```ts
domain.createMaterial('steel', { e: 210e9, g: 81e9, alpha: 12e-6 })
domain.createCrossSection('IPE200', {
  a: 28.5e-4, // m²
  iy: 1943e-8, // m⁴
  h: 0.2, // m
  k: 5 / 6,
})
```

## 材料 {#material}

| パラメーター | 意味 | 単位 | 必要な場面 |
| --- | --- | --- | --- |
| `e` | ヤング係数 $E$ | Pa | 常に |
| `g` | せん断弾性係数 $G$ | Pa | 常に（`k` が非常に大きく、せん断変形を無視する場合を除く） |
| `alpha` | 線膨張係数 $\alpha$ | 1/K | 温度荷重 |
| `d` | 密度 $\rho$ | kg/m³ | 静的解析では使わない |

省略したパラメーターは、典型的な値ではなく **1** になり、警告も出ません。「クイックスタート」の梁で `g` を指定し忘れると、たわみは 22,700 km になります。

## 断面 {#cross-section}

| パラメーター | 意味 | 単位 | 必要な場面 |
| --- | --- | --- | --- |
| `a` | 断面積 $A$ | m² | 常に：軸剛性とせん断剛性 |
| `iy` | 断面二次モーメント $I_y$ | m⁴ | 常に：曲げ剛性 |
| `k` | せん断補正係数 $k$ | – | 常に：せん断剛性 $kGA$ |
| `h` | 断面の高さ $h$ | m | 温度勾配 |
| `iz`, `dyz`, `j` | $I_z$、$I_{yz}$、ねじり定数 | m⁴ | 平面モデルでは使わない |

断面のパラメーターには既定値がありません。`a`、`iy`、`k` のどれかを省略すると、すべての結果が `NaN` になります。`h` を省略すると、温度勾配による結果が `NaN` になります。どちらの場合もエラーにはならないので、結果が `NaN` なら、ほぼ間違いなくパラメーターの指定漏れです。

## せん断変形 {#shear-deformation}

部材はティモシェンコ梁で、曲げだけでなくせん断によっても変形します。その大きさは次の値で決まります。

$$
\Phi = \frac{12\,EI_y}{k\,G\,A\,L^2},
$$

この値は `beam.computeShearFactor()` で得られます。細長い部材では $\Phi$ はごく小さく、たわみの増加は 1 % にも満たない程度です。短くてせいの高い部材では、無視できなくなります。

教科書の表にあるオイラー・ベルヌーイ梁の値を得るには、EduBeam アプリの例題と同じように、せん断補正係数を非常に大きくして、せん断剛性を実質的に無限大にします。

```ts
domain.createCrossSection('IPE200-EB', { a: 28.5e-4, iy: 1943e-8, k: 1e32 })
```

このドキュメントのプログラム例はこの方法をとっているので、数値が公式と完全に一致します。実際のせん断補正係数としては、長方形断面なら $k = 5/6$ が適切です。影響の大きさは[手計算による結果の確認](/ja/guide/verification#shear-deformation)のページで確かめられます。

## 軸方向に剛な部材 {#rigid-in-axial-direction}

断面積を大きくすると、手計算で通常仮定するように、部材は実質的に伸び縮みしなくなります。ラーメンの断面力は断面積にわずかしか依存しませんが、トラスの変位は断面積で完全に決まります。静定構造物の断面力は、剛性にまったく依存しません。

## 後から変更する {#change-them-later}

```ts
domain.getMaterial('steel').change({ e: 200e9 })
domain.getCS('IPE200').change({ iy: 2000e-8 })
solver.solve()
```

各部材は、ソルバーが剛性マトリクスを組み立てるときに材料と断面を読み込むので、もう一度 `solve()` を呼ぶだけで済みます。部材ごとに違う断面を使うこともできます。それぞれに別のラベルを付けてください。
