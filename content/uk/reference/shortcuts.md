# Клавіатура, миша та сенсорний екран

Застосунком EduBeam можна керувати клавіатурою й мишею, тачпадом або пальцем. На цій сторінці зібрано всі гарячі клавіші та жести. На Mac натискайте <kbd>Cmd</kbd> скрізь, де вказано <kbd>Ctrl</kbd>; власні меню застосунку показують там ⌘.

## Клавіатура {#keyboard}

Клавіші для креслення (<kbd>F</kbd>, <kbd>C</kbd>, <kbd>G</kbd>, <kbd>S</kbd>, <kbd>Delete</kbd> і <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>V</kbd>) не діють, поки фокус у текстовому полі, тож літера `f` чи `s`, введена в поле, ніколи їх не запустить. Спершу клацніть креслення.

### Файли та історія змін {#files-and-history}

| Комбінація | Дія |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Скасувати останню зміну моделі |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторити |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Зберегти проєкт (завантажує `project.json`) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Відкрити проєкт |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Експорт зображення |

Скасувати можна й очищення моделі, відкриття файлу, посилання чи прикладу, а також відновлення нещодавньої моделі. Поки ви ще вводите текст у клітинці таблиці, <kbd>Ctrl</kbd>+<kbd>Z</kbd> скасовує введення; щойно значення в клітинці підтверджено, ця комбінація скасовує зміну моделі. У полях діалогу вона завжди скасовує введення.

### Креслення {#drawing}

| Комбінація | Дія |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Виділити все |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Копіювати виділені вузли, елементи та навантаження |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставити. Напівпрозора копія рухається за курсором: клацніть, щоб її розмістити, або введіть зсув Δx, Δz на панелі вгорі й натисніть **Вставити** чи <kbd>Enter</kbd> |
| <kbd>Delete</kbd> | Видалити виділене (на ноутбуці Mac — <kbd>Fn</kbd>+<kbd>Delete</kbd>) |
| <kbd>Esc</kbd> | Вийти з поточного режиму (додавання вузлів, елементів чи розмірів, вставлення, вибір області для зображення) і зняти виділення; також закриває меню ☰ і завершує огляд інтерфейсу |
| <kbd>F</kbd> | Вмістити на екран |
| <kbd>C</kbd> | Центрувати вміст |
| <kbd>G</kbd> | Показати чи сховати сітку |
| <kbd>S</kbd> | Увімкнути чи вимкнути прив’язку до сітки |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Збільшити / зменшити масштаб креслення відносно його центру |

В EduBeam <kbd>Ctrl</kbd>+<kbd>+</kbd> і <kbd>Ctrl</kbd>+<kbd>-</kbd> змінюють масштаб креслення, а не всього інтерфейсу, як на інших сайтах. Вони працюють за будь-якої розкладки клавіатури: це клавіші з позначками + і −, де б вони не були у вашій розкладці (на американській клавіатурі — дві клавіші ліворуч від <kbd>Backspace</kbd>), а також + і − на цифровому блоці.

### Таблиці й діалоги {#tables-and-dialogs}

| Комбінація | Дія |
| --- | --- |
| <kbd>Enter</kbd> | У клітинці таблиці: підтвердити значення. У текстовому полі діалогу: підтвердити діалог, як це робить його головна кнопка |
| <kbd>Esc</kbd> | У клітинці таблиці: вийти з неї, зберігши значення. У діалозі: закрити його без збереження |
| <kbd>Tab</kbd> | Перейти до наступного поля; клітинка таблиці зберігає введене |

У числові поля можна вводити арифметичні вирази так, як ви записали б їх на папері: `6/2`, `3*1.5`, `2^3`, `(4+2)/3`, а також `1e3` або десяткову кому.

## Миша {#mouse}

| Дія | Результат |
| --- | --- |
| Клацання | Вибрати вузол, елемент, навантаження чи розмірну лінію й відкрити панель об’єкта |
| Перетягування по порожньому полотну | Прямокутник виділення |
| Перетягування вузла | Перемістити його; коли прив’язку ввімкнено, вузол прив’язується до сітки |
| Клацання в режимі додавання | Розмістити вузол або почати чи продовжити ламану з елементів |
| Подвійне клацання навантаження | Редагувати навантаження (також задане переміщення) |
| Клацання правою кнопкою | Меню полотна: Додати вузол, Додати елемент, Додати розмір, Проставити розмір елемента (над елементом), Редагувати, Копіювати, Вставити, Видалити |
| <kbd>Ctrl</kbd> + **Додати вузол** або **Додати елемент** у меню полотна | Розмістити об’єкт мишею, а не через діалог |
| Перетягування середньою або правою кнопкою | Панорамування. Кнопку можна вибрати в **Налаштування → Керування та гарячі клавіші → Панорамування за допомогою** |
| Колесо миші | Масштабування в бік курсора |
| Наведення курсора на об’єкт | Підказка з його переміщеннями, характеристиками або значеннями навантаження |

На тачпаді масштаб змінюють і зведення/розведення пальців, і прокручування двома пальцями. Щоб панорамувати, клацніть і перетягніть двома пальцями: це те саме, що перетягування правою кнопкою.

## Сенсорний екран {#touch}

| Жест | Результат |
| --- | --- |
| Дотик | Вибрати об’єкт і показати його відомості та дії |
| Дотик у режимі додавання | Розмістити вузол або продовжити елемент |
| Дотик до вузла й перетягування | Перемістити вузол |
| Перетягування одним пальцем в іншому місці | Панорамування |
| Зведення / розведення пальців | Масштабування |
| Дотик до полотна з утриманням | Меню полотна |
| Кнопка **Виділення рамкою** (угорі праворуч), потім перетягування | Прямокутник виділення; меню полотна з командами Копіювати та Видалити відкривається там, де ви піднімете палець |

Поки ви додаєте вузли, елементи чи розміри, вставляєте або вибираєте область для зображення, панель угорі креслення показує назву режиму й має кнопку **Скасувати**. Без клавіші <kbd>Esc</kbd> саме так можна вийти з режиму на сенсорному екрані.

## Панелі об’єктів {#object-panels}

Клацання або дотик до об’єкта відкриває поруч із ним панель із його відомостями та такими діями:

| Об’єкт | Дії |
| --- | --- |
| Вузол | Додати навантаження · Опори вузла (умовне позначення опори, Dx, Dz, Ry) · Кут локальної системи координат · Задати переміщення (для вузла з опорою) · Видалити |
| Елемент | Редагувати елемент (кінцеві вузли й шарніри, матеріал, переріз) · Додати навантаження · Матриця жорсткості · Видалити |
| Вузлове навантаження або навантаження на елемент | Редагувати навантаження · Видалити |
| Розмірна лінія | Редагувати · Змінити напрям розміру · Видалити |

Сторінка [Інтерфейс користувача](/uk/essentials/user-interface) знайомить з усім екраном, а в розділі налаштувань [Керування та гарячі клавіші](/uk/essentials/units-settings#controls-shortcuts) можна вибрати кнопку для панорамування.
