# Файли, посилання та експорт

:span{#імпорт-експорт-та-обмін}

Збережіть модель як файл, надішліть її посиланням, вбудуйте у вебсторінку або експортуйте її зображення чи таблицю. Усе в [EduBeam]{.edubeam} відбувається у вашому браузері, і нічого не надсилається на сервер: посилання на модель буквально містить саму модель.

## Збереження проєкту {#save-a-project}

**☰ → Зберегти проєкт** або <kbd>Ctrl</kbd>+<kbd>S</kbd> (на Mac <kbd>⌘</kbd>+<kbd>S</kbd>, як і для всіх комбінацій на цій сторінці) завантажує файл `project.json`. Він містить вузли, елементи, матеріали, перерізи (разом із накресленими формами), навантаження, розмірні лінії та версію застосунку, яка його записала. Файл можна вільно перейменувати.

## Відкриття проєкту {#open-a-project}

Виберіть **☰ → Відкрити проєкт** або натисніть <kbd>Ctrl</kbd>+<kbd>O</kbd> і вкажіть файл — або просто **перетягніть файл будь-куди у вікно застосунку**. EduBeam відкриває:

- файли `project.json`, збережені будь-якою версією EduBeam;
- сесії `.xml`, збережені **настільною програмою EduBeam** версій 2.x–3.5. Їхні значення не мають одиниць, тому читаються в kN, kPa і m — одиницях, які використовував її посібник. EduBeam відкриває один випадок навантаження за раз: якщо в сесії їх кілька, відкривається перший, а повідомлення називає пропущені.

Відкриття замінює поточну модель разом з її матеріалами й перерізами. Попередня модель не втрачається: <kbd>Ctrl</kbd>+<kbd>Z</kbd> повертає її, а ще вона зберігається в [Нещодавніх моделях](#recent-structures). Файл, який EduBeam не може прочитати, він відхиляє з повідомленням, а ваша модель залишається незмінною.

## Обмін посиланням {#share-a-link}

**Поділитися моделлю** на панелі застосунку або в меню ☰ відкриває діалог *Поділитися моделлю за URL*:

![Діалог Поділитися моделлю за URL](/screenshots/uk/c1-share.webp){.shot-lg}

- **Копіювати** або клацання будь-де в полі копіює посилання.
- **Відкрити посилання** відкриває його в новій вкладці, тож ви бачите те, що побачить одержувач.
- **Поділитися через системний діалог** передає посилання в системне меню «Поділитися» вашого пристрою, якщо браузер це підтримує.
- **Коротке посилання** (типово ввімкнено) записує ту саму модель приблизно вдвічі меншою кількістю символів. Копії EduBeam, випущені до версії 1.3.2 (листопад 2026 року), не зможуть його прочитати, доки їх не оновлять, тож вимкніть його, якщо посилання має одразу відкриватися будь-де.
- **Показувати те, що бачу я** (типово вимкнено): посилання відкриється з тими епюрами, навантаженнями й мітками, які ввімкнено у вас, а не з налаштуваннями відображення одержувача.

Посилання має вигляд `https://run.edubeam.app/?model=…` і кодує всю модель. Кожен, хто його відкриє, отримає власну копію для редагування; зміни **не** синхронізуються назад, тож коли модель зміниться, надішліть нове посилання. Дуже великі моделі дають дуже довгі посилання; для них краще надіслати файл проєкту.

Коли хтось відкриває посилання, його власна попередня модель потрапляє до Нещодавніх моделей, а повідомлення підказує, де її знайти. Посилання не мають терміну дії: посилання в торішньому конспекті лекцій сьогодні відкриває ту саму модель.

## Вбудовування переглядача {#embed-a-read-only-viewer}

Додайте `&viewer=1` до посилання на модель, і модель відкриється в **режимі перегляду**: панель застосунку, нижня панель, кнопки скасування й повторення, чипи сітки й одиниць і перехрестя приховано, залишаються креслення, кнопки вписування й центрування та налаштування відображення. Вітальне вікно й примітки до випусків також не відкриваються. Вставте таку URL-адресу в `<iframe>`, щоб вбудувати живу модель, яку можна масштабувати, у конспект лекцій, сторінку курсу чи слайд:

```html
<iframe
  src="https://run.edubeam.app/?viewer=1&show=MRLS&model=…"
  width="100%"
  height="400"
></iframe>
```

![Тришарнірна рама в режимі перегляду](/screenshots/uk/viewer-mode.webp){.shot-lg}

Режим перегляду призначений для того, щоб дивитися, але він не заблокований: відвідувачі все одно можуть перетягувати вузли й перемикати епюри. Якщо посилання для перегляду відкрити окремо, воно, як і будь-яке посилання, замінює власну модель відвідувача, а та чекає в Нещодавніх моделях. Коли переглядач вбудовано на сторінку іншого сайту, більшість сучасних браузерів дає фрейму окреме сховище, і модель відвідувача залишається недоторканою, але так роблять не всі браузери.

Для рисунка, якому застосунок узагалі не потрібен, наприклад статичної епюри на сторінці, слайді чи аркуші завдань, графічна бібліотека [@edubeam/plot](/uk/plot) малює конструкції та їхні епюри з коду. Живі рисунки на цьому сайті намальовано саме нею.

## Параметри URL {#url-parameters}

| Параметр | Дія |
| --- | --- |
| `model=<дані>` | Завантажує закодовану модель і вписує її в екран. Його додає кнопка **Поділитися моделлю**. |
| `viewer=1` | [Режим перегляду](#embed-a-read-only-viewer). |
| `show=<літери>` | Відкриває модель саме з цими ввімкненими шарами, по літері на кожен: `N` поздовжня сила, `V` поперечна сила, `M` згинальний момент, `U` деформована схема, `R` реакції, `L` навантаження, `S` опори, `n` мітки вузлів, `e` мітки елементів. `show=MRLS` показує згинальний момент, реакції, навантаження й опори. Його додає перемикач **Показувати те, що бачу я**. |
| `lang=<код>` | Перемикає мову інтерфейсу: `en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn` (китайська), `th`, `uk`, `ru`, `tr`, `hi`, `vi`, `it`, `id`, `ja`, `ko`. |
| `panel=examples` | Одразу відкриває галерею прикладів. |

Параметри поєднують знаком `&`, наприклад `?lang=de&viewer=1&model=…`. Прочитавши параметри, EduBeam прибирає їх з адресного рядка. `lang` і `show` зберігаються як налаштування відвідувача, так ніби він вибрав їх у застосунку сам.

## Експорт зображення {#export-an-image}

**☰ → Експорт зображення** або <kbd>Ctrl</kbd>+<kbd>P</kbd> відкриває експорт зображення. Креслення щоразу компонується заново для вибраного розміру, тож лінії й підписи зберігають свою справжню товщину.

![Експорт зображення: виберіть шари, кадр і розмір, а потім завантажте або скопіюйте](/screenshots/uk/export-image.webp)

::div{.steps}

### Виберіть шари {#choose-the-layers}

Чипи вгорі вибирають, що малювати: деформовану схему, N, V, M і реакції, далі опори, навантаження, мітки вузлів і мітки елементів. Спочатку вони збігаються з налаштуваннями відображення у вікні перегляду, а якщо змінити їх тут, вікно перегляду залишиться без змін.

### Виберіть кадр {#frame-the-drawing}

Виберіть співвідношення сторін (16:9, 4:3, 3:2 або 1:1), **Вписати все** або **Вікно…**, щоб обвести рамкою частину креслення. Можна також перетягувати краї попереднього перегляду.

### Задайте розмір {#set-the-size}

Задайте ширину й висоту в пікселях або **Масштаб**, наприклад 1 : 50, щоб отримати креслення в масштабі на папері (за 96 DPI). **Висота епюр** задає розмір епюр результатів, а **Прозоре тло** прибирає білий фон. Якщо епюри чи підписи не вміщуються, діалог про це повідомить і запропонує зменшити епюри або збільшити полотно.

### Збережіть {#save-it}

**Завантажити PNG**, **Завантажити SVG** або, якщо браузер це дозволяє, **Копіювати в буфер обміну**. Файли називаються за розміром зображення, наприклад `edubeam-512x512.svg`. На екрані з високою роздільною здатністю PNG має більше пікселів, ніж задані ширина й висота, пропорційно щільності пікселів екрана, щоб зображення було таким самим чітким, як у застосунку; його розмір у пікселях показано поруч із кнопками.

::

SVG залишається чітким за будь-якого розміру й працює у Word, Inkscape та LaTeX на Overleaf, тож це найкращий вибір для звітів і дипломних робіт. Той самий розмір завжди однаково кадрує конструкцію, тож епюри N, V і M, експортовані одна за одною, точно збігаються, якщо поставити їх поруч.

Щоб створювати такі рисунки з коду, наприклад для кожної задачі аркуша завдань, бібліотека @edubeam/plot записує [окремий файл SVG](/uk/plot/functions#a-standalone-svg-file), який відкривається в тих самих програмах.

## Нещодавні моделі {#recent-structures}

У **☰ → Нещодавні моделі** зберігаються останні 10 моделей, які було очищено або замінено посиланням, файлом, прикладом, завданням **Намалювати першу балку** чи іншим відновленням. Для кожної показано мініатюру, чим її замінено, а також кількість вузлів і елементів. **Відновити** повертає модель: та, що була відкрита, своєю чергою потрапляє до списку, а <kbd>Ctrl</kbd>+<kbd>Z</kbd> скасовує відновлення. **Вилучити** видаляє запис.

## Автоматичне збереження {#automatic-persistence}

Ваша модель і налаштування зберігаються в локальному сховищі браузера після кожної зміни й відновлюються, коли ви повертаєтеся, навіть після закриття браузера. Це лише зручність, а не резервна копія: збережене належить одному профілю браузера на одному пристрої, приватне вікно його не запам’ятовує, а очищення даних сайту його видаляє. Важливу роботу зберігайте як файл проєкту. Повний перелік наведено в розділі [Що зберігається у вашому браузері](/uk/essentials/units-settings#what-is-stored-in-your-browser).

## Формат файлу проєкту {#project-file-format}

`project.json` — це звичайний читабельний JSON. Ось балка зі сторінки [Швидкий старт](/uk/guide/quick-start) зі сталлю та двотавром IPE 200 з бібліотек:

```json [project.json]
{
  "edubeam": true,
  "version": "1.3.4",
  "domain": {
    "materials": [
      {
        "label": "Steel (S235)",
        "d": 7850,
        "e": 210000000000,
        "g": 81000000000,
        "alpha": 0.000012
      }
    ],
    "crossSections": [
      {
        "label": "IPE 200 (approx)",
        "a": 0.002848,
        "iy": 0.00001943,
        "h": 0.2,
        "k": 0.3932584269662922
      }
    ],
    "nodes": [
      { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] },
      { "label": "2", "coords": [6, 0, 0], "bcs": [2] }
    ],
    "elements": [
      {
        "label": "1",
        "nodes": ["1", "2"],
        "mat": "Steel (S235)",
        "cs": "IPE 200 (approx)",
        "hinges": [false, false]
      }
    ],
    "loadCases": [
      {
        "label": "DefaultLC",
        "nodalLoads": [],
        "elementLoads": [
          { "type": "udl", "target": "1", "lcs": true, "values": [0, 12000] }
        ],
        "prescribedBC": []
      }
    ]
  },
  "dimensions": []
}
```

Усі значення задано в **одиницях СІ** (m, N, Pa, rad), незалежно від того, які одиниці показує застосунок. Координати мають вигляд `[x, y, z]`, де $y = 0$, а вісь $z$ спрямована вниз. Опори й компоненти навантажень використовують ідентифікатори ступенів вільності `0 = Dx`, `2 = Dz`, `4 = Ry`.

| `type` навантаження на елемент | Значення |
| --- | --- |
| `udl` | `values: [fx, fz]` у N/m |
| `trapezoidal` | `startValues: [f1x, f1z]`, `endValues: [f2x, f2z]` у N/m |
| `concentrated` | `values: [Fx, Fz, My, a]` у N, N·m і m від початкового вузла |
| `temperature` | `values: [ΔTc, ΔTb, ΔTt]` у K; перепад температури дорівнює ΔTb − ΔTt |

`lcs: true` або відсутність `lcs` задає навантаження на елемент у локальних осях елемента; `false` — у глобальних. Інші записи:

- **Вузлові навантаження**: `{ "target": "2", "values": { "0": Fx, "2": Fz, "4": My } }`, а для навантаження в осях повернутої опори ще `"lcs": true`.
- **Задані переміщення**: `{ "target": "2", "prescribedValues": { "0": Dx, "2": Dz, "4": Ry } }`; пропущена компонента дорівнює 0.
- Файли, записані застосунком, містять також `date`, `commit`, осі повернутих опор (`lcs` у вузлі) і накреслені форми перерізів `shape`.

Оскільки формат простий, моделі можна генерувати скриптом чи в електронній таблиці й відкривати через **Відкрити проєкт**. Щоб будувати й розраховувати моделі повністю в коді, скористайтеся розв’язувачем, на якому працює застосунок, — розрахунковою бібліотекою [@edubeam/fem](/uk/solver).
