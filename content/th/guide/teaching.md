# สอนด้วย EduBeam

## ในห้องบรรยาย {#in-the-lecture}

- **ทำให้นักศึกษาแถวหลังสุดอ่านได้ชัด** ใน **การตั้งค่า → การตั้งค่าโปรแกรมดู** เพิ่ม **ขนาดตัวอักษร** เป็น 18 หรือ 20 px (20 px คือค่าสูงสุด) และ **ขนาดจุดรองรับ** เป็น 130–150 % ถ้าแผนภาพยังดูเล็ก ให้เพิ่ม **ขนาดผลลัพธ์**
- **แสดงทีละเรื่อง** ในตัวเลือกการแสดงผลที่มุมขวาบนของหน้าจอแสดงผล ยกเลิกการติ๊กทุกอย่าง ยกเว้นปริมาณที่กำลังอธิบาย แล้วค่อยเพิ่มอย่างอื่นทีละอย่าง
- **แก้โมเดลสด ๆ** ลากจุดรองรับ ติ๊ก `Ry` เพิ่มจุดหมุน นักศึกษาเห็นเหตุและผลทันที และ <kbd>Ctrl</kbd>+<kbd>Z</kbd> พากลับไปสถานะเดิมได้
- **ให้ตัวคำนวณอธิบายกลไก** ใส่จุดหมุนเกินไปหนึ่งจุด แล้ว EduBeam จะวาดว่าโครงสร้างเคลื่อนที่ได้อย่างไร แสดงเป็นภาพเคลื่อนไหว และวงกลมล้อมจุดหมุนที่เป็นต้นเหตุ เป็นจังหวะที่ดีที่จะพูดถึงเรื่องเสถียรภาพ สวิตช์ทั้งสองอยู่ใน **การตั้งค่า → การตั้งค่าโปรแกรมดู → การตรวจสอบโมเดล**
- **ใช้ภาษาและแกนแบบที่นักศึกษาคุ้นเคย** EduBeam มี 18 ภาษา และ [การตั้งค่า](/th/essentials/units-settings) สลับได้ทั้งระหว่างหน่วย SI กับหน่วยอเมริกัน และระหว่างแกน z ชี้ลงกับแกน y ชี้ขึ้น ให้ตรงกับเอกสารประกอบการสอนของคุณ

![กลไกที่มองเห็นได้: จุดหมุนที่ B และ C ทำให้โครงข้อแข็งเซได้](/screenshots/th/ui-mechanism.webp)

## ในคาบปฏิบัติการครั้งแรก {#getting-students-started}

เมื่อนักศึกษาเปิดแอปครั้งแรก EduBeam จะถามว่าอยากเริ่มอย่างไร และจะใช้หน่วยและแกนแบบใด จึงควรบอกนักศึกษาล่วงหน้าว่าวิชาของคุณใช้หน่วยและแกนแบบไหน ทัวร์ (**พาชมแอป**) งานพร้อมคำแนะนำ **วาดคานแรกของคุณ** และ **ตัวอย่าง** ยังอยู่ในเมนู **☰** ให้กลับมาใช้ภายหลัง

คาบปฏิบัติการครั้งแรกที่ได้ผลดี: “เปิด run.edubeam.app แล้วเลือก *วาดคานแรกของคุณ*” ต่อด้วย [เริ่มต้นใช้งานด่วน](/th/guide/quick-start) ซึ่งใช้เวลาราวสิบนาทีและจบด้วยการตรวจสอบด้วยการคำนวณมือ

### คอมพิวเตอร์ในห้องปฏิบัติการและการใช้งานออฟไลน์ {#offline-and-lab-computers}

EduBeam เป็น progressive web app (PWA) เมื่อเบราว์เซอร์โหลดแอปแล้วครั้งหนึ่ง ก็ใช้งานต่อได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต และเบราว์เซอร์อาจเสนอให้ติดตั้งเหมือนโปรแกรมเดสก์ท็อป โมเดลและการตั้งค่าเก็บแยกตามโปรไฟล์เบราว์เซอร์ บนคอมพิวเตอร์ในห้องปฏิบัติการที่ใช้ร่วมกัน นักศึกษาจึงควรนำงานกลับไปเป็นไฟล์หรือลิงก์ รายละเอียดอยู่ในหัวข้อ [สิ่งที่เก็บไว้ในเบราว์เซอร์ของคุณ](/th/essentials/units-settings#what-is-stored-in-your-browser)

## ในเอกสารประกอบการสอนและการบ้าน {#in-lecture-notes-and-assignments}

ลิงก์แชร์เก็บโมเดลไว้ทั้งหมด จึงใช้ได้ทุกที่ที่ใส่ลิงก์ได้: PDF สไลด์ หน้าใน LMS หรืออีเมล

::div{.steps}

### สร้างโมเดล {#share-build}

จัดโมเดลให้อยู่ในสภาพที่อยากให้นักศึกษาเห็นเป็นอย่างแรก: แรงกระทำ ป้ายชื่อ และแผนภาพที่ต้องการให้เปิดไว้

### คัดลอกลิงก์ {#share-copy}

กด **แชร์โมเดล** ในแถบแอป ถ้าต้องการให้ลิงก์เปิดพร้อมแผนภาพ แรงกระทำ และป้ายชื่อแบบที่คุณเห็น ให้เปิด **แสดงสิ่งที่ฉันเห็น** แล้วกด **คัดลอก**

### วางลิงก์ในเอกสาร {#share-paste}

นักศึกษาที่เปิดลิงก์จะได้สำเนาของตัวเองไว้ทดลอง สิ่งที่นักศึกษาแก้ไขไม่ส่งผลถึงคุณหรือคนอื่น ลิงก์ยังใช้ได้เมื่อ EduBeam ออกเวอร์ชันใหม่ เอกสารประกอบการสอนจึงใช้ได้ต่อไปทุกปี

::

สำหรับสื่อการสอน ให้ปิด **ลิงก์ที่สั้นกว่า** ไว้ เพราะ EduBeam ในเบราว์เซอร์ที่ยังไม่ได้อัปเดตเป็นเวอร์ชันที่มีตัวเลือกนี้ จะเปิดลิงก์แบบสั้นไม่ได้จนกว่าจะอัปเดต

| ลิงก์ | เปิด |
| --- | --- |
| `run.edubeam.app/?model=…` | โมเดลที่พร้อมแก้ไข |
| `run.edubeam.app/?viewer=1&model=…` | โมเดลใน [โหมดโปรแกรมดู](/th/essentials/import-export#embed-a-read-only-viewer) สำหรับฝังใน `<iframe>` |
| `run.edubeam.app/?panel=examples` | [แกลเลอรีตัวอย่าง](/th/examples/) |
| `run.edubeam.app/?lang=th` | แอปเป็นภาษาไทย หรือ [ภาษาอื่น](/th/essentials/import-export#url-parameters) ใดก็ได้ |

::callout{type="warning" title="ลิงก์จะแทนที่โมเดลของนักศึกษาเอง"}
การเปิดลิงก์ และในบางเบราว์เซอร์รวมถึงการเปิดหน้าที่ฝังโปรแกรมดูไว้ จะย้ายโมเดลเดิมของนักศึกษาไปไว้ที่ **☰ → โครงสร้างล่าสุด** ซึ่งกู้คืนได้ ถึงอย่างนั้นก็ควรบอกนักศึกษาให้บันทึกงานที่สำคัญด้วย **☰ → บันทึกโปรเจกต์** ก่อนเปิดลิงก์จากชั้นเรียน
::

## การบ้านที่นักศึกษาตรวจเองได้ {#assignments-students-can-check-themselves}

นักศึกษาใช้ EduBeam ตรวจการคำนวณมือของตัวเองได้ทันที โดยที่ EduBeam ไม่ได้ทำวิธีทำให้แทน

- **คำนวณก่อน แล้วค่อยตรวจ** ให้คำนวณแรงปฏิกิริยา แรงภายใน และการกระจัดหนึ่งค่าด้วยมือ แล้วให้นักศึกษาสร้างโมเดลและเปรียบเทียบ สูตรอยู่ใน [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification) และ [เริ่มต้นใช้งานด่วน](/th/guide/quick-start#_8-check-by-hand) แสดงขั้นตอนการตรวจ
- **ถามว่าทำไมผลลัพธ์จึงต่างกัน** การเสียรูปเนื่องจากแรงเฉือน จุดหมุนที่ขาดไป แรงกระทำที่กำหนดในแกนท้องถิ่นแทนแกนรวม แต่ละสาเหตุทำให้ผลต่างกันได้ทั้งเล็กน้อยและมาก และการหาสาเหตุให้บทเรียนมากกว่าการได้ค่าตรงกัน
- **ให้ส่งโมเดลมาพร้อมงาน** ขอลิงก์แชร์หรือไฟล์ `project.json` มาพร้อมการคำนวณ คุณเปิดดูได้ว่านักศึกษาสร้างโมเดลไว้อย่างไร
- **รายงานดูเรียบร้อย** นักศึกษาส่งออกภาพวาดเป็น **SVG** ซึ่งคมชัดทั้งใน Word และ LaTeX และส่งออกผลลัพธ์เป็น **CSV** ได้ ดู [ส่งออกรูปภาพ](/th/essentials/import-export#export-an-image)

## แบบฝึกหัดสำเร็จรูป {#ready-made-exercises}

- **[ตัวอย่าง](/th/examples/):** หกโมเดลที่เปิดได้ในคลิกเดียว แต่ละโมเดลมีคำถาม สิ่งที่ควรสังเกต และเฉลย
- **[ฝึกทำโจทย์](/th/practice):** คาน โครงข้อแข็ง และโครงถักที่สร้างอัตโนมัติและตรวจคำตอบของนักศึกษาได้ และ [เครื่องมือสร้างข้อสอบ](/th/exam) ที่พิมพ์โจทย์เหล่านี้เป็นข้อสอบ ดู [ด้านล่าง](#practice-and-test-papers)
- **[บทเรียน](/th/tutorials/inclined-beam):** คานเอียง โครงข้อแข็งสามจุดหมุน โครงถักในระนาบ และคานต่อเนื่องที่มีการทรุดตัวของจุดรองรับ แต่ละบทสร้างโมเดลทีละขั้นและตรวจสอบด้วยการคำนวณมือ ใช้เป็นใบงานในคาบปฏิบัติการได้ บทละ 15–20 นาที
- **[ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification):** กรณีที่มีสูตรปิด ตั้งแต่คานยื่นจนถึงการทรุดตัวของจุดรองรับ ใช้เป็นโจทย์ตรวจสอบสั้น ๆ ได้

## โจทย์ฝึกและข้อสอบ {#practice-and-test-papers}

เว็บไซต์นี้มีสองหน้าที่สร้างโจทย์กลศาสตร์โครงสร้างให้ ไม่ต้องติดตั้งและไม่ต้องเขียนโปรแกรม:

- **[ฝึกทำโจทย์](/th/practice)** ให้โจทย์ใหม่แก่นักศึกษาทุกครั้งที่ขอ นักศึกษาทำบนกระดาษ พิมพ์แรงปฏิกิริยาและโมเมนต์ดัดที่มีค่ามากที่สุดหรือแรงในชิ้นส่วน แล้วหน้าเว็บจะตรวจแต่ละค่ากับคำตอบที่แม่นตรง: คลาดเคลื่อนไม่เกิน 1 % ถือว่าถูก และถ้าขนาดถูกแต่ทิศผิด หน้าเว็บจะบอกให้รู้ คำใบ้บอกว่าควรเริ่มอย่างไร และแผนภาพจะแสดงเมื่อทำเสร็จ โจทย์ทุกข้อมีรหัส เช่น `H2048` ที่หมายถึงโจทย์ข้อเดิมเสมอ ใส่รหัสไว้ในการบ้าน แล้วทุกคนจะตรวจกับตัวเลขชุดเดียวกัน
- **[เครื่องมือสร้างข้อสอบ](/th/exam)** พิมพ์ข้อสอบ: เลือกประเภทโครงสร้าง ข้อสอบแต่ละชุดมีได้สูงสุด 6 ข้อ และสร้างได้สูงสุด 40 ชุด นักศึกษาแต่ละคนจึงได้ข้อสอบคนละชุด ทุกชุดมีโครงสร้างประเภทเดียวกันในลำดับเดียวกัน ข้อสอบจึงยากเท่ากัน เครื่องมือนี้เพิ่มช่องเขียนชื่อ ที่ว่างสำหรับแสดงวิธีทำ และเฉลย ปุ่ม **พิมพ์หรือบันทึกเป็น PDF** ใช้สั่งพิมพ์ ส่วน **ดาวน์โหลด .zip** ให้รูปทุกรูปเป็นไฟล์ SVG สำหรับ LaTeX และ Word และให้คำตอบเป็นตาราง CSV สำหรับการตรวจให้คะแนน

ทั้งสองหน้ามีโครงสร้างแปดประเภทเหมือนกัน: โครงสร้างดีเทอร์มิเนทหกประเภท (คานช่วงเดียวแบบรองรับธรรมดา คานยื่น คานปลายยื่น คาน Gerber โครงข้อแข็งสามจุดหมุน และโครงถัก Warren) และโครงสร้างอินดีเทอร์มิเนทสองประเภท (คานต่อเนื่องสองช่วง และโครงข้อแข็งพอร์ทัล)

เครื่องมือสร้างข้อสอบเก็บการตั้งค่าทั้งหมดไว้ใน URL ของหน้าเว็บ รวมถึง **หมายเลขข้อสอบ** ที่ใช้เลือกตัวเลข บุ๊กมาร์กไว้ แล้วปีหน้าจะได้ข้อสอบและเฉลยชุดเดิมกลับมา โดยค่าเริ่มต้น ข้อสอบจะไม่แสดงรหัสโจทย์ เพราะหน้าฝึกทำโจทย์แสดงเฉลยได้ รหัสโจทย์จึงเหมาะกับการบ้านที่นักศึกษาตรวจงานของตัวเองหลังทำเสร็จ

## แบบฝึกหัด ข้อสอบ และสไลด์จากโค้ด {#exercise-sheets-tests-and-slides-from-code}

แผนภาพในเว็บไซต์นี้วาดด้วย [@edubeam/plot](/th/plot) ไลบรารีคอมโพเนนต์ Vue ที่วาดคาน โครงข้อแข็ง หรือโครงถักในระนาบใดก็ได้ที่คำนวณด้วย [@edubeam/fem](/th/solver) ซึ่งเป็นตัวคำนวณเบื้องหลัง EduBeam ถ้าคุณเขียน JavaScript ได้บ้าง โค้ดไม่กี่บรรทัดก็กลายเป็นสื่อการสอนได้:

- **โจทย์ประเภทของคุณเอง** ถ้าโครงสร้างในเครื่องมือสร้างข้อสอบไม่ใช่แบบที่คุณสอน ก็เขียนเองได้: ค่า seed ของการสุ่มเป็นตัวกำหนดโครงสร้างและตัวเลข ค่า seed เดียวกันจึงให้โจทย์ข้อเดิมเสมอ และเฉลยก็สร้างจากค่า seed เดียวกัน
- **สไลด์ที่ค่อย ๆ เพิ่มทีละชั้น** แสดงโครงสร้าง แล้วจุดรองรับและแรงกระทำ แล้วแรงปฏิกิริยา แล้วแผนภาพโมเมนต์ดัด ทีละขั้น โดยภาพไม่ขยับระหว่างขั้น
- **รูปสำหรับเอกสารและหน้าเว็บรายวิชา** SVG คมชัดที่เปลี่ยนตามธีมสว่างหรือมืดของหน้าเว็บ และต่างจากแอปที่ฝังไว้ตรงที่ไม่แตะต้องโมเดลของนักศึกษาเลย
