# EduBeam คำนวณโมเดลอย่างไร

ทุกครั้งที่คุณแก้ไขโมเดล EduBeam จะคำนวณใหม่ด้วย **วิธีความแข็งโดยตรง** (direct stiffness method) ในเบราว์เซอร์ของคุณภายในไม่กี่มิลลิวินาที หน้านี้ไล่ตามการทำงานของตัวคำนวณ [@edubeam/fem](/th/solver) ทีละขั้นบนตัวอย่างเล็ก ๆ คุณจึงคำนวณตัวเลขทุกค่าซ้ำได้ด้วยมือ และรู้ว่าทำไมผลลัพธ์จึงเชื่อถือได้

ตัวอย่างคือคานปลายยึดแน่น–ปลายรองรับธรรมดา: หน้าตัดเหล็ก IPE 300 ยาว 4 m ยึดแน่นที่ A วางบนล้อเลื่อนที่ B และรับแรงแผ่กระจาย 10 kN/m ความแข็งเกร็งต่อการดัดคือ $EI = 210 \text{ GPa} \times 8356 \text{ cm}^4 = 17{,}548$ kNm² เมื่อไม่คิดการเสียรูปเนื่องจากแรงเฉือน คำตอบตามตำราคือ $M_A = -qL^2/8 = -20$ kNm, $R_B = 3qL/8 = 15$ kN และ $\varphi_B = qL^3/(48EI)$

## จากโมเดลสู่การกระจัด {#from-model-to-displacements}

::div{.steps}
### กำหนดหมายเลขให้องศาความเป็นอิสระ {#number-the-degrees-of-freedom}

ทุกโหนดได้ DOF ตามที่เอลิเมนต์ของโหนดนั้นต้องการ เอลิเมนต์ทุกชิ้นเป็น [เอลิเมนต์คาน](/th/elements/beam) ทุกโหนดจึงมี `Dx`, `Dz` และ `Ry` ตัวคำนวณให้หมายเลข DOF ที่ **เป็นอิสระ** ก่อน แล้วจึงให้หมายเลข DOF ที่ **ถูกยึด** โดยไล่ไปทีละโหนด ในตัวอย่างนี้ A ยึดแน่น ส่วน B ถูกยึดเฉพาะแนวดิ่ง DOF ที่เป็นอิสระจึงมีสององศา

$$
\begin{gathered}
\mathbf{r} = \begin{bmatrix} \mathbf{r}_u \\ \mathbf{r}_p \end{bmatrix},
\qquad
\mathbf{r}_u = \begin{bmatrix} u_B \\ \varphi_B \end{bmatrix}, \\[1ex]
\mathbf{r}_p = \begin{bmatrix} u_A & w_A & \varphi_A & w_B \end{bmatrix}^\mathsf{T}.
\end{gathered}
$$

$u$, $w$ และ $\varphi$ คือการกระจัดตามแกน x และ z และมุมหมุน ตาม [ตาราง DOF](/th/elements/conventions#degrees-of-freedom) เอลิเมนต์แต่ละชิ้นเก็บ **อาร์เรย์ตำแหน่ง** (location array) ไว้ ซึ่งบอกตำแหน่งของ DOF ทั้งหกของเอลิเมนต์ใน $\mathbf{r}$ เมื่อนับจาก 1 DOF ของคาน $(u_A, w_A, \varphi_A, u_B, w_B, \varphi_B)$ อยู่ที่ตำแหน่ง $(3, 4, 5, 1, 6, 2)$

### คำนวณเมทริกซ์ของเอลิเมนต์ {#compute-the-element-matrices}

สำหรับเอลิเมนต์แต่ละชิ้น ตัวคำนวณสร้าง [เมทริกซ์ความแข็งในพิกัดท้องถิ่น](/th/elements/beam#local-stiffness-matrix) ลดรูป [จุดหมุนที่ปลาย](/th/elements/beam#end-hinges) ถ้ามี แล้วแปลงเป็นแกนรวม $\mathbf{K}_g = \mathbf{T}^\mathsf{T}\mathbf{K}_l\,\mathbf{T}$ แรงกระทำบนเอลิเมนต์แต่ละรายการกลายเป็น [แรงที่โหนดสมมูล](/th/elements/beam#element-loads) $\mathbf{f}_\mathrm{eq} = -\mathbf{f}_\mathrm{fix}$ คานของเราอยู่ในแนวนอน $\mathbf{T}$ จึงเป็นเมทริกซ์เอกลักษณ์ และแรงแผ่กระจายสม่ำเสมอให้ค่าดังนี้ (หน่วย kN และ kNm)

$$
\mathbf{f}_\mathrm{eq} = \begin{bmatrix} 0 \\[0.5ex] qL/2 \\[0.5ex] -qL^2/12 \\[0.5ex] 0 \\[0.5ex] qL/2 \\[0.5ex] qL^2/12 \end{bmatrix}
= \begin{bmatrix} 0 \\[0.5ex] 20 \\[0.5ex] -13.33 \\[0.5ex] 0 \\[0.5ex] 20 \\[0.5ex] 13.33 \end{bmatrix}.
$$

### ประกอบเมทริกซ์ {#assemble}

เมทริกซ์ความแข็งรวม $\mathbf{K}$ เริ่มต้นเป็นศูนย์ทั้งหมด เอลิเมนต์แต่ละชิ้นนำสมาชิก $(i, j)$ ของตัวเองไปบวกในแถวและคอลัมน์ที่อาร์เรย์ตำแหน่งระบุสำหรับ $i$ และ $j$ ดังนั้นที่โหนดซึ่งมีหลายเอลิเมนต์มาบรรจบกัน ความแข็งเกร็งของเอลิเมนต์เหล่านั้นสำหรับ DOF ของโหนดนั้นจะรวมกัน เวกเตอร์แรง $\mathbf{F}$ รวบรวมแรงกระทำที่โหนดและแรงที่โหนดสมมูลด้วยวิธีเดียวกัน ส่วนการกระจัดที่กำหนด (การทรุดตัวของจุดรองรับ) ใส่ไว้ใน $\mathbf{r}_p$ เมื่อเรียง DOF อิสระก่อน DOF ที่ถูกยึด ระบบสมการจะแยกเป็นบล็อก

$$
\begin{bmatrix} \mathbf{K}_{uu} & \mathbf{K}_{up} \\ \mathbf{K}_{pu} & \mathbf{K}_{pp} \end{bmatrix}
\begin{bmatrix} \mathbf{r}_u \\ \mathbf{r}_p \end{bmatrix}
=
\begin{bmatrix} \mathbf{F}_u \\ \mathbf{F}_p + \mathbf{R} \end{bmatrix},
$$

โดย $\mathbf{R}$ คือแรงปฏิกิริยาที่ยังไม่ทราบค่า ในตัวอย่างนี้ มีเพียงแถวและคอลัมน์ของปลาย B ของคานที่อยู่ใน $\mathbf{K}_{uu}$

$$
\begin{aligned}
\mathbf{K}_{uu} &= \begin{bmatrix} EA/L & 0 \\ 0 & 4EI/L \end{bmatrix} \\[1ex]
&= \begin{bmatrix} 282{,}450 \text{ kN/m} & 0 \\ 0 & 17{,}548 \text{ kNm} \end{bmatrix}, \\[1ex]
\mathbf{F}_u &= \begin{bmatrix} 0 \\ 13.33 \text{ kNm} \end{bmatrix}.
\end{aligned}
$$

### ใส่เงื่อนไขจุดรองรับและแก้สมการ {#apply-the-supports-and-solve}

จุดรองรับไม่ได้แทนด้วยสปริงหรือตัวเลขค่ามากบนเส้นทแยงมุมหลัก: ตัวคำนวณเพียงแยก DOF ที่ถูกยึดออกไป การกระจัดของ DOF อิสระหาได้จาก

$$
\mathbf{K}_{uu}\,\mathbf{r}_u = \mathbf{F}_u - \mathbf{K}_{up}\,\mathbf{r}_p,
$$

ซึ่งแก้ด้วยการแยกตัวประกอบ LU เมื่อไม่มีการทรุดตัว $\mathbf{r}_p = \mathbf{0}$ และในตัวอย่างนี้

$$
\varphi_B = \frac{13.33}{17{,}548} = 7.598 \times 10^{-4} \text{ rad},
$$

ซึ่งตรงกับ $qL^3/(48EI)$ ในตำรา และ $u_B = 0$

### คำนวณแรงปฏิกิริยา {#compute-the-reactions}

เมื่อทราบการกระจัดทั้งหมดแล้ว แถวของ DOF ที่ถูกยึดจะให้แรงปฏิกิริยา ซึ่งคือแรงที่จุดรองรับกระทำต่อโครงสร้าง

$$
\mathbf{R} = \mathbf{K}_{pu}\,\mathbf{r}_u + \mathbf{K}_{pp}\,\mathbf{r}_p - \mathbf{F}_p.
$$

สำหรับ $w_A$ แถวของ $\mathbf{K}_{pu}$ มีค่า $-6EI/L^2$ ในคอลัมน์ของ $\varphi_B$ และ $\mathbf{F}_p$ มีค่า $qL/2$

$$
\begin{aligned}
R_{wA} &= -\frac{6EI}{L^2}\,\varphi_B - \frac{qL}{2} \\
&= -5 - 20 = -25 \text{ kN},
\end{aligned}
$$

ซึ่งคือ 25 kN ทิศขึ้น (แกน z ชี้ลง) ในทำนองเดียวกัน $R_{\varphi A} = +20$ kNm และ $R_{wB} = -15$ kN ตรงกับ $qL^2/8$ และ $3qL/8$ ในตำรา
::

## ผลลัพธ์ตามชิ้นส่วน {#results-along-the-members}

สำหรับเอลิเมนต์แต่ละชิ้น ตัวคำนวณดึงการกระจัดที่ปลายออกจาก $\mathbf{r}$ แปลงเป็นแกนท้องถิ่น $\mathbf{d}_l = \mathbf{T}\,\mathbf{d}_g$ แล้วคำนวณ [แรงปลาย](/th/elements/conventions#end-forces-element-results-table)

$$
\mathbf{f} = \mathbf{K}_l\,\mathbf{d}_l + \mathbf{f}_\mathrm{fix}.
$$

สำหรับตัวอย่างนี้ $\mathbf{d}_l = [0,\ 0,\ 0,\ 0,\ 0,\ \varphi_B]^\mathsf{T}$ ให้ $Z_{12} = -25$ kN, $M_{12} = 20$ kNm, $Z_{21} = -15$ kN และ $M_{21} = 0$

จากนั้นแรงภายในที่ตำแหน่ง $x$ ใด ๆ หาได้จากสมดุลของส่วนของเอลิเมนต์ระหว่างจุดเริ่มต้นกับ $x$: แรงที่จุดเริ่มต้นบวกกับแรงกระทำบนส่วนนั้น

$$
\begin{aligned}
N(x) &= -X_{12} + N_q(x), \\
V(x) &= -Z_{12} + V_q(x), \\
M(x) &= -M_{12} - Z_{12}\,x + M_q(x),
\end{aligned}
$$

โดย $N_q$, $V_q$ และ $M_q$ มาจากแรงกระทำบนส่วนนั้น สำหรับแรงแผ่กระจายสม่ำเสมอ $q_z$ แรงแผ่กระจายรูปสี่เหลี่ยมคางหมูจาก $q_1$ ถึง $q_2$ (โดย $\Delta q = q_2 - q_1$) และแรง $F_z$ หรือโมเมนต์ $M_y$ ที่ระยะ $a$ ซึ่งมีผลเฉพาะเมื่อ $x \ge a$

$$
\begin{array}{l|cc}
\text{แรงกระทำ} & V_q(x) & M_q(x) \\[0.5ex] \hline
\rule{0pt}{4ex}q_z & -q_z\,x & -\dfrac{q_z\,x^2}{2} \\[3ex]
q_1 \to q_2 & -q_1 x - \dfrac{\Delta q\,x^2}{2L} & -\dfrac{q_1 x^2}{2} - \dfrac{\Delta q\,x^3}{6L} \\[3ex]
F_z,\ M_y & -F_z & -F_z\,(x-a) - M_y
\end{array}
$$

$N_q$ คือ $V_q$ ที่ใช้องค์ประกอบตามแนวแกน $q_x$ และ $F_x$ แทน $q_z$ และ $F_z$

สำหรับตัวอย่างนี้ $M(x) = -20 + 25\,x - 5\,x^2$ kNm มีค่ามากที่สุดที่ $x = 2.5$ m คือ $11.25$ kNm $= 9qL^2/128$ แรงกระทำเนื่องจากอุณหภูมิไม่มีพจน์ของตัวเอง: มีผลผ่านแรงปลายเท่านั้น

การโก่งตัวคือ [ฟังก์ชันรูปร่าง](/th/elements/beam#local-stiffness-matrix) คูณกับการกระจัดที่ปลาย บวกกับการโก่งตัวของแรงกระทำบนเอลิเมนต์เมื่อปลายทั้งสองยึดแน่น ปลายที่มีจุดหมุนจะได้มุมหมุนของตัวเองกลับมาจาก [การลดรูป](/th/elements/beam#end-hinges) ก่อน แผนภาพและรูปร่างที่เสียรูปก็คือฟังก์ชันเหล่านี้ที่คำนวณไปตลอดความยาวของชิ้นส่วนแต่ละชิ้น

## ทำไมผลลัพธ์จึงแม่นตรง {#exact}

ทุกขั้นตอนข้างต้นแม่นตรงสำหรับโมเดลที่คำนวณ

- ความแข็งเกร็งของเอลิเมนต์มาจาก **ผลเฉลยแม่นตรง** ของชิ้นส่วน Timoshenko หน้าตัดคงที่ ไม่ได้มาจากรูปร่างพหุนามที่สมมติขึ้น จึงเป็นความแข็งเกร็งที่แท้จริงของชิ้นส่วน
- แรงปลายยึดแน่นเป็นผลเฉลยแม่นตรงของชิ้นส่วนที่ยึดแน่นสองปลายสำหรับแรงกระทำแต่ละแบบ แรงที่โหนดสมมูลจึงแทนแรงกระทำได้โดยไม่สูญเสียความแม่นยำ
- การกระจัดที่โหนดจึงแม่นตรง และแรงภายในระหว่างโหนดมาจากสมดุลของแรงกระทำจริง จึงแม่นตรงเช่นกัน

EduBeam จึงไม่ต้องให้คุณแบ่งเอลิเมนต์ให้ละเอียดขึ้นเลย: เอลิเมนต์เดียวต่อชิ้นส่วนให้คำตอบเท่ากับร้อยเอลิเมนต์ ต้องมีโหนดเฉพาะตำแหน่งที่ตัวชิ้นส่วนเปลี่ยนไป ได้แก่ จุดรองรับ จุดหมุน มุมโครง หรือตำแหน่งที่หน้าตัดเปลี่ยน แรงกระทำเป็นจุดระหว่างโหนดเหล่านี้ใส่เป็นแรงกระทำบนเอลิเมนต์ได้ ความคลาดเคลื่อนที่เหลืออยู่มีเพียงการปัดเศษของเลขจุดลอยตัว ตารางผลลัพธ์แสดงค่าที่น้อยกว่า $10^{-12}$ ของค่ามากที่สุดในชนิดเดียวกันเป็น 0

คำว่า “แม่นตรง” หมายถึงแม่นตรงสำหรับโมเดล ซึ่งมีข้อจำกัดของตัวเอง

::div{.limits}
- **วัสดุยืดหยุ่นเชิงเส้น** และ **การกระจัดน้อย**: สมการสมดุลเขียนบนรูปร่างก่อนเสียรูป จึงไม่มีผลกระทบอันดับสอง (P–Δ) และไม่มีการโก่งเดาะ
- **ชิ้นส่วนตรงที่มีหน้าตัดคงที่**: หนึ่งหน้าตัดต่อหนึ่งเอลิเมนต์ ชิ้นส่วนที่หน้าตัดค่อย ๆ เปลี่ยนขนาดต้องประมาณด้วยหลายเอลิเมนต์
- **การดัดในระนาบ x–z เท่านั้น**: ไม่มีการบิดและไม่มีพฤติกรรมนอกระนาบ
::

## เมื่อโครงสร้างตั้งอยู่ไม่ได้ {#mechanisms}

โครงสร้างที่เคลื่อนที่ได้โดยไม่เสียรูปมีเมทริกซ์ความแข็งเป็นเอกฐานและไม่มีผลเฉลยที่เป็นหนึ่งเดียว EduBeam ตรวจหากรณีนี้ก่อนคำนวณ และตรวจคำตอบอีกครั้งหลังคำนวณ

1. **ก่อนคำนวณ** EduBeam ตรวจแต่ละส่วนของโครงสร้างที่เชื่อมต่อถึงกันจากรูปทรงเรขาคณิตเพียงอย่างเดียว จุดรองรับต้องหยุดการเคลื่อนที่แบบวัตถุแข็งเกร็งทั้งสามแบบของวัตถุในระนาบได้: ถ้ามีการยึดน้อยกว่าสามรายการ แปลว่าโมเดลยังสร้างไม่เสร็จ (*โครงสร้างต้องมีจุดรองรับจึงจะคำนวณได้*) แต่ถ้ามีสามรายการขึ้นไปที่ยังปล่อยให้โครงสร้างเลื่อนหรือหมุนได้ เช่น ล้อเลื่อนที่ขนานกัน จะถือเป็นข้อผิดพลาด จากนั้นจึงตรวจจุดหมุน: ถ้าชิ้นส่วนหมุนรอบจุดหมุนได้โดยที่ทุกชิ้นส่วนยังยาวเท่าเดิม โครงสร้างเป็นกลไก และ EduBeam จะวาดวงล้อมจุดหมุนเหล่านั้นและแสดงการเคลื่อนที่
2. **ระหว่างคำนวณ** เมทริกซ์ที่เป็นเอกฐานพอดีจะทำให้การแยกตัวประกอบ LU หยุด: *โครงสร้างเป็นกลไก: เมทริกซ์ความแข็งเป็นเมทริกซ์เอกฐาน*
3. **หลังคำนวณ** การกระจัดหรือมุมหมุนที่มากกว่า $10^6$ m หรือ rad แปลว่าเมทริกซ์เป็นเอกฐานจริง ๆ เพียงแต่ความคลาดเคลื่อนจากการปัดเศษทำให้คำนวณต่อได้ EduBeam ระบุโหนดและทิศที่เคลื่อนที่: *โครงสร้างไม่มีเสถียรภาพ: … เคลื่อนที่ได้โดยแทบไม่มีความต้านทาน* วัสดุหรือหน้าตัดที่ใส่ค่าเป็นศูนย์ หรือใส่ผิดหน่วย ก็จะมาลงเอยที่ข้อนี้เช่นกัน

มุมหมุนที่ไม่มีอะไรเชื่อมต่ออยู่ ที่โหนดซึ่งทุกชิ้นส่วนมีจุดหมุน ไม่ถือเป็นกลไก: ตัวคำนวณกำหนดให้มุมหมุนนั้นเป็นศูนย์ หน้า [การแก้ปัญหา](/th/reference/troubleshooting#no-results-are-drawn) อธิบายทุกข้อความและวิธีแก้

## ลองใช้ตัวคำนวณเอง {#library}

ตัวคำนวณเป็นโอเพนซอร์ส: [@edubeam/fem](/th/solver) เขียนด้วย TypeScript ใช้ได้ทั้งในเบราว์เซอร์และ Node ต่อไปนี้คือคานปลายยึดแน่น–ปลายรองรับธรรมดาตัวเดิม

```ts
import { DofID, LinearStaticSolver, type Beam2D } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
const lc = solver.loadCases[0]

// หน่วย SI: m, N, Pa เหล็ก IPE 300 ค่า k = 1e32 ทำให้แข็งเกร็งต่อแรงเฉือน
domain.createMaterial(1, { e: 210e9, g: 81e9 })
domain.createCrossSection(1, { a: 53.8e-4, iy: 8356e-8, h: 0.3, k: 1e32 })

domain.createNode('A', [0, 0, 0], [DofID.Dx, DofID.Dz, DofID.Ry]) // ยึดแน่น
domain.createNode('B', [4, 0, 0], [DofID.Dz]) // ล้อเลื่อน
domain.createBeam2D('1', ['A', 'B'], 1, 1)
lc.createBeamElementUniformEdgeLoad('1', [0, 10_000], true) // 10 kN/m ทิศลง

solver.solve()

solver.neq // 2: Dx และ Ry ของ B เป็นอิสระ
lc.r.toArray() // [0, 0.0007598, 0, 0, 0, 0]: DOF อิสระ แล้วตามด้วย DOF ที่ถูกยึด
lc.R.toArray() // [0, -25000, 20000, -15000]: A (Dx, Dz, Ry) แล้วตามด้วย B (Dz)

const beam = domain.getElement('1') as Beam2D
beam.computeEndForces(lc).toArray() // [0, -25000, 20000, 0, -15000, 0]
beam.computeBendingMomentAt(lc, 0) // -20000: N·m โมเมนต์ลบที่ผนัง
beam.computeBendingMomentAt(lc, 2.5) // 11250: โมเมนต์บวกที่มากที่สุด
```

หลัง `solve()` แล้ว `solver.k` เก็บเมทริกซ์ $\mathbf{K}$ ที่ประกอบแล้ว และ `solver.f` เก็บเวกเตอร์แรง $\mathbf{F}$ ไว้ให้เทียบกับการประกอบของคุณเอง ขั้นตอนในหน้านี้อยู่ในไฟล์ `Solver.ts` (การกำหนดหมายเลข) `LinearStaticSolver.ts` (การประกอบ การแก้สมการ และแรงปฏิกิริยา) และ `Beam2D.ts` (เมทริกซ์ของเอลิเมนต์และผลลัพธ์)
