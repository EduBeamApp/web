# แป้นพิมพ์ เมาส์ และระบบสัมผัส

EduBeam ใช้ได้ทั้งกับแป้นพิมพ์และเมาส์ ทัชแพด หรือนิ้ว หน้านี้รวบรวมแป้นพิมพ์ลัดและท่าทางทั้งหมด บน Mac ให้ใช้ <kbd>Cmd</kbd> แทน <kbd>Ctrl</kbd> ทุกที่ที่เห็น ซึ่งเมนูในแอปจะแสดงเป็น ⌘

## แป้นพิมพ์ {#keyboard}

แป้นพิมพ์ลัดสำหรับการวาด (<kbd>F</kbd>, <kbd>C</kbd>, <kbd>G</kbd>, <kbd>S</kbd>, <kbd>Delete</kbd> และ <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>V</kbd>) ไม่ทำงานขณะเคอร์เซอร์อยู่ในช่องข้อความ การพิมพ์ `f` หรือ `s` ลงในช่องจึงไม่เรียกใช้ทางลัดเหล่านี้ ให้คลิกที่ภาพวาดก่อน

### ไฟล์และประวัติการแก้ไข {#files-and-history}

| ทางลัด | การทำงาน |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | เลิกทำการแก้ไขโมเดลครั้งล่าสุด |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | ทำซ้ำ |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | บันทึกโปรเจกต์ (ดาวน์โหลด `project.json`) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | เปิดโปรเจกต์ |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | ส่งออกรูปภาพ |

เลิกทำยังย้อนการล้างโมเดล การเปิดไฟล์ ลิงก์ หรือตัวอย่าง และการกู้คืนโครงสร้างล่าสุดได้ด้วย ขณะที่ยังพิมพ์อยู่ในเซลล์ตาราง <kbd>Ctrl</kbd>+<kbd>Z</kbd> จะย้อนสิ่งที่พิมพ์ เมื่อยืนยันค่าในเซลล์แล้ว จะเลิกทำการแก้ไขโมเดลแทน ส่วนในช่องของกล่องโต้ตอบ จะย้อนสิ่งที่พิมพ์เสมอ

### การวาด {#drawing}

| ทางลัด | การทำงาน |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | เลือกทั้งหมด |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | คัดลอกโหนด เอลิเมนต์ และแรงกระทำที่เลือก |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | วาง เงาของสำเนาจะเคลื่อนตามเคอร์เซอร์ คลิกเพื่อวาง หรือพิมพ์ระยะเลื่อน Δx, Δz ในแถบประกาศแล้วกด **วาง** หรือ <kbd>Enter</kbd> |
| <kbd>Delete</kbd> | ลบสิ่งที่เลือก (บนโน้ตบุ๊ก Mac ใช้ <kbd>Fn</kbd>+<kbd>Delete</kbd>) |
| <kbd>Esc</kbd> | ออกจากโหมดปัจจุบัน (เพิ่มโหนด เอลิเมนต์ หรือเส้นบอกขนาด วาง หรือเลือกกรอบสำหรับรูปภาพ) และล้างการเลือก นอกจากนี้ยังปิดเมนู ☰ และจบทัวร์ด้วย |
| <kbd>F</kbd> | ปรับเนื้อหาให้พอดีกับหน้าจอ |
| <kbd>C</kbd> | จัดเนื้อหาให้อยู่กึ่งกลาง |
| <kbd>G</kbd> | เปิด/ปิดกริด |
| <kbd>S</kbd> | เปิด/ปิดการสแนปกับกริด |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ซูมภาพวาดเข้า / ออกรอบจุดกึ่งกลาง |

ใน EduBeam <kbd>Ctrl</kbd>+<kbd>+</kbd> และ <kbd>Ctrl</kbd>+<kbd>-</kbd> ซูมเฉพาะภาพวาด ไม่ซูมทั้งอินเทอร์เฟซเหมือนในเว็บไซต์อื่น ใช้ได้กับแป้นพิมพ์ทุกรูปแบบ: ปุ่มที่มีเครื่องหมาย + และ − ไม่ว่าจะอยู่ตำแหน่งใดในแป้นพิมพ์ของคุณ ปุ่มสองปุ่มทางซ้ายของ <kbd>Backspace</kbd> บนแป้นพิมพ์แบบสหรัฐฯ และปุ่ม + และ − บนแป้นตัวเลข

### ตารางและกล่องโต้ตอบ {#tables-and-dialogs}

| ทางลัด | การทำงาน |
| --- | --- |
| <kbd>Enter</kbd> | ในเซลล์ตาราง: ยืนยันค่า ในช่องข้อความของกล่องโต้ตอบ: ยืนยันกล่องโต้ตอบเหมือนปุ่มหลัก |
| <kbd>Esc</kbd> | ในเซลล์ตาราง: ออกจากเซลล์โดยเก็บค่าไว้ ในกล่องโต้ตอบ: ปิดโดยไม่บันทึก |
| <kbd>Tab</kbd> | ไปยังช่องถัดไป เซลล์ตารางจะเก็บสิ่งที่พิมพ์ไว้ |

ช่องตัวเลขรับนิพจน์เลขคณิตแบบที่เขียนเวลาคิดเลข: `6/2`, `3*1.5`, `2^3`, `(4+2)/3` และ `1e3` ส่วนจุดทศนิยมจะพิมพ์เป็นจุลภาคก็ได้

## เมาส์ {#mouse}

| การกระทำ | ผลลัพธ์ |
| --- | --- |
| คลิก | เลือกโหนด เอลิเมนต์ แรงกระทำ หรือเส้นบอกขนาด และเปิดแผงของสิ่งนั้น |
| ลากบนพื้นที่วาดที่ว่าง | กรอบเลือก |
| ลากโหนด | ย้ายโหนด และสแนปกับกริดเมื่อเปิดการสแนป |
| คลิกขณะเพิ่ม | วางโหนด หรือเริ่มหรือต่อเส้นต่อเนื่องของเอลิเมนต์ |
| ดับเบิลคลิกแรงกระทำ | แก้ไขแรงกระทำ (รวมถึงการกระจัดที่กำหนด) |
| คลิกขวา | เมนูพื้นที่วาด: เพิ่มโหนด เพิ่มเอลิเมนต์ เพิ่มเส้นบอกขนาด บอกขนาดเอลิเมนต์ (เมื่อคลิกบนเอลิเมนต์) แก้ไข คัดลอก วาง ลบ |
| <kbd>Ctrl</kbd> + **เพิ่มโหนด** หรือ **เพิ่มเอลิเมนต์** ในเมนูพื้นที่วาด | วางด้วยเมาส์แทนการเปิดกล่องโต้ตอบ |
| ลากด้วยปุ่มกลางหรือปุ่มขวา | เลื่อนมุมมอง เลือกปุ่มได้ใน **การตั้งค่า → การควบคุมและทางลัด → เลื่อนโดยใช้** |
| ล้อเมาส์ | ซูมเข้าหาเคอร์เซอร์ |
| ชี้ที่วัตถุ | Tooltip แสดงการกระจัด คุณสมบัติ หรือค่าแรงกระทำ |

บนทัชแพด ทั้งการจีบนิ้วและการเลื่อนด้วยสองนิ้วจะซูม ถ้าต้องการเลื่อนมุมมอง ให้คลิกแล้วลากด้วยสองนิ้ว ซึ่งเท่ากับการลากด้วยปุ่มขวา

## ระบบสัมผัส {#touch}

| ท่าทาง | ผลลัพธ์ |
| --- | --- |
| แตะ | เลือกวัตถุ และแสดงรายละเอียดและคำสั่งของวัตถุนั้น |
| แตะขณะเพิ่ม | วางโหนดหรือต่อเอลิเมนต์ |
| กดที่โหนดแล้วลาก | ย้ายโหนด |
| ลากนิ้วเดียวที่ตำแหน่งอื่น | เลื่อนมุมมอง |
| จีบนิ้ว | ซูม |
| กดค้างบนพื้นที่วาด | เมนูพื้นที่วาด |
| ปุ่ม **เลือกแบบกรอบ** (มุมขวาบน) แล้วลาก | กรอบเลือก เมนูพื้นที่วาดซึ่งมีคัดลอกและลบจะเปิดตรงจุดที่ยกนิ้วขึ้น |

ขณะเพิ่มโหนด เอลิเมนต์ หรือเส้นบอกขนาด ขณะวาง หรือขณะเลือกกรอบสำหรับรูปภาพ จะมีแถบประกาศที่ด้านบนของภาพวาดบอกชื่อโหมด พร้อมปุ่ม **ยกเลิก** บนหน้าจอสัมผัสซึ่งไม่มีปุ่ม <kbd>Esc</kbd> ปุ่มนี้คือวิธีออกจากโหมด

## แผงของวัตถุ {#object-panels}

การคลิกหรือแตะวัตถุจะเปิดแผงข้าง ๆ วัตถุนั้น พร้อมรายละเอียดและคำสั่งต่อไปนี้:

| วัตถุ | คำสั่ง |
| --- | --- |
| โหนด | เพิ่มแรงกระทำ · จุดรองรับของโหนด (สัญลักษณ์จุดรองรับ, Dx, Dz, Ry) · มุมระบบพิกัดท้องถิ่นของโหนด · กำหนดการกระจัด (บนโหนดที่มีจุดรองรับ) · ลบ |
| เอลิเมนต์ | แก้ไขเอลิเมนต์ (โหนดปลายและจุดหมุน วัสดุ หน้าตัด) · เพิ่มแรงกระทำ · เมทริกซ์ความแข็ง · ลบ |
| แรงกระทำที่โหนดหรือบนเอลิเมนต์ | แก้ไขแรงกระทำ · ลบ |
| เส้นบอกขนาด | แก้ไข · กลับด้านเส้นบอกขนาด · ลบ |

หน้า [ส่วนติดต่อผู้ใช้](/th/essentials/user-interface) พาชมหน้าจอทั้งหมด และ [การควบคุมและทางลัด](/th/essentials/units-settings#controls-shortcuts) ในการตั้งค่าใช้เลือกปุ่มสำหรับเลื่อนมุมมอง
