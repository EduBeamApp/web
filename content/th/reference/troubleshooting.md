# การแก้ปัญหา

เมื่อคำนวณโมเดลไม่ได้ [EduBeam]{.edubeam} จะบอกเหตุผลในข้อความที่มุมซ้ายบนของหน้าจอแสดงผล และปุ่ม **แสดงรายละเอียด** จะแสดงปัญหาทั้งหมดแบบครบถ้วน เลือกชื่อกล่องโต้ตอบที่คุณเห็น แล้วอ่านความหมายและวิธีแก้ของแต่ละข้อความด้านล่าง

::card-grid{cols="2"}
:::card{title="ยังไม่พร้อมคำนวณ" icon="lucide:circle-dashed" to="#still-needed"}
ป้ายสีน้ำเงิน **ต้องมีจุดรองรับ** ไม่มีอะไรผิด เพียงแต่ยังไม่มีจุดรองรับยึดโครงสร้างไว้
:::
:::card{title="ไม่สามารถคำนวณโมเดลได้" icon="lucide:circle-x" to="#errors"}
ข้อความสีแดง จุดรองรับที่ยึดไม่อยู่ จุดหมุนที่ทำให้เกิดกลไก หรือเอลิเมนต์ที่ยาวเป็นศูนย์
:::
:::card{title="คำเตือนของโมเดล" icon="lucide:triangle-alert" to="#warnings"}
ข้อความสีเหลือง คำนวณโมเดลได้แล้ว แต่บางอย่างน่าจะไม่ใช่สิ่งที่คุณตั้งใจ
:::
:::card{title="ผลลัพธ์ดูผิด" icon="lucide:scale" to="#results-look-wrong"}
แรงกระทำชี้ขึ้น การโก่งตัวผิดไปเป็นสิบ ร้อย หรือพันเท่า เครื่องหมายที่ดูกลับด้าน
:::
::

## ข้อความ {#messages}

### ความหมายของสี {#read-the-message}

| สิ่งที่เห็น | ความหมาย |
| --- | --- |
| ป้ายสีน้ำเงิน **ต้องมีจุดรองรับ** | โมเดลยังไม่เสร็จ ให้เพิ่มจุดรองรับ ชี้เมาส์ที่ป้ายเพื่อดูเส้นประที่แสดงว่าโครงสร้างยังเคลื่อนที่ได้อย่างไร |
| ข้อความ **สีแดง** | มีบางอย่างทำให้คำนวณไม่ได้ ข้อความจะบอกปัญหา หรือแสดงเป็น *โมเดลมีข้อผิดพลาด n รายการ* เมื่อมีหลายปัญหา และ EduBeam วงกลมล้อมโหนดที่เกี่ยวข้องไว้บนภาพวาด |
| ข้อความ **สีเหลือง** | คำเตือน แต่ EduBeam ก็ยังคำนวณโมเดลให้ ถ้ามีหลายรายการจะแสดงเป็น *โมเดลมีคำเตือน n รายการ* |
| *ไม่มีการกำหนดวัสดุ* / *ไม่มีการกำหนดหน้าตัด* | เอลิเมนต์ต้องมีทั้งสองอย่าง เพิ่มได้ด้วยปุ่ม **เพิ่มใหม่** ข้างข้อความ |

**แสดงรายละเอียด** เปิดกล่องโต้ตอบชื่อ *ยังไม่พร้อมคำนวณ* *ไม่สามารถคำนวณโมเดลได้* หรือ *คำเตือนของโมเดล* สวิตช์ในกล่องนี้ใช้แสดงหรือซ่อนว่าโครงสร้างเคลื่อนที่ได้อย่างไร และลิงก์ **การแก้ปัญหา** พามาที่หน้านี้

![กล่องโต้ตอบไม่สามารถคำนวณโมเดลได้ พร้อมสวิตช์แสดงว่าโครงสร้างเคลื่อนที่ได้อย่างไร](/screenshots/th/ui-diagnostics.webp){.shot-lg}

บนภาพวาด:

- ปุ่ม **✕** บนข้อความสีแดงจะย่อข้อความเป็นป้ายเล็ก ๆ *ไม่สามารถคำนวณโมเดลได้* เพื่อประหยัดพื้นที่บนหน้าจอเล็ก คลิกป้ายเพื่อขยายกลับ
- ปุ่ม **รูปตา** บนข้อความสีแดงแสดงหรือซ่อนเส้นประของการเคลื่อนที่ **การตั้งค่า → การตั้งค่าโปรแกรมดู → การตรวจสอบโมเดล** ปิดเส้นประและภาพเคลื่อนไหวนี้ถาวรได้
- ปุ่ม **✕** บนข้อความสีเหลืองซ่อนคำเตือน

### สิ่งที่ยังขาด {#still-needed}

โมเดลไม่ได้ผิด เพียงแต่ยังไม่เสร็จ ชี้เมาส์ที่ป้ายเพื่ออ่านข้อความสั้น ส่วนกล่องโต้ตอบแสดงข้อความยาว

| ข้อความ | ความหมายและวิธีแก้ |
| --- | --- |
| *โครงสร้างต้องมีจุดรองรับจึงจะคำนวณได้* <br> *โมเดลต้องมีองศาความเป็นอิสระที่ถูกยึดอย่างน้อย 3 รายการจึงจะมีเสถียรภาพในการวิเคราะห์ 2 มิติ* | ทิศทางที่ถูกยึดรวมกันน้อยกว่าสามทิศทาง ให้เพิ่มจุดรองรับ |
| *ส่วนที่มีโหนด … ต้องมีจุดรองรับ* <br> *ส่วนที่แยกออกของโครงสร้าง (โหนด …) มีองศาความเป็นอิสระที่ถูกยึดน้อยกว่า 3 รายการ และสามารถเคลื่อนที่ได้อย่างอิสระ* | โมเดลแยกเป็นหลายส่วน และมีส่วนหนึ่งลอยอยู่ ให้เชื่อมส่วนนั้นเข้ากับส่วนที่เหลือ หรือใส่จุดรองรับให้ |
| *โครงสร้าง n ส่วนต้องมีจุดรองรับ* | มีหลายส่วนที่ลอยอยู่ กด **แสดงรายละเอียด** เพื่อดูรายการทั้งหมด |

### ข้อผิดพลาด {#errors}

มีบางอย่างทำให้คำนวณไม่ได้ ข้อความสีแดงแสดงข้อความสั้น ส่วนกล่องโต้ตอบแสดงข้อความยาว

| ข้อความ | ความหมายและวิธีแก้ |
| --- | --- |
| *จุดรองรับไม่สามารถยึดโครงสร้างไว้ได้: โครงสร้างยังสามารถเลื่อนในแนวนอน / เคลื่อนที่ในแนวดิ่ง / หมุนได้อย่างอิสระ / เคลื่อนที่แบบวัตถุแข็งเกร็งได้* <br> *โครงสร้างมีจุดรองรับเพียงพอ แต่จุดรองรับไม่สามารถยึดโครงสร้างไว้ได้: โครงสร้างยังสามารถ…* | การยึดมีจำนวนพอ แต่ขนานกันทั้งหมด หรือแนวแรงตัดกันที่จุดเดียว เช่น ล้อเลื่อนสามจุดบนคานแนวนอน เส้นประแสดงการเคลื่อนที่ ให้หมุนหรือย้ายจุดรองรับหนึ่งจุด |
| *ส่วนที่มีโหนด … ไม่ถูกยึดไว้: ยังสามารถ…* <br> *ส่วนที่แยกออกของโครงสร้าง (โหนด …) มีจุดรองรับเพียงพอ แต่จุดรองรับไม่สามารถยึดไว้ได้: ส่วนนี้ยังสามารถ…* | เหมือนข้อบน แต่เกิดกับส่วนหนึ่งของโมเดลที่แยกเป็นหลายส่วน |
| *จุดหมุนที่โหนด … ทำให้โครงสร้างเคลื่อนที่ได้* <br> *จุดรองรับยึดโครงสร้างไว้ได้ แต่โครงสร้างยังเป็นกลไก: ชิ้นส่วนหมุนรอบจุดหมุนที่โหนด … ได้* | จุดหมุนทำให้ชิ้นส่วนหมุนสัมพัทธ์กันได้ เช่น โครงข้อแข็งที่ฐานเสาทั้งสองต้นเป็นหมุดและมีจุดหมุนที่ยอดเสาทั้งสองต้น หรือโครงสี่เหลี่ยมที่ต่อแบบหมุดโดยไม่มีชิ้นส่วนทแยง ให้เอาจุดหมุนออก หรือเพิ่มชิ้นส่วนหรือจุดรองรับ |
| *โครงสร้างไม่มีเสถียรภาพ: เคลื่อนที่ได้แทบไม่มีแรงต้าน* <br> *โครงสร้างไม่มีเสถียรภาพ: โหนด … ในแนวนอน (Dx) … เคลื่อนที่ได้โดยแทบไม่มีความต้านทาน* | เกือบเป็นกลไก หรือความแข็งเกร็งใกล้ศูนย์ ข้อความยาวระบุโหนดและทิศทาง ตรวจสอบจุดรองรับ จุดหมุน และค่า `E`, `A` และ `Iy` |
| *โครงสร้างเป็นกลไก: เคลื่อนที่ได้โดยไม่มีแรงต้าน* <br> *โครงสร้างเป็นกลไก: เมทริกซ์ความแข็งเป็นเมทริกซ์เอกฐาน* | มีบางส่วนเคลื่อนที่ได้อิสระโดยที่การตรวจสอบข้างต้นจับไม่ได้ ตรวจสอบว่าทุกส่วนถูกยึดด้วยการยึดอย่างน้อยสามรายการ และจุดหมุนที่ปลายไม่ทำให้ชิ้นส่วนใดหมุนได้อย่างอิสระ |
| *เอลิเมนต์ … มีความยาวเป็นศูนย์ เพราะโหนด … และ … อยู่ที่ตำแหน่งเดียวกัน* | โหนดสองโหนดของเอลิเมนต์เดียวกันซ้อนทับกัน ให้ย้ายโหนดหนึ่ง หรือลบเอลิเมนต์ |
| *เอลิเมนต์ … อ้างอิงโหนดเดียวกันที่ปลายทั้งสองด้าน* | ลบเอลิเมนต์แล้ววาดใหม่ระหว่างโหนดสองโหนดที่ต่างกัน |
| *เอลิเมนต์ … อ้างอิงโหนด / วัสดุ / หน้าตัด … ที่ไม่มีอยู่* | สิ่งที่เอลิเมนต์ใช้ถูกลบไปแล้ว มักเกิดในไฟล์โปรเจกต์ที่แก้ไขด้วยมือ ให้กำหนดใหม่ในตาราง *เอลิเมนต์* |
| *เอลิเมนต์ … ต้องอ้างอิงโหนดจำนวน 2 โหนดพอดี* | เอลิเมนต์ที่เสียหายในไฟล์ที่นำเข้า ให้ลบแล้ววาดใหม่ |
| *แรงกระทำที่โหนด #n อ้างอิงโหนด … ที่ไม่มีอยู่* <br> *การกระจัดที่กำหนด #n อ้างอิงโหนด … ที่ไม่มีอยู่* | ลบแรงกระทำนั้น หรือกำหนดโหนดที่มีอยู่ให้ |
| *แรงกระทำบนเอลิเมนต์ #n อ้างอิงเอลิเมนต์ … ที่ไม่มีอยู่* | ลบแรงกระทำนั้น |
| *การคำนวณล้มเหลวเนื่องจากความไม่สอดคล้องภายในโมเดล* | ความผิดพลาดทั่วไป ให้เลิกทำขั้นล่าสุด หรือบันทึกโปรเจกต์แล้ว [รายงานปัญหา](#reporting-a-bug) |

### คำเตือน {#warnings}

โมเดลคำนวณได้แล้ว แต่ควรตรวจสอบรายการเหล่านี้:

| ข้อความ | ความหมายและวิธีแก้ |
| --- | --- |
| *โหนด … ไม่ได้เชื่อมต่อกับเอลิเมนต์ใด และจะถูกละเว้นในการคำนวณ* | โหนดลอยที่ไม่ได้ต่อกับเอลิเมนต์ใด ให้ลบหรือเชื่อมต่อ |
| *โหนด … มีจุดรองรับ แต่ไม่มีเอลิเมนต์ใดเชื่อมต่อ จุดรองรับจึงไม่ได้รับแรงใด ๆ* | จุดรองรับบนโหนดลอย |
| *แรงกระทำที่โหนด #n มีค่าที่ไม่ถูกต้อง* <br> *การกระจัดที่กำหนด #n มีค่าที่ไม่ถูกต้อง* | มีองค์ประกอบที่ไม่ใช่ตัวเลข ให้แก้ไขแรงกระทำ |

### ระหว่างแก้ไข {#while-editing}

ข้อความเหล่านี้ขึ้นเป็นกล่องโต้ตอบของเบราว์เซอร์ระหว่างที่คุณทำงาน และโมเดลจะคงเดิม:

| ข้อความ | ความหมายและวิธีแก้ |
| --- | --- |
| *โปรดเพิ่มวัสดุก่อน* <br> *โปรดเพิ่มหน้าตัดก่อน* | เอลิเมนต์ต้องมีทั้งสองอย่าง เพิ่มในแท็บ *วัสดุ* หรือ *หน้าตัด* แล้ววาดเอลิเมนต์อีกครั้ง |
| *โปรดเลือกวัสดุและหน้าตัด* | กล่องโต้ตอบ **เพิ่มเอลิเมนต์** มีช่องว่างอยู่ ให้เลือกทั้งสองอย่าง |
| *ชื่อ … ถูกใช้แล้ว* | โหนด เอลิเมนต์ วัสดุ หรือหน้าตัดสองรายการใช้ชื่อเดียวกันไม่ได้ ให้เลือกชื่ออื่น |
| *โหนดนี้มีการกระจัดที่กำหนดอยู่แล้ว โปรดลบออกก่อน* | โหนดหนึ่งมีการกระจัดที่กำหนดได้รายการเดียว ให้แก้ไขรายการที่มีอยู่ หรือลบออกก่อน |

## ไม่มีผลลัพธ์แสดง {#no-results-are-drawn}

เมื่อแผนภาพไม่ปรากฏ ให้ตรวจสอบตามลำดับนี้:

::div{.steps}

### ตรวจสอบตัวเลือกการแสดงผล {#check-the-display-options}

ถ้าไม่มีข้อความใดเลย แสดงว่าโมเดลคำนวณได้แล้ว แผนภาพอาจแค่ปิดอยู่ ติ๊ก **M<sub>y</sub>(x)** หรือผลลัพธ์อื่นในตัวเลือกการแสดงผลที่มุมขวาบนของหน้าจอแสดงผล ปุ่ม ⚙ เหนือตัวเลือกเหล่านั้นใช้แสดงแผง โมเดลที่ไม่มีแรงกระทำเลยมีผลลัพธ์เป็นศูนย์ทุกที่ จึงไม่มีอะไรให้วาดเช่นกัน

### ตรวจสอบจุดรองรับ {#check-the-supports}

ตัวคำนวณต้องการทิศทางที่ถูกยึดอย่างน้อยสามทิศทาง และจุดรองรับทั้งหมดรวมกันต้องกันไม่ให้โครงสร้างเลื่อนหรือหมุนได้ คานบนล้อเลื่อนสองจุดมีเพียงสองทิศทางและจะเลื่อนหลุดไป ให้เปลี่ยนจุดหนึ่งเป็น **หมุด** ล้อเลื่อนสามจุดที่ขนานกัน หรือจุดรองรับที่แนวแรงตัดกันที่จุดเดียว ก็ยึดโครงสร้างไว้ไม่ได้เช่นกัน ดู [โหนดและจุดรองรับ](/th/essentials/nodes-supports#supports)

### ตรวจสอบว่าเอลิเมนต์เชื่อมต่อกัน {#check-the-connections}

โหนดสองโหนดที่มีพิกัดเดียวกันยังเป็นสองโหนดแยกกัน และส่วนที่แตะส่วนอื่นเฉพาะตรงนั้นจะลอยเป็นอิสระ ให้ลบโหนดที่เกินแล้วเชื่อมต่อใหม่ เมื่อวางโหนดบนเอลิเมนต์ ให้ตอบ **เชื่อมต่อกับโครงสร้าง** เพื่อแบ่งเอลิเมนต์ที่ตำแหน่งนั้น

### นับจุดหมุน {#count-the-hinges}

โครงข้อแข็งที่ฐานเสาทั้งสองต้นเป็นหมุดและมีจุดหมุนที่ยอดเสาทั้งสองต้น หรือโครงสี่เหลี่ยมที่ต่อแบบหมุดโดยไม่มีชิ้นส่วนทแยง เป็นกลไก EduBeam จะวงกลมล้อมจุดหมุนเหล่านั้น และแสดงเส้นประที่แกว่งไปตามการเคลื่อนที่ ดู [จุดหมุนที่ปลาย](/th/essentials/elements#end-hinges)

### มองหาความแข็งเกร็งที่เป็นศูนย์ {#look-for-zero-stiffness}

`E`, `A` หรือ `Iy` ที่ใส่เป็น 0 หรือใส่ผิดหน่วย ทำให้บางส่วนของโครงสร้างเคลื่อนที่ได้โดยแทบไม่มีความต้านทาน EduBeam รายงานกรณีนี้ว่า *ไม่มีเสถียรภาพ*

::

## ผลลัพธ์ดูผิด {#results-look-wrong}

| อาการ | สาเหตุที่น่าจะเป็น |
| --- | --- |
| แรงกระทำชี้ขึ้น | แกนรวม **z ชี้ลง** `Fz` หรือ `fz` ที่เป็นบวกจึงมีทิศลง ค่าลบชี้ขึ้น ถ้าใช้แกน y ชี้ขึ้นจะกลับกัน ดู [แรงกระทำ](/th/essentials/loads#sign-convention-in-one-line) |
| การโก่งตัวผิดไปเป็นสิบ ร้อย หรือพันเท่า | ใช้หน่วยสับสน: ใส่ `E` เป็น Pa ขณะที่ช่องรับค่าเป็น MPa หรือใส่ `Iy` เป็น cm⁴ ขณะที่ช่องรับค่าเป็น m⁴ ป้ายหน่วยที่มุมขวาล่างของหน้าจอแสดงผลบอกหน่วยที่ทุกช่องใช้ |
| การโก่งตัวมากกว่าสูตรในตำราเล็กน้อย | การเสียรูปเนื่องจากแรงเฉือนของคาน Timoshenko ดู [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification#shear-deformation) |
| เครื่องหมายดูผิด | อ่านเครื่องหมายจากค่า ไม่ใช่จากด้านที่วาดแผนภาพ M ที่เป็นบวกคือโมเมนต์บวก แรงปลายใน *ผลลัพธ์ที่เอลิเมนต์* เป็นไปตามแกนท้องถิ่นของเอลิเมนต์ ไม่ใช่ข้อตกลงของ N-V-M ดู [การอ่านเครื่องหมาย](/th/essentials/results#reading-the-sign) |
| แผนภาพอยู่ “ผิด” ด้าน | ด้านที่วาดเป็นการตั้งค่าการแสดงผล: โมเมนต์ดัดวาดด้านรับแรงดึงหรือด้านรับแรงอัด N และ V วาดด้านใดด้านหนึ่งของเส้นประ **การตั้งค่า → การตั้งค่าโปรแกรมดู → แผนภาพแรงภายใน** |
| เสาสองต้นที่เหมือนกันมีเครื่องหมายแรงเฉือนตรงข้ามกัน | เครื่องหมายของ V เป็นไปตามทิศของแต่ละเอลิเมนต์ สลับโหนดของต้นหนึ่งเพื่อเปรียบเทียบ |
| ตัวเลขอย่าง `4 · 10¹` | รูปแบบตัวเลขแบบวิทยาศาสตร์ เลือก *อัตโนมัติ* ใน **การตั้งค่า → ภาษาและภูมิภาค → รูปแบบตัวเลข** |
| แผนภาพใหญ่หรือเล็กมาก | เป็นเรื่องของภาพวาดเท่านั้น ปรับ **ขนาดผลลัพธ์** ใน **การตั้งค่า → การตั้งค่าโปรแกรมดู** |
| แรงกระทำในแกนท้องถิ่นชี้ผิดทาง | แกน x ท้องถิ่นของเอลิเมนต์ชี้จากโหนด *เริ่มต้น* ไปยังโหนด *ปลาย* ให้สลับโหนด หรือกลับเครื่องหมาย |
| แรงกระทำบนชิ้นส่วนเอียงไม่ถูกต้อง | ช่อง **LCS** ติ๊กไว้เป็นค่าเริ่มต้น `fz` จึงกระทำตั้งฉากกับชิ้นส่วน ยกเลิกการติ๊กถ้าต้องการแรงแนวดิ่ง |
| แรงกระทำเนื่องจากอุณหภูมิไม่มีผล | โครงสร้างดีเทอร์มิเนทเสียรูปได้อย่างอิสระภายใต้อุณหภูมิโดยไม่เกิดแรงภายใน ถ้าต้องการเห็นการเสียรูป ให้ตรวจสอบว่า α ไม่เป็น 0 และสำหรับผลต่างอุณหภูมิ ให้ตรวจว่ากำหนดความสูงหน้าตัด $h$ แล้ว |

| ลิงก์ที่สั้นกว่าเปิดไม่ได้ที่เครื่องของเพื่อนร่วมงาน | EduBeam ของเพื่อนร่วมงานเก่ากว่าเวอร์ชัน 1.3.2 เพื่อนร่วมงานควรโหลดแอปใหม่ หรือคุณแชร์โดยปิด **ลิงก์ที่สั้นกว่า** ไว้ ดู [แชร์ลิงก์](/th/essentials/import-export#share-a-link) |

## ปัญหาของอินเทอร์เฟซ {#interface-issues}

| อาการ | วิธีแก้ |
| --- | --- |
| ทางลัดไม่ทำงาน | คลิกที่ภาพวาดก่อน: ปุ่มเดี่ยวจะไม่ทำงานขณะเคอร์เซอร์อยู่ในช่องข้อความ บน Mac ให้ใช้ <kbd>Cmd</kbd> แทน <kbd>Ctrl</kbd> ดู [แป้นพิมพ์ เมาส์ และระบบสัมผัส](/th/reference/shortcuts) |
| <kbd>Delete</kbd> ไม่ทำงานบน Mac | ปุ่มที่เขียนว่า *delete* บนแป้นพิมพ์ Mac คือ Backspace ให้กด <kbd>Fn</kbd>+<kbd>Delete</kbd> |
| เลื่อนมุมมองไม่ได้ | การเลื่อนมุมมองใช้ปุ่มกลางหรือปุ่มขวาของเมาส์ เลือกได้ใน **การตั้งค่า → การควบคุมและทางลัด** บนทัชแพด ให้คลิกแล้วลากด้วยสองนิ้ว บนหน้าจอสัมผัส ให้ลากด้วยนิ้วเดียว |
| โมเดลของฉันหายไป | การเปิดลิงก์ ไฟล์ หรือตัวอย่าง และการล้างโมเดล จะเก็บโมเดลเดิมไว้: **☰ → โครงสร้างล่าสุด** หรือ <kbd>Ctrl</kbd>+<kbd>Z</kbd> เมื่อเปิดลิงก์ จะมีข้อความที่ด้านล่างของหน้าจอบอกว่า *เปิดโครงสร้างที่แชร์แล้ว โครงสร้างก่อนหน้าถูกเก็บไว้ใน โครงสร้างล่าสุด* พร้อมปุ่ม **แสดง** |
| ภาษาไม่ถูกต้อง | **การตั้งค่า → ภาษาและภูมิภาค** หรือเพิ่ม `?lang=th` ต่อท้ายที่อยู่ |
| การตั้งค่าที่เปลี่ยนไว้หายไป | local storage ถูกบล็อก เช่น ในหน้าต่างส่วนตัวหรือโหมดความเป็นส่วนตัวแบบเข้มงวด ทั้งการตั้งค่า โมเดลที่บันทึกไว้ และโครงสร้างล่าสุดต้องใช้ local storage |
