# คำถามที่พบบ่อย

คำตอบสั้น ๆ แต่ละข้อมีลิงก์ไปยังหน้าที่อธิบายเรื่องนั้นอย่างละเอียด ถ้าไม่พบคำถามของคุณ ดู [การแก้ปัญหา](/th/reference/troubleshooting) หรือ [ถามบน GitHub](https://github.com/janvorisek/edubeam/issues)

## ทั่วไป {#general}

### EduBeam คืออะไร? {#what-is-edubeam}

แอปโอเพนซอร์สที่ใช้ฟรีสำหรับการวิเคราะห์สถิตเชิงเส้นของคาน โครงข้อแข็ง และโครงถัก 2 มิติ ทำขึ้นสำหรับนักศึกษา ผู้สอน และวิศวกรที่ต้องการเห็นผลทันที ทำงานบนเบราว์เซอร์ หน้า [บทนำ](/th/guide/introduction) บอกว่าทำอะไรได้และทำอะไรไม่ได้

### ฟรีจริงไหม? ต้องมีบัญชีหรือเปล่า? {#is-it-really-free-do-i-need-an-account}

ฟรีจริง และไม่ต้องมีบัญชี เปิด [run.edubeam.app](https://run.edubeam.app/?lang=th){target="_blank"} แล้วเริ่มสร้างโมเดลได้เลย ไม่ต้องติดตั้งอะไร และไม่จำกัดการใช้งาน ซอร์สโค้ดอยู่บน [GitHub](https://github.com/janvorisek/edubeam) ภายใต้สัญญาอนุญาต GPL-3.0

### ใช้กับเบราว์เซอร์และอุปกรณ์ใดได้บ้าง? {#which-browsers-and-devices-work}

Chrome, Edge, Firefox หรือ Safari เวอร์ชันปัจจุบัน บนคอมพิวเตอร์ แท็บเล็ต หรือโทรศัพท์ บนหน้าจอสัมผัส ให้แตะเพื่อเลือก ลากโหนดเพื่อย้าย ลากที่อื่นเพื่อเลื่อนมุมมอง จีบนิ้วเพื่อซูม และกดค้างเพื่อเปิดเมนูของพื้นที่วาด แต่เมาส์และแป้นพิมพ์ยังสร้างโมเดลได้เร็วกว่า ดู [แป้นพิมพ์ เมาส์ และระบบสัมผัส](/th/reference/shortcuts#touch)

### โมเดลหาย กู้คืนได้ไหม? {#i-lost-my-model-can-i-get-it-back}

น่าจะได้ เมื่อคุณล้างโมเดล หรือเปิดลิงก์ ไฟล์ หรือตัวอย่างทับโมเดลเดิม EduBeam จะเก็บโมเดลนั้นไว้ใน **☰ → โครงสร้างล่าสุด** (10 รายการล่าสุด) และ <kbd>Ctrl</kbd>+<kbd>Z</kbd> ยกเลิกการแทนที่ได้ ทั้งสองอย่างอยู่ในเบราว์เซอร์นี้เท่านั้น โมเดลจากคอมพิวเตอร์เครื่องอื่นหรือโปรไฟล์เบราว์เซอร์อื่นจึงไม่อยู่ในนั้น ดู [โครงสร้างล่าสุด](/th/essentials/import-export#recent-structures)

### ใช้แบบออฟไลน์ได้ไหม? {#can-i-use-it-offline}

ได้ EduBeam เป็น progressive web app เมื่อเบราว์เซอร์โหลดแอปแล้วครั้งหนึ่ง ก็ใช้งานต่อได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต และเบราว์เซอร์อาจเสนอให้ติดตั้ง เมื่อมีเวอร์ชันใหม่ จะมีกล่องโต้ตอบถามก่อนอัปเดต

### ข้อมูลของฉันเก็บไว้ที่ไหน? {#where-is-my-data-stored}

ในเบราว์เซอร์ของคุณ ไม่มีบัญชีและไม่มีที่เก็บข้อมูลบนคลาวด์ แอปเก็บโมเดลและการตั้งค่าไว้ในเบราว์เซอร์นี้ และลิงก์แชร์เก็บโมเดลไว้ในตัวลิงก์เอง ดู [สิ่งที่เก็บไว้ในเบราว์เซอร์ของคุณ](/th/essentials/units-settings#what-is-stored-in-your-browser)

แต่แอปที่ run.edubeam.app เก็บสถิติการใช้งาน (Google Analytics) และรายงานข้อผิดพลาด (Sentry) รายงานข้อผิดพลาด และการบันทึกเซสชันบางส่วนที่ Sentry สุ่มเก็บ อาจมีสิ่งที่แสดงบนหน้าจออยู่ด้วย รวมถึงโมเดลของคุณ

### ฝึกทำโจทย์กลศาสตร์โครงสร้างได้ที่ไหน? {#practice}

ที่หน้า [ฝึกทำโจทย์](/th/practice) หน้านี้ให้คาน โครงข้อแข็ง หรือโครงถักที่มีตัวเลขใหม่ทุกครั้ง หาแรงปฏิกิริยาและโมเมนต์ดัดที่มีค่ามากที่สุดหรือแรงในชิ้นส่วนบนกระดาษ แล้วพิมพ์ลงไป หน้าเว็บจะตรวจแต่ละค่าทันที [ตัวอย่าง](/th/examples/) ก็มีคำถามพร้อมเฉลยเช่นกัน ผู้สอนพิมพ์ข้อสอบคนละชุดพร้อมเฉลยให้นักศึกษาทุกคนได้จาก [เครื่องมือสร้างข้อสอบ](/th/exam) ดู [โจทย์ฝึกและข้อสอบ](/th/guide/teaching#practice-and-test-papers)

### จะอ้างอิง EduBeam อย่างไร? {#cite}

อ้างอิงเป็นซอฟต์แวร์ โดยระบุเวอร์ชันและวันที่ใช้งาน เวอร์ชันอยู่ด้านล่างสุดของเมนู **☰** ตัวอย่างเช่น:

> Voříšek, J. และผู้ร่วมพัฒนา. *EduBeam* (เวอร์ชัน 1.3.4) \[ซอฟต์แวร์\]. สืบค้นเมื่อ 18 พฤศจิกายน 2569, จาก https://edubeam.app

ถ้าต้องการอ้างถึงโมเดลใดโมเดลหนึ่ง ให้แนบ [ลิงก์แชร์](/th/essentials/import-export#share-a-link) ของโมเดลนั้น ผู้อ่านทุกคนจะเปิดได้โมเดลเดียวกัน

## การสร้างโมเดล {#modelling}

### จะสร้างจุดรองรับแบบยึดแน่น หมุด หรือล้อเลื่อนอย่างไร? {#how-do-i-make-a-fixed-pinned-roller-support}

คลิกโหนด เลือก **จุดรองรับของโหนด** แล้วเลือกสัญลักษณ์: หมุด ล้อเลื่อน ยึดแน่น แบบเลื่อน และอื่น ๆ หรือติ๊กองศาความเป็นอิสระที่ยึดไว้ในแท็บ **โหนด**: `Dx` + `Dz` + `Ry` คือยึดแน่น `Dx` + `Dz` คือหมุด และ `Dz` อย่างเดียวคือล้อเลื่อน หน้า [โหนดและจุดรองรับ](/th/essentials/nodes-supports#supports) แสดงทุกประเภท

### จะสร้างโครงถักอย่างไร? {#how-do-i-make-a-truss}

วาดชิ้นส่วนโครงถักเป็นเอลิเมนต์ธรรมดา แล้วปลดทั้งสองปลายของแต่ละชิ้น: ติ๊ก **จุดหมุนที่ปลาย** ทั้งสองช่องในแท็บ **เอลิเมนต์** หรือติ๊ก **จุดหมุนที่จุดเริ่มต้น** และ **จุดหมุนที่จุดปลาย** ในแถบประกาศก่อนวาดชิ้นส่วนด้วยเมาส์ ใส่แรงกระทำที่จุดต่อ บทเรียน [โครงถักในระนาบ](/th/tutorials/truss) สร้างโครงถักทีละขั้น

### จะใส่จุดหมุนในโครงข้อแข็งอย่างไร? {#how-do-i-put-a-hinge-in-a-frame}

ปลดโมเมนต์ที่ปลายของเอลิเมนต์ที่ควรหมุนได้อิสระ: ติ๊กจุดหมุนที่ปลายนั้นในแท็บ **เอลิเมนต์** จุดหมุนเป็นของปลายเอลิเมนต์เพียงปลายเดียว ที่โหนดซึ่งมีหลายเอลิเมนต์มาต่อกัน ถ้าปลดเพียงเอลิเมนต์เดียว เอลิเมนต์อื่นจะยังต่อกันแบบแข็งเกร็งอยู่ ดู [จุดหมุนที่ปลาย](/th/essentials/elements#end-hinges)

### จะเพิ่มจุดรองรับหรือแรงกระทำเป็นจุดตรงกลางคานอย่างไร? {#how-do-i-add-a-support-or-a-point-load-in-the-middle-of-a-beam}

สำหรับจุดรองรับ ให้เพิ่มโหนดบนคานด้วยเมาส์ (ปุ่ม **เพิ่มโหนด** ที่มีไอคอนเคอร์เซอร์) แล้วเลือก **เชื่อมต่อกับโครงสร้าง** EduBeam จะแบ่งคานเป็นสองส่วนที่โหนดนั้น แล้วจึงใส่จุดรองรับที่โหนดได้ ส่วนแรงกระทำเป็นจุดไม่ต้องมีโหนด: เพิ่ม **แรงกระทำเป็นจุด** บนเอลิเมนต์ แล้วกำหนดตำแหน่งจากโหนดเริ่มต้น ดู [การวางโหนดบนเอลิเมนต์ที่มีอยู่](/th/essentials/nodes-supports#placing-a-node-on-an-existing-element) และ [แรงกระทำเป็นจุด](/th/essentials/loads#concentrated-load)

### ใส่น้ำหนักตัวเองได้ไหม? {#can-i-apply-self-weight}

ไม่ได้แบบอัตโนมัติ เพราะการวิเคราะห์สถิตไม่ได้ใช้ความหนาแน่นของวัสดุ ให้ใส่เป็นแรงแผ่กระจายสม่ำเสมอ $f_z = \rho g A$ เช่น สำหรับ IPE 200: $7850 \cdot 9.81 \cdot 28.48 \cdot 10^{-4} = 219$ N/m หรือ 0.22 kN/m

### สร้างจุดรองรับแบบเอียงได้ไหม? {#can-i-model-inclined-supports}

ได้ กำหนด **มุมระบบพิกัดท้องถิ่นของโหนด** ให้โหนด แล้วจุดรองรับของโหนดนั้นจะทำงานตามแกนที่หมุนแล้ว ดู [จุดรองรับแบบเอียง](/th/essentials/nodes-supports#inclined-skewed-supports)

### ใช้หน่วยอเมริกันได้ไหม? {#can-i-work-in-us-customary-units}

ได้ คลิกป้ายหน่วยที่มุมขวาล่างของหน้าจอแสดงผล ซึ่งจะเปิด **การตั้งค่า → ภาษาและภูมิภาค** แล้วตั้ง **ระบบหน่วย** เป็น **ระบบอเมริกัน (อิมพีเรียล)** เพื่อใช้ฟุตและกิป หรือเลือกทีละหน่วยก็ได้ โมเดลเก็บค่าในหน่วย SI การเปลี่ยนหน่วยจึงแปลงเฉพาะสิ่งที่แสดง และไม่เปลี่ยนโมเดลเลย ดู [หน่วยและการตั้งค่า](/th/essentials/units-settings)

### มีกรณีแรงกระทำหรือการจัดหมู่แรงกระทำไหม? {#are-there-load-cases-or-combinations}

ไม่มี โมเดลหนึ่งมีกรณีแรงกระทำเดียว ให้บันทึกแต่ละกรณีเป็นไฟล์หรือลิงก์แยกกัน แล้วรวมผลเอง เซสชันจาก EduBeam รุ่นเดสก์ท็อปที่มีหลายกรณีแรงกระทำจะเปิดด้วยกรณีแรก และมีข้อความบอกว่ากรณีใดที่ไม่ได้นำเข้า

### ทำไมแรงกระทำของฉันชี้ขึ้น? {#why-do-my-loads-point-up}

น่าจะเป็นเพราะใส่ค่าลบ ใน EduBeam แกนรวม z ชี้ **ลง** `fz` หรือ `Fz` ที่เป็นบวกจึงเป็นแรงทิศลงตามแรงโน้มถ่วง: แรง 12 kN/m ทิศลงคือ `fz = 12` ดู [ระบบพิกัดและข้อตกลงเรื่องเครื่องหมาย](/th/elements/conventions#loads) ถ้าวิชาของคุณใช้แกนดิ่งชี้ขึ้น ให้สลับไปใช้ **x ไปทางขวา, y ชี้ขึ้น** ใน **การตั้งค่า → ภาษาและภูมิภาค → ระบบพิกัด** แล้วค่าที่ใส่และผลลัพธ์จะเป็นไปตามแกนนั้น

## ผลลัพธ์ {#results}

### ทำไมไม่มีปุ่ม “คำนวณ”? {#why-is-there-no-solve-button}

เพราะ EduBeam คำนวณโมเดลใหม่ทุกครั้งที่มีการแก้ไข ถ้าไม่มีผลลัพธ์แสดง แสดงว่ายังคำนวณโมเดลไม่ได้ และมีข้อความบนพื้นที่วาดบอกเหตุผล หน้า [การแก้ปัญหา](/th/reference/troubleshooting#no-results-are-drawn) มีรายการสิ่งที่ควรตรวจสอบ

### ทำไมการโก่งตัวต่างจากสูตรเล็กน้อย? {#why-does-my-deflection-differ-slightly-from-the-formula}

EduBeam ใช้เอลิเมนต์คาน Timoshenko การโก่งตัวจึงรวมการเสียรูปเนื่องจากแรงเฉือนซึ่งสูตรในตำรามักไม่คิด สำหรับคานชะลูด ความต่างอยู่ราว 1 % และ [เริ่มต้นใช้งานด่วน](/th/guide/quick-start#_8-check-by-hand) คำนวณส่วนนี้ด้วยมือให้ดู ในโครงสร้างอินดีเทอร์มิเนท ความแข็งเกร็งต่อแรงเฉือนยังทำให้แรงภายในเปลี่ยนไปเล็กน้อยด้วย ดูเพิ่มเติมใน [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification)

### ผลลัพธ์แม่นยำแค่ไหน? ต้องใช้เอลิเมนต์มากขึ้นไหม? {#how-accurate-are-the-results-do-i-need-more-elements}

สำหรับการวิเคราะห์สถิตเชิงเส้น เอลิเมนต์คานให้ผลแม่นตรงสำหรับแรงกระทำทุกประเภทที่ EduBeam มี ชิ้นส่วนหนึ่งชิ้นจึงใช้เอลิเมนต์เดียวก็พอ และไม่ต้องแบ่งเอลิเมนต์ให้ละเอียดขึ้น เพิ่มโหนดเฉพาะที่ที่ต้องการจุดรองรับ จุดหมุน การเปลี่ยนหน้าตัด แรงกระทำที่โหนด หรือการกระจัดที่ต้องการอ่านค่า ดู [ความละเอียดและความแม่นยำ](/th/essentials/results#precision-and-accuracy)

### EduBeam คำนวณผลลัพธ์อย่างไร? {#how-does-edubeam-compute-the-results}

ด้วยวิธีความแข็งโดยตรงของวิธีไฟไนต์เอลิเมนต์ ซึ่งเป็นวิธีที่สอนในวิชาการวิเคราะห์โครงสร้าง และคำนวณในเบราว์เซอร์ของคุณ หน้า [EduBeam คำนวณโมเดลอย่างไร](/th/elements/analysis) ไล่ทุกขั้นบนตัวอย่างเล็ก ๆ ที่คุณคำนวณมือตามได้ และตัวคำนวณเองก็เป็นโอเพนซอร์สในชื่อ [@edubeam/fem](/th/solver)

### ดูเมทริกซ์ความแข็งได้ไหม? {#can-i-see-the-stiffness-matrices}

ได้ ในแท็บ **เอลิเมนต์** ปุ่มเมทริกซ์ในแถวของเอลิเมนต์จะเปิดเมทริกซ์ความแข็งขนาด 6 × 6 ในแกนรวมและหน่วย SI (N, m) การคลิกเอลิเมนต์บนหน้าจอแสดงผลก็มีตัวเลือก **เมทริกซ์ความแข็ง** เช่นกัน หน้า [เอลิเมนต์คาน](/th/elements/beam#global-stiffness-matrix) แสดงที่มาของเมทริกซ์นี้

### แรงปฏิกิริยาแสดงอยู่ที่ไหน? {#where-are-the-reactions-listed}

บนหน้าจอแสดงผลเป็นลูกศรพร้อมค่า: **แรงปฏิกิริยา** ในตัวเลือกการแสดงผล ซึ่งเปิดเป็นค่าเริ่มต้น และยังอยู่ในไฟล์จาก **ผลลัพธ์ → ส่งออก CSV** และในข้อมูลที่ **คัดลอก** วางลงคลิปบอร์ด แท็บ **ผลลัพธ์** แสดงการกระจัดที่โหนดและแรงปลายของเอลิเมนต์ ดู [ผลลัพธ์และแผนภาพ](/th/essentials/results)

## ไฟล์และการแชร์ {#files-sharing}

### จะแชร์โมเดลอย่างไร? {#how-do-i-share-a-model}

กด **แชร์โมเดล** แล้วกด **คัดลอก** ลิงก์นี้เก็บโมเดลไว้ทั้งหมด และผู้ที่เปิดลิงก์จะได้สำเนาของตัวเองไว้แก้ไข ไม่มีการทำงานร่วมกันแบบเรียลไทม์ เปิด **แสดงสิ่งที่ฉันเห็น** ถ้าต้องการให้ลิงก์เปิดพร้อมแผนภาพและป้ายชื่อที่คุณเปิดไว้ ดู [แชร์ลิงก์](/th/essentials/import-export#share-a-link) และสำหรับรายวิชา ดู [สอนด้วย EduBeam](/th/guide/teaching#in-lecture-notes-and-assignments)

### ฝังโมเดลในเว็บไซต์หรือสไลด์ได้ไหม? {#can-i-embed-a-model-on-my-website-or-in-slides}

ได้ เพิ่ม `&viewer=1` ต่อท้ายลิงก์แชร์แล้วใส่ใน `<iframe>` ดู [ฝังโปรแกรมดู](/th/essentials/import-export#embed-a-read-only-viewer) ถ้าต้องการรูปนิ่งในหน้าเว็บ สไลด์ หรือเอกสารที่พิมพ์ ให้ส่งออกเป็น SVG หรือวาดจากโค้ดด้วย [@edubeam/plot](/th/plot)

### ส่งออกรูปภาพหรือตารางได้ไหม? {#can-i-export-images-or-tables}

ได้ **☰ → ส่งออกรูปภาพ** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) บันทึกภาพวาดเป็น PNG หรือ SVG ตามขนาดหรือมาตราส่วนที่เลือก **ผลลัพธ์ → ส่งออก CSV** บันทึกตารางผลลัพธ์ทั้งสองตาราง และ **คัดลอก** วางตารางลงคลิปบอร์ดสำหรับสเปรดชีต ดู [ส่งออกรูปภาพ](/th/essentials/import-export#export-an-image)

### เปิดไฟล์จาก EduBeam รุ่นเดสก์ท็อปได้ไหม? {#can-i-open-files-from-the-desktop-edubeam}

ได้ เซสชันที่บันทึกจาก EduBeam รุ่นเดสก์ท็อป 2.x ถึง 3.5 (`.xml`) เปิดได้ด้วย **☰ → เปิดโปรเจกต์** หรือลากไฟล์มาวางบนแอป เหมือนไฟล์ `project.json` ค่าในไฟล์จะอ่านเป็นหน่วย kN, kPa และ m ดู [เปิดโปรเจกต์](/th/essentials/import-export#open-a-project)

### สร้างโมเดลด้วยโปรแกรมได้ไหม? {#can-i-generate-models-programmatically}

ได้ มีสองวิธี:

- **เขียนไฟล์** `project.json` เป็น JSON ธรรมดาในหน่วย SI สคริปต์ภาษาใดก็เขียนไฟล์นี้ได้ และ EduBeam เปิดได้ด้วย **เปิดโปรเจกต์** หรือลากไฟล์มาวาง ดู [รูปแบบไฟล์โปรเจกต์](/th/essentials/import-export#project-file-format)
- **คำนวณในโค้ด** [@edubeam/fem](/th/solver) คือตัวคำนวณไฟไนต์เอลิเมนต์เบื้องหลัง EduBeam ในรูปไลบรารี JavaScript และ TypeScript จากนั้น [@edubeam/plot](/th/plot) วาดผลลัพธ์ได้ เช่น เป็น [แบบฝึกหัดที่สร้างอัตโนมัติ](/th/plot/exercises)

คานจาก [เริ่มต้นใช้งานด่วน](/th/guide/quick-start) ในหน่วย SI:

```ts
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
domain.createMaterial('steel', { e: 210e9, g: 81e9 }) // Pa
const section = { a: 28.48e-4, iy: 1943e-8, h: 0.2, k: 0.3933 } // m², m⁴, m
domain.createCrossSection('IPE200', section)
domain.createNode('1', [0, 0, 0], [DofID.Dx, DofID.Dz]) // หมุด
domain.createNode('2', [6, 0, 0], [DofID.Dz]) // ล้อเลื่อน
const beam = domain.createBeam2D('1', ['1', '2'], 'steel', 'IPE200')
const lc = solver.loadCases[0]
lc.createBeamElementUniformEdgeLoad('1', [0, 12e3], true) // 12 kN/m ทิศลง

solver.solve()
beam.computeBendingMomentAt(lc, 3) // 54000 N·m ที่กึ่งกลางช่วง
beam.computeLocalDefl(lc, 2).w[1] // 0.0502 m ที่กึ่งกลางช่วง
```
