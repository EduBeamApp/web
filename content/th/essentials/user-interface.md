# ส่วนติดต่อผู้ใช้

[EduBeam]{.edubeam} แบ่งหน้าจอเป็นสามส่วน: **แถบแอป** ด้านบน **หน้าจอแสดงผล** (viewer) ตรงกลางซึ่งเป็นที่วาดโมเดล และ **แถบด้านล่าง** ที่มีตารางสำหรับวัตถุแต่ละประเภท ทุกอย่างที่ทำบนหน้าจอแสดงผลได้ ก็ทำในตารางได้ และในทางกลับกัน

![ส่วนต่าง ๆ ของอินเทอร์เฟซ มีหมายเลขตามรายการด้านล่าง](/screenshots/th/ui-overview.webp)

1. **เมนู ☰**: เปิด บันทึก แชร์ และส่งออก รวมถึงตัวอย่างและทัวร์แนะนำ
2. **ล้างโมเดล** และ **แชร์โมเดล**
3. **เลิกทำ** และ **ทำซ้ำ**
4. **ปุ่มของหน้าจอแสดงผล**: จัดกึ่งกลาง ปรับให้พอดีหน้าจอ และตัวเลือกการแสดงผล
5. **ตัวเลือกการแสดงผล**: เลือกว่าจะวาดผลลัพธ์ใดและส่วนใดของโมเดล
6. **กริด การสแนป เส้นเล็ง และหน่วย**
7. **แท็บของแถบด้านล่าง**: โหนด เอลิเมนต์ แรงกระทำ วัสดุ หน้าตัด ผลลัพธ์
8. **ตาราง** ของแท็บที่เปิดอยู่ ซึ่งแก้ไขได้ทุกค่า

::callout{type="tip" title="ลองทัวร์"}
**☰ → พาชมแอป** จะชี้ส่วนต่าง ๆ เหล่านี้ในตัวแอปทีละส่วน
::

## แถบแอป {#app-bar}

- **☰** เปิดเมนูหลัก ดูหัวข้อถัดไป
- **ล้างโมเดล** ลบโหนด เอลิเมนต์ และแรงกระทำทั้งหมดหลังจากคุณยืนยัน ถ้าต้องการลบวัสดุหรือหน้าตัดด้วย ให้ติ๊ก **ลบวัสดุ** หรือ **ลบหน้าตัด** <kbd>Ctrl</kbd>+<kbd>Z</kbd> นำโมเดลกลับมาได้ และโมเดลนั้นยังเก็บอยู่ใน *โครงสร้างล่าสุด* ด้วย
- **แชร์โมเดล** เปิด [กล่องโต้ตอบการแชร์](/th/essentials/import-export#share-a-link) พร้อมลิงก์ที่เก็บโมเดลไว้ทั้งหมด
- **มีอะไรใหม่?** แสดงบันทึกการเปลี่ยนแปลงของแต่ละเวอร์ชัน และจะเปิดขึ้นเองหนึ่งครั้งหลังแอปอัปเดต
- **เอกสาร** เปิดคู่มือนี้ ส่วนไอคอน GitHub เปิดซอร์สโค้ด

บนโทรศัพท์มีที่พอสำหรับ ☰ และ **เอกสาร** เท่านั้น **ล้างโมเดล** และ **แชร์โมเดล** จึงย้ายไปอยู่ในเมนู

### เมนู ☰ {#the-☰-menu}

![เมนู ☰](/screenshots/th/ui-app-menu.webp){.shot-xs}

- **เปิดโปรเจกต์** และ **บันทึกโปรเจกต์** เปิดหรือดาวน์โหลดไฟล์ `project.json` (<kbd>Ctrl</kbd>+<kbd>O</kbd>, <kbd>Ctrl</kbd>+<kbd>S</kbd>)
- **โครงสร้างล่าสุด** เก็บโมเดล 10 รายการล่าสุดที่คุณล้างหรือแทนที่ไว้ พร้อมให้กู้คืน
- **ส่งออกรูปภาพ** บันทึกภาพวาดเป็น PNG หรือ SVG หรือคัดลอกไปยังคลิปบอร์ด (<kbd>Ctrl</kbd>+<kbd>P</kbd>)
- **ตัวอย่าง** คือแกลเลอรีของโมเดลสำเร็จรูป **วาดคานแรกของคุณ** คืองานฝึกเจ็ดขั้นตอนที่มีคำแนะนำทีละขั้น และ **พาชมแอป** คือทัวร์แนะนำอินเทอร์เฟซ
- **แชร์โมเดล** และ **ล้างโมเดล** ทำงานเหมือนปุ่มบนแถบแอป

ด้านล่างสุดของเมนูแสดงเวอร์ชันของแอปและวันที่เผยแพร่ การเปิด บันทึก แชร์ และส่งออกอธิบายไว้ในหน้า [ไฟล์ ลิงก์ และการส่งออก](/th/essentials/import-export)

## หน้าจอแสดงผล {#viewer}

พื้นที่วาด (canvas) คือที่ที่คุณวาดและตรวจดูโมเดล EduBeam คำนวณผลลัพธ์ใหม่ทุกครั้งที่โมเดลเปลี่ยน จึงไม่มีปุ่ม *คำนวณ*

### ปุ่มบนพื้นที่วาด {#buttons-on-the-canvas}

**มุมซ้ายบน: เลิกทำและทำซ้ำ** ย้อนกลับและทำซ้ำได้ทุกการเปลี่ยนแปลงในโมเดล ทั้งการเพิ่ม แก้ไข ลาก ลบ และล้างโมเดล (<kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>)

**มุมขวาบน:**

- **เลือกแบบกรอบ** มีบนอุปกรณ์ที่มีหน้าจอสัมผัส เมื่อกดแล้ว การลากนิ้วครั้งถัดไปจะเลือกพื้นที่สี่เหลี่ยม
- **จัดเนื้อหาให้อยู่กึ่งกลาง** เลื่อนโมเดลมาไว้กลางจอโดยไม่ซูม (<kbd>C</kbd>) ส่วน **ปรับเนื้อหาให้พอดีกับหน้าจอ** ซูมจนเห็นโมเดลทั้งหมด (<kbd>F</kbd>)
- **⚙** แสดงหรือซ่อน [ตัวเลือกการแสดงผล](#display-options)

**มุมขวาล่าง:**

![ปุ่มกริด การสแนป เส้นเล็ง และหน่วย](/screenshots/th/ui-grid-units.webp){.shot-sm}

- **G** แสดงหรือซ่อนกริดและไม้บรรทัด (<kbd>G</kbd>) ส่วน **S** เปิดหรือปิดการสแนปกับกริด (<kbd>S</kbd>)
- ปุ่ม **เส้นเล็ง** แสดงตำแหน่งของตัวชี้บนไม้บรรทัด ใช้ได้กับเมาส์เท่านั้น
- **ป้ายหน่วย** เปิดการตั้งค่าที่หน้า [ภาษาและภูมิภาค](/th/essentials/units-settings#language-locale)

### ตัวเลือกการแสดงผล {#display-options}

ปุ่ม ⚙ เปิดช่องให้ติ๊กสองแถว แถวแรกเลือกผลลัพธ์ที่วาดทับโมเดล: *รูปร่างที่เสียรูป*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)* และ *แรงปฏิกิริยา* ตอนเริ่มต้นจะเปิดรูปร่างที่เสียรูป โมเมนต์ดัด และแรงปฏิกิริยาไว้ แถวที่สองแสดงหรือซ่อนส่วนต่าง ๆ ของโมเดล: *จุดรองรับ*, *แรงกระทำ*, *ป้ายโหนด* และ *ป้ายเอลิเมนต์* ซึ่งเปิดไว้ทั้งหมดตั้งแต่เริ่มต้น

![ปุ่มของหน้าจอแสดงผลและตัวเลือกการแสดงผล](/screenshots/th/ui-display-settings.webp){.shot-lg}

**การตั้งค่าเพิ่มเติม** เปิด [การตั้งค่าโปรแกรมดู](/th/essentials/units-settings#viewer-settings) ซึ่งกำหนดขนาด สี และวิธีวาดแผนภาพ ส่วนหน้า [ผลลัพธ์และแผนภาพ](/th/essentials/results#overlays-in-the-viewer) อธิบายว่าผลลัพธ์แต่ละอย่างแสดงอะไร

### การซูมและเลื่อนมุมมอง {#navigating}

| การทำงาน | เมาส์และแป้นพิมพ์ | หน้าจอสัมผัส |
| --- | --- | --- |
| ซูม | ล้อเมาส์ ซูมเข้าหาตัวชี้ บนทัชแพดใช้การจีบนิ้วหรือเลื่อนด้วยสองนิ้ว | จีบนิ้ว |
| เลื่อนมุมมอง | ลากด้วยปุ่มขวา หรือกดล้อเมาส์ค้างแล้วลาก เลือกแบบที่ต้องการได้ใน [การควบคุมและทางลัด](/th/essentials/units-settings#controls-shortcuts) | ลากด้วยนิ้วเดียว |
| พอดีหน้าจอ จัดกึ่งกลาง | <kbd>F</kbd>, <kbd>C</kbd> หรือปุ่มที่มุมขวาบน | ปุ่มที่มุมขวาบน |

<kbd>Ctrl</kbd>+<kbd>+</kbd> และ <kbd>Ctrl</kbd>+<kbd>-</kbd> ซูมภาพวาดรอบจุดกึ่งกลาง ไม่ว่าจะใช้ผังแป้นพิมพ์แบบใด และไม่ขยายทั้งอินเทอร์เฟซอย่างที่การซูมของเบราว์เซอร์ทำ

### การเลือกและการแก้ไข {#selecting-and-editing}

| ต้องการ | วิธีทำ |
| --- | --- |
| เลือกวัตถุหนึ่งชิ้น | คลิกโหนด เอลิเมนต์ แรงกระทำ หรือเส้นบอกขนาด แผงจะเปิดขึ้นข้าง ๆ พร้อมการดำเนินการที่ใช้ได้: เพิ่มแรงกระทำ กำหนดจุดรองรับ แก้ไข แสดงเมทริกซ์ความแข็ง ลบ แถบด้านล่างจะสลับไปที่แท็บของวัตถุนั้น |
| เลือกหลายชิ้น | ลากกรอบสี่เหลี่ยมบนพื้นที่วาดที่ว่าง (บนหน้าจอสัมผัสให้กด **เลือกแบบกรอบ** ก่อน) กรอบจะเลือกทุกโหนดที่อยู่ข้างในและทุกเอลิเมนต์ที่กรอบแตะ พร้อมแรงกระทำและเส้นบอกขนาดของวัตถุเหล่านั้น <kbd>Ctrl</kbd>+<kbd>A</kbd> เลือกทุกอย่าง |
| ลบ คัดลอก วาง | <kbd>Delete</kbd>, <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd> สิ่งที่วางจะเคลื่อนตามตัวชี้จนกว่าคุณจะคลิก หรือจะพิมพ์ระยะเลื่อน Δx, Δz ในแถบประกาศก็ได้ |
| ย้ายโหนด | ลากโหนด ถ้าเปิดการสแนปไว้ โหนดจะลงบนกริด เอลิเมนต์และแรงกระทำที่เชื่อมอยู่จะเคลื่อนตาม |
| แก้ไขแรงกระทำ | ดับเบิลคลิกที่แรงกระทำ |
| ดูรายละเอียด | ชี้เมาส์ที่วัตถุใดก็ได้เพื่อดู Tooltip: โหนดแสดงการกระจัดและมุมหมุน เอลิเมนต์แสดงวัสดุและหน้าตัด แรงกระทำแสดงค่า บนหน้าจอสัมผัสให้แตะ แล้วแผงจะแสดงข้อมูลเดียวกัน |
| เปิดเมนูพื้นที่วาด | คลิกขวาบนพื้นที่วาด หรือกดค้างบนหน้าจอสัมผัส |

**เมนูพื้นที่วาด** มี *เพิ่มโหนด*, *เพิ่มเอลิเมนต์*, *เพิ่มเส้นบอกขนาด* (และ *บอกขนาดเอลิเมนต์* เมื่อเปิดเมนูบนเอลิเมนต์) ตามด้วย *แก้ไข*, *คัดลอก*, *วาง* และ *ลบ* สำหรับสิ่งที่เลือกอยู่ กด <kbd>Ctrl</kbd> ค้างไว้ขณะเลือก *เพิ่มโหนด* หรือ *เพิ่มเอลิเมนต์* เพื่อวางด้วยเมาส์แทนการใช้กล่องโต้ตอบ

### เมื่อคำนวณโมเดลไม่ได้ {#when-the-model-cannot-be-solved}

ข้อความจะปรากฏที่มุมซ้ายบนของหน้าจอแสดงผล:

| ข้อความ | ความหมาย |
| --- | --- |
| *ไม่มีการกำหนดวัสดุ*, *ไม่มีการกำหนดหน้าตัด* | เพิ่มได้ด้วยปุ่ม **เพิ่มใหม่** ที่อยู่ข้าง ๆ |
| ป้ายสีฟ้า **ต้องมีจุดรองรับ** | โมเดลแค่ยังสร้างไม่เสร็จ ต้องเพิ่มจุดรองรับอีก |
| ข้อความสีแดงพร้อมปุ่ม **แสดงรายละเอียด** | มีบางอย่างผิดพลาด รายละเอียดจะแสดงปัญหาทุกข้อพร้อมคำแนะนำ |
| ข้อความสีเหลือง | คำนวณโมเดลได้ แต่มีบางอย่างดูแปลก เช่น โหนดที่ไม่มีเอลิเมนต์ใดเชื่อมอยู่ |

เมื่อโครงสร้างยังเคลื่อนที่ได้ EduBeam จะแสดงการเคลื่อนที่เป็นเส้นประที่แกว่งไปมา และวงกลมล้อมโหนดหรือจุดหมุนที่เป็นต้นเหตุ ชี้เมาส์ที่ข้อความเพื่อดูการเคลื่อนที่อีกครั้ง หรือกดปุ่มรูปตาเพื่อซ่อน

![โครงข้อแข็งที่มีจุดหมุนที่ B และ C เป็นกลไก: EduBeam แสดงว่าโครงสร้างเคลื่อนที่อย่างไร](/screenshots/th/ui-mechanism.webp)

หน้า [การแก้ปัญหา](/th/reference/troubleshooting#messages) อธิบายทุกข้อความและวิธีแก้

## แถบด้านล่าง {#bottom-bar}

แถบด้านล่างมีหกแท็บ แต่ละแท็บมีแถบเครื่องมือและตารางที่แก้ไขได้ ชื่อแท็บแสดงจำนวนวัตถุในแท็บนั้น ลากแถบแท็บขึ้นหรือลงเพื่อปรับความสูงของแถบ หรือพับเก็บด้วยปุ่มทางขวา ปุ่ม **?** ข้าง ๆ อธิบายแท็บที่เปิดอยู่ และ **?** ข้างหัวคอลัมน์บางคอลัมน์ก็อธิบายคอลัมน์นั้น

| แท็บ | แถบเครื่องมือ | คอลัมน์ในตาราง |
| --- | --- | --- |
| **โหนด** | เพิ่มโหนด (กล่องโต้ตอบ), เพิ่มโหนด (เมาส์) | โหนด, พิกัด, **องศาความเป็นอิสระที่รองรับ** (สัญลักษณ์จุดรองรับ, `Dx`, `Dz`, `Ry`, มุม α), แรงกระทำ, การดำเนินการ |
| **เอลิเมนต์** | เพิ่มเอลิเมนต์ (กล่องโต้ตอบ), เพิ่มเอลิเมนต์ (เมาส์) | เอลิเมนต์, ประเภท, โหนด (พร้อม **สลับโหนด**), วัสดุ, หน้าตัด, **จุดหมุนที่ปลาย**, แรงกระทำ, การดำเนินการ |
| **แรงกระทำ** | เพิ่มแรงกระทำที่โหนด, เพิ่มแรงกระทำบนเอลิเมนต์ | ประเภท, เป้าหมาย, ส่วนประกอบ, การดำเนินการ |
| **วัสดุ** | เพิ่มวัสดุ, ไลบรารีวัสดุ | วัสดุ, E, G, α<sub>T</sub>, การดำเนินการ |
| **หน้าตัด** | เพิ่มหน้าตัด, ไลบรารีหน้าตัด, หน้าตัดรูปหลายเหลี่ยม | รูปร่าง, หน้าตัด, พื้นที่, I<sub>y</sub>, ความสูง, สัมประสิทธิ์เฉือน, การดำเนินการ |
| **ผลลัพธ์** | ผลลัพธ์ที่โหนด, ผลลัพธ์ที่เอลิเมนต์, ส่งออก CSV, คัดลอก | การกระจัดของแต่ละโหนด หรือแรงปลายของแต่ละเอลิเมนต์ ดู [ผลลัพธ์และแผนภาพ](/th/essentials/results#results-tab) |

### การพิมพ์ค่า {#typing-values}

ช่องตัวเลขทุกช่อง ทั้งในตารางและในกล่องโต้ตอบ ทำงานแบบเดียวกัน:

- ค่าอยู่ใน [หน่วยปัจจุบัน](/th/essentials/units-settings#units) ซึ่งแสดงไว้ที่หัวคอลัมน์หรือท้ายช่อง
- ใช้จุดหรือจุลภาคเป็นจุดทศนิยมก็ได้ `2.5` กับ `2,5` มีค่าเท่ากัน
- พิมพ์นิพจน์คำนวณได้ด้วย `+ - * / ^` และวงเล็บ เช่น `6/2`, `3*1.5`, `2^3` หรือ `(4+2)/3` แล้ว EduBeam จะคำนวณให้ ส่วน `1e-5` หมายถึง $10^{-5}$
- ในตาราง กด <kbd>Enter</kbd>, <kbd>Esc</kbd>, <kbd>Tab</kbd> หรือคลิกที่อื่นเพื่อใช้ค่า จากนั้น <kbd>Ctrl</kbd>+<kbd>Z</kbd> จะย้อนค่านั้นกลับ แต่ระหว่างที่ยังพิมพ์อยู่ <kbd>Ctrl</kbd>+<kbd>Z</kbd> จะย้อนการพิมพ์แทน

## แท็บเหนือหน้าจอแสดงผล {#tabs-above-the-viewer}

**โปรแกรมดู** แสดงพื้นที่วาด **การตั้งค่า** แสดง [การตั้งค่า](/th/essentials/units-settings) แบบเต็มขนาดแทนที่พื้นที่วาด คุณจึงเปลี่ยนสีหรือหน่วยแล้วสลับกลับไปดูผลได้ ป้ายหน่วยและ *การตั้งค่าเพิ่มเติม* เปิดการตั้งค่าชุดเดียวกันเป็นกล่องโต้ตอบเหนือโมเดล

## หน้าต่างลอย {#floating-windows}

**เมทริกซ์ความแข็ง** (จากแผงของเอลิเมนต์หรือจากตาราง *เอลิเมนต์*) เปิดหน้าต่างที่แสดงเมทริกซ์ความแข็งขนาด 6 × 6 ของเอลิเมนต์ในแกนรวม **แก้ไข** ในเมนูพื้นที่วาดเปิดตารางของสิ่งที่เลือกอยู่ ย้ายหน้าต่างได้โดยลากแถบชื่อ และปิดด้วยปุ่ม ×
