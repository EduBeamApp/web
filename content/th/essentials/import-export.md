# ไฟล์ ลิงก์ และการส่งออก

:span{#นําเข้า-ส่งออก-และแชร์}

บันทึกโมเดลเป็นไฟล์ ส่งเป็นลิงก์ ฝังในหน้าเว็บ หรือส่งออกเป็นรูปภาพหรือตาราง ทุกอย่างใน [EduBeam]{.edubeam} เกิดขึ้นในเบราว์เซอร์ของคุณ ไม่มีการอัปโหลดข้อมูลใดเลย ตัวโมเดลทั้งหมดอยู่ในลิงก์แชร์นั้นเอง

## บันทึกโปรเจกต์ {#save-a-project}

**☰ → บันทึกโปรเจกต์** หรือ <kbd>Ctrl</kbd>+<kbd>S</kbd> (บน Mac ให้ใช้ <kbd>⌘</kbd>+<kbd>S</kbd> เช่นเดียวกับแป้นพิมพ์ลัดทุกตัวในหน้านี้) ดาวน์โหลดไฟล์ `project.json` ซึ่งเก็บโหนด เอลิเมนต์ วัสดุ หน้าตัด (รวมรูปร่างที่วาดไว้) แรงกระทำ เส้นบอกขนาด และเวอร์ชันของแอปที่เขียนไฟล์ เปลี่ยนชื่อไฟล์ได้ตามสะดวก

## เปิดโปรเจกต์ {#open-a-project}

**☰ → เปิดโปรเจกต์** หรือ <kbd>Ctrl</kbd>+<kbd>O</kbd> แล้วเลือกไฟล์ หรือ **ลากไฟล์มาวางที่ใดก็ได้บนหน้าต่างแอป** EduBeam เปิดได้:

- ไฟล์ `project.json` ที่บันทึกจาก EduBeam ทุกเวอร์ชัน
- เซสชัน `.xml` ที่บันทึกจาก **EduBeam รุ่นเดสก์ท็อป** 2.x ถึง 3.5 ค่าในไฟล์เหล่านี้ไม่มีหน่วยกำกับ EduBeam จึงอ่านเป็น kN, kPa และ m ตามหน่วยที่คู่มือของโปรแกรมนั้นใช้ EduBeam เปิดได้ทีละกรณีแรงกระทำ เซสชันที่มีหลายกรณีจะเปิดกรณีแรก และแจ้งชื่อกรณีที่ไม่ได้เปิด

การเปิดจะแทนที่โมเดลปัจจุบัน รวมถึงวัสดุและหน้าตัด โมเดลเดิมไม่หายไป <kbd>Ctrl</kbd>+<kbd>Z</kbd> นำกลับมาได้ และยังเก็บไว้ใน [โครงสร้างล่าสุด](#recent-structures) ถ้า EduBeam อ่านไฟล์ไม่ได้ จะแสดงข้อความแจ้งและไม่เปิดไฟล์นั้น โมเดลของคุณยังอยู่เหมือนเดิม

## แชร์ลิงก์ {#share-a-link}

**แชร์โมเดล** ในแถบแอปหรือในเมนู ☰ เปิดกล่องโต้ตอบ *แชร์โมเดลผ่าน URL*:

![กล่องโต้ตอบแชร์โมเดลผ่าน URL](/screenshots/th/c1-share.webp){.shot-lg}

- กด **คัดลอก** หรือคลิกที่ใดก็ได้ในช่องลิงก์เพื่อคัดลอกลิงก์
- **เปิดลิงก์** เปิดลิงก์ในแท็บใหม่ คุณจึงเห็นสิ่งที่ผู้รับจะเห็น
- **แชร์ผ่านกล่องโต้ตอบของระบบ** ส่งลิงก์ไปยังเมนูแชร์ของอุปกรณ์ ถ้าเบราว์เซอร์รองรับ
- **ลิงก์ที่สั้นกว่า** (เปิดไว้เป็นค่าเริ่มต้น) เขียนโมเดลเดียวกันด้วยจำนวนตัวอักษรประมาณครึ่งหนึ่ง EduBeam ที่เก่ากว่าเวอร์ชัน 1.3.2 (พฤศจิกายน 2026) จะอ่านลิงก์นี้ไม่ได้จนกว่าจะอัปเดต จึงควรปิดตัวเลือกนี้เมื่อลิงก์ต้องเปิดได้ทุกที่ทันที
- **แสดงสิ่งที่ฉันเห็น** (ปิดไว้เป็นค่าเริ่มต้น) ทำให้ลิงก์เปิดพร้อมแผนภาพ แรงกระทำ และป้ายที่คุณเปิดไว้ แทนตัวเลือกการแสดงผลของผู้รับเอง

ลิงก์มีรูปแบบ `https://run.edubeam.app/?model=…` และเข้ารหัสทั้งโมเดลไว้ ผู้ที่เปิดลิงก์จะได้สำเนาของตัวเองไว้แก้ไข การแก้ไขของผู้รับจะ **ไม่** ซิงค์กลับมาหาคุณ และเมื่อคุณแก้โมเดล ต้องส่งลิงก์ใหม่ โมเดลที่ใหญ่มากจะได้ลิงก์ที่ยาวมาก ในกรณีนั้นให้แชร์ไฟล์โปรเจกต์แทน

เมื่อมีคนเปิดลิงก์ โมเดลเดิมของเขาจะย้ายไปที่โครงสร้างล่าสุด และมีข้อความบอกว่าหาได้ที่ไหน ลิงก์ไม่มีวันหมดอายุ ลิงก์ในเอกสารประกอบการสอนของปีที่แล้วยังเปิดโมเดลเดิมได้ในวันนี้

## ฝังโปรแกรมดู {#embed-a-read-only-viewer}

เติม `&viewer=1` ต่อท้ายลิงก์แชร์เพื่อเปิดโมเดลใน **โหมดโปรแกรมดู** แถบแอป แถบด้านล่าง ปุ่มเลิกทำและทำซ้ำ ป้ายกริดและป้ายหน่วย และเส้นเล็งจะซ่อนไป เหลือเพียงภาพวาด ปุ่มปรับให้พอดีและจัดกึ่งกลาง และตัวเลือกการแสดงผล กล่องต้อนรับและบันทึกการเปลี่ยนแปลงก็จะไม่เปิดขึ้น ใส่ URL นั้นใน `<iframe>` เพื่อฝังโมเดลที่โต้ตอบและซูมได้ในเอกสารประกอบการสอน หน้าเว็บของรายวิชา หรือสไลด์:

```html
<iframe
  src="https://run.edubeam.app/?viewer=1&show=MRLS&model=…"
  width="100%"
  height="400"
></iframe>
```

![โครงข้อแข็งสามจุดหมุนในโหมดโปรแกรมดู](/screenshots/th/viewer-mode.webp){.shot-lg}

โหมดโปรแกรมดูมีไว้สำหรับดู แต่ไม่ได้ล็อก ผู้เข้าชมยังลากโหนดและสลับแผนภาพได้ ถ้าเปิดลิงก์โปรแกรมดูโดยตรง ลิงก์จะแทนที่โมเดลของผู้เข้าชมเหมือนลิงก์ทั่วไป และโมเดลเดิมจะรออยู่ในโครงสร้างล่าสุด ถ้าฝังไว้ในหน้าของเว็บไซต์อื่น เบราว์เซอร์รุ่นปัจจุบันส่วนใหญ่จะให้กรอบนั้นมีพื้นที่เก็บข้อมูลแยกต่างหาก โมเดลของผู้เข้าชมจึงไม่ได้รับผลกระทบ แต่ไม่ใช่ทุกเบราว์เซอร์ที่ทำเช่นนี้

ถ้าต้องการรูปที่ไม่ต้องใช้แอปเลย เช่น แผนภาพนิ่งในหน้าเว็บ สไลด์ หรือแบบฝึกหัด ไลบรารีวาดภาพ [@edubeam/plot](/th/plot) วาดโครงสร้างและแผนภาพจากโค้ดได้ รูปที่โต้ตอบได้ในเว็บไซต์นี้ก็วาดด้วยไลบรารีนี้

## พารามิเตอร์ URL {#url-parameters}

| พารามิเตอร์ | ผล |
| --- | --- |
| `model=<data>` | โหลดโมเดลที่เข้ารหัสไว้และปรับให้พอดีหน้าจอ ปุ่ม **แชร์โมเดล** ใส่พารามิเตอร์นี้ให้ |
| `viewer=1` | [โหมดโปรแกรมดู](#embed-a-read-only-viewer) |
| `show=<letters>` | เปิดโดยแสดงเฉพาะชั้นข้อมูลที่ระบุ ตัวอักษรละหนึ่งชั้น: `N` แรงตามแนวแกน `V` แรงเฉือน `M` โมเมนต์ดัด `U` รูปร่างที่เสียรูป `R` แรงปฏิกิริยา `L` แรงกระทำ `S` จุดรองรับ `n` ป้ายโหนด `e` ป้ายเอลิเมนต์ `show=MRLS` แสดงโมเมนต์ดัด แรงปฏิกิริยา แรงกระทำ และจุดรองรับ ตัวเลือก **แสดงสิ่งที่ฉันเห็น** ใส่พารามิเตอร์นี้ให้ |
| `lang=<code>` | เปลี่ยนภาษาของอินเทอร์เฟซ: `en`, `cs`, `sk`, `de`, `fr`, `es`, `pt`, `pl`, `hu`, `ro`, `el`, `cn` (ภาษาจีน), `th`, `uk`, `ru`, `tr`, `hi`, `vi`, `it`, `id`, `ja`, `ko` |
| `panel=examples` | เปิดแกลเลอรีตัวอย่างทันที |

รวมพารามิเตอร์หลายตัวด้วย `&` เช่น `?lang=de&viewer=1&model=…` หลังอ่านพารามิเตอร์แล้ว EduBeam จะลบออกจากแถบที่อยู่ ส่วน `lang` และ `show` จะเก็บไว้เป็นการตั้งค่าของผู้เข้าชม เหมือนกับที่เขาเลือกเองในแอป

## ส่งออกรูปภาพ {#export-an-image}

**☰ → ส่งออกรูปภาพ** หรือ <kbd>Ctrl</kbd>+<kbd>P</kbd> เปิดกล่องโต้ตอบส่งออกรูปภาพ EduBeam จัดวางภาพวาดใหม่ตามขนาดที่คุณเลือก เส้นและป้ายจึงคงความหนาจริงไว้

![ส่งออกรูปภาพ: เลือกชั้นข้อมูล กรอบ และขนาด แล้วดาวน์โหลดหรือคัดลอก](/screenshots/th/export-image.webp)

::div{.steps}

### เลือกชั้นข้อมูล {#choose-the-layers}

ป้ายด้านบนใช้เลือกสิ่งที่จะวาด: รูปร่างที่เสียรูป N, V, M และแรงปฏิกิริยา ตามด้วยจุดรองรับ แรงกระทำ ป้ายโหนด และป้ายเอลิเมนต์ ค่าเริ่มต้นตรงกับตัวเลือกการแสดงผลของหน้าจอแสดงผล และการเปลี่ยนที่นี่ไม่กระทบหน้าจอแสดงผล

### จัดกรอบภาพ {#frame-the-drawing}

เลือกอัตราส่วนภาพ (16:9, 4:3, 3:2 หรือ 1:1) **แสดงทั้งหมด** หรือ **เลือกพื้นที่…** เพื่อลากกรอบสี่เหลี่ยมบนภาพวาด ลากขอบของภาพตัวอย่างได้ด้วย

### กำหนดขนาด {#set-the-size}

กำหนดความกว้างและความสูงเป็นพิกเซล หรือ **มาตราส่วน** เช่น 1 : 50 สำหรับภาพวาดตามมาตราส่วนบนกระดาษ (ที่ 96 DPI) **ความสูงแผนภาพ** กำหนดขนาดของแผนภาพผลลัพธ์ และ **พื้นหลังโปร่งใส** ตัดพื้นหลังสีขาวออก ถ้าแผนภาพหรือป้ายไม่พอดี กล่องโต้ตอบจะแจ้ง และเสนอให้ย่อแผนภาพหรือขยายพื้นที่วาด

### บันทึก {#save-it}

**ดาวน์โหลด PNG** **ดาวน์โหลด SVG** หรือ **คัดลอกไปยังคลิปบอร์ด** ถ้าเบราว์เซอร์อนุญาต ไฟล์จะตั้งชื่อตามขนาด เช่น `edubeam-512x512.svg` บนหน้าจอความละเอียดสูง ไฟล์ PNG จะมีพิกเซลมากกว่าความกว้างและความสูงที่ตั้งไว้ ตามสัดส่วนความหนาแน่นพิกเซลของหน้าจอ เพื่อให้คมชัดเท่าในแอป ขนาดเป็นพิกเซลจริงแสดงไว้ข้างปุ่ม

::

SVG คมชัดทุกขนาด และใช้ได้ใน Word, Inkscape และ LaTeX บน Overleaf จึงเป็นตัวเลือกที่ดีที่สุดสำหรับรายงานและวิทยานิพนธ์ ขนาดเดียวกันจะจัดกรอบโครงสร้างแบบเดียวกันเสมอ N, V และ M ที่ส่งออกทีละภาพจึงวางเรียงข้างกันได้พอดี

ถ้าต้องการสร้างรูปเหล่านี้จากโค้ด เช่น หนึ่งรูปต่อโจทย์แต่ละข้อในแบบฝึกหัด @edubeam/plot เขียน [ไฟล์ SVG แบบ standalone](/th/plot/functions#a-standalone-svg-file) ที่เปิดได้ในโปรแกรมเดียวกันนี้

## ส่งออกผลลัพธ์ {#export-the-results}

**ส่งออก CSV** ในแท็บ **ผลลัพธ์** ดาวน์โหลดตารางผลลัพธ์ทั้งสองตาราง รวมแรงปฏิกิริยา และ **คัดลอก** นำตารางไปไว้ในคลิปบอร์ดเพื่อวางในสเปรดชีต ดู [ส่งออก CSV และคัดลอก](/th/essentials/results#export-csv-and-copy)

## โครงสร้างล่าสุด {#recent-structures}

**☰ → โครงสร้างล่าสุด** เก็บโครงสร้าง 10 รายการล่าสุดที่ถูกล้าง หรือถูกแทนที่ด้วยลิงก์ ไฟล์ ตัวอย่าง แบบฝึกวาดคานแรก หรือการกู้คืนครั้งอื่น แต่ละรายการแสดงภาพย่อ สิ่งที่มาแทนที่ และจำนวนโหนดกับเอลิเมนต์ **กู้คืน** นำโครงสร้างกลับมา โมเดลที่เปิดอยู่ตอนนั้นจะเข้าไปอยู่ในรายการแทน และ <kbd>Ctrl</kbd>+<kbd>Z</kbd> ยกเลิกการกู้คืนได้ **นำออก** ลบรายการนั้น

![โครงสร้างล่าสุด](/screenshots/th/recent.webp){.shot-lg}

รายการนี้เก็บไว้ในเบราว์เซอร์นี้เท่านั้น

## การบันทึกอัตโนมัติ {#automatic-persistence}

โมเดลและการตั้งค่าของคุณบันทึกลง local storage ของเบราว์เซอร์หลังทุกการเปลี่ยนแปลง และนำกลับมาให้เมื่อคุณเปิดแอปอีกครั้ง แม้จะปิดเบราว์เซอร์ไปแล้วก็ตาม ระบบนี้มีไว้เพื่อความสะดวก ไม่ใช่การสำรองข้อมูล ข้อมูลผูกกับโปรไฟล์เบราว์เซอร์เดียวบนอุปกรณ์เดียว หน้าต่างส่วนตัวจะลืมข้อมูลนี้ และถ้าล้างข้อมูลของเว็บไซต์ ข้อมูลนี้จะหายไป งานสำคัญให้บันทึกเป็นไฟล์โปรเจกต์ หัวข้อ [สิ่งที่เก็บไว้ในเบราว์เซอร์ของคุณ](/th/essentials/units-settings#what-is-stored-in-your-browser) แสดงรายการทั้งหมด

## รูปแบบไฟล์โปรเจกต์ {#project-file-format}

`project.json` เป็น JSON ธรรมดาที่อ่านได้ ตัวอย่างนี้คือคานจากหน้า [เริ่มต้นใช้งานด่วน](/th/guide/quick-start) ที่ใช้เหล็กและ IPE 200 จากไลบรารี:

```json [project.json]
{
  "edubeam": true,
  "version": "1.3.4",
  "domain": {
    "materials": [
      {
        "label": "Steel (S235)",
        "d": 7850,
        "e": 210000000000,
        "g": 81000000000,
        "alpha": 0.000012
      }
    ],
    "crossSections": [
      {
        "label": "IPE 200 (approx)",
        "a": 0.002848,
        "iy": 0.00001943,
        "h": 0.2,
        "k": 0.3932584269662922
      }
    ],
    "nodes": [
      { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] },
      { "label": "2", "coords": [6, 0, 0], "bcs": [2] }
    ],
    "elements": [
      {
        "label": "1",
        "nodes": ["1", "2"],
        "mat": "Steel (S235)",
        "cs": "IPE 200 (approx)",
        "hinges": [false, false]
      }
    ],
    "loadCases": [
      {
        "label": "DefaultLC",
        "nodalLoads": [],
        "elementLoads": [
          { "type": "udl", "target": "1", "lcs": true, "values": [0, 12000] }
        ],
        "prescribedBC": []
      }
    ]
  },
  "dimensions": []
}
```

ค่าทั้งหมดอยู่ใน **หน่วย SI** (m, N, Pa, rad) ไม่ว่าแอปจะแสดงด้วยหน่วยใด พิกัดอยู่ในรูป `[x, y, z]` โดย $y = 0$ และ $z$ ชี้ลง จุดรองรับและส่วนประกอบของแรงใช้รหัสองศาความเป็นอิสระ `0 = Dx`, `2 = Dz`, `4 = Ry`

| `type` ของแรงกระทำบนเอลิเมนต์ | ค่า |
| --- | --- |
| `udl` | `values: [fx, fz]` หน่วย N/m |
| `trapezoidal` | `startValues: [f1x, f1z]`, `endValues: [f2x, f2z]` หน่วย N/m |
| `concentrated` | `values: [Fx, Fz, My, a]` หน่วย N, N·m และ m วัดจากโหนดเริ่มต้น |
| `temperature` | `values: [ΔTc, ΔTb, ΔTt]` หน่วย K ผลต่างอุณหภูมิคือ ΔTb − ΔTt |

`lcs: true` หรือไม่มี `lcs` เลย หมายถึงแรงกระทำบนเอลิเมนต์อยู่ในแกนท้องถิ่นของเอลิเมนต์ ส่วน `false` หมายถึงแกนรวม รายการอื่น ๆ:

- **แรงกระทำที่โหนด**: `{ "target": "2", "values": { "0": Fx, "2": Fz, "4": My } }` และเติม `"lcs": true` สำหรับแรงในแกนของจุดรองรับที่หมุนแกนไว้
- **การกระจัดที่กำหนด**: `{ "target": "2", "prescribedValues": { "0": Dx, "2": Dz, "4": Ry } }` ส่วนประกอบที่ไม่ได้ใส่มีค่าเป็น 0
- ไฟล์ที่แอปเขียนยังมี `date`, `commit` แกนของจุดรองรับที่หมุน (`lcs` ของโหนด) และ `shape` ของหน้าตัดที่วาดไว้ด้วย

เนื่องจากรูปแบบไฟล์เรียบง่าย คุณจึงเขียนโมเดลด้วยสคริปต์หรือสเปรดชีต แล้วเปิดด้วย **เปิดโปรเจกต์** ได้ ถ้าต้องการสร้างและคำนวณโมเดลด้วยโค้ดทั้งหมด ให้ใช้ตัวคำนวณที่อยู่เบื้องหลังแอป [@edubeam/fem](/th/solver)
