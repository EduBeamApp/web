# Συχνές ερωτήσεις

Σύντομες απαντήσεις, η καθεμία με σύνδεσμο προς τη σελίδα που καλύπτει πλήρως το θέμα. Δεν βρίσκετε τη δική σας ερώτηση; Δείτε την [Επίλυση προβλημάτων](/el/reference/troubleshooting) ή [ρωτήστε στο GitHub](https://github.com/janvorisek/edubeam/issues).

## Γενικά {#general}

### Τι είναι το EduBeam; {#what-is-edubeam}

Μια δωρεάν εφαρμογή ανοιχτού κώδικα για τη γραμμική στατική ανάλυση επίπεδων δοκών, πλαισίων και δικτυωμάτων, για φοιτητές, διδάσκοντες και μηχανικούς που θέλουν άμεση ανατροφοδότηση. Λειτουργεί στο πρόγραμμα περιήγησης. Η [Εισαγωγή](/el/guide/introduction) περιγράφει τι κάνει και τι όχι.

### Είναι πράγματι δωρεάν; Χρειάζομαι λογαριασμό; {#is-it-really-free-do-i-need-an-account}

Ναι, είναι δωρεάν, και όχι, δεν χρειάζεστε λογαριασμό. Ανοίξτε το [run.edubeam.app](https://run.edubeam.app/?lang=el){target="_blank"} και ξεκινήστε τη μοντελοποίηση: δεν χρειάζεται εγκατάσταση και δεν υπάρχει όριο χρήσης. Ο πηγαίος κώδικας βρίσκεται στο [GitHub](https://github.com/janvorisek/edubeam) με άδεια GPL-3.0.

### Σε ποια προγράμματα περιήγησης και συσκευές λειτουργεί; {#which-browsers-and-devices-work}

Σε κάθε τρέχουσα έκδοση των Chrome, Edge, Firefox ή Safari, σε υπολογιστή, tablet ή κινητό. Σε οθόνη αφής, πατήστε για επιλογή, σύρετε έναν κόμβο για να τον μετακινήσετε, σύρετε αλλού για να μετακινήσετε την προβολή, τσιμπήστε για μεγέθυνση, και κρατήστε πατημένο για το μενού του καμβά. Με ποντίκι και πληκτρολόγιο η μοντελοποίηση είναι πάντως γρηγορότερη. Δείτε [Πληκτρολόγιο, ποντίκι και αφή](/el/reference/shortcuts#touch).

### Έχασα το μοντέλο μου. Μπορώ να το ανακτήσω; {#i-lost-my-model-can-i-get-it-back}

Πιθανότατα. Όταν ένα μοντέλο διαγράφεται ή αντικαθίσταται από σύνδεσμο, αρχείο ή παράδειγμα, το EduBeam το κρατά στο **☰ → Πρόσφατοι φορείς** (τα 10 τελευταία), και το <kbd>Ctrl</kbd>+<kbd>Z</kbd> αναιρεί την αντικατάσταση. Και τα δύο λειτουργούν μόνο μέσα στο συγκεκριμένο πρόγραμμα περιήγησης, οπότε ένα μοντέλο από άλλον υπολογιστή ή άλλο προφίλ προγράμματος περιήγησης δεν βρίσκεται εκεί. Δείτε [Πρόσφατοι φορείς](/el/essentials/import-export#recent-structures).

### Μπορώ να το χρησιμοποιήσω χωρίς σύνδεση; {#can-i-use-it-offline}

Ναι. Το EduBeam είναι progressive web app (PWA): μόλις το φορτώσει το πρόγραμμα περιήγησής σας, συνεχίζει να λειτουργεί χωρίς σύνδεση, και το πρόγραμμα περιήγησης μπορεί να προτείνει την εγκατάστασή του. Όταν βγαίνει νέα έκδοση, ένα παράθυρο ζητά τη συγκατάθεσή σας πριν από την ενημέρωση.

### Πού αποθηκεύονται τα δεδομένα μου; {#where-is-my-data-stored}

Στο πρόγραμμα περιήγησής σας. Δεν υπάρχουν λογαριασμοί ούτε αποθήκευση στο cloud: η εφαρμογή κρατά το μοντέλο και τις ρυθμίσεις σας σε αυτό το πρόγραμμα περιήγησης, και ένας σύνδεσμος κοινής χρήσης περιέχει το μοντέλο μέσα στον ίδιο τον σύνδεσμο. Δείτε [Τι αποθηκεύεται στο πρόγραμμα περιήγησης](/el/essentials/units-settings#what-is-stored-in-your-browser).

Η εφαρμογή στο run.edubeam.app συλλέγει πάντως στατιστικά χρήσης (Google Analytics) και αναφορές σφαλμάτων (Sentry). Μια αναφορά σφάλματος, καθώς και η καταγραφή που κάνει το Sentry σε ένα δείγμα συνεδριών, μπορεί να περιλαμβάνει ό,τι ήταν στην οθόνη, μαζί και το μοντέλο σας.

### Πού μπορώ να εξασκηθώ σε ασκήσεις Στατικής; {#practice}

Στη σελίδα [Ασκήσεις](/el/practice). Σας δίνει μια δοκό, ένα πλαίσιο ή ένα δικτύωμα με νέους αριθμούς κάθε φορά: υπολογίστε στο χαρτί τις αντιδράσεις και τη μέγιστη καμπτική ροπή ή τη δύναμη μιας ράβδου, πληκτρολογήστε τες, και κάθε τιμή ελέγχεται αμέσως. Και τα [παραδείγματα](/el/examples/) συνοδεύονται από ερωτήσεις και απαντήσεις. Οι διδάσκοντες μπορούν να τυπώσουν διαφορετικό διαγώνισμα για κάθε φοιτητή, με φύλλο λύσεων, από τον [δημιουργό διαγωνισμάτων](/el/exam)· δείτε [Ασκήσεις και διαγωνίσματα](/el/guide/teaching#practice-and-test-papers).

### Πώς αναφέρω το EduBeam σε μια εργασία; {#cite}

Ως λογισμικό, με την έκδοση και την ημερομηνία που το χρησιμοποιήσατε. Η έκδοση βρίσκεται στο κάτω μέρος του μενού **☰**. Για παράδειγμα:

> Voříšek, J. και συντελεστές. *EduBeam*, έκδοση 1.3.4 \[λογισμικό\]. https://edubeam.app (πρόσβαση: 18 Νοεμβρίου 2026).

Για να αναφερθείτε σε ένα συγκεκριμένο μοντέλο, προσθέστε τον [σύνδεσμο κοινής χρήσης](/el/essentials/import-export#share-a-link) του: ανοίγει το ίδιο μοντέλο σε κάθε αναγνώστη.

## Μοντελοποίηση {#modelling}

### Πώς ορίζω πάκτωση, άρθρωση ή κύλιση; {#how-do-i-make-a-fixed-pinned-roller-support}

Κάντε κλικ στον κόμβο, επιλέξτε **Στηρίξεις κόμβου** και διαλέξτε το σύμβολο: άρθρωση, κύλιση, πάκτωση, ολισθαίνουσα πάκτωση και άλλα. Ή επιλέξτε τους δεσμευμένους βαθμούς ελευθερίας στην καρτέλα **Κόμβοι**: `Dx` + `Dz` + `Ry` είναι πάκτωση, `Dx` + `Dz` άρθρωση, μόνο `Dz` κύλιση. Η σελίδα [Κόμβοι και στηρίξεις](/el/essentials/nodes-supports#supports) περιγράφει όλα τα είδη.

### Πώς φτιάχνω ένα δικτύωμα; {#how-do-i-make-a-truss}

Σχεδιάστε τις ράβδους ως κανονικά στοιχεία και απελευθερώστε και τα δύο άκρα της καθεμίας: επιλέξτε και τις δύο **Ακραίες αρθρώσεις** στην καρτέλα **Στοιχεία**, ή επιλέξτε **Άρθρωση αρχής** και **Άρθρωση τέλους** στη γραμμή στο πάνω μέρος πριν σχεδιάσετε τις ράβδους με το ποντίκι. Εφαρμόστε τα φορτία στους κόμβους. Ο οδηγός [Επίπεδο δικτύωμα](/el/tutorials/truss) φτιάχνει ένα βήμα προς βήμα.

### Πώς βάζω άρθρωση σε ένα πλαίσιο; {#how-do-i-put-a-hinge-in-a-frame}

Απελευθερώστε τη ροπή στο άκρο του στοιχείου που πρέπει να στρέφεται ελεύθερα: επιλέξτε την ακραία άρθρωσή του στην καρτέλα **Στοιχεία**. Μια άρθρωση ανήκει σε ένα άκρο στοιχείου, οπότε σε έναν κόμβο όπου συναντώνται πολλά στοιχεία, η απελευθέρωση ενός από αυτά αφήνει τα υπόλοιπα μονολιθικά συνδεδεμένα. Δείτε [Ακραίες αρθρώσεις](/el/essentials/elements#end-hinges).

### Πώς προσθέτω στήριξη ή συγκεντρωμένο φορτίο στο μέσο μιας δοκού; {#how-do-i-add-a-support-or-a-point-load-in-the-middle-of-a-beam}

Για στήριξη, προσθέστε έναν κόμβο πάνω στη δοκό με το ποντίκι (το κουμπί **Προσθήκη κόμβου** με το εικονίδιο του δείκτη) και επιλέξτε **Σύνδεση με τον φορέα**: η δοκός χωρίζεται στα δύο σε αυτόν τον κόμβο, και μπορείτε να τη στηρίξετε εκεί. Ένα συγκεντρωμένο φορτίο δεν χρειάζεται κόμβο: προσθέστε ένα **Συγκεντρωμένο φορτίο** στο στοιχείο και ορίστε τη θέση του από τον κόμβο αρχής. Δείτε [Τοποθέτηση κόμβου πάνω σε υπάρχον στοιχείο](/el/essentials/nodes-supports#placing-a-node-on-an-existing-element) και [Συγκεντρωμένο φορτίο](/el/essentials/loads#concentrated-load).

### Μπορώ να εισαγάγω το ίδιο βάρος; {#can-i-apply-self-weight}

Όχι αυτόματα: η πυκνότητα του υλικού δεν χρησιμοποιείται στη στατική ανάλυση. Προσθέστε το ως ομοιόμορφα κατανεμημένο φορτίο $f_z = \rho g A$, για παράδειγμα $7850 \cdot 9{,}81 \cdot 28{,}48 \cdot 10^{-4} = 219$ N/m, δηλαδή 0,22 kN/m, για μια IPE 200.

### Μπορώ να μοντελοποιήσω κεκλιμένες στηρίξεις; {#can-i-model-inclined-supports}

Ναι. Δώστε στον κόμβο μια **Γωνία τοπικού συστήματος κόμβου**, και οι στηρίξεις του ενεργούν τότε κατά τους στραμμένους άξονες. Δείτε [Κεκλιμένες στηρίξεις](/el/essentials/nodes-supports#inclined-skewed-supports).

### Μπορώ να δουλέψω σε αμερικανικές μονάδες; {#can-i-work-in-us-customary-units}

Ναι. Κάντε κλικ στην ένδειξη μονάδων κάτω δεξιά στην προβολή, που ανοίγει τις **Ρυθμίσεις → Γλώσσα και τοπικές ρυθμίσεις**, και ορίστε το **Σύστημα μονάδων** σε **Αμερικανικό (αγγλοσαξονικό)** για πόδια και kips, ή επιλέξτε κάθε μονάδα χωριστά. Το μοντέλο αποθηκεύεται σε SI, οπότε η αλλαγή μονάδων μετατρέπει ό,τι βλέπετε και δεν αλλάζει ποτέ το μοντέλο. Δείτε [Μονάδες και ρυθμίσεις](/el/essentials/units-settings).

### Υπάρχουν περιπτώσεις φόρτισης ή συνδυασμοί; {#are-there-load-cases-or-combinations}

Όχι, ένα μοντέλο έχει μία περίπτωση φόρτισης. Αποθηκεύστε κάθε περίπτωση ως χωριστό αρχείο ή σύνδεσμο, και συνδυάστε τα αποτελέσματα μόνοι σας. Μια συνεδρία από το desktop EduBeam με πολλές περιπτώσεις φόρτισης ανοίγει με την πρώτη, και ένα μήνυμα αναφέρει όσες παραλείφθηκαν.

### Γιατί τα φορτία μου δείχνουν προς τα πάνω; {#why-do-my-loads-point-up}

Πιθανότατα επειδή δώσατε αρνητική τιμή. Στο EduBeam ο καθολικός άξονας z δείχνει **προς τα κάτω**, οπότε θετικό `fz` ή `Fz` είναι φορτίο βαρύτητας, προς τα κάτω: 12 kN/m προς τα κάτω είναι `fz = 12`. Δείτε [Σύστημα συντεταγμένων και συμβάσεις προσήμων](/el/elements/conventions#loads). Αν στο μάθημά σας ο κατακόρυφος άξονας δείχνει προς τα πάνω, επιλέξτε **x δεξιά, y πάνω** στις **Ρυθμίσεις → Γλώσσα και τοπικές ρυθμίσεις → Σύστημα συντεταγμένων**: τα δεδομένα και τα αποτελέσματα ακολουθούν τότε αυτόν τον άξονα.

## Αποτελέσματα {#results}

### Γιατί δεν υπάρχει κουμπί «Επίλυση»; {#why-is-there-no-solve-button}

Επειδή το μοντέλο επιλύεται ξανά μετά από κάθε αλλαγή. Αν δεν εμφανίζονται αποτελέσματα, το μοντέλο δεν μπορεί ακόμη να επιλυθεί, και ένα μήνυμα στον καμβά εξηγεί γιατί. Η [Επίλυση προβλημάτων](/el/reference/troubleshooting#no-results-are-drawn) αναφέρει τι να ελέγξετε.

### Γιατί το βέλος μου διαφέρει λίγο από τον τύπο; {#why-does-my-deflection-differ-slightly-from-the-formula}

Το EduBeam χρησιμοποιεί στοιχεία δοκού Timoshenko, οπότε ένα βέλος περιλαμβάνει τη διατμητική παραμόρφωση που οι τύποι των βιβλίων συνήθως αγνοούν. Σε μια λυγηρή δοκό η διαφορά είναι περίπου 1 %, και η [Γρήγορη εκκίνηση](/el/guide/quick-start#_8-check-by-hand) την υπολογίζει με το χέρι. Σε έναν υπερστατικό φορέα η διατμητική στιβαρότητα μετατοπίζει επίσης ελαφρά τα εντατικά μεγέθη. Περισσότερα στη σελίδα [Έλεγχος αποτελεσμάτων με το χέρι](/el/guide/verification).

### Πόσο ακριβή είναι τα αποτελέσματα; Χρειάζομαι περισσότερα στοιχεία; {#how-accurate-are-the-results-do-i-need-more-elements}

Στη γραμμική στατική ανάλυση το στοιχείο δοκού είναι ακριβές για κάθε είδος φορτίου που προσφέρει το EduBeam, οπότε ένα στοιχείο ανά μέλος αρκεί και δεν υπάρχει πλέγμα για πύκνωση. Προσθέστε κόμβους μόνο όπου χρειάζεστε στήριξη, άρθρωση, αλλαγή διατομής, κομβικό φορτίο ή σημείο όπου θέλετε να διαβάσετε μια μετακίνηση. Δείτε [Ακρίβεια](/el/essentials/results#precision-and-accuracy).

### Πώς υπολογίζει το EduBeam τα αποτελέσματα; {#how-does-edubeam-compute-the-results}

Με τη μέθοδο άμεσης στιβαρότητας, τη μορφή της μεθόδου των πεπερασμένων στοιχείων που διδάσκεται στα μαθήματα Στατικής, μέσα στο πρόγραμμα περιήγησής σας. Η σελίδα [Πώς επιλύει το EduBeam ένα μοντέλο](/el/elements/analysis) ακολουθεί κάθε βήμα σε ένα μικρό παράδειγμα που μπορείτε να επαναλάβετε με το χέρι, και ο ίδιος ο επιλυτής είναι ανοιχτού κώδικα ως [@edubeam/fem](/el/solver).

### Μπορώ να δω τα μητρώα στιβαρότητας; {#can-i-see-the-stiffness-matrices}

Ναι. Στην καρτέλα **Στοιχεία**, το κουμπί του μητρώου στη γραμμή ενός στοιχείου ανοίγει το μητρώο στιβαρότητάς του 6 × 6, σε καθολικούς άξονες και μονάδες SI (N, m). Με κλικ σε ένα στοιχείο στην προβολή εμφανίζεται επίσης η επιλογή **Μητρώο στιβαρότητας**. Η σελίδα [Στοιχείο δοκού](/el/elements/beam#global-stiffness-matrix) δίνει την παραγωγή του.

### Πού βρίσκονται οι αντιδράσεις; {#where-are-the-reactions-listed}

Στην προβολή, ως βέλη με τις τιμές τους: **Αντιδράσεις** στις επιλογές εμφάνισης, ενεργές από προεπιλογή. Βρίσκονται επίσης στο αρχείο που δημιουργεί το **Αποτελέσματα → Εξαγωγή CSV** και σε ό,τι βάζει η **Αντιγραφή** στο πρόχειρο. Η καρτέλα **Αποτελέσματα** περιέχει τις μετακινήσεις κόμβων και τις δυνάμεις άκρων των στοιχείων. Δείτε [Αποτελέσματα και διαγράμματα](/el/essentials/results).

## Αρχεία και κοινή χρήση {#files-sharing}

### Πώς μοιράζομαι ένα μοντέλο; {#how-do-i-share-a-model}

Πατήστε **Κοινή χρήση μοντέλου** και μετά **Αντιγραφή**. Ο σύνδεσμος περιέχει ολόκληρο το μοντέλο, και όποιος τον ανοίξει παίρνει το δικό του αντίγραφο για επεξεργασία: δεν υπάρχει ταυτόχρονη συνεργασία. Ενεργοποιήστε το **Να φαίνεται ό,τι βλέπω** για να ανοίγει ο σύνδεσμος με τα διαγράμματα και τις ετικέτες σας ενεργά. Δείτε [Κοινή χρήση μέσω συνδέσμου](/el/essentials/import-export#share-a-link) και, για μαθήματα, [Διδασκαλία με το EduBeam](/el/guide/teaching#in-lecture-notes-and-assignments).

### Μπορώ να ενσωματώσω ένα μοντέλο στον ιστότοπό μου ή σε διαφάνειες; {#can-i-embed-a-model-on-my-website-or-in-slides}

Ναι. Προσθέστε `&viewer=1` σε έναν σύνδεσμο κοινής χρήσης και βάλτε τον σε ένα `<iframe>`: δείτε [Ενσωμάτωση προβολής](/el/essentials/import-export#embed-a-read-only-viewer). Για ένα στατικό σχήμα σε σελίδα, διαφάνεια ή έντυπες σημειώσεις, εξαγάγετε ένα SVG ή σχεδιάστε το από κώδικα με το [@edubeam/plot](/el/plot).

### Μπορώ να εξαγάγω εικόνες ή πίνακες; {#can-i-export-images-or-tables}

Ναι. Το **☰ → Εξαγωγή εικόνας** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) αποθηκεύει το σχέδιο ως PNG ή SVG, στο μέγεθος ή την κλίμακα που επιλέγετε. Το **Αποτελέσματα → Εξαγωγή CSV** αποθηκεύει και τους δύο πίνακες αποτελεσμάτων, και η **Αντιγραφή** τους βάζει στο πρόχειρο για επικόλληση σε υπολογιστικό φύλλο. Δείτε [Εξαγωγή εικόνας](/el/essentials/import-export#export-an-image).

### Μπορώ να ανοίξω αρχεία από το desktop EduBeam; {#can-i-open-files-from-the-desktop-edubeam}

Ναι. Οι συνεδρίες που αποθηκεύτηκαν από το desktop EduBeam 2.x έως 3.5 (`.xml`) ανοίγουν με **☰ → Άνοιγμα έργου** ή σέρνοντάς τες στην εφαρμογή, όπως ένα `project.json`. Οι τιμές τους διαβάζονται σε kN, kPa και m. Δείτε [Άνοιγμα έργου](/el/essentials/import-export#open-a-project).

### Μπορώ να δημιουργώ μοντέλα προγραμματιστικά; {#can-i-generate-models-programmatically}

Ναι, με δύο τρόπους:

- **Γράψτε το αρχείο.** Ένα `project.json` είναι απλό JSON σε μονάδες SI, οπότε ένα script σε οποιαδήποτε γλώσσα μπορεί να το γράψει, και το EduBeam το ανοίγει με το **Άνοιγμα έργου** ή με σύρσιμο και απόθεση. Δείτε τη [μορφή του αρχείου έργου](/el/essentials/import-export#project-file-format).
- **Επιλύστε το σε κώδικα.** Το [@edubeam/fem](/el/solver) είναι ο επιλυτής πεπερασμένων στοιχείων του EduBeam, διαθέσιμος ως βιβλιοθήκη JavaScript και TypeScript. Το [@edubeam/plot](/el/plot) σχεδιάζει στη συνέχεια το αποτέλεσμα, για παράδειγμα ως [φυλλάδιο ασκήσεων που δημιουργείται αυτόματα](/el/plot/exercises).

Η δοκός της [Γρήγορης εκκίνησης](/el/guide/quick-start), σε μονάδες SI:

```ts
import { DofID, LinearStaticSolver } from '@edubeam/fem'

const solver = new LinearStaticSolver()
const { domain } = solver
domain.createMaterial('steel', { e: 210e9, g: 81e9 }) // Pa
const section = { a: 28.48e-4, iy: 1943e-8, h: 0.2, k: 0.3933 } // m², m⁴, m
domain.createCrossSection('IPE200', section)
domain.createNode('1', [0, 0, 0], [DofID.Dx, DofID.Dz]) // άρθρωση
domain.createNode('2', [6, 0, 0], [DofID.Dz]) // κύλιση
const beam = domain.createBeam2D('1', ['1', '2'], 'steel', 'IPE200')
const lc = solver.loadCases[0]
lc.createBeamElementUniformEdgeLoad('1', [0, 12e3], true) // 12 kN/m, προς τα κάτω

solver.solve()
beam.computeBendingMomentAt(lc, 3) // 54000 N·m στο μέσο του ανοίγματος
beam.computeLocalDefl(lc, 2).w[1] // 0.0502 m στο μέσο του ανοίγματος
```
