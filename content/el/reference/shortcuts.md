# Πληκτρολόγιο, ποντίκι και αφή

Το EduBeam λειτουργεί με πληκτρολόγιο και ποντίκι, με touchpad ή με το δάχτυλο. Αυτή η σελίδα παραθέτει κάθε συντόμευση και χειρονομία. Σε Mac, χρησιμοποιήστε το <kbd>Cmd</kbd> όπου εμφανίζεται το <kbd>Ctrl</kbd>· τα μενού της εφαρμογής δείχνουν εκεί το ⌘.

## Πληκτρολόγιο {#keyboard}

Οι συντομεύσεις σχεδίασης (<kbd>F</kbd>, <kbd>C</kbd>, <kbd>G</kbd>, <kbd>S</kbd>, <kbd>Delete</kbd> και <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>V</kbd>) δεν κάνουν τίποτα όσο ένα πεδίο κειμένου είναι ενεργό, οπότε ένα `f` ή ένα `s` που πληκτρολογείτε σε πεδίο δεν τις ενεργοποιεί ποτέ. Κάντε πρώτα κλικ στο σχέδιο.

### Αρχεία και ιστορικό {#files-and-history}

| Συντόμευση | Ενέργεια |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Αναίρεση της τελευταίας αλλαγής στο μοντέλο |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Επανάληψη |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Αποθήκευση έργου (κατεβάζει το `project.json`) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Άνοιγμα έργου |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Εξαγωγή εικόνας |

Η αναίρεση ακυρώνει επίσης τη διαγραφή του μοντέλου, το άνοιγμα αρχείου, συνδέσμου ή παραδείγματος, και την επαναφορά ενός πρόσφατου φορέα. Όσο πληκτρολογείτε ακόμη σε ένα κελί πίνακα, το <kbd>Ctrl</kbd>+<kbd>Z</kbd> αναιρεί την πληκτρολόγηση· μόλις επιβεβαιωθεί το κελί, αναιρεί την αλλαγή στο μοντέλο. Στα πεδία ενός παραθύρου διαλόγου αναιρεί πάντα την πληκτρολόγηση.

### Σχεδίαση {#drawing}

| Συντόμευση | Ενέργεια |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Επιλογή όλων |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Αντιγραφή των επιλεγμένων κόμβων, στοιχείων και φορτίων |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Επικόλληση. Ένα ημιδιάφανο είδωλο του αντιγράφου ακολουθεί τον δείκτη: κάντε κλικ για να το τοποθετήσετε, ή πληκτρολογήστε μια μετατόπιση Δx, Δz στη γραμμή στο πάνω μέρος και πατήστε **Επικόλληση** ή <kbd>Enter</kbd> |
| <kbd>Delete</kbd> | Διαγραφή της επιλογής (σε φορητό Mac, <kbd>Fn</kbd>+<kbd>Delete</kbd>) |
| <kbd>Esc</kbd> | Έξοδος από την τρέχουσα λειτουργία (προσθήκη κόμβων, στοιχείων ή διαστάσεων, επικόλληση, επιλογή περιοχής για εικόνα) και κατάργηση της επιλογής· κλείνει επίσης το μενού ☰ και τερματίζει την περιήγηση |
| <kbd>F</kbd> | Προσαρμογή στην οθόνη |
| <kbd>C</kbd> | Κεντράρισμα |
| <kbd>G</kbd> | Εμφάνιση/απόκρυψη κανάβου |
| <kbd>S</kbd> | Ενεργοποίηση/απενεργοποίηση έλξης στον κάναβο |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Μεγέθυνση / σμίκρυνση του σχεδίου ως προς το κέντρο του |

Στο EduBeam, τα <kbd>Ctrl</kbd>+<kbd>+</kbd> και <kbd>Ctrl</kbd>+<kbd>-</kbd> μεγεθύνουν το σχέδιο, ποτέ ολόκληρο το περιβάλλον όπως σε άλλους ιστότοπους. Λειτουργούν με οποιαδήποτε διάταξη πληκτρολογίου: τα πλήκτρα με τα σύμβολα + και −, όπου κι αν βρίσκονται στη διάταξή σας, τα δύο αριστερά από το <kbd>Backspace</kbd> σε αμερικανικό πληκτρολόγιο, και τα + και − του αριθμητικού πληκτρολογίου.

### Πίνακες και παράθυρα διαλόγου {#tables-and-dialogs}

| Συντόμευση | Ενέργεια |
| --- | --- |
| <kbd>Enter</kbd> | Σε κελί πίνακα: επιβεβαιώνει την τιμή. Σε πεδίο κειμένου παραθύρου διαλόγου: επιβεβαιώνει το παράθυρο, όπως το κύριο κουμπί του |
| <kbd>Esc</kbd> | Σε κελί πίνακα: βγαίνει από αυτό και κρατά την τιμή. Σε παράθυρο διαλόγου: το κλείνει χωρίς αποθήκευση |
| <kbd>Tab</kbd> | Μετάβαση στο επόμενο πεδίο· ένα κελί πίνακα κρατά ό,τι πληκτρολογήσατε |

Τα αριθμητικά πεδία δέχονται αριθμητικές πράξεις, όπως θα τις γράφατε στο χαρτί: `6/2`, `3*1,5`, `2^3`, `(4+2)/3`, καθώς και `1e3`· ως υποδιαστολή μπορείτε να χρησιμοποιήσετε κόμμα ή τελεία.

## Ποντίκι {#mouse}

| Ενέργεια | Αποτέλεσμα |
| --- | --- |
| Κλικ | Επιλέγει κόμβο, στοιχείο, φορτίο ή γραμμή διάστασης και ανοίγει το πλαίσιό του |
| Σύρσιμο σε κενό σημείο του καμβά | Ορθογώνιο επιλογής |
| Σύρσιμο κόμβου | Τον μετακινεί· έλκεται στον κάναβο όταν η έλξη είναι ενεργή |
| Κλικ κατά την προσθήκη | Τοποθετεί κόμβο ή ξεκινά ή συνεχίζει μια τεθλασμένη γραμμή στοιχείων |
| Διπλό κλικ σε φορτίο | Επεξεργασία του φορτίου (και μιας επιβαλλόμενης μετακίνησης) |
| Δεξί κλικ | Μενού καμβά: Προσθήκη κόμβου, Προσθήκη στοιχείου, Προσθήκη διάστασης, Διάσταση στοιχείου (πάνω από στοιχείο), Επεξεργασία, Αντιγραφή, Επικόλληση, Διαγραφή |
| <kbd>Ctrl</kbd> + **Προσθήκη κόμβου** ή **Προσθήκη στοιχείου** στο μενού του καμβά | Τοποθέτηση με το ποντίκι αντί για άνοιγμα παραθύρου διαλόγου |
| Σύρσιμο με το μεσαίο ή το δεξί κουμπί | Μετακίνηση προβολής. Επιλέξτε το κουμπί στις **Ρυθμίσεις → Χειρισμός και συντομεύσεις → Μετακίνηση προβολής με** |
| Ροδέλα | Μεγέθυνση προς τη θέση του δείκτη |
| Δείκτης πάνω σε αντικείμενο | Επεξήγηση με τις μετακινήσεις, τις ιδιότητες ή τις τιμές φορτίου του |

Σε touchpad, τόσο το τσίμπημα όσο και η κύλιση με δύο δάχτυλα κάνουν μεγέθυνση. Για μετακίνηση της προβολής, κάντε κλικ και σύρετε με δύο δάχτυλα, που ισοδυναμεί με σύρσιμο με το δεξί κουμπί.

## Αφή {#touch}

| Χειρονομία | Αποτέλεσμα |
| --- | --- |
| Πάτημα | Επιλέγει ένα αντικείμενο και δείχνει τις λεπτομέρειες και τις ενέργειές του |
| Πάτημα κατά την προσθήκη | Τοποθετεί κόμβο ή συνεχίζει ένα στοιχείο |
| Πάτημα σε κόμβο και σύρσιμο | Μετακινεί τον κόμβο |
| Σύρσιμο με ένα δάχτυλο αλλού | Μετακίνηση προβολής |
| Τσίμπημα | Μεγέθυνση |
| Παρατεταμένο πάτημα στον καμβά | Μενού καμβά |
| Κουμπί **Επιλογή με πλαίσιο** (πάνω δεξιά), μετά σύρσιμο | Ορθογώνιο επιλογής· το μενού του καμβά, με Αντιγραφή και Διαγραφή, ανοίγει εκεί όπου σηκώνετε το δάχτυλο |

Όσο προσθέτετε κόμβους, στοιχεία ή διαστάσεις, επικολλάτε ή επιλέγετε περιοχή για εικόνα, μια γραμμή στο πάνω μέρος του σχεδίου αναφέρει τη λειτουργία και έχει κουμπί **Άκυρο**. Σε οθόνη αφής, όπου δεν υπάρχει πλήκτρο <kbd>Esc</kbd>, έτσι βγαίνετε από τη λειτουργία.

## Πλαίσια αντικειμένων {#object-panels}

Με κλικ ή πάτημα σε ένα αντικείμενο ανοίγει δίπλα του ένα πλαίσιο με τις λεπτομέρειές του και τις εξής ενέργειες:

| Αντικείμενο | Ενέργειες |
| --- | --- |
| Κόμβος | Προσθήκη φορτίου · Στηρίξεις κόμβου (σύμβολο στήριξης, Dx, Dz, Ry) · Γωνία τοπικού συστήματος κόμβου · Επιβολή μετακίνησης (σε στηριζόμενο κόμβο) · Διαγραφή |
| Στοιχείο | Επεξεργασία στοιχείου (ακραίοι κόμβοι και αρθρώσεις, υλικό, διατομή) · Προσθήκη φορτίου · Μητρώο στιβαρότητας · Διαγραφή |
| Κομβικό φορτίο ή φορτίο στοιχείου | Επεξεργασία φορτίου · Διαγραφή |
| Γραμμή διάστασης | Επεξεργασία · Αναστροφή διάστασης · Διαγραφή |

Η σελίδα [Περιβάλλον εργασίας](/el/essentials/user-interface) παρουσιάζει την οθόνη της εφαρμογής, και η ρύθμιση [Χειρισμός και συντομεύσεις](/el/essentials/units-settings#controls-shortcuts) επιλέγει το κουμπί μετακίνησης της προβολής.
