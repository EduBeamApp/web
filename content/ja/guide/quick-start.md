# クイックスタート

約 10 分で鋼製の単純梁をモデル化し、反力、せん断力、曲げモーメント、たわみを読み取り、すべての数値を手計算で確認します。EduBeam を別のタブか、このページの隣に開き、実際に操作しながら読み進めてください。

::div{.actions}
[EduBeam を開く ↗](https://run.edubeam.app/?lang=ja){target="_blank"} [手計算による確認へ移動](#_8-check-by-hand)
::

## 問題 {#the-problem}

長さ 6 m の梁が、節点 1 でピン支点、節点 2 でローラー支点に支持され、全長にわたって 12 kN/m の等分布荷重を受けます。断面は鋼製の IPE 200 で、$E = 210$ GPa、$G = 81$ GPa、$A = 28.48\ \text{cm}^2$、$I_y = 1943\ \text{cm}^4$ です。この 4 つの値はどれも EduBeam のライブラリに入っているので、調べる必要はありません。

## モデルを作る {#build-the-model}

::div{.steps}

### 空のモデルから始める {#start-from-an-empty-model}

はじめてアプリを開くと、ようこそダイアログでどのように始めるかを尋ねられます。**単位系**で **SI（メートル法）** を選び、**座標系**は **x 右向き、z 下向き**のままにして、**今はスキップ**を押します。すると小さなラーメンの例題が表示されます。

1. アプリバーの**モデルをクリア**を押します（スマートフォンでは **☰** メニューの中にあります）。
2. **材料を削除**と**断面を削除**にチェックを入れ、**確定**を押します。

キャンバスが空になり、材料と断面がまだないことを知らせる赤いメッセージが 2 つ表示されます。これは次の手順で解消します。元のラーメンは失われません。<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せますし、**☰ → 最近のモデル**にも残っています。

### 単位を確認する {#_1-check-the-units}

ビューアの右下にある単位チップには、すべての入力欄と結果で使われる単位が表示されます。このページでは SI 単位（チップの表示は `m m² kN kNm MPa`）と、下向きの z 軸を使います。チップにフィートとキップが表示されている場合は、チップをクリックして**単位系**を **SI（メートル法）** にしてください。同じ場所で、**座標系**が **x 右向き、z 下向き**になっていることも確認してください。y 上向きでは正の荷重が上を向くので、このページの符号と合わなくなります。

![グリッド（G）とスナップ（S）の切り替えボタン、クロスヘア、単位チップ](/screenshots/ja/ui-grid-units.webp){.shot-sm}

### 材料と断面を追加する {#_2-add-the-material-and-cross-section}

要素には材料と断面が必要なので、先にライブラリから追加します。

1. 下部バーの**材料**タブを開き、**材料ライブラリ**をクリックします。
2. **鋼材 (S235)** の行で **+** を押します（$E = 210{,}000$ MPa、$G = 81{,}000$ MPa）。ライブラリは続けて追加できるよう開いたままなので、**キャンセル**で閉じます。
3. **断面**タブを開き、**断面ライブラリ**をクリックします。
4. **IPE 200 (概略)** の行までスクロールして **+** を押し、**キャンセル**でライブラリを閉じます。

赤いメッセージは 2 つとも消え、**断面**タブに IPE 200 が表示されます。

![断面タブの IPE 200：断面積、Iy、高さ、せん断補正係数](/screenshots/ja/a-qs-cross-sections.webp)

自分で値を入力したい場合は、**材料を追加**と**断面を追加**を使います。ここでのせん断補正係数 0.3933 は、後の[手計算による確認](#_8-check-by-hand)でも使います。

### 節点を追加する {#_3-add-the-nodes}

1. **節点**タブを開きます。**節点を追加**ボタンは 2 つあり、**+** のボタンはダイアログを開き、カーソルアイコンのボタンではマウスで節点を配置します。**+ 節点を追加**をクリックします。
2. **X 座標**と **Z 座標**は `0` のままにして、**節点を追加**を押します。ダイアログが閉じ、節点 `1` が表示されます。
3. もう一度 **+ 節点を追加**をクリックし、**X 座標**に `6` を入力して**節点を追加**を押します。これが節点 `2` です。

![「新しい節点を追加」ダイアログ。支点もその場で設定できます。](/screenshots/ja/qs-node.webp){.shot-md}

### 要素でつなぐ {#_4-connect-them-with-an-element}

**要素**タブを開き、**+ 要素を追加**をクリックします。ダイアログには、**始端節点** `1`、**終端節点** `2`、追加した材料と断面がすでに入っています。**要素を追加**を押します。

![「新しい要素を追加」ダイアログ：両端の節点、必要に応じて各端のヒンジ、材料と断面](/screenshots/ja/a-qs-element.webp){.shot-md}

節点の間に梁が表示されます。<kbd>F</kbd> を押すと画面に合わせて表示されます。ビューアの左上にある青い**支点が必要**チップが、まだ結果が出ない理由を示しています。

### 支点を追加する {#_5-add-the-supports}

**節点**タブに戻ります。各行の**拘束自由度**列の先頭に、支点の選択ボタンがあります。

- 節点 `1`：**ピン**を選びます。`Dx` と `Dz` にチェックが入ります。
- 節点 `2`：**ローラー**を選びます。`Dz` だけにチェックが入ります。

![節点タブの表にある支点の選択ボタン](/screenshots/ja/a-qs-support-picker.webp){.shot-lg}

**支点が必要**チップが消えます。ビューアで節点をクリックし、**支点条件**を選んで設定することもできます。支点の種類はすべて[節点と支点](/ja/essentials/nodes-supports#supports)に載っています。

### 荷重を追加する {#_6-add-the-load}

1. **荷重**タブを開き、**要素荷重を追加**をクリックします。
2. **荷重の種類**は*等分布荷重*、**要素**は `1` のままにします。
3. **fz** に `12` を入力し、**fx** は `0` のままにして、**要素荷重を追加**を押します。

![ダイアログでは要素上の荷重をプレビューできます](/screenshots/ja/a-qs-load.webp){.shot-md}

正の `fz` は +z 方向、つまり**下向き**なので、正の値が重力方向の荷重になります。**LCS** にチェックが入っているのは、荷重が要素自身の座標軸（ローカル座標系）に従うという意味です。左から右へ描いた水平な梁では、ローカル座標系はグローバル座標系と一致します。詳しくは[座標系と符号規約](/ja/elements/conventions#loads)をご覧ください。

::

## 結果を読む {#_7-read-the-results}

荷重を入力した時点で EduBeam が梁を解き、以後も変更するたびに解き直します。*解析*ボタンはありません。ビューア右上のパネルで、各図の表示・非表示を切り替えます。**変位図**、**M<sub>y</sub>(x)**、**反力**は初期状態でオンです。**V<sub>z</sub>(x)** にチェックを入れると、せん断力も表示されます。

![表示オプション：せん断力をオンにした状態](/screenshots/ja/a-qs-display.webp){.shot-md}

画面は次の図と同じになっているはずです。曲げモーメントとせん断力を切り替えてみてください。

| 表示 | 確認するポイント |
| --- | --- |
| **反力** | 各支点に 1 本ずつ、上向きの **36 kN** の矢印が 2 本。 |
| **V<sub>z</sub>(x)** | 節点 `1` の **+36 kN** から節点 `2` の **−36 kN** までの直線。スパン中央で 0 になる。 |
| **M<sub>y</sub>(x)** | スパン中央で最大値 **54 kNm** をとる放物線。引張側、つまり梁の下側に描かれる。 |
| **変位図** | 左右対称のたわみ。拡大して描かれる。 |

数値は**結果**タブで確認します。**節点結果**には各節点の変位 `Dx`、`Dz` と回転角 `Ry` が、**要素結果**には各要素のローカル座標系での材端力が表示されます。節点 `1` は $R_y = -2.6469 \cdot 10^{-2}$ rad 回転し、節点 `2` は同じ大きさだけ逆向きに回転します。表と符号の詳細は[結果と断面力図](/ja/essentials/results)で説明しています。

図が大きすぎたり小さすぎたりする場合は、**設定 → 表示設定**の**結果の表示倍率**を変更してください。

## 手計算で確認する {#_8-check-by-hand}

$q = 12$ kN/m、$L = 6$ m として、教科書の公式から次の値が得られます。

| 量 | 式 | 手計算 | EduBeam |
| --- | --- | --- | --- |
| 反力 | $qL/2$ | 36 kN | 36 kN |
| 最大せん断力 | $qL/2$ | 36 kN | 36 kN |
| 最大曲げモーメント | $qL^2/8$ | 54 kNm | 54 kNm |
| 材端のたわみ角 | $qL^3/(24EI)$ | 0.02647 rad | 0.02647 rad |
| スパン中央のたわみ | $w_b + w_s$ | 49.63 + 0.60 = 50.22 mm | 50.22 mm |

たわみは 2 つの成分からなります。たいていの教科書に載っているのは 1 つ目だけです。

- **曲げ：** $w_b = 5qL^4/(384EI) = 49.63$ mm。$E = 210$ GPa と $I_y = 1943\ \text{cm}^4$ から $EI = 4080$ kNm²。
- **せん断：** $w_s = qL^2/(8kGA) = 0.60$ mm。$k = 0.3933$、$G = 81$ GPa、$A = 28.48\ \text{cm}^2$ から $kGA \approx 90{,}700$ kN。

スパン中央にはまだ節点がないので、たわみを読むために 1 つ追加します。

1. **節点**タブで、2 つ目の**節点を追加**ボタン（カーソルアイコンのボタン）をクリックします。
2. 梁の `x = 3` の位置をクリックします。スナップがオンなら、節点はグリッド上に置かれます。節点をどう扱うかを尋ねられるので、**構造物に接続**を押します。要素は荷重ごと `1a` と `1b` に分割され、節点の配置は終了します。**節点**タブで節点 `3` の X が `3` になっていなければ、そこに `3` と入力してください。
3. **結果 → 節点結果**で、節点 `3` に $D_z = 5.0224 \cdot 10^{-2}$ m、つまり 50.22 mm と表示されます。

![分割後の節点結果：節点 3 は 50.22 mm 下に変位](/screenshots/ja/a-qs-nodal-results.webp){.shot-lg}

梁を分割しても結果は変わりません。この種の荷重に対しては要素そのものが厳密な解を与えるので、メッシュを細かくする必要がないのです。

::callout{type="details" title="せん断補正係数はなぜ重要か"}
EduBeam はせん断変形を考慮するティモシェンコ梁要素を使います。せん断補正係数 $k$ はせん断を負担する面積の割合を表し、$kGA$ がせん断剛性になります。ライブラリの I 形断面では、$k$ はウェブが占める面積の割合 $h t_w / A$ です。IPE 200 では $0.2 \cdot 0.0056 / 0.002848 = 0.3933$ になります。たわみのせん断成分 $w_s = qL^2/(8kGA)$ は、$V/(kGA)$ を支点からスパン中央まで積分したものです。

この細長い梁では、せん断成分は 0.60 mm で、全体の約 1 % です。短くてせいの高い梁では、これがずっと大きくなります。**断面**タブでせん断補正係数を非常に大きな値（たとえば `1e10`）にすると、EduBeam は曲げだけによる 49.63 mm を返します。理論は[梁要素](/ja/elements/beam)のページで説明しています。
::

ほかの手計算による確認方法（片持ち梁、両端固定梁、トラス、温度荷重、支点沈下）は[手計算による結果の確認](/ja/guide/verification)にあります。

## いろいろ試す {#_9-experiment}

モデルを変更して、図がどう追従するかを見てみましょう。変更は 1 つずつ試し、次に進む前に <kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻してください。節点 `3` は、先ほど追加したスパン中央の節点です。

- **節点 `2` を右へドラッグ**します。曲げモーメントは $L^2$ に、たわみは $L^4$ に比例して大きくなります。
- **節点 `1` の `Ry` にチェック**を入れて、その端を固定します。固定端に負の曲げモーメント（上側引張）が生じます。教科書の公式では $qL^2/8 = 54$ kNm、EduBeam では 53.8 kNm です。不静定梁では、せん断剛性が断面力にも影響するためです。
- **節点 `3` の `Dz` にチェック**を入れて中間支点を加え、2 径間連続梁にします。中間支点上の曲げモーメントは負になります。手計算では $q(L/2)^2/8 = 13.5$ kNm、EduBeam では同じ理由で 13.3 kNm です。
- **節点 `3` の `Dz` と、要素 `1a` の*材端ヒンジ*列の 2 つ目のチェックボックス**（節点 `3` 側の端、**要素**タブ）にチェックを入れます。梁はスパン 3 m の単純梁 2 つに分かれます。ここで節点 `3` の `Dz` のチェックを外すと、梁は不安定構造になり、EduBeam がその動き方を示します。

モデルを作らずにスパンと荷重を変えてみたい場合は、下のスライダーをドラッグしてください。結果を切り替えると、それぞれがスパンとともにどう大きくなるかがわかります。

## 保存・共有する {#_10-save-or-share}

- **人に送る：** アプリバーの**モデルを共有**を押し、**コピー**を押します。リンクにはモデル全体が含まれ、開いた人は自分用のコピーを編集できます。
- **ファイルとして残す：** **☰ → プロジェクトを保存**（<kbd>Ctrl</kbd>+<kbd>S</kbd>）で `project.json` がダウンロードされます。もう一度開くには、**☰ → プロジェクトを開く**（<kbd>Ctrl</kbd>+<kbd>O</kbd>）を使うか、ファイルをアプリにドロップします。
- **レポートに図を載せる：** **☰ → 画像をエクスポート**（<kbd>Ctrl</kbd>+<kbd>P</kbd>）で PNG または SVG として保存します。

モデルはブラウザにも保存されるので、ページを再読み込みしても失われません。詳しくは[ファイル・リンク・エクスポート](/ja/essentials/import-export)をご覧ください。
