# キーボード・マウス・タッチ

EduBeam は、キーボードとマウス、トラックパッド、指のどれでも操作できます。このページでは、すべてのショートカットとジェスチャーを紹介します。Mac では、<kbd>Ctrl</kbd> と書かれているところで <kbd>Cmd</kbd> を使ってください。アプリのメニューでも、その箇所には ⌘ が表示されます。

## キーボード {#keyboard}

描画用のショートカット（<kbd>F</kbd>、<kbd>C</kbd>、<kbd>G</kbd>、<kbd>S</kbd>、<kbd>Delete</kbd>、<kbd>Ctrl</kbd>+<kbd>A</kbd>、<kbd>C</kbd>、<kbd>V</kbd>）は、入力欄にフォーカスがある間は働きません。そのため、入力欄に `f` や `s` を入力しても、ショートカットが誤って実行されることはありません。使うときは、先に図をクリックしてください。

### ファイルと履歴 {#files-and-history}

| ショートカット | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | モデルへの最後の変更を元に戻す |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | やり直し |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | プロジェクトを保存（`project.json` をダウンロード） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | プロジェクトを開く |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 画像をエクスポート |

元に戻す操作では、モデルのクリア、ファイル・リンク・例題を開く操作、最近のモデルの復元も取り消せます。表のセルに入力している途中なら、<kbd>Ctrl</kbd>+<kbd>Z</kbd> は入力した文字を取り消します。セルの値を確定した後は、モデルへの変更を元に戻します。ダイアログの入力欄では、常に入力した文字を取り消します。

### 描画 {#drawing}

| ショートカット | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | すべて選択 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 選択した節点、要素、荷重をコピー |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 貼り付け。コピーの半透明の像がポインターに付いてくるので、クリックして配置するか、バナーにオフセット Δx、Δz を入力して**貼り付け**か <kbd>Enter</kbd> を押す |
| <kbd>Delete</kbd> | 選択したものを削除（Mac のノートパソコンでは <kbd>Fn</kbd>+<kbd>Delete</kbd>） |
| <kbd>Esc</kbd> | 現在のモード（節点・要素・寸法線の追加、貼り付け、画像の範囲の指定）を終了し、選択を解除。☰ メニューを閉じ、ツアーも終了 |
| <kbd>F</kbd> | 画面に合わせる |
| <kbd>C</kbd> | 中央に表示 |
| <kbd>G</kbd> | グリッドの表示を切り替え |
| <kbd>S</kbd> | グリッドへのスナップを切り替え |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 図の中心を基準にズームイン / ズームアウト |

EduBeam では、<kbd>Ctrl</kbd>+<kbd>+</kbd> と <kbd>Ctrl</kbd>+<kbd>-</kbd> は図をズームします。ほかのサイトのように画面全体を拡大・縮小することはありません。キーボード配列にかかわらず使えます。+ と − の刻印があるキー（位置は配列によって異なります）、US 配列で <kbd>Backspace</kbd> の左にある 2 つのキー、テンキーの + と − のどれでも働きます。

### 表とダイアログ {#tables-and-dialogs}

| ショートカット | 操作 |
| --- | --- |
| <kbd>Enter</kbd> | 表のセルでは値を確定。ダイアログの入力欄では、メインのボタンと同じようにダイアログを確定 |
| <kbd>Esc</kbd> | 表のセルでは値を残したままセルを離れる。ダイアログでは保存せずに閉じる |
| <kbd>Tab</kbd> | 次の入力欄へ移動。表のセルでは入力した値を残す |

数値の入力欄には、手で計算するときと同じように式を入力できます（`6/2`、`3*1.5`、`2^3`、`(4+2)/3` など）。`1e3` のような指数表記や、小数点の代わりのコンマも使えます。

## マウス {#mouse}

| 操作 | 結果 |
| --- | --- |
| クリック | 節点、要素、荷重、寸法線を選択し、そのパネルを開く |
| キャンバスの何もない所をドラッグ | 範囲選択の矩形 |
| 節点をドラッグ | 節点を移動（スナップがオンならグリッドにスナップ） |
| 追加モード中にクリック | 節点を配置、または要素の折れ線を開始・継続 |
| 荷重をダブルクリック | 荷重を編集（強制変位も同様） |
| 右クリック | キャンバスのメニュー：節点を追加、要素を追加、寸法線を追加、要素に寸法線を追加（要素の上で）、編集、コピー、貼り付け、削除 |
| キャンバスのメニューで <kbd>Ctrl</kbd> を押しながら**節点を追加**または**要素を追加** | ダイアログを開かず、マウスで配置 |
| 中ボタンまたは右ボタンでドラッグ | パン。どちらのボタンを使うかは**設定 → 操作とショートカット → パン操作**で選ぶ |
| ホイール | ポインターの位置に向かってズーム |
| オブジェクトにポインターを合わせる | 変位、特性、荷重の値を示すツールチップ |

トラックパッドでは、ピンチでも 2 本指のスクロールでもズームします。パンするには、2 本指でクリックしてドラッグします（右ボタンでのドラッグにあたります）。

## タッチ {#touch}

| ジェスチャー | 結果 |
| --- | --- |
| タップ | オブジェクトを選択し、詳細と操作を表示 |
| 追加モード中にタップ | 節点を配置、または要素を継続 |
| 節点を押してドラッグ | 節点を移動 |
| それ以外の場所を 1 本指でドラッグ | パン |
| ピンチ | ズーム |
| キャンバスを長押し | キャンバスのメニュー |
| **矩形選択**ボタン（右上）を押してからドラッグ | 範囲選択の矩形。指を離した位置に、コピーと削除のあるキャンバスのメニューが開く |

節点・要素・寸法線の追加、貼り付け、画像の範囲の指定を行っている間は、図の上部にモード名と**キャンセル**ボタンのあるバナーが表示されます。<kbd>Esc</kbd> キーのないタッチスクリーンでは、このボタンでモードを終了します。

## オブジェクトのパネル {#object-panels}

オブジェクトをクリックまたはタップすると、その横にパネルが開き、詳細と次の操作が表示されます。

| オブジェクト | 操作 |
| --- | --- |
| 節点 | 荷重を追加 · 支点条件（支点記号、Dx、Dz、Ry） · 節点座標系の角度 · 強制変位を設定（支点のある節点で） · 削除 |
| 要素 | 要素を編集（両端の節点とヒンジ、材料、断面） · 荷重を追加 · 剛性マトリクス · 削除 |
| 節点荷重または要素荷重 | 荷重を編集 · 削除 |
| 寸法線 | 編集 · 寸法線を反転 · 削除 |

画面の構成は[ユーザーインターフェース](/ja/essentials/user-interface)で順に紹介しています。パンに使うボタンは、設定の[操作とショートカット](/ja/essentials/units-settings#controls-shortcuts)で選べます。
