# トラブルシューティング

モデルを解けない場合、[EduBeam]{.edubeam} はビューア左上のメッセージでその理由を示し、**詳細を表示**ですべての問題を詳しく一覧表示します。表示されたダイアログのタイトルを選んでください。下の各メッセージについて、意味と直し方を説明しています。

::card-grid{cols="2"}
:::card{title="まだ解析できません" icon="lucide:circle-dashed" to="#still-needed"}
青い**支点が必要**チップ。何も間違ってはいません。構造物がまだ支持されていないだけです。
:::
:::card{title="モデルを解析できません" icon="lucide:circle-x" to="#errors"}
赤いメッセージ。構造物を固定できない支点、不安定構造をつくるヒンジ、長さ 0 の要素など。
:::
:::card{title="モデルの警告" icon="lucide:triangle-alert" to="#warnings"}
黄色いメッセージ。モデルは解析されていますが、おそらく意図とは違う点があります。
:::
:::card{title="結果がおかしく見える" icon="lucide:scale" to="#results-look-wrong"}
上向きに作用する荷重、桁が違うたわみ、逆に見える符号。
:::
::

## メッセージ {#messages}

### 色の意味 {#read-the-message}

| 表示 | 意味 |
| --- | --- |
| 青い**支点が必要**チップ | モデルが未完成です。支点を追加してください。チップにポインターを合わせると、構造物がまだどう動けるかが破線で表示されます。 |
| **赤い**メッセージ | 何かが解析を妨げています。問題の内容が示されるか、複数ある場合は「モデルのエラー：n」と表示されます。関係する節点は図の上で丸で囲まれます。 |
| **黄色い**メッセージ | 警告です。モデルは解析されています。複数ある場合は「モデルの警告：n」と表示されます。 |
| 「材料が定義されていません。」 / 「断面が定義されていません。」 | 要素には材料と断面の両方が必要です。メッセージの横の**新規追加**ボタンで追加してください。 |

**詳細を表示**を押すと、*まだ解析できません*、*モデルを解析できません*、*モデルの警告*のいずれかのタイトルのダイアログが開きます。ダイアログのスイッチで構造物の動きを表示・非表示にでき、**トラブルシューティング**のリンクからこのページに来られます。

![「モデルを解析できません」ダイアログ：構造物の動きを表示するスイッチ付き](/screenshots/ja/ui-diagnostics.webp){.shot-lg}

図の上では、次のように操作できます。

- 赤いメッセージの **✕** を押すと、メッセージが小さな*モデルを解析できません*チップにたたまれ、小さな画面でも場所を取りません。チップをクリックすると元に戻ります。
- 赤いメッセージの**目**のボタンで、動きを示す破線を表示・非表示にします。破線とそのアニメーションを常にオフにするには、**設定 → 表示設定 → モデルチェック**を使います。
- 黄色いメッセージの **✕** を押すと、警告が非表示になります。

### 未完了 {#still-needed}

モデルは間違っているのではなく、まだ完成していないだけです。チップにポインターを合わせると短いメッセージが、ダイアログには長いメッセージが表示されます。

| メッセージ | 意味と対処 |
| --- | --- |
| 「構造物を解析するには支点が必要です。」 <br> 「2D 解析で安定するには、モデルに少なくとも 3 つの拘束自由度が必要です。」 | 拘束されている方向が合計で 3 つ未満です。支点を追加してください。 |
| 「節点 … を含む部分に支点が必要です。」 <br> 「構造物の独立した部分（節点 …）は拘束自由度が 3 つ未満のため、自由に動くことができます。」 | モデルがいくつかの部分に分かれていて、その 1 つが浮いています。ほかの部分に接続するか、支点を設けてください。 |
| 「支点が必要な部分が n か所あります。」 | 浮いている部分が複数あります。**詳細を表示**で一覧を確認できます。 |

### エラー {#errors}

何かが解析を妨げています。赤いメッセージには短いメッセージが、ダイアログには長いメッセージが表示されます。

| メッセージ | 意味と対処 |
| --- | --- |
| 「支点が構造物を固定できていません。まだ水平に移動する / 鉛直に移動する / 自由に回転する / 剛体として動くことができます。」 <br> 「支点の数は足りていますが、構造物を固定できていません。構造物はまだ…ことができます。」 | 拘束の数は足りていますが、すべて平行であるか、作用線が 1 点で交わっています。水平な梁を 3 つのローラー支点で支えた場合がその例です。破線が動きを示しています。いずれかの支点の向きか位置を変えてください。 |
| 「節点 … を含む部分が固定されていません。まだ…ことができます。」 <br> 「構造物の独立した部分（節点 …）は、支点の数は足りていますが固定できていません。この部分はまだ…ことができます。」 | 上と同じ状態が、いくつかに分かれたモデルの 1 つの部分で起きています。 |
| 「節点 … のヒンジにより、構造物が動いてしまいます。」 <br> 「支点は構造物を固定していますが、不安定構造（機構）のままです。節点 … のヒンジまわりで部材が回転できます。」 | ヒンジによって部材どうしが回転できてしまいます。2 つのピン支点で支えたラーメンで両方の柱頭にヒンジがある場合や、斜材のないピン接合の四角形がその例です。ヒンジを 1 つ外すか、部材または支点を追加してください。 |
| 「構造物が不安定です。ほとんど抵抗なく動いてしまいます。」 <br> 「構造物が不安定です：節点 … の水平変位（Dx）… に対する抵抗がほとんどありません。」 | ほぼ不安定構造であるか、剛性が 0 に近い状態です。長いメッセージには該当する節点と方向が示されます。支点、ヒンジ、`E`、`A`、`Iy` の値を確認してください。 |
| 「不安定構造です。抵抗なく動いてしまいます。」 <br> 「不安定構造（機構）です：剛性マトリクスが特異になっています。」 | 上のチェックでは見つからなかった何かが、自由に動けます。各部分が少なくとも 3 つの拘束で固定されているか、材端ヒンジによって自由に回転できる部材がないかを確認してください。 |
| 「要素 … の長さがゼロです。節点 … と … が同じ位置にあります。」 | 1 つの要素の 2 つの節点が重なっています。一方を移動するか、要素を削除してください。 |
| 「要素 … の両端が同じ節点を参照しています。」 | 要素を削除し、異なる 2 つの節点の間に描き直してください。 |
| 「要素 … が存在しない節点 / 材料 / 断面 … を参照しています。」 | 参照先のオブジェクトが削除されています。通常は手で編集したプロジェクトファイルで起こります。*要素*の表で割り当て直してください。 |
| 「要素 … はちょうど 2 つの節点を参照する必要があります。」 | インポートしたファイル内の壊れた要素です。削除して描き直してください。 |
| 「節点荷重 #n が存在しない節点 … を参照しています。」 <br> 「強制変位 #n が存在しない節点 … を参照しています。」 | 荷重を削除するか、存在する節点を指定してください。 |
| 「要素荷重 #n が存在しない要素 … を参照しています。」 | 荷重を削除してください。 |
| 「モデル内部の不整合により、ソルバーが失敗しました。」 | 一般的なエラーです。直前の操作を元に戻すか、プロジェクトを保存して[報告](#reporting-a-bug)してください。 |

### 警告 {#warnings}

モデルは解析されていますが、次の点を確認してください。

| メッセージ | 意味と対処 |
| --- | --- |
| 「節点 … はどの要素にも接続されていないため、ソルバーでは無視されます。」 | 余分な節点です。削除するか、接続してください。 |
| 「節点 … には支点がありますが、接続している要素がないため、この支点は何も負担しません。」 | 余分な節点に支点が設けられています。 |
| 「節点荷重 #n に無効な値が含まれています。」 <br> 「強制変位 #n に無効な値が含まれています。」 | 数値でない成分があります。荷重を編集してください。 |

### 編集中 {#while-editing}

次のメッセージは作業中にブラウザのダイアログで表示され、モデルは変更されません。

| メッセージ | 意味と対処 |
| --- | --- |
| 「先に材料を追加してください。」 <br> 「先に断面を追加してください。」 | 要素には材料と断面の両方が必要です。*材料*タブまたは*断面*タブで追加してから、要素を描き直してください。 |
| 「材料と断面を選択してください。」 | **要素を追加**ダイアログに空欄があります。両方を選んでください。 |
| 「ラベル … は既に使われています。」 | 節点、要素、材料、断面では、同じラベルを 2 つに付けることはできません。別のラベルを選んでください。 |
| 「この節点には既に強制変位が設定されています。先に削除してください。」 | 1 つの節点に設定できる強制変位は 1 つだけです。今の強制変位を編集するか、先に削除してください。 |

## 結果が描かれない {#no-results-are-drawn}

図が表示されないときは、次の順に確認してください。

::div{.steps}

### 表示オプションを確認する {#check-the-display-options}

メッセージがまったくなければ、モデルは解析されています。図の表示がオフになっているだけかもしれません。ビューア右上の表示オプションで、**M<sub>y</sub>(x)** などの結果にチェックを入れてください。表示オプションが見えない場合は、その上の ⚙ ボタンでパネルを表示します。荷重がまったくないモデルでは、結果はどこでも 0 なので、描くものがありません。

### 支点を確認する {#check-the-supports}

ソルバーには少なくとも 3 つの拘束された方向が必要で、さらに支点全体で構造物の移動と回転を止めなければなりません。2 つのローラー支点に載った梁は拘束が 2 つしかなく、滑って動いてしまいます。一方を**ピン**にしてください。平行な 3 つのローラー支点や、作用線が 1 点で交わる支点でも、構造物は固定されません。[節点と支点](/ja/essentials/nodes-supports#supports)をご覧ください。

### 要素が接続されているか確認する {#check-the-connections}

同じ座標にある 2 つの節点は、別々の 2 つの節点のままです。そこでだけほかの部分と接している部分は、浮いた状態になります。余分な節点を削除して、接続し直してください。要素の上に節点を配置するときは、**構造物に接続**を選ぶと、そこで要素が分割されます。

### ヒンジの数を数える {#count-the-hinges}

2 つのピン支点で支えたラーメンで両方の柱頭にヒンジがある場合や、斜材のないピン接合の四角形は、不安定構造です。EduBeam はそのヒンジを丸で囲み、動きを破線のアニメーションで示します。[材端ヒンジ](/ja/essentials/elements#end-hinges)をご覧ください。

### 剛性が 0 になっていないか確認する {#look-for-zero-stiffness}

`E`、`A`、`Iy` を 0 と入力したり、間違った単位で入力したりすると、構造物の一部がほとんど抵抗なく動きます。EduBeam はこれを「不安定」と報告します。

::

## 結果がおかしく見える {#results-look-wrong}

| 症状 | 考えられる原因 |
| --- | --- |
| 荷重が上向きに作用する | グローバル座標系の **z 軸は下向き**なので、正の `Fz` や `fz` は下向きに作用し、負の値は上を向きます。y 上向きの座標軸では逆になります。[荷重](/ja/essentials/loads#sign-convention-in-one-line)をご覧ください。 |
| たわみの桁が違う | 単位の取り違えです。入力欄が MPa を想定しているのに `E` を Pa で入力した、m⁴ を想定しているのに `Iy` を cm⁴ で入力した、などです。ビューア右下の単位チップに、各入力欄で使われる単位が表示されています。 |
| たわみが教科書の公式よりわずかに大きい | ティモシェンコ梁のせん断変形によるものです。[手計算による結果の確認](/ja/guide/verification#shear-deformation)をご覧ください。 |
| 符号が間違って見える | 符号は、図が描かれている側ではなく値から読んでください。正の M は下側引張です。*要素結果*の材端力は要素のローカル座標系に従い、N・V・M の符号規約には従いません。[符号の読み方](/ja/essentials/results#reading-the-sign)をご覧ください。 |
| 図が「逆」の側に描かれている | どちらの側に描くかは表示の設定です。曲げモーメントは引張側か圧縮側、N と V は破線のどちら側かを選べます。**設定 → 表示設定 → 断面力図**で変更します。 |
| 同じ 2 本の柱でせん断力の符号が逆になる | V の符号は各要素の向きに従います。比べるときは、一方の要素の節点を入れ替えてください。 |
| `4 · 10¹` のような数値 | 指数表記の表示形式になっています。**設定 → 言語と地域 → 数値の表示形式**で*自動*を選んでください。 |
| 図が大きすぎる、または小さすぎる | 描画だけの問題です。**設定 → 表示設定**の**結果の表示倍率**を調整してください。 |
| ローカル座標系の荷重が逆を向く | 要素のローカル x 軸は*始端*節点から*終端*節点へ向かいます。節点を入れ替えるか、符号を逆にしてください。 |
| 傾斜部材の荷重がおかしい | **LCS** は初期状態でチェックが入っているので、`fz` は部材に垂直に作用します。鉛直荷重にするにはチェックを外してください。 |
| 温度荷重をかけても何も起きない | 静定構造は温度によって自由に変形し、断面力は生じません。変形が出ない場合は、α が 0 でないか、温度勾配なら断面の高さ $h$ が設定されているかを確認してください。 |

## ファイルとリンク {#files-and-links}

| 症状 | 対処 |
| --- | --- |
| 「ファイルをインポートできませんでした。ファイル形式を確認してください。」 | ファイルが EduBeam のプロジェクトでも、デスクトップ版 EduBeam のセッションでもありません。開いていたモデルは変更されていません。 |
| 「この EduBeam セッションには複数の荷重ケースがありますが、開けるのは 1 つだけです。」 | 複数の荷重ケースを含むデスクトップ版 EduBeam のセッションです。EduBeam は最初のケースを開き、開かなかったケースを示します。 |
| 共有リンクを開いたのに前のモデルが表示される | リンクが途中で切れたか、変更されています。たとえばメールソフトがリンクを折り返した場合です。EduBeam は読めないリンクを無視し、開いていたモデルを残します。リンク全体をもう一度コピーしてください。 |
| 短いリンクが同僚の環境で開かない | 同僚の EduBeam がバージョン 1.3.2 より古いためです。アプリを再読み込みしてもらうか、**短いリンク**をオフにして共有してください。[リンクで共有する](/ja/essentials/import-export#share-a-link)をご覧ください。 |

## インターフェースの問題 {#interface-issues}

| 症状 | 対処 |
| --- | --- |
| ショートカットが効かない | 先に図をクリックしてください。入力欄にフォーカスがある間、1 文字のキーは無視されます。Mac では <kbd>Ctrl</kbd> の代わりに <kbd>Cmd</kbd> を使ってください。[キーボード・マウス・タッチ](/ja/reference/shortcuts)をご覧ください。 |
| Mac で <kbd>Delete</kbd> が効かない | Mac のキーボードで *delete* と書かれたキーは Backspace です。<kbd>Fn</kbd>+<kbd>Delete</kbd> を押してください。 |
| パンできない | パンにはマウスの中ボタンか右ボタンを使います。どちらを使うかは**設定 → 操作とショートカット**で選べます。トラックパッドでは 2 本指でクリックしてドラッグし、タッチスクリーンでは 1 本指でドラッグします。 |
| モデルが消えた | リンク、ファイル、例題を開いたときや、モデルをクリアしたときも、前のモデルは残っています。**☰ → 最近のモデル**を開くか、<kbd>Ctrl</kbd>+<kbd>Z</kbd> を押してください。リンクを開いたときは、画面下部に*共有されたモデルを開きました。以前のモデルは「最近のモデル」に保存されています。* というメッセージが**表示**ボタンとともに表示されます。 |
| 言語が違う | **設定 → 言語と地域**で変更するか、アドレスに `?lang=ja` を付けてください。 |
| 設定の変更が保存されない | ローカルストレージがブロックされています。たとえばプライベートウィンドウや、厳しいプライバシー設定の場合です。設定、保存されたモデル、最近のモデルは、どれもローカルストレージを必要とします。 |

## 不具合の報告 {#reporting-a-bug}

[GitHub の issue](https://github.com/janvorisek/edubeam/issues) を作成し、ブラウザと OS、行った操作、期待した結果を書いてください。何より役に立つのは、問題を再現できる**共有リンク**か**プロジェクトファイル**です。
