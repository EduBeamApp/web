# ユーザーインターフェース

[EduBeam]{.edubeam} の画面は 3 つの領域からなります。上部の**アプリバー**、中央でモデルを描く**ビューア**、そしてオブジェクトの種類ごとに表が並ぶ**下部バー**です。ビューアでできることはすべて表でもでき、その逆も同じです。

![インターフェースの各部。番号は下のリストに対応しています](/screenshots/ja/ui-overview.webp)

1. **☰ メニュー**：開く、保存、共有、エクスポート。例題とガイド付きツアー。
2. **モデルをクリア**と**モデルを共有**。
3. **元に戻す**と**やり直し**。
4. **ビューアのボタン**：中央に表示、画面に合わせる、表示オプション。
5. **表示オプション**：どの結果とモデルのどの部分を描くか。
6. **グリッド、スナップ、クロスヘア、単位。**
7. **下部バーのタブ**：節点、要素、荷重、材料、断面、結果。
8. 開いているタブの**表**：すべての値をここで編集できます。

::callout{type="tip" title="ツアーを見てみましょう"}
**☰ → ツアーを見る**を選ぶと、アプリの中でこれらの部分を 1 つずつ案内します。
::

## アプリバー {#app-bar}

- **☰** はメインメニューを開きます（下記）。
- **モデルをクリア**は、確認のあと、すべての節点、要素、荷重を削除します。**材料を削除**や**断面を削除**にチェックを入れると、それらも削除します。<kbd>Ctrl</kbd>+<kbd>Z</kbd> でモデルを元に戻せるほか、*最近のモデル*にも残ります。
- **モデルを共有**は、モデル全体を収めたリンクを表示する[共有ダイアログ](/ja/essentials/import-export#share-a-link)を開きます。
- **更新情報**はリリースノートを表示します。アップデートの後には、一度だけ自動でも開きます。
- **ドキュメント**はこのガイドを、GitHub のアイコンはソースコードを開きます。

スマートフォンでは ☰ と**ドキュメント**しか収まらないため、**モデルをクリア**と**モデルを共有**はメニューの中にあります。

### ☰ メニュー {#the-☰-menu}

![☰ メニュー](/screenshots/ja/ui-app-menu.webp){.shot-xs}

- **プロジェクトを開く**と**プロジェクトを保存**は、`project.json` ファイルを開くか、ダウンロードします（<kbd>Ctrl</kbd>+<kbd>O</kbd>、<kbd>Ctrl</kbd>+<kbd>S</kbd>）。
- **最近のモデル**には、クリアまたは置き換えた直近 10 件のモデルが残り、すぐに復元できます。
- **画像をエクスポート**は、図を PNG や SVG で保存するか、コピーします（<kbd>Ctrl</kbd>+<kbd>P</kbd>）。
- **例題**は用意されたモデルのギャラリー、**はじめての梁を描く**は 7 ステップのガイド付きの課題、**ツアーを見る**はインターフェースのツアーです。
- **モデルを共有**と**モデルをクリア**は、アプリバーのボタンと同じです。

メニューの下部には、アプリのバージョンとリリース日が表示されます。開く、保存、共有、エクスポートについては[ファイル・リンク・エクスポート](/ja/essentials/import-export)で説明します。

## ビューア {#viewer}

キャンバスは、モデルを描いて確かめる場所です。モデルを変更するたびに結果を再計算するので、*解析*ボタンはありません。

### キャンバス上のボタン {#buttons-on-the-canvas}

**左上：元に戻すとやり直し。** 追加、編集、ドラッグ、削除、クリアなど、モデルへのすべての変更を 1 つずつ戻したり進めたりします（<kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>）。

**右上：**

- **矩形選択**は、タッチスクリーンのある端末で使います。次に指でドラッグした範囲を矩形で選択します。
- **中央に表示**はズームを変えずにモデルを中央に移し（<kbd>C</kbd>）、**画面に合わせる**はモデル全体が収まるようにズームします（<kbd>F</kbd>）。
- **⚙** は[表示オプション](#display-options)の表示・非表示を切り替えます。

**右下：**

![グリッド、スナップ、クロスヘア、単位のボタン](/screenshots/ja/ui-grid-units.webp){.shot-sm}

- **G** はグリッドと定規の表示を（<kbd>G</kbd>）、**S** はグリッドへのスナップのオン・オフを切り替えます（<kbd>S</kbd>）。
- **クロスヘア**のボタンは、ポインターの位置を定規の上に示します。マウスでのみ使えます。
- **単位チップ**は、設定の[言語と地域](/ja/essentials/units-settings#language-locale)を開きます。

### 表示オプション {#display-options}

⚙ ボタンを押すと、チェックボックスが 2 段に並びます。1 段目では、モデルの上に描く結果を選びます：*変位図*、*N (x)*、*V<sub>z</sub> (x)*、*M<sub>y</sub> (x)*、*反力*。最初は変位図、曲げモーメント、反力にチェックが入っています。2 段目では、モデルの各部の表示・非表示を切り替えます：*支点*、*荷重*、*節点ラベル*、*要素ラベル*。最初はすべて表示されています。

![ビューアのボタンと表示オプション](/screenshots/ja/ui-display-settings.webp){.shot-lg}

**その他の設定**は[表示設定](/ja/essentials/units-settings#viewer-settings)を開きます。大きさ、色、断面力図の描き方はここで変えられます。それぞれの結果が何を表すかは[結果と断面力図](/ja/essentials/results#overlays-in-the-viewer)で説明します。

### 画面操作 {#navigating}

| 操作 | マウスとキーボード | タッチ |
| --- | --- | --- |
| ズーム | マウスホイール（ポインターに向かって）。トラックパッドではピンチまたは 2 本指でスクロール | ピンチ |
| パン | 右ボタンまたはホイールを押したままドラッグ。どちらを使うかは[操作とショートカット](/ja/essentials/units-settings#controls-shortcuts)で選びます | 1 本指でドラッグ |
| 画面に合わせる、中央に表示 | <kbd>F</kbd>、<kbd>C</kbd>、または右上のボタン | 右上のボタン |

<kbd>Ctrl</kbd>+<kbd>+</kbd> と <kbd>Ctrl</kbd>+<kbd>-</kbd> は、どのキーボード配列でも、図をその中心を基準にズームします。ブラウザ自体のズームとは違い、画面全体を拡大・縮小することはありません。

### 選択と編集 {#selecting-and-editing}

| 目的 | 操作 |
| --- | --- |
| 1 つを選択する | 節点、要素、荷重、寸法線をクリックします。その横にパネルが開き、荷重の追加、支点の設定、編集、剛性マトリクスの表示、削除などの操作が並びます。下部バーもそのタブに切り替わります。 |
| 複数を選択する | キャンバスの何もない所で矩形をドラッグします（タッチ操作では先に**矩形選択**を押します）。矩形の中にあるすべての節点と、矩形にかかるすべての要素が、その荷重と寸法線と一緒に選択されます。<kbd>Ctrl</kbd>+<kbd>A</kbd> ですべてを選択します。 |
| 削除、コピー、貼り付け | <kbd>Delete</kbd>、<kbd>Ctrl</kbd>+<kbd>C</kbd>、<kbd>Ctrl</kbd>+<kbd>V</kbd>。貼り付けたものはクリックするまでポインターについてきます。バナーにずらす量 Δx、Δz を入力して置くこともできます。 |
| 節点を移動する | ドラッグします。スナップがオンならグリッド上に置かれ、接続された要素と荷重も一緒に動きます。 |
| 荷重を編集する | ダブルクリックします。 |
| 詳細を見る | ポインターを重ねるとツールチップが出ます。節点は変位と回転角、要素は材料と断面、荷重はその値です。タッチ操作ではタップすると、パネルに同じ内容が表示されます。 |
| キャンバスのメニューを開く | キャンバスを右クリックします（タッチスクリーンでは長押し）。 |

::div{.shots}

![節点のパネル：荷重の追加、支点の設定、強制変位の設定](/screenshots/ja/ui-node-menu.webp)

![節点にポインターを重ねると、変位と回転角が表示されます](/screenshots/ja/ui-hover.webp)

::

**キャンバスのメニュー**には、*節点を追加*、*要素を追加*、*寸法線を追加*（要素の上では*要素に寸法線を追加*も）があり、その下に現在の選択に対する*編集*、*コピー*、*貼り付け*、*削除*が並びます。*節点を追加*や*要素を追加*を選ぶときに <kbd>Ctrl</kbd> を押したままにすると、ダイアログではなくマウスで配置できます。

![キャンバスのメニュー](/screenshots/ja/ui-canvas-menu.webp){.shot-sm}

ショートカットと操作の一覧は[キーボード・マウス・タッチ](/ja/reference/shortcuts)のページにあります。

### モデルを解析できないとき {#when-the-model-cannot-be-solved}

ビューアの左上にメッセージが表示されます。

| メッセージ | 意味 |
| --- | --- |
| 「材料が定義されていません。」、「断面が定義されていません。」 | 横にある**新規追加**ボタンで追加します。 |
| 青い**支点が必要**チップ | モデルがまだ完成していないだけで、支点が足りません。 |
| **詳細を表示**の付いた赤いメッセージ | どこかに誤りがあります。詳細には問題がすべて、それぞれヒント付きで一覧表示されます。 |
| 黄色のメッセージ | 解析はできましたが、どの要素にもつながっていない節点など、気になる点があります。 |

構造物がまだ動ける場合、EduBeam はその動きを破線の輪郭で揺らして見せ、原因となる節点やヒンジを丸で囲みます。メッセージにポインターを重ねると動きをもう一度表示でき、目のボタンで非表示にできます。

![B と C にヒンジがあるラーメンは不安定構造：EduBeam がその動き方を示します](/screenshots/ja/ui-mechanism.webp)

各メッセージの意味と直し方は[トラブルシューティング](/ja/reference/troubleshooting#messages)で説明しています。

## 下部バー {#bottom-bar}

6 つのタブがあり、それぞれにツールバーと編集できる表があります。タブのラベルには、そのタブに含まれるオブジェクトの数が表示されます。タブの並びを上下にドラッグすると下部バーの高さを変えられ、右端のボタンで折りたたむこともできます。その横の **?** は開いているタブを説明し、一部の列見出しの横にある **?** もその列を説明します。

| タブ | ツールバー | 表の列 |
| --- | --- | --- |
| **節点** | 節点を追加（ダイアログ）、節点を追加（マウス） | 節点、座標、**拘束自由度**（支点記号、`Dx`、`Dz`、`Ry`、角度 α）、荷重、操作 |
| **要素** | 要素を追加（ダイアログ）、要素を追加（マウス） | 要素、種類、節点（**節点を入れ替え**付き）、材料、断面、**材端ヒンジ**、荷重、操作 |
| **荷重** | 節点荷重を追加、要素荷重を追加 | 種類、対象、成分、操作 |
| **材料** | 材料を追加、材料ライブラリ | 材料、E、G、α<sub>T</sub>、操作 |
| **断面** | 断面を追加、断面ライブラリ、多角形断面 | 形状、断面、断面積、I<sub>y</sub>、高さ、せん断補正係数、操作 |
| **結果** | 節点結果、要素結果、CSV をエクスポート、コピー | 節点ごとの変位、または要素ごとの材端力。[結果と断面力図](/ja/essentials/results#results-tab)を参照 |

各タブの詳しい説明は、[節点と支点](/ja/essentials/nodes-supports)、[要素・材料・断面](/ja/essentials/elements)、[荷重](/ja/essentials/loads)、[結果と断面力図](/ja/essentials/results#results-tab)にあります。

### 値の入力 {#typing-values}

表でもダイアログでも、数値の入力欄はすべて同じように動きます。

- 値は[現在の単位](/ja/essentials/units-settings#units)で入力します。単位は列見出しか入力欄の後ろに表示されます。
- 小数点はピリオドでもカンマでもかまいません。`2.5` と `2,5` は同じ値です。
- 計算式も入力できます。`+ - * / ^` と括弧が使えるので、`6/2`、`3*1.5`、`2^3`、`(4+2)/3` はその場で計算され、`1e-5` は $10^{-5}$ になります。
- 表では、<kbd>Enter</kbd>、<kbd>Esc</kbd>、<kbd>Tab</kbd> を押すか、ほかの場所をクリックすると値が確定します。そのあと <kbd>Ctrl</kbd>+<kbd>Z</kbd> を押すと値が元に戻ります。入力の途中では、入力した文字のほうを元に戻します。

## ビューアの上のタブ {#tabs-above-the-viewer}

**ビューア**はキャンバスを表示します。**設定**はその場所に[設定](/ja/essentials/units-settings)を大きく表示するので、色や単位を変えてからビューアに戻り、効果を確かめられます。単位チップと*その他の設定*は、同じ設定をモデルの上にダイアログとして開きます。

## フローティングウィンドウ {#floating-windows}

**剛性マトリクス**（要素のパネルか*要素*の表から開きます）は、グローバル座標系での要素の 6 × 6 剛性マトリクスをウィンドウに表示します。キャンバスのメニューの**編集**は、現在の選択内容の表を開きます。ウィンドウはタイトルバーをドラッグして移動し、× で閉じます。
