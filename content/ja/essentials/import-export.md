# ファイル・リンク・エクスポート

モデルはファイルとして保存したり、リンクとして送ったり、Web ページに埋め込んだり、画像や表としてエクスポートしたりできます。[EduBeam]{.edubeam} の処理はすべてブラウザの中で行われ、何もアップロードされません。共有リンクには、文字どおりモデルそのものが含まれています。

::card-grid{cols="3"}
:::card{title="プロジェクトファイル" icon="lucide:file-json" to="#save-a-project"}
`project.json` を保存しておけば、提出したり、あとで開いたりできます。
:::
:::card{title="共有リンク" icon="lucide:link" to="#share-a-link"}
モデル全体を 1 つの URL に収め、講義資料、スライド、メッセージで使えます。
:::
:::card{title="画像または表" icon="lucide:image" to="#export-an-image"}
レポートには PNG や SVG、表計算ソフトには CSV。
:::
::

## プロジェクトの保存 {#save-a-project}

**☰ → プロジェクトを保存**または <kbd>Ctrl</kbd>+<kbd>S</kbd>（Mac では <kbd>⌘</kbd>+<kbd>S</kbd>。このページのショートカットはすべて同様です）で `project.json` がダウンロードされます。このファイルには、節点、要素、材料、断面（描いた形状を含む）、荷重、寸法線と、ファイルを書き出したアプリのバージョンが含まれます。ファイル名は自由に変えてかまいません。

## プロジェクトを開く {#open-a-project}

**☰ → プロジェクトを開く**または <kbd>Ctrl</kbd>+<kbd>O</kbd> を押してファイルを選ぶか、**ファイルをアプリのウィンドウのどこかにドロップ**します。EduBeam が開けるのは次のファイルです。

- EduBeam のすべてのバージョンで保存した `project.json` ファイル。
- **デスクトップ版 EduBeam** 2.x〜3.5 で保存した `.xml` セッション。値に単位が付いていないので、当時のマニュアルが使っていた単位（kN、kPa、m）で読み込みます。EduBeam が開ける荷重ケースは一度に 1 つです。複数の荷重ケースを含むセッションでは最初のケースを開き、読み込まなかったケースの名前を表示します。

ファイルを開くと、材料と断面も含めて現在のモデルが置き換えられます。それまでのモデルは失われません。<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せ、[最近のモデル](#recent-structures)にも残ります。EduBeam が読み込めないファイルの場合はメッセージが表示され、モデルはそのまま残ります。

## リンクで共有する {#share-a-link}

アプリバーか ☰ メニューの**モデルを共有**を押すと、*URL でモデルを共有*ダイアログが開きます。

![URL でモデルを共有ダイアログ](/screenshots/ja/c1-share.webp){.shot-lg}

- **コピー**を押すか、リンク欄のどこかをクリックすると、リンクがコピーされます。
- **リンクを開く**は新しいタブでリンクを開くので、受け取った人に何が見えるかを確かめられます。
- **システムの共有ダイアログで共有**は、ブラウザが対応していれば、端末の共有シートにリンクを渡します。
- **短いリンク**（初期状態でオン）は、同じモデルを約半分の文字数で書き表します。バージョン 1.3.2（2026 年 11 月）より古い EduBeam では、更新するまでこのリンクを読めません。どこでもすぐに開ける必要があるリンクでは、オフにしてください。
- **自分の表示を共有**（初期状態でオフ）をオンにすると、リンクは受け取った人の表示オプションではなく、自分がオンにしている断面力図、荷重、ラベルで開きます。

リンクは `https://run.edubeam.app/?model=…` の形式で、モデル全体がエンコードされています。リンクを開いた人は、それぞれ自分用のコピーを編集できます。編集内容は元に同期**されない**ので、モデルを変更したら新しいリンクを送ってください。非常に大きなモデルではリンクも非常に長くなるので、プロジェクトファイルを共有してください。

誰かがリンクを開くと、その人の以前のモデルは最近のモデルに移り、どこにあるかがメッセージで知らされます。リンクに有効期限はありません。昨年の講義資料に載せたリンクでも、今日開けば同じモデルが表示されます。

## ビューアの埋め込み {#embed-a-read-only-viewer}

共有リンクに `&viewer=1` を付けると、モデルが**ビューアモード**で開きます。アプリバー、下部バー、元に戻す・やり直し、グリッドと単位のチップ、クロスヘアが非表示になり、図、画面に合わせる・中央に表示のボタン、表示オプションだけが残ります。ようこそダイアログとリリースノートも開きません。この URL を `<iframe>` に入れれば、その場でズームや操作ができるモデルを、講義資料、授業のページ、スライドに埋め込めます。

```html
<iframe
  src="https://run.edubeam.app/?viewer=1&show=MRLS&model=…"
  width="100%"
  height="400"
></iframe>
```

![ビューアモードの 3 ヒンジラーメン](/screenshots/ja/viewer-mode.webp){.shot-lg}

ビューアモードは見るためのものですが、ロックされてはいません。閲覧者は節点をドラッグしたり、断面力図を切り替えたりできます。ビューアのリンクを単独で開くと、ほかのリンクと同じように閲覧者自身のモデルが置き換えられ、そのモデルは最近のモデルに残ります。別のサイトのページに埋め込んだ場合、最近のブラウザの多くはフレームに専用の保存領域を与えるので、閲覧者のモデルはそのまま残りますが、すべてのブラウザがそうするわけではありません。

ページ内の静止した図、スライド、演習プリントなど、アプリそのものが要らない図には、描画ライブラリ [@edubeam/plot](/ja/plot) を使えば、構造物とその断面力図をコードから描けます。このサイトの操作できる図も、このライブラリで描いています。

## URL パラメーター {#url-parameters}

| パラメーター | 効果 |
| --- | --- |
| `model=<data>` | エンコードされたモデルを読み込み、画面に合わせて表示します。**モデルを共有**が書き込みます。 |
| `viewer=1` | [ビューアモード](#embed-a-read-only-viewer)。 |
| `show=<letters>` | ここに挙げた表示だけをオンにして開きます。1 文字が 1 つの表示です：`N` 軸力、`V` せん断力、`M` 曲げモーメント、`U` 変位図、`R` 反力、`L` 荷重、`S` 支点、`n` 節点ラベル、`e` 要素ラベル。`show=MRLS` なら曲げモーメント、反力、荷重、支点を表示します。**自分の表示を共有**が書き込みます。 |
| `lang=<code>` | インターフェースの言語を切り替えます：`en`、`cs`、`de`、`fr`、`es`、`pt`、`pl`、`cn`（中国語）、`th`、`uk`、`ru`、`tr`、`hi`、`vi`、`it`、`id`、`ja`、`ko`。 |
| `panel=examples` | 例題ギャラリーをすぐに開きます。 |

パラメーターは `?lang=de&viewer=1&model=…` のように `&` でつなぎます。EduBeam はパラメーターを読み取ったあと、アドレスバーから削除します。`lang` と `show` は、閲覧者がアプリで自分で選んだのと同じように、その人の設定として残ります。

## 画像のエクスポート {#export-an-image}

**☰ → 画像をエクスポート**または <kbd>Ctrl</kbd>+<kbd>P</kbd> で、画像のエクスポート画面が開きます。図は選んだサイズに合わせて描き直されるので、線とラベルは本来の太さのままです。

![画像をエクスポート：レイヤー、範囲、サイズを選び、ダウンロードまたはコピーします](/screenshots/ja/export-image.webp)

::div{.steps}

### レイヤーを選ぶ {#choose-the-layers}

上部のチップで、描く内容を選びます：変位図、N、V、M、反力、続いて支点、荷重、節点ラベル、要素ラベル。最初はビューアの表示オプションと同じで、ここで変えてもビューアはそのままです。

### 範囲を決める {#frame-the-drawing}

縦横比（16:9、4:3、3:2、1:1）、**全体を収める**、または図の上で矩形をドラッグする**範囲指定…** を選びます。プレビューの辺をドラッグすることもできます。

### サイズを設定する {#set-the-size}

ピクセル単位の幅と高さを入力するか、紙の上で縮尺どおりの図にするなら 1 : 50 のような**縮尺**を入力します（96 DPI 換算）。**図の高さ**は結果の断面力図の大きさを決め、**背景を透明にする**は白い背景をなくします。断面力図やラベルが収まらない場合は、ダイアログがそれを知らせ、断面力図を小さくするかキャンバスを大きくするかを提案します。

### 保存する {#save-it}

**PNG をダウンロード**、**SVG をダウンロード**、またはブラウザが対応していれば**クリップボードにコピー**を選びます。ファイル名は `edubeam-512x512.svg` のように、サイズに基づいて付けられます。高解像度の画面では、PNG はアプリと同じ鮮明さになるよう、画面の画素密度に比例して、設定した幅と高さより多くのピクセルを持ちます。そのピクセル数はボタンの横に表示されます。

::

SVG はどのサイズでも鮮明で、Word、Inkscape、Overleaf 上の LaTeX で使えるので、レポートや卒業論文にはいちばん適しています。同じサイズなら構造物は常に同じ位置に収まるので、N、V、M を続けてエクスポートすれば横に並べてそろえられます。

演習プリントの問題ごとに 1 枚ずつなど、こうした図をコードで作るには、@edubeam/plot が同じプログラムで開ける[単独の SVG ファイル](/ja/plot/functions#a-standalone-svg-file)を書き出します。

## 結果のエクスポート {#export-the-results}

**結果**タブの **CSV をエクスポート**は、反力を含む両方の結果表をダウンロードし、**コピー**は表計算ソフト用にクリップボードへコピーします。[CSV のエクスポートとコピー](/ja/essentials/results#export-csv-and-copy)を参照してください。

## 最近のモデル {#recent-structures}

**☰ → 最近のモデル**には、クリアされたモデル、またはリンク、ファイル、例題、**はじめての梁を描く**の課題、別の復元によって置き換えられたモデルが、直近 10 件まで残ります。それぞれにサムネイル、何によって置き換えられたか、節点と要素の数が表示されます。**復元**でモデルを戻せます。その時点のモデルが今度はリストに入り、<kbd>Ctrl</kbd>+<kbd>Z</kbd> で復元を取り消せます。**削除**で項目を消します。

![最近のモデル](/screenshots/ja/recent.webp){.shot-lg}

このリストは、このブラウザの中だけに保存されます。

## 例題 {#examples}

**☰ → 例題**で、授業用に用意されたモデルのギャラリーが開きます。例題を開くとモデルが置き換えられますが、<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元のモデルに戻せます。同じモデルは演習付きで、このガイドの[例題](/ja/examples/)のページにもあります。

![例題ギャラリー](/screenshots/ja/examples.webp){.shot-lg}

## 自動保存 {#automatic-persistence}

モデルと設定は、変更のたびにブラウザのローカルストレージに保存され、ブラウザを閉じたあとでも、戻ってきたときに復元されます。これは便利機能であってバックアップではありません。1 台の端末の 1 つのブラウザプロファイルに属し、プライベートウィンドウでは残らず、サイトのデータを消去すると削除されます。大事な作業はプロジェクトファイルとして保存してください。保存される内容の一覧は[ブラウザに保存される内容](/ja/essentials/units-settings#what-is-stored-in-your-browser)にあります。

## プロジェクトファイルの形式 {#project-file-format}

`project.json` は、人が読めるプレーンな JSON です。次の例は[クイックスタート](/ja/guide/quick-start)の梁で、ライブラリの鋼材と IPE 200 を使っています。

```json [project.json]
{
  "edubeam": true,
  "version": "1.3.4",
  "domain": {
    "materials": [
      {
        "label": "Steel (S235)",
        "d": 7850,
        "e": 210000000000,
        "g": 81000000000,
        "alpha": 0.000012
      }
    ],
    "crossSections": [
      {
        "label": "IPE 200 (approx)",
        "a": 0.002848,
        "iy": 0.00001943,
        "h": 0.2,
        "k": 0.3932584269662922
      }
    ],
    "nodes": [
      { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] },
      { "label": "2", "coords": [6, 0, 0], "bcs": [2] }
    ],
    "elements": [
      {
        "label": "1",
        "nodes": ["1", "2"],
        "mat": "Steel (S235)",
        "cs": "IPE 200 (approx)",
        "hinges": [false, false]
      }
    ],
    "loadCases": [
      {
        "label": "DefaultLC",
        "nodalLoads": [],
        "elementLoads": [
          { "type": "udl", "target": "1", "lcs": true, "values": [0, 12000] }
        ],
        "prescribedBC": []
      }
    ]
  },
  "dimensions": []
}
```

アプリの表示単位にかかわらず、値はすべて **SI 単位**（m、N、Pa、rad）です。座標は `[x, y, z]` で、$y = 0$、$z$ は下向きです。支点と荷重の成分には、自由度の ID `0 = Dx`、`2 = Dz`、`4 = Ry` を使います。

| 要素荷重の `type` | 値 |
| --- | --- |
| `udl` | `values: [fx, fz]`、単位は N/m |
| `trapezoidal` | `startValues: [f1x, f1z]`、`endValues: [f2x, f2z]`、単位は N/m |
| `concentrated` | `values: [Fx, Fz, My, a]`、単位は N、N·m、および始端節点からの距離 m |
| `temperature` | `values: [ΔTc, ΔTb, ΔTt]`、単位は K。温度勾配は ΔTb − ΔTt |

`lcs: true`、または `lcs` がない場合は、要素荷重は要素のローカル座標軸で与えられ、`false` ならグローバル座標軸で与えられます。そのほかの項目は次のとおりです。

- **節点荷重**：`{ "target": "2", "values": { "0": Fx, "2": Fz, "4": My } }`。回転した支点の座標軸で与える荷重には `"lcs": true` を加えます。
- **強制変位**：`{ "target": "2", "prescribedValues": { "0": Dx, "2": Dz, "4": Ry } }`。省略した成分は 0 になります。
- アプリが書き出したファイルには、`date`、`commit`、回転した支点の座標軸（節点の `lcs`）、描いた断面の `shape` も含まれます。

形式が単純なので、スクリプトや表計算ソフトでモデルを作り、**プロジェクトを開く**で開けます。モデルの作成から解析までをすべてコードで行うには、アプリの背後にあるソルバーライブラリ [@edubeam/fem](/ja/solver) を使ってください。
