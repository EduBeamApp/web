# 節点と支点

節点はモデルの点です。要素は節点どうしを結び、支点と節点荷重は節点に設定します。節点は座標を入力するかクリックして配置し、支えられている節点には、図に合った支点を与えます。

## 座標 {#coordinates}

各節点の位置は、**X** 座標と **Z** 座標で表します。単位は現在の[長さの単位](/ja/essentials/units-settings#units)です。x 軸は右向き、**z 軸は下向き**です。そのため、地面より上にある点の Z は負になります。高さ 4 m の柱は `Z = 0` から `Z = −4` まで伸びます。

鉛直軸を上向きにしたい場合は、設定で [y 上向きの座標軸](/ja/elements/conventions#y-up-axes)に切り替えてください。変わるのは表示だけで、モデルとそのファイルはそのままです。

## 節点の追加 {#adding-nodes}

- **入力して追加。** *節点*タブ → **節点を追加**（**+** アイコンのボタン）、またはキャンバスを右クリック → *節点を追加*。X と Z を入力し、必要に応じて支点とその角度も設定します。
- **クリックして追加。** *節点*タブ → **節点を追加**（カーソルアイコンのボタン）、またはキャンバスのメニューで <kbd>Ctrl</kbd> を押しながら*節点を追加*を選びます。クリックするたびに節点が 1 つ置かれます。終えるには <kbd>Esc</kbd>、**キャンセル**、または同じボタンをもう一度押します。
- **要素を描きながら追加。** [マウスで要素を描く](/ja/essentials/elements#adding-elements)ときに、キャンバスの何もない所をクリックすると、そこに節点ができます。
- **コピーして追加。** 節点（と要素）を選択して <kbd>Ctrl</kbd>+<kbd>C</kbd>、<kbd>Ctrl</kbd>+<kbd>V</kbd> を押し、コピー先をクリックします。またはバナーにずらす量 Δx、Δz を入力して**貼り付け**を押します。

::div{.shots}

![節点を追加ダイアログ](/screenshots/ja/qs-node.webp)

![マウスモードでは、上部のバナーで、配置するすべての節点の支点と角度を設定できます](/screenshots/ja/nodes-add-banner.webp)

::

新しい節点には、空いている次の番号 `1`、`2`、`3`、… が付きます。表の*節点*列で、`A`、`B`、`C` のように自由に名前を変えられます。

### スナップ {#snapping}

**グリッドにスナップ**がオンのとき（<kbd>S</kbd> を押すか、ビューア右下の **S** チップを押します）、配置したりドラッグしたりした節点はグリッド上に置かれます。間隔の初期値は 0.1 m、米国単位では 0.5 ft で、[設定 → 表示設定 → グリッド](/ja/essentials/units-settings#viewer-settings)で変更できます。それ以外の位置に置きたいときは、表に正確な座標を入力してください。

### 既存の要素の上に節点を置く {#placing-a-node-on-an-existing-element}

マウスで節点を追加しているときに要素の上（またはそのすぐ近く）をクリックすると、EduBeam がどうしたいかを尋ねます。

- **構造物に接続**は、要素を新しい節点で 2 つの要素 `1a` と `1b` に分割します。中間支点や荷重点を追加するいちばん速い方法です。外側の端のヒンジはそのまま残ります。等分布荷重と台形分布荷重は 2 つの要素に分けられます。集中荷重と温度荷重はすべて 1 つ目の `1a` に移ります。新しい節点より先にあった集中荷重は、*荷重*の表で `1b` に移してください（位置は新しい節点から測った値になります）。温度荷重は `1b` にも別に与えてください。
- **独立した節点を配置**は、要素に接続せずに、その上に節点を置きます。

どちらを選んでも、節点の配置はそこで終わります。続けて置くには、カーソルのボタンをもう一度押してください。

## 節点の編集 {#editing-nodes}

| 目的 | 操作 |
| --- | --- |
| 節点を移動する | ビューアでドラッグする（タッチスクリーンでは押したままドラッグ）か、*節点*の表に X と Z を入力します。接続された要素、その荷重、寸法線も一緒に動きます。 |
| 名前を変える | *節点*列に新しいラベルを入力します。 |
| 支点を変える | 節点をクリック → **支点条件**、または*拘束自由度*列を使います。[支点](#supports)を参照してください。 |
| まとめて編集する | *操作*列の鉛筆アイコンで**節点を編集**が開きます。座標、支点、支点の角度を設定でき、支点記号のプレビューも表示されます。 |
| 削除する | 表の ×、節点のパネルの**削除**、または選択して <kbd>Delete</kbd>。その節点に接続された要素、荷重、寸法線も削除されます。 |

どの変更も <kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せます。

## 支点 {#supports}

各節点は 3 通りに動けます。これが節点の**自由度**（DOF）で、x 方向の `Dx`、z 方向の `Dz`、図の面内の回転 `Ry` です。支点はこのうちいくつかを**拘束**します。

8 種類の支点は、この 3 つの自由度の 8 通りの組み合わせです。表は行ごとに横に読みます。中央の列は自由に回転でき、右の列は回転も拘束されます。

| 拘束する並進 | 自由に回転 | 回転も拘束 |
| --- | --- | --- |
| **両方**（`Dx` と `Dz`） | ![](/screenshots/ja/b-support-pin.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **ピン** | ![](/screenshots/ja/b-support-fixed.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **固定** |
| **鉛直のみ**（`Dz`）：水平に移動 | ![](/screenshots/ja/b-support-roller.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **ローラー** | ![](/screenshots/ja/b-support-slider.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **ローラー（回転拘束）** |
| **水平のみ**（`Dx`）：鉛直に移動 | ![](/screenshots/ja/b-support-vertical-roller.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **鉛直ローラー** | ![](/screenshots/ja/b-support-vertical-slider.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **鉛直ローラー（回転拘束）** |
| **なし**：水平にも鉛直にも移動 | ![](/screenshots/ja/b-support-free.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **自由**（支点なし） | ![](/screenshots/ja/b-support-rotation-only.webp){width="34" style="display:inline;border:0;border-radius:0;margin:0 0.35em 0 0;vertical-align:middle"} **回転のみ拘束** |

EduBeam は、拘束された自由度ごとに**反力**を計算します。`Dx` からは水平力 $R_x$、`Dz` からは鉛直力 $R_z$、`Ry` からはモーメント $M$ が生じます。つまり、ピンでは $R_x$ と $R_z$、ローラーでは $R_z$ だけ、ローラー（回転拘束）では $R_z$ と $M$、固定支点では 3 つすべてが生じます。

### 支点の設定 {#setting-a-support}

記号を選ぶか、自由度に 1 つずつチェックを入れます。両者は常に連動しています。どちらも次の 3 か所にあります。

- 節点のパネル（節点をクリック）→ **支点条件**。下の図のように、**節点座標系の角度**も一緒に設定できます。
- **節点を追加**と**節点を編集**のダイアログ。
- *節点*の表の*拘束自由度*列。記号は小さなメニューになっていて、`Dx`、`Dz`、`Ry` はチェックボックスです。

![節点のパネルの支点条件：記号、自由度のチェックボックス、支点の角度](/screenshots/ja/nodes-support-picker.webp){.shot-lg}

記号にポインターを重ねると、その名前が表示されます。

### ローラーとローラー（回転拘束）の違い {#roller-or-slider}

どちらもレールの上に載っていて、レールに沿って移動できます。違いは回転です。

- **ローラー**は、レールに載ったピンです。端は**自由に回転**できるので、そこに曲げモーメントは生じません。
- **ローラー（回転拘束）** は、レールに載った固定支点です。端は**回転できない**ので、支点がモーメントを受けます。

同じ 6 m の梁に 10 kN/m の等分布荷重をかけ、右側の支点だけを変えてみます。変位図と曲げモーメント図を切り替えて比べてください。

1 つ目は単純梁です（スパン中央で $M_{max} = qL^2/8 = 45\ \text{kNm}$）。鉛直荷重に対しては、ローラー（回転拘束）は固定端とまったく同じように働くので、2 つ目は一端固定他端ローラー支持梁になります（$R_B = 5qL/8 = 37.5\ \text{kN}$、$M_B = -qL^2/8 = -45\ \text{kNm}$）。端を水平に保つと梁の剛性も上がり、最大たわみは 9.617 mm から 4 mm に減ります。ローラー（回転拘束）と固定端の違いが現れるのは、レールに沿った方向に力がかかるときだけです。

### 傾斜支点 {#inclined-skewed-supports}

斜面上の支点は、回転した軸の方向に節点を拘束します。**節点座標系の角度** α を、度単位で −180° から 180° の範囲で設定します。設定できるのは、節点のパネルの*支点条件*、節点の追加・編集ダイアログ、*節点*の表の **α** 欄です。

節点の座標軸が α だけ回転し、チェックを入れた自由度はその軸の方向に働きます。α は x 軸を z 軸の方へ回すので、画面上では**時計回り**です（y 上向きの座標軸では x 軸を y 軸の方へ回すので、反時計回り）。たとえば、右に向かって 30° 下がる面の上のローラーは、α = 30° のローラーです。記号も軸と一緒に回転し、反力もその軸の方向で表示されます。

::model-figure{caption="B のローラーを α = 30° 回転：反力 34.64 kN は斜面に垂直に働き、梁には N = +17.32 kN が生じます"}

  - { member: 1, qz: 10 }

上と同じ 6 m の梁に 10 kN/m の荷重をかけたものですが、ローラーは 30° の斜面に載っています。B の反力の鉛直成分は変わらず $qL/2 = 30\ \text{kN}$ なので、反力そのものは $30/\cos 30° = 34.64\ \text{kN}$ です。その水平成分 $30 \tan 30° = 17.32\ \text{kN}$ が B を右へ押し、A のピンがそれを引き止めるので、梁には引張が生じます。曲げモーメントは変わりません。

回転した節点の[節点荷重](/ja/essentials/loads#nodal-loads)は、全体座標軸でも節点座標軸でも与えられます。[強制変位](/ja/essentials/loads#prescribed-displacements-support-settlements)は常に支点自身の座標軸の方向に働きます。

### 安定性 {#stability}

平面内の構造物には、少なくとも **3 つの拘束自由度**が必要で、しかもそれが実際に構造物を固定できる配置になっていなければなりません。支点が足りないうちは、ビューアに青い**支点が必要**チップが表示されます。支点の数は足りていても構造物を固定できない場合（すべて平行、またはすべて 1 点で交わる）や、ヒンジによって部材どうしが回転できてしまう場合は、赤いメッセージが問題を示し、破線の輪郭で構造物の動き方を示します。各メッセージは[トラブルシューティング](/ja/reference/troubleshooting#messages)で説明しています。

## 節点荷重と支点沈下 {#nodal-loads-and-settlements}

力やモーメントを与えるには、節点をクリック → **荷重を追加**を選びます。支点を決まった量だけ動かす（支点沈下）には、節点をクリック → **強制変位を設定**を選びます。どちらも[節点荷重](/ja/essentials/loads#nodal-loads)で説明しています。

## 寸法線 {#dimension-lines}

寸法線は図に長さを書き込むものです。解析には影響しませんが、プロジェクトと一緒に保存され、共有リンクにも含まれ、[エクスポートした画像](/ja/essentials/import-export#export-an-image)にも描かれます。

| 目的 | 操作 |
| --- | --- |
| 寸法線を追加する | キャンバスを右クリック → **寸法線を追加**を選び、2 つの端点をクリックします。節点の近くの点は節点にスナップします。 |
| 要素に寸法線を付ける | 要素を右クリック → **要素に寸法線を追加**。 |
| 編集・反転する | 寸法線をクリック → **編集**で座標を入力するか、**寸法線を反転**でラベルを反対側に移します。 |
| 移動する | 寸法線か端点をドラッグします。節点の上にある端点は節点に結び付いていて、節点と一緒に動きます。 |
