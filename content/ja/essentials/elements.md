# 要素・材料・断面

[EduBeam]{.edubeam} の要素はどれも、2 つの節点を結ぶ梁で、材料と断面を持ちます。節点の間に要素を描き、構造物にピン接合がある所ではヒンジで端を解放し、材料と断面はライブラリから選ぶか自分で定義します。

## 梁要素 {#the-beam-element}

要素の種類は 1 つだけです。x–z 平面内の **2D ティモシェンコ梁**で、両端にそれぞれ 3 つの自由度（`Dx`、`Dz`、`Ry`）を持ちます。軸力、せん断力、曲げモーメントを負担し、[せん断変形](#shear-deformation)も考慮します。トラス材は、同じ要素の[両端にヒンジ](#end-hinges)を入れたものです。定式化は理論マニュアルの[梁要素](/ja/elements/beam)にあります。

要素に沿った結果は線形モデルの範囲で厳密なので、**部材 1 本につき要素 1 つで十分です**。部材の途中に節点を追加するのは、支点、ヒンジ、断面の変化が必要な所や、変位を読みたい点だけにしてください。集中荷重のために節点を追加する必要はありません。[集中荷重](/ja/essentials/loads#concentrated-load)は要素上のどこにでも置けます。

## 要素の追加 {#adding-elements}

要素には材料と断面が必要なので、先にそれらを追加します（[材料](#materials)と[断面](#cross-sections)を参照）。どちらもないうちは、ビューアに「材料が定義されていません。」または「断面が定義されていません。」と表示され、**新規追加**ボタンが付きます。

- **節点を選んで追加。** *要素*タブ → **要素を追加**（**+** アイコンのボタン）、またはキャンバスを右クリック → *要素を追加*。**始端節点**と**終端節点**を選び、必要ならそれぞれの下の**ヒンジ**にチェックを入れ、**材料**と**断面**を選びます。節点が 2 つ以上必要です。
- **クリックして追加。** *要素*タブ → **要素を追加**（カーソルアイコンのボタン）、またはキャンバスのメニューで <kbd>Ctrl</kbd> を押しながら*要素を追加*を選びます。節点をクリックし（何もない所をクリックすると節点ができます）、次の節点をクリックします。クリックを続けると要素を連続して描けます。終えるには <kbd>Esc</kbd> か**キャンセル**を押します。上部のバナーで、描くすべての要素の**始端ヒンジ**と**終端ヒンジ**を設定できます。材料と断面には、モデルの最初のものが使われます。

![要素を追加ダイアログ](/screenshots/ja/qs-element.webp){.shot-md}

## 要素の向き {#element-direction}

各要素には固有の**ローカル座標系**があります。ローカル x 軸は**始端節点**から**終端節点**へ向かい、ローカル z 軸はローカル x 軸を画面上で時計回りに 90° 回した向きです。左から右へ描いた要素では、ローカル座標系はグローバル座標系と一致します。各要素に沿って描かれる**破線**は、ローカル +z 側、つまり「下縁」を示します。

![A → B → C → D の順に描いた門形ラーメン：3 つの要素の破線はすべてラーメンの内側にあります](/screenshots/ja/p2b-element-direction.webp){.shot-md}

このラーメンでは、要素 1 は A から B へ上向きなので、ローカル z 軸とその破線は右を向きます。要素 3 は C から D へ下向きなので、破線は左側にあります。このように描くと、門形ラーメンの破線はすべて内側に来ます。

要素の向きが関係するのは次の点です。

- ローカル座標系で与える荷重（**LCS** にチェック）。[要素荷重](/ja/essentials/loads#element-loads)を参照。
- 集中荷重の**始端節点からの荷重位置**。
- 結果に表示される[材端力](/ja/elements/conventions#end-forces-element-results-table)の順序。始端節点が `X12, Z12, M12`、終端節点が `X21, Z21, M21` です。
- [断面力図の設定](/ja/essentials/units-settings#viewer-settings)で、どちらが「破線側」になるか。

要素の向きを逆にするには、**節点を入れ替え**（*要素*の表で 2 つの節点の間にある矢印）を押します。

## 材端ヒンジ {#end-hinges}

材端ヒンジは、要素の一方の端で曲げモーメントを解放します。その端のモーメントは 0 になり、端は節点とは別に回転できます。

- **ヒンジが 1 つ**なら、梁やラーメンの途中にピン接合ができます。
- **ヒンジが 2 つ**なら、軸力だけを負担する**トラス材**になります。

ヒンジは次のいずれかの場所で設定できます。

- *要素*の表の**材端ヒンジ**列。端ごとにチェックボックスが 1 つあります。
- **要素を追加**ダイアログ、または要素のパネル → **要素を編集**の**ヒンジ**のチェックボックス。
- マウスで描くときのバナーの**始端ヒンジ**と**終端ヒンジ**。

![3 ヒンジラーメンの要素の表：要素 2 は終端（節点 C）にヒンジがあります](/screenshots/ja/elements-table.webp)

手計算では、連続梁は $M_B = -qL^2/8 = -31.25\ \text{kNm}$、各スパンの最大値は $9qL^2/128 = 17.58\ \text{kNm}$ です。ヒンジがあると $M_B = 0$、各スパン中央で $M_{max} = qL^2/8 = 31.25\ \text{kNm}$ になります。ヒンジは支点上のモーメントをなくしますが、スパンのモーメントはほぼ 2 倍になります。中間ヒンジのある梁を手で解き、入力しながら答えを確かめたいときは、[練習問題 G2048](/ja/practice?p=G2048) を試してみてください。

### ヒンジ 2 つ：トラス材 {#both-hinges-a-truss-bar}

2 本の部材からなる壁の持ち送り（ブラケット）です。どちらの部材も両端にヒンジがあり、B に 20 kN がかかります。部材は軸力だけを負担し、曲げモーメント図には何も描かれません。

::model-figure{caption="引張材 AB：N = +26.67 kN（引張）、圧縮材 CB：N = −33.33 kN（圧縮）"}
---

supports: { A: pin, C: pin }
members: [{ nodes: [A, B], hinges: [true, true] }, { nodes: [C, B], hinges: [true, true] }]
loads:
  - { node: B, fz: 20 }
results: [N, M]
show: [nodeLabels]
---
::

手計算では、圧縮材は長さ 5 m で高さが 3 m 変わるので、$N_{CB} = -20 \cdot 5/3 = -33.33\ \text{kN}$ です。引張材はその水平成分とつり合うので、$N_{AB} = 33.33 \cdot 4/5 = 26.67\ \text{kN}$ になります。[チュートリアル：平面トラス](/ja/tutorials/truss)では、この方法でトラス全体を組み立てます。[練習問題](/ja/practice?p=T2048)には、手で解くトラスの問題があります。

### ヒンジは節点ではなく要素に付ける {#hinge-the-element-not-the-node}

ヒンジは 1 つの要素の一方の端に属します。その端だけが自由に回転できるようになり、節点に集まるほかの要素はすべて節点に剛に接合されたままです。そのため、2 本の部材が接する所では、ヒンジを 1 つ付ければピン接合になります。何本も集まる所では、1 本を除くすべてにヒンジを付けます。すべての部材がトラス材であるトラスの節点では、すべてにヒンジが付いています。

すべての要素がヒンジで接続された節点は、回転剛性を持ちません。EduBeam はそれを受け入れ、その回転角を 0 として表示します。ヒンジによって構造物が不安定構造になる場合は、EduBeam がそのヒンジを丸で囲み、動き方を表示します。[トラブルシューティング](/ja/reference/troubleshooting#messages)を参照してください。

## 材料 {#materials}

*材料*タブ → **材料を追加**、または用意された材料を使うなら**材料ライブラリ**。1 つの材料をいくつの要素でも共有でき、材料を変えると、それを使うすべての要素が更新されます。

| 項目 | 単位 | 役割 |
| --- | --- | --- |
| ヤング係数 $E$ | MPa | 軸剛性 $EA$ と曲げ剛性 $EI_y$。鋼 210,000 MPa、コンクリート約 30,000 MPa、木材約 11,000 MPa。 |
| せん断弾性係数 $G$ | MPa | せん断剛性 $kGA$。断面の $k$ が非常に大きくない限り、[せん断変形](#shear-deformation)が加わります。たわみが大きくなり、不静定構造では断面力も変わります。$G = E/(2(1+\nu))$。鋼は約 81,000 MPa。 |
| 密度 $\rho$ | kg/m³ | 材料と一緒に保存されますが、計算には使いません。自重を荷重として扱う機能はないためです。 |
| 線膨張係数 $\alpha$ | 1/K | [温度荷重](/ja/essentials/loads#temperature-load)で使います。鋼は $12 \times 10^{-6}$ 1/K。 |

表の単位は SI の初期値です。実際の単位は[設定](/ja/essentials/units-settings#units)に従うので、米国単位では E と G が ksi、密度が lb/ft³、α が 1/°F になります。

新しい材料の初期値は、$E$ = 210,000 MPa、$G$ = 87,500 MPa（$E/2.4$、つまり $\nu = 0.2$）、$\rho$ = 1000 kg/m³、$\alpha = 12 \times 10^{-6}$ 1/K です。米国単位では ASTM A992 鋼が初期値になります。鋼を使うなら、$G$ を 81,000 MPa に変えるか、ライブラリから鋼材を選んでください。

![材料を追加ダイアログ](/screenshots/ja/qs-material.webp){.shot-md}

**材料ライブラリ**（材料を追加ダイアログの*またはライブラリから選択*からも開けます）は、メートル法（EN）の材料を先に表示します。長さの単位がフィートかインチのときは、米国の材料（ASTM の鋼材、ACI のコンクリート）が先に来ます。行の **+** を押すと、その材料が同じ名前で追加されます。

| 分類 | 材料 |
| --- | --- |
| 金属 | 鋼材 S235、S275、S355。ステンレス鋼 304、316。鋳鉄。アルミニウム 6061-T6、7075-T6、5083。銅、黄銅、青銅。チタン Grade 2 と Ti-6Al-4V。米国の鋼材 ASTM A992、A36、A572 Gr. 50 と HSS A500 Gr. C |
| コンクリート | C25/30、C30/37、C40/50、軽量コンクリート。米国の $f'_c$ = 4 ksi と 5 ksi |
| 木材 | C24、GL24h、GL32h |
| その他 | ガラス、GFRP、CFRP、HDPE、PVC、PMMA、ポリカーボネート |

要素が使っている材料は削除できません。先にそれらの要素に別の材料を割り当ててください。

## 断面 {#cross-sections}

*断面*タブ → **断面を追加**、**断面ライブラリ**、または独自の形状を描く**多角形断面**。材料と同じく、1 つの断面をいくつの要素でも共有できます。

| 項目 | 単位 | 役割 |
| --- | --- | --- |
| 断面積 $A$ | m² | 軸剛性 $EA$ とせん断断面積 $kA$。 |
| 断面二次モーメント $I_y$ | m⁴ | 図の面に垂直な軸まわりの曲げ剛性 $EI_y$。 |
| 高さ $h$ | m | 温度荷重にだけ使います。曲率は $\alpha\,(\Delta T_b - \Delta T_t)/h$ です。 |
| せん断補正係数 $k$ | – | 有効せん断断面積は $kA$、せん断剛性は $kGA$ です。長方形で約 0.83、I 形断面で $A_{web}/A$。 |

新しい断面の初期値は、$A$ = 1 m²、$I_y = 10^{-4}$ m⁴、$h$ = 1 m、$k$ = 1 です（米国単位では W12×26、$k$ = 1）。使う断面の値に書き換えるか、ライブラリから選んでください。

::callout{type="tip" title="せん断変形を無視する教科書と合わせるには"}
手計算の多くは、せん断変形を考えないオイラー・ベルヌーイ梁を使います。それと結果を合わせるには、$k$ に `1e10` のような非常に大きな値を入れてください。アプリの例題とこのサイトの図では `1e32` を使っています。新しい断面（$k = 1$）、ライブラリ、多角形エディタは、どれもせん断変形を含みます。それでどれだけ結果が変わるかは[下](#shear-deformation)で説明します。
::

**断面ライブラリ**には、次の断面のおおよその値が入っています。

| 分類 | 断面 | $k$ |
| --- | --- | --- |
| 中実断面 | 長方形、正方形、円形 | 0.833（長方形）、0.9（円形） |
| I 形 | IPE 100、IPE 200、HEA 100、HEA 200。AISC W 形鋼 W8×31〜W36×150 | $h\,t_w/A$（ウェブ） |
| 角形鋼管 | RHS 100×50×3、150×100×5。AISC HSS | $2ht/A$（両側のウェブ） |
| 丸形鋼管 | CHS Ø60×3、Ø114×5。AISC 丸形 HSS | 0.5 |

ライブラリの値に頼る前に、断面表で確認してください。

![断面ライブラリ](/screenshots/ja/sections-library.webp){.shot-lg}

手早く確かめるには、$b \times h$ の長方形は $A = bh$、$I_y = bh^3/12$、直径 $d$ の中実円は $A = \pi d^2/4$、$I_y = \pi d^4/64$ です。

### せん断変形：G と k が効くとき {#shear-deformation}

せん断剛性 $kGA$ は、[せん断パラメーター](/ja/elements/beam#timoshenko-or-euler-bernoulli) $\Phi = 12EI_y/(kGAL^2)$ を通じて要素に入ります。$k$ が非常に大きければ $\Phi = 0$ となり、要素はオイラー・ベルヌーイ梁になるので、$G$ は影響しません。実際の $k$ を使うと、せん断変形の分だけたわみは必ず大きくなります。静定構造では断面力は変わりませんが、不静定構造では断面力も変わります。不静定力が剛性によって決まるからです。

どれだけ変わるかは、部材がどれだけ太短いかによります。ライブラリの IPE 200（$k = h\,t_w/A = 0.393$）、鋼材 S235（$G$ = 81,000 MPa）、10 kN/m の荷重で、$k$ = `1e32` とした同じ梁と比べます。

| 梁 | せん断変形あり | オイラー・ベルヌーイ |
| --- | --- | --- |
| 単純梁、$L$ = 2 m（$L/h$ = 10）：スパン中央のたわみ | 0.566 mm | 0.511 mm |
| 一端固定他端ローラー支持梁、$L$ = 2 m：固定端のモーメント | −4.84 kNm | −5.00 kNm |
| 単純梁、$L$ = 6 m（$L/h$ = 30）：スパン中央のたわみ | 41.85 mm | 41.36 mm |

手計算では、スパン中央のたわみのうちせん断による分は $qL^2/(8kGA)$ で、短い梁では 0.055 mm、曲げによる分 $5qL^4/(384EI_y)$ の 11 % にあたります。一端固定他端ローラー支持梁では、固定端モーメントが $qL^2/8$ から $(qL^2/8)/(1 + \Phi/4)$ に下がります。$L/h$ = 30 ではどちらの影響も 1 % 程度以下です。細長い部材からなるラーメンで、$k$ の値にかかわらず教科書の答えと一致するのはこのためです。

### 多角形断面 {#polygonal-sections}

*断面*タブ → **多角形断面**、または断面を追加ダイアログの*または多角形形状を定義*で形状エディタが開き、断面性能を計算してくれます。

![多角形断面エディタ：I 形のプリセットと、その主軸、慣性楕円](/screenshots/ja/sections-polygon.webp)

::div{.steps}

### プリセットから始める {#start-from-a-preset}

**プリセット**（長方形、I 形、T 形、L 形、溝形、角形中空、円形、円形中空）を選び、寸法を設定して**適用**を押します。

### 形状を調整する {#adjust-the-shape}

頂点をドラッグする（**スナップ間隔**にスナップします）、辺の中点をクリックして頂点を挿入する、頂点をダブルクリックして削除する、のいずれかで形を整えます。**頂点**の表に座標を入力することもできます。**穴を追加**で内側の輪郭を追加し、**図心を中心に配置**で図心が原点に来るように形状を移動します。

### 断面性能を読む {#read-the-properties}

**断面性能**タブには、$A$、図心、図心軸まわりの $I_y$、$I_z$、$I_{yz}$、主断面二次モーメント $I_1$、$I_2$ と**主軸角** $\alpha$（$y$ 軸から 1 軸まで）、断面二次半径が表示されます。図には主軸と慣性楕円が描かれます。

### 追加する {#add-it}

**ラベル**と**せん断補正係数** $k$ を確認します。$k$ の初期値 0.833 は長方形向けの値で、I 形断面にはおよそ $A_{web}/A$ が必要です。そのあと**断面を追加**を押します（既存の形状を編集しているときは**保存**）。$A$、$I_y$、$h$ は形状から求められ、表では読み取り専用です。変えたいときは、*操作*列の多角形ボタンで形状をもう一度編集します。

::

断面の座標はローカルの右手系で、$x$ は画面の手前向き、$y$ は左向き、$z$ は下向きです。

形状が骨組の平面に対して対称でない場合（たとえば L 形鋼）、エディタは警告を表示します。2D 解析が厳密に成り立つのは、床スラブなどによって、部材が全長にわたり面外のたわみとねじれを拘束されている場合だけです。$I_{yz}$ が無視できないときは、どちらの曲げ剛性を使うかを選びます：**全長にわたり面外変形とねじれを拘束**（$I_y$）か、それより小さい**面外たわみは自由**か。どちらの場合もねじれは考慮されません。
