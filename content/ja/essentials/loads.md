# 荷重

荷重は節点に、または要素に沿って作用します。すべての荷重は **1 つの荷重ケース**に属し、同時に作用します。複数の状況を比べるには、それぞれを[プロジェクトファイルか共有リンク](/ja/essentials/import-export)として保存してください。

| 荷重 | 作用する対象 | 追加のしかた |
| --- | --- | --- |
| [力またはモーメント](#nodal-loads) | 節点 | *荷重*タブ → **節点荷重を追加**、または節点をクリック → **荷重を追加** |
| [強制変位](#prescribed-displacements-support-settlements)（支点沈下） | 支点のある節点 | 同じダイアログ、または節点をクリック → **強制変位を設定** |
| [等分布荷重](#uniformly-distributed-load)、[台形分布荷重](#trapezoidal-load)、[集中荷重](#concentrated-load)、[温度荷重](#temperature-load) | 要素 | *荷重*タブ → **要素荷重を追加**、または要素をクリック → **荷重を追加** |

## 符号規約 {#sign-convention-in-one-line}

x 軸は**右向き**、z 軸は**下向き**で、モーメントは**反時計回り**が正です。したがって正の `Fz` や `fz` は重力と同じ下向きの荷重で、上向きの荷重は負になります。

::model-figure{caption="ここにある荷重はすべて正：Fx = +10 kN は右向き、Fz = +10 kN は下向き、My = +10 kNm は反時計回り"}
---
nodes: { A: [0, 0], B: [3, 0], C: [6, 0] }
supports: { A: pin, C: roller }
members: [[A, B], [B, C]]
loads:
  - { node: A, fx: 10 }
  - { node: B, fz: 10 }
  - { node: C, my: 10 }
results: []
---
::

| 正の向き | 標準の座標軸（z 下向き） | [y 上向きの座標軸](/ja/elements/conventions#y-up-axes) |
| --- | --- | --- |
| 水平力 `Fx`、`fx` | 右向き | 右向き |
| 鉛直力 | `Fz`、`fz`：**下向き** | `Fy`、`fy`：**上向き** |
| モーメント | `My`：反時計回り | `Mz`：反時計回り |
| 鉛直方向の支点沈下 | `Dz`：下向き | `Dy`：上向き |

要素の**ローカル座標系**で与える荷重（LCS にチェック）は、要素の向きに従います。ローカル x 軸は始端節点から終端節点へ向かい、ローカル z 軸はローカル x 軸を時計回りに 90° 回した向き、つまり要素に沿って描かれる破線の側です。[要素の向き](/ja/essentials/elements#element-direction)を参照してください。断面力も含めた符号規約の全体は[座標系と符号規約](/ja/elements/conventions#loads)にあります。

## 節点荷重 {#nodal-loads}

*荷重*タブ → **節点荷重を追加**、または節点をクリック → **荷重を追加**を選び、**力/モーメント**を選んだままにします。力 `Fx`、`Fz`（kN）とモーメント `My`（kNm）を、[上](#sign-convention-in-one-line)の符号に従って入力します。入力に合わせて、プレビューに荷重が描かれます。

![節点荷重を追加：入力に合わせて、プレビューに向きが表示されます](/screenshots/ja/loads-nodal.webp){.shot-md}

- 成分は**グローバル**座標系で表します。座標軸が回転した節点（[傾斜支点](/ja/essentials/nodes-supports#inclined-skewed-supports)）では、ダイアログに**全体座標軸** / **節点座標軸**の切り替えが加わります。節点座標軸では、`Fx′`、`Fz′` と表示される成分が節点自身の座標軸の方向に働き、あとで角度を変えると一緒に回転します。切り替えると値が換算されるので、荷重そのものは変わりません。
- 1 つの節点に複数の節点荷重をかけられます。それらは足し合わされます。

### 強制変位（支点沈下） {#prescribed-displacements-support-settlements}

支点を決まった量だけ動かすには、同じダイアログで**強制変位**を選ぶか、支点のある節点をクリック → **強制変位を設定**を選びます。変位 `Dx`、`Dz`（右向きと下向きが正、[変位の単位](/ja/essentials/units-settings#units)で、初期値は m）と回転角 `Ry`（rad、反時計回りが正）を入力します。

- 値を与えられるのは**拘束された**自由度だけです。ほかの入力欄はグレー表示になり、支点のない節点には支点沈下をまったく与えられません。
- 強制変位は 1 つの節点に 1 つまでです。変えたいときは、2 つ目を追加せずに既存のものを編集してください。
- 傾斜支点では入力欄が `Dx′`、`Dz′` になります。支点沈下は支点自身の座標軸の方向に働きます。

支点沈下で断面力が生じるかどうかは、構造物によって決まります。ほかの荷重はなく、支点 B が同じ 10 mm だけ沈下した場合を比べます。

::div{.shots}

results: [w, M]
show: [nodeLabels]
---
:::

:::model-figure{caption="2 径間連続梁：梁は曲がり、B 上で M = 21.06 kNm"}

members: [[A, B], [B, C]]

  - { node: B, settlement: { dz: 0.01 } }

::

静定構造は、抵抗なく支点に追従します。連続梁は曲がらざるを得ません。支点 B が梁を $\delta = 10\ \text{mm}$ だけ引き下げるので、スパン 10 m の単純梁の中央に集中荷重をかけたのと同じ状態になります。$L = 5\ \text{m}$、例題の鋼の $EI = 17{,}548\ \text{kNm}^2$ とすると、その荷重は $P = 6EI\delta/L^3 = 8.423\ \text{kN}$ で、これが B の反力です。また $M_B = PL/2 = 3EI\delta/L^2 = 21.06\ \text{kNm}$ です。[チュートリアル：連続梁と支点沈下](/ja/tutorials/continuous-beam)では、支点沈下とほかの荷重を組み合わせます。

## 要素荷重 {#element-loads}

*荷重*タブ → **要素荷重を追加**、または要素をクリック → **荷重を追加**を選びます。**荷重の種類**を選ぶと、入力に合わせてプレビューに要素上の荷重が表示されます。力は kN、分布荷重は kN/m で、[単位](/ja/essentials/units-settings#units)を変えていればその単位になります。

![要素荷重を追加：等分布荷重の場合](/screenshots/ja/loads-udl.webp){.shot-md}

### 等分布荷重 {#uniformly-distributed-load}

要素全体にかかる、単位長さあたり一定の荷重 `fx` と `fz` です。**LCS** にチェックを入れると（初期状態）要素のローカル座標軸の方向に、チェックを外すとグローバル座標軸の方向に働きます。左から右へ描いた水平な要素では両者は同じですが、傾いた部材では違います。

| 与えたい荷重 | 入力 |
| --- | --- |
| 部材に**垂直な**荷重（垂木にかかる風荷重） | LCS に**チェックを入れて** `fz` |
| 部材長さ 1 m あたりの**鉛直**荷重（自重） | LCS の**チェックを外して** `fz` |
| 水平投影長さ 1 m あたりの**鉛直**荷重（積雪荷重） | 直接は入力できません。部材の傾斜角を $\alpha$ として $\cos\alpha$ を掛け、鉛直荷重として入力します |

水平に 4 m、高さ 3 m、長さ 5 m の垂木に、同じ 10 kN/m をかけた場合です。

::div{.shots}

:::model-figure{caption="LCS のチェックなし：鉛直方向、合計 50 kN、M = 25 kNm"}
---

  - { member: 1, qz: 10 }

---
:::

:::model-figure{caption="LCS にチェック：部材に垂直、M = 31.25 kNm"}
---
nodes: { A: [0, 0], B: [4, -3] }
supports: { A: pin, B: roller }

---
:::

::

手計算では、部材に垂直な場合は $M = qL^2/8 = 10 \cdot 5^2/8 = 31.25\ \text{kNm}$ です。鉛直の場合は、50 kN が水平距離 4 m に分布するので水平投影長さあたり 12.5 kN/m となり、$M = 12.5 \cdot 4^2/8 = 25\ \text{kNm}$ です。

### 台形分布荷重 {#trapezoidal-load}

要素に沿って直線的に変化する荷重です。**始端**節点で `f1x`、`f1z`、**終端**節点で `f2x`、`f2z` を与えます。一方の端を 0 にすれば三角形分布荷重になります。

::model-figure{caption="0 から 10 kN/m の三角形分布荷重：反力 10 kN と 20 kN、M の最大値は 3.46 m の位置で 23.09 kNm"}
---
nodes: { A: [0, 0], B: [6, 0] }
supports: { A: pin, B: roller }
members: [[A, B]]
loads:
  - { member: 1, qz: [0, 10] }
results: [M, V]
show: [nodeLabels]
---
::

手計算では、荷重の合計 $qL/2 = 30\ \text{kN}$ が $2L/3$ の位置に作用するので、$R_A = 10\ \text{kN}$、$R_B = 20\ \text{kN}$ です。せん断力が 0 になり、モーメントが最大になるのは $x = L/\sqrt{3} = 3.46\ \text{m}$ の位置で、$M = qL^2/(9\sqrt{3}) = 23.09\ \text{kNm}$ です。

台形分布荷重は要素の**ローカル座標軸**の方向に働きます（LCS のチェックボックスは変更できません）。左から右へ描いた水平な要素ではグローバル座標軸と同じです。傾いた要素では、`f1z` と `f2z` は部材に垂直、`f1x` と `f2x` は部材に沿った方向です。

傾斜角 $\alpha$ の部材にかかる変化する**鉛直**荷重も、厳密に与えられます。両端それぞれでローカル成分を 2 つ入力します。$f_z = q\cos\alpha$ と、斜面を下る向きの $f_x = q\sin\alpha$ です。要素が始端節点から上り坂になっている場合、$f_x$ は負になります。上の垂木（水平に 4 m、高さ 3 m、下端から描いたもの）で、部材長さあたり 0 から 10 kN/m に増える鉛直荷重は、`f1x` = `f1z` = 0、`f2x` = −6、`f2z` = 8 kN/m です。

::model-figure{caption="部材長さあたり 0 から 10 kN/m の鉛直荷重をローカル成分で入力：反力 8.333 kN と 16.67 kN、M の最大値 12.83 kNm"}
---
nodes: { A: [0, 0], B: [4, -3] }
supports: { A: pin, B: roller }
members: [[A, B]]
loads:
  - { member: 1, qx: [0, -6], qz: [0, 8], local: true }
results: [M]
show: [nodeLabels]
---
::

手計算では、合力 25 kN が水平距離の 3 分の 2、2.67 m の位置に作用するので、$R_B = 25 \cdot 2.667/4 = 16.67\ \text{kN}$ です。水平投影 4 m の上で荷重は 12.5 kN/m まで増える三角形になるので、上と同じく $M = 12.5 \cdot 4^2/(9\sqrt{3}) = 12.83\ \text{kNm}$ です。

### 集中荷重 {#concentrated-load}

要素**上の**任意の位置にかける集中力 `Fx`、`Fz` または集中モーメント `My` で、節点を追加する必要はありません。**始端節点からの荷重位置**は、始端節点からの距離 $a$ で、$0 \le a \le L$ です。初期値は要素長さの半分をメートル単位で切り捨てた値（最大 5 m、米国単位ではフィート単位で最大 15 ft）なので、実際に荷重がかかる位置に設定してください。**LCS** は等分布荷重と同じように働きます。

::model-figure{caption="スパン 6 m の梁の A から 2 m の位置に 20 kN：V は 13.33 kN から −6.667 kN へ不連続に変わり、荷重の位置で M = 26.67 kNm"}
---
nodes: { A: [0, 0], B: [6, 0] }
supports: { A: pin, B: roller }
members: [[A, B]]
loads:
  - { member: 1, pz: 20, at: 2 }
results: [V, M]
show: [nodeLabels]
---
::

せん断力図には荷重の位置で `Fz` の大きさの段差が生じ、曲げモーメント図はそこで折れ曲がります。$R_A = 20 \cdot 4/6 = 13.33\ \text{kN}$、$M = 13.33 \cdot 2 = 26.67\ \text{kNm}$ です。集中モーメント `My` の場合は、曲げモーメント図のほうに段差が生じます。

### 温度荷重 {#temperature-load}

| 項目 | 意味 | 効果 |
| --- | --- | --- |
| **ΔT<sub>c</sub>**、材軸の温度変化 | 断面全体で同じ温度変化 | 伸び $\alpha\,\Delta T_c\,L$ |
| **ΔT<sub>b</sub> − ΔT<sub>t</sub>** | 下縁の温度変化から上縁の温度変化を引いた差 | 曲率 $\alpha\,(\Delta T_b - \Delta T_t)/h$ |

どちらも応力のない状態からの温度の*変化*で、初期値の単位は °C です。1 °C の変化は 1 K に等しくなります。温度荷重には、材料の **α** と断面の**高さ h** を使います。**下縁**は破線の側です。ΔT<sub>b</sub> − ΔT<sub>t</sub> が正（下側のほうが高温）なら下縁が伸びるので、要素は重力荷重を受ける梁のように下にたわみます。

静定構造では、温度変化は変位を生じるだけです。拘束（固定端、連続性、余剰部材）があると、それが断面力に変わります。長さ 6 m、せい 0.3 m の同じ鋼の梁で、下面が上面より 20 K 高温の場合を比べます。

::div{.shots}

:::model-figure{caption="単純梁：スパン中央で 3.6 mm たわみ、M = 0"}
---
nodes: { A: [0, 0], B: [6, 0] }
supports: { A: pin, B: roller }
members: [[A, B]]
section: { h: 0.3 }
loads:
  - { member: 1, temperature: { bottom: 20 } }
results: [w, M]
---
:::

:::model-figure{caption="両端固定：梁はまっすぐなまま、全長で M = −14.04 kNm"}
---
nodes: { A: [0, 0], B: [6, 0] }
supports: { A: fixed, B: fixed }
members: [[A, B]]
section: { h: 0.3 }
loads:
  - { member: 1, temperature: { bottom: 20 } }
results: [M, w]
---
:::

::

手計算では、拘束のないときの曲率は $\kappa = \alpha\,\Delta T/h = 12 \times 10^{-6} \cdot 20/0.3 = 8 \times 10^{-4}\ \text{1/m}$ です。単純梁ではこの曲率がそのまま生じ、$\kappa L^2/8 = 3.6\ \text{mm}$ たわみます。両端固定では、一定のモーメントがそれを打ち消さなければならないので、$M = -EI\kappa = -17{,}548 \cdot 8 \times 10^{-4} = -14.04\ \text{kNm}$ です。[手計算による結果の確認](/ja/guide/verification#temperature-gradient-on-a-simply-supported-beam)では、別の例を順を追って解いています。

## 荷重の編集と削除 {#editing-and-removing-loads}

| 目的 | 操作 |
| --- | --- |
| 値をすばやく変える | *荷重*タブで、成分（と LCS のボックス）をその場で編集します。 |
| 編集ダイアログを開く | ビューアで荷重をダブルクリックするか、クリック → **荷重を編集**。荷重は*節点*と*要素*の表にもチップとして表示され、クリックすると編集できます。 |
| 削除する | 選択して <kbd>Delete</kbd> を押すか、クリック → **削除**、または*荷重*タブの × を使います。 |

荷重はその節点や要素に属します。節点や要素を削除すると荷重も削除され、荷重を選択したまま節点や要素をコピーすると、荷重も一緒にコピーされます。

![荷重タブ：荷重ごとに 1 行で、成分をその場で編集できます](/screenshots/ja/loads-table.webp)

## できないこと {#what-is-not-available}

::div{.limits}
- **荷重ケースは 1 つだけ。** 荷重の組み合わせはありません。ケースごとに別のファイルかリンクとして保存してください。
- **自重は考慮されません。** LCS のチェックを外した等分布荷重 $f_z = \rho\,g\,A$ として入力してください。たとえば IPE 200 なら $\approx 0.22\ \text{kN/m}$ です。
- **台形分布荷重はローカル座標軸だけ。** 傾いた部材にかかる変化する鉛直荷重は、[ローカル成分](#trapezoidal-load)で入力してください。
- **部分的な分布荷重はありません。** 分布荷重は要素全体にかかります。荷重が始まる点や終わる点に節点を追加してください。
::
