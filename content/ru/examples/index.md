# Примеры

Каждая карточка ниже — интерактивная, уже рассчитанная модель. Щёлкните по ней, и она откроется в [EduBeam]{.edubeam}, готовая к редактированию: перетащите узел, измените нагрузку или отметьте шарнир и посмотрите, как вслед за этим меняются эпюры. Упражнения ниже превращают каждую модель в небольшое задание с ответами, по которым можно проверить свой ручной расчёт.

::feature-structures
::

Те же модели есть в приложении в разделе **☰ → Примеры**, а ссылка [run.edubeam.app/?panel=examples&lang=ru](https://run.edubeam.app/?panel=examples&lang=ru){target="_blank"} сразу открывает эту галерею.

::callout{type="info" title="Один тип стержня во всех шести примерах"}
Во всех примерах используется один и тот же стальной стержень: $E = 210$ ГПа, $I_y = 8356\ \text{см}^4$ (т. е. $EI = 17\,548$ кН·м²), площадь $1\ \text{м}^2$ и настолько большая жёсткость на сдвиг, что продольными и сдвиговыми деформациями можно пренебречь. Поэтому учебные формулы для гибких балок совпадают с результатами приложения во всех показанных знаках. Высота сечения $1$ м; она важна только для температурной нагрузки.
::

## Предлагаемые упражнения {#suggested-exercises}

Сначала найдите ответ вручную, затем проверьте его в приложении: откройте модель с её карточки выше или кнопкой **Открыть в EduBeam** под её рисунком. Открытая модель заменяет текущую; <kbd>Ctrl</kbd>+<kbd>Z</kbd> вернёт вашу модель, а кроме того, она сохранится в **☰ → Недавние модели**.

### Статически неопределимая балка {#exercise-indeterminate-beam}

Балка длиной 3 м с заделкой в точке A и шарнирно-подвижной опорой в точке B под нагрузкой 10 кН/м.

::model-figure{caption="Заделка в A, шарнирно-подвижная опора в B, 10 кН/м"}
---
nodes: { A: [0, 0], B: [3, 0] }
supports: { A: fixed, B: roller }
members: [[A, B]]
loads:
  - { member: 1, qz: 10 }
results: []
show: [nodeLabels, dimensions]
---
::

1. Определите вручную реакции и момент в заделке методом сил или по таблице реакций защемления.
2. Снимите флажок `Ry` в узле A, чтобы балка стала шарнирно опёртой. Как изменится наибольший момент?
3. Снова отметьте `Ry` в узле A, а также в узле B, чтобы защемить оба конца.

**Обратите внимание**, где эпюра моментов меняет знак и как заделка воспринимает больше нагрузки, чем шарнирно-подвижная опора.

::callout{type="details" title="Ответы"}
- Заделка и шарнирно-подвижная опора: $R_A = 5qL/8 = 18{,}75$ кН, $R_B = 3qL/8 = 11{,}25$ кН, $M_A = qL^2/8 = 11{,}25$ кН·м, растянуты верхние волокна. Наибольший положительный момент $9qL^2/128 = 6{,}33$ кН·м действует на расстоянии 1,125 м от B, где поперечная сила равна нулю.
- Шарнирно опёртая балка: $qL^2/8 = 11{,}25$ кН·м в середине пролёта, столько же, сколько раньше воспринимала заделка.
- Заделки на обоих концах: $qL^2/12 = 7{,}5$ кН·м у концов (растянуты верхние волокна) и $qL^2/24 = 3{,}75$ кН·м в середине пролёта (растянуты нижние).
::

### Консоль {#exercise-cantilever}

Консоль длиной 4 м, защемлённая в точке A, с силой 18 кН, направленной вниз, на свободном конце B.

::model-figure{caption="Консоль, 18 кН на свободном конце"}
---
nodes: { A: [0, 0], B: [4, 0] }
supports: { A: fixed }
members: [[A, B]]
loads:
  - { node: B, fz: 18 }
results: []
show: [nodeLabels, dimensions]
---
::

1. Найдите момент в заделке, прогиб и угол поворота свободного конца. Сравните их со значениями для узла B в **Результаты → Узловые результаты**.
2. Уменьшите $I_y$ вдвое на вкладке **Сечения**. Что изменится, а что нет?
3. Замените сосредоточенную силу равномерно распределённой нагрузкой 4,5 кН/м, т. е. теми же 18 кН в сумме: удалите узловую нагрузку на вкладке **Нагрузки**, затем выберите **Добавить нагрузку на элемент**.

**Обратите внимание** на форму эпюры моментов: прямая при сосредоточенной силе, парабола при равномерно распределённой нагрузке.

::callout{type="details" title="Ответы"}
- $M_A = FL = 72$ кН·м, $w_B = FL^3/(3EI) = 21{,}88$ мм, $\varphi_B = FL^2/(2EI) = 8{,}21$ мрад.
- При вдвое меньшем $I_y$ прогиб удваивается до 43,77 мм. Момент остаётся равным 72 кН·м: консоль статически определима, поэтому усилия в ней не зависят от жёсткости.
- Равномерно распределённая нагрузка: $M_A = qL^2/2 = 36$ кН·м и $w_B = qL^4/(8EI) = 8{,}21$ мм. Та же суммарная нагрузка даёт вдвое меньший момент и три восьмых прогиба.
::

### Ферма Уоррена {#exercise-pratt-truss}

Ферма пролётом 9 м и высотой 1,8 м с силами 8 кН в каждом из трёх верхних узлов E, F и G. Отметьте **N(x)** в параметрах отображения, чтобы увидеть продольные силы. (Раскосы чередуются, стоек нет: такую схему большинство учебников называет фермой Уоррена.)

::model-figure{caption="Узлы A–G, по 8 кН в узлах E, F и G"}
---
nodes: { A: [0, 0], B: [3, 0], C: [6, 0], D: [9, 0], E: [1.5, -1.8], F: [4.5, -1.8], G: [7.5, -1.8] }
supports: { A: pin, D: roller }
members: [[A, B], [B, C], [C, D], [E, F], [F, G], [A, E], [E, B], [B, F], [F, C], [C, G], [G, D]]
loads:
  - { node: E, fz: 8 }
  - { node: F, fz: 8 }
  - { node: G, fz: 8 }
results: []
show: [nodeLabels]
---
::

1. Определите реакции, затем методом вырезания узлов найдите усилия в опорном раскосе A–E и в нижнем поясе A–B.
2. Методом сечений найдите усилие в верхнем поясе средней панели и в нижнем поясе B–C.
3. Узлы в этой модели жёсткие. На вкладке **Элементы** отметьте оба концевых шарнира у каждого стержня, чтобы получилась шарнирная ферма, и сравните продольные силы.
4. Удалите раскос B–F, сначала при жёстких узлах, затем при шарнирных. Устоит ли ферма?

**Обратите внимание** на знаки: верхний пояс сжат, нижний растянут, а в раскосах знаки чередуются.

::callout{type="details" title="Ответы"}
- Реакции: по 12 кН в A и в D.
- Опорные раскосы: сжатие 15,62 кН. Нижний пояс A–B и C–D: растяжение 10,00 кН.
- Верхний пояс E–F и F–G: сжатие 13,33 кН (моменты относительно B: $(12 \cdot 3 - 8 \cdot 1{,}5)/1{,}8$). Нижний пояс B–C: растяжение 16,67 кН (моменты относительно F: $(12 \cdot 4{,}5 - 8 \cdot 3)/1{,}8$). Внутренние раскосы: 5,21 кН; те, что идут от E и G вниз к нижнему поясу, растянуты, а те, что идут вверх к F, сжаты.
- Жёсткие и шарнирные узлы дают одинаковые продольные силы с точностью до 0,1 %. Изгиб в ферме с треугольной решёткой пренебрежимо мал, поэтому шарнирная модель и работает.
- Без B–F ферма с жёсткими узлами всё ещё стоит за счёт рамной работы, с изгибающими моментами около 3 кН·м. С шарнирами ей не хватает одного стержня: она становится механизмом, и EduBeam показывает, как она может двигаться.
::

### Трёхпролётная неразрезная балка {#exercise-three-span-continuous-beam}

Балка длиной 16 м с пролётами 5 + 6 + 5 м: 8 кН/м на первом пролёте, 20 кН в точке C и 6 кН/м на последнем пролёте. Сразу после открытия опоры есть только в A и D.

::model-figure{caption="Сразу после открытия: опоры только в A и D"}
---
nodes: { A: [0, 0], B: [5, 0], C: [11, 0], D: [16, 0] }
supports: { A: pin, D: roller }
members: [[A, B], [B, C], [C, D]]
loads:
  - { member: 1, qz: 8 }
  - { node: C, fz: 20 }
  - { member: 3, qz: 6 }
results: []
show: [nodeLabels, dimensions]
---
::

1. В исходном виде это одна шарнирно опёртая балка пролётом 16 м. Найдите реакции и моменты в точках B и C.
2. Отметьте `Dz` в узлах B и C, чтобы получилась неразрезная балка на четырёх опорах.
3. Найдите опорные моменты над B и C по уравнению трёх моментов, затем реакции.

**Обратите внимание** на отрицательные моменты, которые появляются над промежуточными опорами, на то, насколько уменьшаются все моменты, и на то, что происходит с силой 20 кН, когда в C появляется опора.

::callout{type="details" title="Ответы"}
- Шарнирно опёртая балка: $R_A = 44{,}69$ кН, $R_D = 45{,}31$ кН, $M_B = 123{,}4$ кН·м и $M_C = 151{,}6$ кН·м, оба момента положительные (растянуты нижние волокна).
- Неразрезная балка, при $M_A = M_D = 0$ уравнения
  $$22 M_B + 6 M_C = -\tfrac{8 \cdot 5^3}{4}$$
  $$6 M_B + 22 M_C = -\tfrac{6 \cdot 5^3}{4}$$
  дают $M_B = -9{,}766$ кН·м и $M_C = -5{,}859$ кН·м (растянуты верхние волокна). Сила 20 кН в точке C передаётся прямо на опору и ничего не изгибает.
- Реакции: A 18,05 кН, B 22,60 кН, C 35,52 кН (вместе с 20 кН), D 13,83 кН. В сумме они дают 90 кН, т. е. всю нагрузку.

::model-figure{caption="Неразрезная балка на четырёх опорах"}
---

supports: { A: pin, B: roller, C: roller, D: roller }
members: [[A, B], [B, C], [C, D]]

  - { member: 1, qz: 8 }

### П-образная рама {#exercise-portal-frame}

Ригель пролётом 8 м на двух стойках высотой 6 м, заделка в A и шарнирно-подвижная опора в D. Ригель несёт 10 кН/м, а в верхнем углу C приложены силы 8 кН влево и 10 кН вниз.

::model-figure{caption="Заделка в A, шарнирно-подвижная опора в D: 10 кН/м на ригеле, 8 кН и 10 кН в узле C"}
---
nodes: { A: [0, 0], B: [0, -6], C: [8, -6], D: [8, 0] }
supports: { A: fixed, D: roller }
members: [[A, B], [B, C], [C, D]]
loads:
  - { member: 2, qz: 10 }
  - { node: C, fx: -8 }
  - { node: C, fz: 10 }
results: []
show: [nodeLabels, dimensions]
---
::

1. Сколько раз рама статически неопределима?
2. Снимите флажок `Ry` в узле A, чтобы опора A стала шарнирно-неподвижной. Теперь рама статически определима: найдите вручную реакции и моменты в углах B и C.
3. Снова отметьте `Ry` в узле A, затем отметьте `Dx` в узле D, чтобы и эта опора стала шарнирно-неподвижной. Посмотрите на боковое смещение ригеля на деформированной схеме.

**Обратите внимание**, куда смещается верх рамы. В исходной модели он смещается вправо, против силы 8 кН. Почему?

::callout{type="details" title="Ответы"}
- Четыре реакции (три в заделке, одна в шарнирно-подвижной опоре) и три уравнения равновесия: рама один раз статически неопределима. Если и опору D сделать шарнирно-неподвижной — дважды.
- Шарнир в A: $V_D = (10 \cdot 8 \cdot 4 + 10 \cdot 8 - 8 \cdot 6)/8 = 44$ кН, $V_A = 46$ кН, $H_A = 8$ кН вправо. Момент в углу B равен $8 \cdot 6 = 48$ кН·м. В углу C он равен нулю: горизонтальной реакции в D нет, поэтому правая стойка воспринимает только продольную силу 44 кН.
- В исходной модели верх смещается на 9,5 мм вправо: момент от нагруженного ригеля изгибает защемлённую стойку сильнее, чем сила 8 кН. Если опора D шарнирно-неподвижна, она воспринимает 4,9 кН по горизонтали, и верх смещается на 4,8 мм влево.
::

### Температурная нагрузка {#exercise-temperature-load}

Шарнирно опёртая балка пролётом 8 м, ось которой нагрета на $\Delta T_c = 20$ К, а низ на 10 К холоднее верха ($\Delta T_b - \Delta T_t = -10$ К).

::model-figure{caption="Шарнирно опёртая балка пролётом 8 м, нагретая на 20 К, низ на 10 К холоднее верха"}
---
nodes: { A: [0, 0], B: [8, 0] }
supports: { A: pin, B: roller }
members: [[A, B]]
loads:
  - { member: 1, temperature: { centre: 20, bottom: -10, top: 0 } }
results: []
show: [nodeLabels, dimensions]
---
::

1. Прежде чем смотреть на результаты: какие внутренние усилия вызывает изменение температуры и как перемещается балка?
2. Отметьте `Dx` в узле B, чтобы балка не могла удлиняться.
3. Отметьте также `Ry` на обоих концах.

**Обратите внимание** на деформированную схему и на числа в **Результаты → Узловые результаты**: балка перемещается без всяких внутренних усилий, пока вы её не закрепите.

::callout{type="details" title="Ответы"}
- Статически определимая балка может свободно удлиняться и изгибаться, поэтому внутренних усилий нет. Узел B смещается наружу на $\alpha \Delta T_c L = 12 \cdot 10^{-6} \cdot 20 \cdot 8 = 1{,}92$ мм. Более холодный низ укорачивается, и балка выгибается вверх с кривизной $\kappa = \alpha (\Delta T_b - \Delta T_t)/h = -1{,}2 \cdot 10^{-4}$ 1/м: концы поворачиваются на $\kappa L/2 = 0{,}48$ мрад, а середина пролёта поднимается на $\kappa L^2/8 = 0{,}96$ мм.
- Если оба конца закреплены по x: $N = -EA\alpha\Delta T_c = -50\,400$ кН, сжатие. Такая величина получается из-за условной площади 1 м²; IPE 200 с площадью 28,48 см² воспринял бы 143,5 кН.
- Если оба конца защемлены: постоянный момент $EI\alpha(\Delta T_b - \Delta T_t)/h = 2{,}11$ кН·м по всей длине балки.
::

## Другие задачи {#more-problems}

На странице [Задачи по строительной механике](/ru/practice) по вашему запросу появляется новая балка, рама или ферма с новыми числами, а ваши реакции и наибольший момент или усилие в стержне сразу проверяются. Для учебной группы [конструктор контрольных работ](/ru/exam) печатает каждому студенту свой вариант контрольной работы с ответами, а [@edubeam/plot](/ru/guide/teaching#exercise-sheets-tests-and-slides-from-code) создаёт наборы задач прямо из кода.
